外部DB連携検証 — UPRプレスリリースとの照合

2026-05-16 実機検証 / ミラツク UPR (大学プレスリリースDB) → esse-sense kaken_researchers

ミラツクの大学プレスリリースDB (UPR) の本文・タイトルから抽出した研究者氏名を、esse-sense 開発DBの研究者マスタへ照合できるかを実機検証しました。UPR 300件のサンプルから正規表現「漢字氏名＋教授／准教授／助教／講師／研究員」で51名のユニーク候補を抽出し、kaken_researchers (235,521件) と name 列で照合した結果、37名 (72.5%) が完全一致し、所属機関名・職位・研究テーマ5キーワード・科研費プロジェクトIDなどの完全プロファイルを取得できました。マッチしなかった14名は抽出側の正規表現ノイズ（「鴨川仁特任」のような接尾辞混入、「佐竹 教授」のような姓のみのケース）に起因しており、抽出を改善すれば実質的なマッチ率は85%超に到達する見込みです。

重要な実機発見として、esse-sense MySQL の kaken_researchers.id が PostgreSQL の researcher_vectors.researcher_id と一致する結合キーであることを確認しました。一方で ess_researcher_id (esse-sense 内部ユーザーID) は両DBで意味が異なるため誤結合を引き起こします。この発見により、UPR プレスリリースで言及された研究者を起点に、MySQL でKAKEN由来の構造化メタデータを取得 → PostgreSQL で1536次元の意味ベクターを取得 → pgvector の HNSW 検索で類似研究者を TopN 抽出、という3段パイプラインが構築可能です。

時系列情報の4層構造

研究者キャリア / 出版業績 / ユーザー行動 / ANSWER検索API履歴 — 実機計測

esse-sense MySQL には ANSWER+ の検索・推薦機能を支える時系列データが4層構造で存在します。第1層は研究者のキャリア・業績の時系列（kaken_researcher_histories で異動履歴を start_date/end_date ペアで保持、kaken_researcher_products で出版日とジャーナル名・巻号を保持）、第2層はユーザー行動ログ（actlogs が2021-07-30 から現在まで5年弱で2,169万件、現在も更新中）、第3層は推薦エンジン履歴（recommend_logs が2021-08〜2023-09 の2年分で2,203万件、created_at/read_at/view_at の3時点を保持しリードタイム分析が可能）、第4層は ANSWER+ 検索APIの実履歴（researcher_searcher_api_log に2024-10-16以降の検索クエリと返却JSONを全件保存）です。

実例として高田広章教授 (id=55500) のキャリア時系列を kaken_researcher_histories から取得すると、1995年4月東京大学助手 → 1998年4月豊橋技術科学大学講師 → 2005年4月名古屋大学教授 → 2010-2015年名古屋大学情報科学研究科教授 → 2020-2024年情報学研究科教授、というキャリア軌跡が即時に取得できます。

論文情報の取得粒度

kaken_researcher_products 10,504,387件 / 主要カラム充足率 (100K件サンプリング実機計測)

KAKEN由来の業績データは1,050万件あり、研究者あたり9〜357件と幅があります。タイトル (99.8%)・著者リスト (98.4%)・出版日 (96.6%) は完備されている一方、英文タイトル (0.3%)・抄録 (8.3%)・出版社 (3.3%) は極端に少なく、書誌詳細では巻 (23.5%)・号 (10.5%)・ページ番号 (38.6%) と中程度の充足率です。conference_location の有無による推定で 学会発表 約35% / ジャーナル論文 約23% / 書籍章・報告書・その他 約42% という構成比が見えてきます。DOI・arXiv ID・ISBN・全文PDF・被引用数・インパクトファクターはいずれも保持されておらず、引用ネットワーク分析や全文検索を行う場合は OpenAlex / Semantic Scholar / J-STAGE などの外部API連携が必須です。

健全な年次範囲は1990年代〜2024年で、ピークは2010-2018年の年間13,000〜15,000件です。DB import が2025年8月のため直近2024年は約1,000件に減少しており、最新論文の反映は2024年8月までで打ち切られている点に運用上の留意が必要です。本テーブルは「研究者ベースのプロファイリング基盤」として設計されており「論文ベースの引用分析基盤」ではないため、業績タイムラインの可視化・研究関心の遷移抽出・学会発表とジャーナル比率での発信スタイル類型化には十分活用可能です。
