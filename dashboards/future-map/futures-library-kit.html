データキット

書庫の裏にあるデータを、そのまま使える形にしたものです。 読むだけでなく、数えたり・結合したり・自分の判断に使うためのものです。

★ダウンロード: futures-library-kit.zip （524 KB・CSV／JSON／SQLite・README つき）

3つの形式で同じ内容が入っています

★1つの形式に賭けていません。

形式用途
CSV表計算ソフトでそのまま開く（UTF-8 BOM つきで Excel でも文字化けしない）
JSONプログラムから読む。表ごとに説明と列名が入っている
SQLite結合して問う。README の例がそのまま動く

入っている表

表行説明
methods99未来学の手法。★evidence_tier が最重要の列。逐語の裏づけがある行と、散文だけの行と、自ら合成と申告している行を、これで見分ける。
method_quotes196手法の逐語引用。★訳していない —— 逐語は証拠であり、訳すとこちらの言葉になる。aspect が when_not_to_use のものが多いのは、この分野が「道具が壊れる条件」を厚く書いてきたためである。

★使う前に読んでほしいこと

1　裏づけの強さが違う行が、同じ表に入っています

methods.evidence_tier が最も重要な列です。

層行
散文のみ・逐語なし74
逐語の裏づけあり23
自ら合成であると申告2
★この列を落として集計すると、実在の裏づけがある記述と、この体系が整理しただけの記述と、 自ら「作り物かもしれない」と言っているものが、同じ重みで並びます。
同じことが school_relations.basis（この体系の整理 17／人物の連なりから機械照合 6／文献で確認 3）と bell_claims.stance（★ベルが批判している主張 28／ベルが紹介している他者の主張 71／ベル自身の主張 310）にも当てはまります。

2　訳はこちらの言葉です。原文が正です

*_ja と *_en を対で持たせてあります。 ★*_ja はこちらが訳したもので、原典の記述ではありません。 引用するときは *_en を見てください。

3　逐語引用は訳していません

method_quotes.quote_en と bell_claims.quote_en は英語のままです。 ★逐語は証拠であり、訳すとこちらの言葉になります。

4　同名が2行あるものがあります

methods.duplicate_name = 1 の行です。 name_en で GROUP BY すると、その分だけ二重に数えます。

使い方の例

-- ★逐語の裏づけがある手法だけを見る
SELECT name_ja, quote_count, quote_count_when_not_to_use
  FROM methods WHERE evidence_tier = 'quote' ORDER BY quote_count DESC;

-- ★ベルが「批判している」主張だけ（これを未来学の主張として引かないため）
SELECT claim_type_ja, claim_ja, quote_en
  FROM bell_claims WHERE stance = 'criticized';

-- まだ決着していない論争
SELECT title_ja, current_status_ja
  FROM debates WHERE has_practical_implication = 0;

-- ★学派の影響のうち、文献で確認できているものだけ
SELECT from_ja, relation_type, to_ja
  FROM school_relations WHERE basis = 'documented';

出典と扱い

一次の出どころは未来学知見DB（futures-studies-db）です。 そこに集められた元の出典は、各行の source_url / doi / work_title にあります。 ★このキットは二次的な整理物です。引用するときは各行の出典まで遡ってください。 逐語引用の権利は原典の著作権者に属します。
