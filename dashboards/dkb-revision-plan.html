『深い知の書』修正方針書
CCM v2 統合のための編集計画

本方針書は、4DB統合分析から構築された世紀的連鎖モデル v2（Centennial Cascade Model v2、CCM v2）の発見を、既刊『深い知の書（Deep Knowledge Book）』に統合するための編集計画である。CCM v2 と『深い知の書』の相互検証で得られた7論点（4確認・1修正・3拡張）に基づき、20章のうち14章に対する修正方針を、優先度順に整理する。修正後の書籍は『深い知の書 第二版（with CCM v2）』として、構造的時間理論をより明示的に持つ統合理論書となる。

01編集方針サマリ

修正の核心は 「双子峰プラトー」を否定するのではなく、その上に「100年周期構造」を重ねる ことにある。CTI v2 の保守的評価は維持しつつ、CTI v2 が見ている指標が「100年周期の Phase 3-4 区間における高位プラトー」であるという、より基底的な構造解釈を加える。これにより、書籍は次の3層的読みが可能になる：

  • 表層（CTI v2）：6次元×3成分の文明転換指標による定量評価
  • 中層（CCM v2）：100年周期＋三層連鎖＋4位相による時間構造
  • 深層（思想的基盤）：軸時代・第四変容・知識運動体としての方向感覚

023つの編集原則

原則1：保守的読み替えの原則

CCM v2 を導入することで『深い知の書』の既存の主張を否定する箇所は 1箇所のみ（双子峰の二峰解釈） に留める。残りはすべて「同じ事実を別の言語で記述する」「予測の時間構造を補強する」「新しい歴史的アナロジーを追加する」という形で統合する。これは原書の知的努力への敬意であり、同時に読者に対する誠実さでもある。

原則2：「謙虚さ」の継承

『深い知の書』の核心的な姿勢——「現代特異というナラティブを慎重に扱う」「予測ではなく希望の書」——は、CCM v2 統合後も維持される。CCM v2 の位相予測は機械的時間軸に過ぎず、各位相の「内容」（誰が・何を・どう作るか）を予測しない。CTI v2 と CCM v2 はともに、文明史を測る定規であって、文明の意味を決定するものではない、という姿勢を貫く。

原則3：時間構造の明示化

『深い知の書』は時間軸を「2030・2050・2100」というスナップショットとして扱う。CCM v2 はこれを 「Phase 1（2008-2033 Crisis）→ Phase 2（2033-2058 Reconstruction）→ Phase 3（2058-2083 Innovation）→ Phase 4（2083-2108 Institutionalization）」 という4位相の連続としてリフレームする。スナップショットは保持しつつ、その間の「動き」を構造的に記述することで、本書は予測の精度ではなく予測の解像度を上げる。

09編集リスクと対策

リスク1：原書の主張を毀損するリスク

CCM v2 の導入により、双子峰プラトーの解釈を「単一100年周期の二相」へ修正するため、原書の独自の主張がぼやける可能性。対策：双子峰プラトーは表層的観測として完全に維持し、CCM v2 を中層的構造として加える二重表記を徹底する。

リスク2：書籍が長くなりすぎるリスク

修正で約25,000-30,000字の加筆。本書はすでに大著であり、全体が膨張する。対策：(1) 既存章の冗長部分を逆に圧縮し純加筆を15,000字以内に抑える、(2) 新章は本論ではなく「方法論補論」として位置づけ、本書全体のスケルトンを破壊しない。

リスク3：時間軸予測の精度過剰主張のリスク

CCM v2 が示す「2058-2083年AI制度結晶化」のような予測が断言的に書かれると、本書の「予測ではなく希望の書である」という基本姿勢を毀損する。対策：CCM v2 の予測は常に「100年周期構造から導かれる蓋然性」として記述し、断言を避ける。Turchin、Modelski らの先行研究との比較でその位置づけを示す。

リスク4：読者の混乱リスク

CTI v2 と CCM v2 という二つの指標が並走することで、読者が混乱する可能性。対策：序章と新章で「二つの定規」のメタファーを明確に提示。CTI v2 = 文明の高さ、CCM v2 = 文明の時間構造、として住み分け。各章末に簡潔な「両指標による要約」を配置することも検討。

リスク5：データ更新による修正作業の遡及リスク

SI Framework DB は v9 まで進行中、データ追加が継続している。第二版執筆中にも CCM v2 の検出値が微妙に変動しうる。対策：第二版の数値は「2026年5月時点」と明記し、以降は別途アップデート版で対応。固定スナップショットとして書籍化する。
