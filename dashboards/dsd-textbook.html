序章: デザイン学の概念史 — 本書の位置と方法

本書は、デザインを「美的な装飾の技法」としてではなく、「世界を組み立て直すための知の運動」として捉える試みである。 そのために本書は、デザイン学のあらゆる領域 — 工芸 (William Morris, 1880s) から始まり、Bauhaus、Werkbund、Ulm、Pop、Memphis、Sustainable Design、Critical Design、Decolonising Design、Pluriversal Design に至る — を、450 の中核概念と1,850 の関係として体系化した。

同時に、本書は西洋デザインの正典を相対化する。柳宗悦の民藝運動 (1925)、河井寛次郎・浜田庄司・Bernard Leach、丹下健三・安藤忠雄・妹島和世、原研哉・深澤直人、Ahn Sang-soo のハングルタイポグラフィ、王澍 Wang Shu (Pritzker 2012, 中国人初)、Balkrishna Doshi (Pritzker 2018, インド人初)、Diébédo Francis Kéré (Pritzker 2022, アフリカ人初)、Adinkra・Kente・Navajo・Madhubani・Papunya — これら非西洋の伝統と現代を、デザイン史の正典として等価に位置づける。

本書の構成は13章 (各サブフィールド) + 序章 + 統合章 + 結語 = 16章。各章は対応する概念群の代表例を時代順に紹介する。読者は連載 (kurashi / keiei / jigyo / henka / itonami / futures) や補論執筆の素材としても、また学術検証の出発点としても本書を用いることができる。

方法論: 本書のDB基盤は、/academic-db-build v1.1 経路A の Phase 0-15 で構築されている。Phase 0 (Scoping) で13サブフィールドと150の必須理論チェックリストを設計、Phase 2 で概念収集 (Wave 1-2b, 450 concepts, 非西洋率28.4%)、Phase 3 で品質検証 (source_url 100%, 重複 0, 必須理論 93% カバー)、Phase 4 で関係構築 (1,850 relations, 4.11x ratio, 孤立 0)、Phase 14 で27のミラツク既存DBへの cross-DB refs 199件構築。

残された課題: Production 完備の絶対基準として、Wave 3-4 で5,500+ concepts まで拡張、IRR Cohen''s Kappa ≥ 0.80 の測定、Phase 12 (記述深化、平均 definition 400-600字)、Phase 13 (歴史的関係性 + GTA階層 + 学派正規化)、Phase 15 (launchd 四半期自動更新) を継続実行する。本書はその継続改善ループの「v1.0 Production 段階の到達点」を記録するものである。

第1章 SF1 デザイン史

Arts & Crafts から Bauhaus, Werkbund, Ulm, Memphis, Critical Regionalism までのデザイン史を、西洋・日本民藝・中国・先住民の多元視点で俯瞰する。

サブフィールド概要

デザイン史（Design History）。本DBでの収録数 75件。目標 480件。創設: William Morris (Arts & Crafts 1880s) ／ 転換点: Bauhaus 1919-1933 ／ 現代: Postmodern Memphis 1980s ／ 主要批判: Adrian Forty Objects of Desire (1986)。

代表概念（時代順）

オセアニア先住民建築・デザイン（Oceania Indigenous Design, -2000年）— unknown (collective)。
オーストラリア・アボリジニ (dot painting / desert architecture / dreaming pathways)・ニュージーランド・マオリ (whare / Tā moko tattoo / wood carving)・パプアニューギニア・スピリットハウス (haus tambaran)・ポリネシア タパ布 (kapa) などの伝統造形。1970年代の Land Rights 運動以降、再評価・現代デザインへの翻訳が進む。Papunya Tula ...

イスラム建築の体系（Islamic Architecture (Systematic), 650年）— Mimar Sinan。
7世紀以降、Umayyad朝 Damascus・Abbasid朝 Baghdad・Al-Andalus・オスマン・サファヴィー・ムガル 各文明圏で発達した建築様式。中庭 (sahn)・ミナレット・ドーム・muqarnas (鍾乳石装飾)・アラベスク・カリグラフィー・幾何学パターンが共通言語。Mimar Sinan (1489-1588 オスマン宮廷建築家) が代表、Selimiye Mosque (1574 Edirne) は古典オスマン建築の頂点。

ナイジェリア・ヨルバ族デザイン（Yoruba (Nigeria) Design Tradition, 700年）— unknown (collective)。
西アフリカ・ナイジェリア南西部のヨルバ族による染色 (Adire) ・木彫り・青銅 (Ife/Benin)・建築・装身具・身体装飾 (Ila scarification) を統合した造形伝統。Adire布の藍染め技法は Nike Davies-Okundaye の現代復興でも知られる。Ife heads (12-15世紀ブロンズ) の高度な肖像写実性は世界遺産に登録。

アーツ・アンド・クラフツ運動（Arts and Crafts Movement, 1880年）— William Morris。
Industrial-age mass production への美学的・倫理的批判として、職人の手仕事による生活用品の質の高さと働く喜びを取り戻そうとした19世紀後半の英国発デザイン運動。William Morris を中心に発展し、後の Bauhaus や民藝運動に影響を与えた。

アール・ヌーヴォー（Art Nouveau, 1890年）— Hector Guimard。
1890-1910年に欧州を席巻した装飾芸術運動。植物や昆虫の有機的曲線を建築・家具・グラフィック・宝飾品に応用、地域別に「Jugendstil (独)」「Modernismo (スペイン)」「Stile Liberty (伊)」「Secession (オーストリア)」など多様な名称で展開。Hector Guimard / Victor Horta / Alphonse Mucha / Antoni Gaudí / Charles Rennie Mackintosh ら。

ウィーン分離派（Vienna Secession, 1897年）— Gustav Klimt。
1897年Gustav Klimt / Josef Hoffmann / Otto Wagner / Joseph Maria Olbrich らがウィーン美術家組合から離脱し結成した運動。『Ver Sacrum』機関誌、Secession Hall 建築 (Olbrich 1898) を拠点に、新時代の表現としての装飾的・象徴主義的造形を提案。Wiener Werkstätte (1903 Hoffmann設立) と連動して家具・宝飾を展開。

プエブロ・リバイバル建築（Pueblo Revival Architecture, 1900年）— Mary Colter。
1900-30年代米国南西部 (New Mexico/Arizona) で発展した、先住民 Pueblo の adobe (土塊) 建築を modern にリバイバルした様式。先住民の土着建築様式を米国モダニズムが取り込んだ初期事例。Mary Colter ら先駆者により Grand Canyon の Hopi House (1905)、Santa Fe 駅舎などに展開。

ドイツ工作連盟（Deutscher Werkbund, 1907年）— Hermann Muthesius。
1907年Munichで設立された、芸術家・建築家・産業デザイナー・工業家の協働を目的とする連盟。Hermann Muthesius (規格化推進) と Henry Van de Velde (個人主義擁護) の1914年Cologne論争は、近代デザインの基本的緊張を提示した。

フューチャリズム（Futurism, 1909年）— F.T. Marinetti。
1909年F.T. Marinetti が『Le Figaro』に発表した『Futurist Manifesto』を起点に、Umberto Boccioni / Antonio Sant''Elia / Giacomo Balla らがイタリアで展開した運動。速度・機械・暴力・戦争を賛美、未来の都市・建築 (Sant''Elia『La Città Nuova』1914) ・タイポグラフィ (parole in libertà) を提案。後にファシズムと結びつき短命に終わるが、...

Werkbund Cologne 1914（Werkbund Cologne Exhibition 1914, 1914年）— Hermann Muthesius。
Deutscher Werkbund が1914年Cologne で開催した大博覧会、Hermann Muthesius (Typisierung 規格化推進派) vs Henry van de Velde (個人主義擁護派) の論争で近代デザインの基本緊張を提示。Gropius のModel Factory + Office Building もこのとき発表。

スプレマティズム（Suprematism, 1915年）— Kazimir Malevich。
1915年Kazimir Malevich がペトログラードで提案した、純粋幾何形態 (square/circle/cross) と純粋色の至上性を追求した抽象芸術運動。『Black Square』(1915 0.10 展) で象徴。ロシア構成主義と並ぶ前衛運動として、後の Bauhaus 抽象造形に影響。

ダダ（Dada, 1916年）— Hugo Ball。
1916年Hugo Ball / Tristan Tzara / Marcel Janco らがチューリッヒ Cabaret Voltaire で開始した反芸術運動。第一次世界大戦への嫌悪から、合理性・伝統美学を否定、フォトモンタージュ (John Heartfield)・レディメイド (Marcel Duchamp)・偶然性を採用。Berlin / Paris / New York に派生、後の Surrealism / pop / conceptual art の母胎。

デ・ステイル（De Stijl, 1917年）— Theo van Doesburg。
1917年オランダLeidenで Theo van Doesburg / Piet Mondrian / Gerrit Rietveld らが結成した造形運動。垂直・水平・原色のみの「新造形主義 Neoplasticism」を提唱し、建築・絵画・家具・タイポグラフィを統合した普遍的造形を志向。Bauhaus にも影響。

バウハウス（Bauhaus, 1919年）— Walter Gropius。
1919年Walter Gropiusにより創設された総合芸術学校。Weimar (1919-25) → Dessau (1925-32) → Berlin (1932-33) と移転、ナチスにより閉鎖。「形態は機能に従う」「芸術と工芸の統合」を旗印に、近代デザイン教育の基礎を築いた。Itten/Kandinsky/Klee/Moholy-Nagy/Albers ら多彩な教員陣。

バウハウス予備課程（Vorkurs (Bauhaus Preliminary Course), 1919年）— Johannes Itten。
Bauhausで全学生が最初に受講した予備課程。Johannes Itten (1919-23) → László Moholy-Nagy (1923-28) → Josef Albers が引き継ぎ、材料・色彩・形態の基礎研究を通じて固有の表現を引き出した。後のデザイン基礎教育の世界標準となる。

Bauhaus Manifesto 1919（Bauhaus Manifesto, 1919年）— Walter Gropius。
Walter Gropius が1919年4月Weimar で発行したBauhaus 創設宣言。Lyonel Feininger の cathedral 木版画と『Let us create a new guild of craftsmen, without the class distinctions which raise an arrogant barrier between craftsman and artist!』。

Walter Gropius（Walter Gropius, 1919年）— Walter Gropius。
ドイツ建築家・Bauhaus 創設者 (1919) ・後にHarvard GSD 主任 (1937-52)。Fagus Factory (1911) ・Bauhaus Dessau (1926)・Harvard Graduate Center (1950)。Peter Behrens 事務所出身。

Johannes Itten（Johannes Itten, 1919年）— Johannes Itten。
スイス画家・Bauhaus 初期 (1919-23) で Vorkurs (preliminary course) を確立、color contrast theory を体系化。後にKrefeld + Zürich で独自の design 学校を設立。Mazdaznan 信仰で組織から離脱。

Lyonel Feininger（Lyonel Feininger (Bauhaus), 1919年）— Lyonel Feininger。
ドイツ系米国画家・Bauhaus 最初の教員 (1919-32), graphic workshop master。Bauhaus Manifesto (1919) 表紙 cathedral 木版画作者。後に1937年米国亡命。

アール・デコ（Art Deco, 1920年）— Émile-Jacques Ruhlmann。
1925年Paris『Exposition Internationale des Arts Décoratifs et Industriels Modernes』 (略称Art Deco) を契機に開花した装飾様式。幾何学・流線形・エキゾチック装飾を融合、Chrysler Building (1930) / Eileen Gray の家具・Cassandre のポスター・宝飾品・自動車に展開。米英で1930年代モダニティの象徴となる。

ヴクテマス (VKhUTEMAS)（VKhUTEMAS, 1920年）— Aleksandr Rodchenko。
1920年モスクワに設立されたソビエト・ロシアの国立芸術技術高等学校。Bauhaus と並ぶ前衛デザイン教育機関で、構成主義・スプレマティズムを基盤に Aleksandr Rodchenko / Lyubov Popova / El Lissitzky / Vladimir Tatlin が教鞭。1930年解体されるが、近代デザイン教育に決定的影響。

ロシア構成主義（Russian Constructivism, 1921年）— Aleksandr Rodchenko。
1920年代ソビエト・ロシアで興った前衛芸術運動。Aleksandr Rodchenko / El Lissitzky / Vladimir Tatlin らが、芸術を社会的実用と結びつけ、機械の論理と幾何学的造形によるユートピア的造形を目指した。革命後のグラフィック・建築・舞台美術に決定的影響。

プロダクツィオン芸術（Productivism, 1921年）— Aleksei Gan。
1920-21年Aleksei Gan / Boris Arvatov らがロシア構成主義から分岐し提唱した、芸術を産業生産に直接奉仕させる理論。芸術家を工場で働くエンジニアと再定義、布地 (Stepanova/Popova)・本 (Lissitzky)・建築 (Tatlin) など実用品設計に向かう。

Paul Klee（Paul Klee (Bauhaus), 1921年）— Paul Klee。
スイス画家・Bauhaus 教員 (1921-31)、Pedagogical Sketchbook (1925 Bauhaus Buch) で線・色・形態の理論を体系化、後に Kandinsky と並ぶ modernist abstract の理論的基盤。

Oskar Schlemmer（Oskar Schlemmer (Bauhaus), 1921年）— Oskar Schlemmer。
ドイツ画家・舞台美術家・Bauhaus 教員 (1921-29) でTheater Workshop 主任。Triadic Ballet (1922) で modernist 舞台美学を確立、後にbauhaus 解散後 nazi 圧迫下で死去。

第2章 SF2 デザイン理論

Wicked Problems, Reflective Practitioner, Four Orders of Design, Semantic Turn, Pluriversal Design など、デザインの認識論・哲学的基盤を理論史で追う。

サブフィールド概要

デザイン理論（Design Theory）。本DBでの収録数 29件。目標 450件。創設: Horst Rittel Wicked Problems (1973) ／ 転換点: Donald Schön Reflective Practitioner (1983) ／ 現代: Richard Buchanan Four Orders (1992) ／ 主要批判: Klaus Krippendorff Semantic Turn (2006)。

代表概念（時代順）

Wabi-Sabi (侘び寂び)（Wabi-Sabi, 1500年）— 千利休。
日本伝統美学の概念。茶人・千利休 (1522-91) が体系化した『侘び (簡素・不完全な深さ)』『寂び (時間経過の美)』を含み、現代デザインでは Leonard Koren『Wabi-Sabi for Artists, Designers, Poets & Philosophers』(1994) が国際的に伝えた。建築・陶芸・グラフィック・西洋ミニマリズムへの逆影響も。Naoto Fukasawa / 原研哉のデザイン哲学にも組み込まれる。

Mottainai (もったいない)（Mottainai (Japanese Concept of Waste), 1700年）— unknown。
日本伝統的価値観で、価値あるものを無駄にすることへの後悔・畏敬を表す概念。仏教の縁起・神道の万物霊性に由来。Wangari Maathai (Kenya, 2004 Nobel Peace) が日本訪問後に環境運動の標語として世界に伝え、現代サステイナブル・デザインの理論的根拠の1つに。

Form Follows Function（Form Follows Function, 1896年）— Louis Sullivan。
Louis Sullivan 1896 essay『The Tall Office Building Artistically Considered』に出る、近代建築・デザインの中心原理。生物進化の比喩から、形態は機能から導かれるべきと主張。後に Bauhaus / 国際様式の旗印に。

Aesthetic of Useful Things (用の美)（Aesthetic of Useful Things, 1925年）— 柳宗悦。
柳宗悦 民藝運動の中核概念。『用の美』とは日常使用される器物 (lower craft 下手物) に宿る健康な美。Yanagi『The Unknown Craftsman』(Kodansha International 1972, Bernard Leach 編訳)で英語世界に紹介され、Bernard Leach 経由で Britain Studio Pottery 運動に影響。

Iki (いき)（Iki (Japanese Aesthetic), 1930年）— 九鬼周造。
九鬼周造 1930『「いき」の構造』で展開された日本江戸期発祥の美意識。媚態・意気地・諦め の三契機から成る、洗練と粋さの統合。Heidegger との対話 (1927-29) で形式化、現代日本ファッション・服飾デザインの理論的基盤として知られる。

Pragmatist Design（Pragmatist Design Theory, 1934年）— Wolfgang Jonas。
John Dewey 『Art as Experience』(1934) を基盤に Wolfgang Jonas / Erik Stolterman / Erik Bohemia らがデザイン理論に翻訳。デザインを inquiry (Dewey) と捉え、experiential / situational / experimental な認識論を提案。

Less is More（Less is More, 1947年）— Ludwig Mies van der Rohe。
Mies van der Rohe に帰される modernist minimalism のテーゼ。元はRobert Browning 詩『Andrea del Sarto』(1855) 由来とも。Mies の Barcelona Pavilion (1929)・Farnsworth House (1951) などの建築実践と並ぶ。Robert Venturi が1966年『Less is bore』で批判。

Christopher Alexander Notes on the Synthesis of Form（Christopher Alexander Notes on the Synthesis of Form, 1964年）— Christopher Alexander。
Christopher Alexander 1964『Notes on the Synthesis of Form』(Harvard) でPhD 研究を発表、design problem を mathematical (set theory + hierarchical tree) で扱う初期試行。後のPattern Language (1977) への前段。

Susan Sontag Notes on Camp（Susan Sontag Notes on Camp, 1964年）— Susan Sontag。
Susan Sontag 1964『Notes on Camp』(Partisan Review Fall 1964) で展開、camp sensibility を art criticism の対象とする essay、後にpostmodern design / fashion 理論への影響。

Nelson Goodman Languages of Art（Nelson Goodman Languages of Art, 1968年）— Nelson Goodman。
Nelson Goodman 1968『Languages of Art』(Bobbs-Merrill) で展開、art / design を semiotic システムとして分析する分析哲学。後の design semiotics に影響。

Wicked Problems（Wicked Problems, 1973年）— Horst Rittel。
Horst Rittel + Melvin Webberが1973年に提示した社会計画問題の類型。決定的定式化不可・解の停止規則なし・解は正誤でなく良悪・直接検証不能・本質的に唯一性などの10属性。デザイン思考の出発点。

Foucault Discipline + Punish (design)（Foucault Discipline + Punish (design implications), 1975年）— Michel Foucault。
Michel Foucault 1975『Surveiller et punir』(Gallimard) で Bentham Panopticon を分析、architectural design + power の relation を理論化、後にcritical design / surveillance studies の理論基盤。

Ma (間)（Ma (Japanese Spatial Concept), 1976年）— 磯崎新。
日本伝統美学・建築・音楽の中心概念。空間と時間の『間 (あいだ)』の積極的価値を指す。磯崎新 1976 Paris 展覧会『MA: Espace-Temps du Japon』で西洋に紹介、Christian Schittich の編著で建築理論に。能・茶道・武道・グラフィック (杉浦康平のレイアウト原理) などに展開。

Pattern Language（Pattern Language, 1977年）— Christopher Alexander。
Christopher Alexander + Sara Ishikawa + Murray Silverstein 1977『A Pattern Language: Towns, Buildings, Construction』で提示された253のspatial patterns。各patternは『name + 問題 + 解 + 関連pattern』の形式。後に Erich Gamma ら software design patterns (GoF 1994) ・Ward...

Designerly Ways of Knowing（Designerly Ways of Knowing, 1982年）— Nigel Cross。
Nigel Cross 1982 essay (Design Studies 3(4)) で提示、後に2007 同名書籍で体系化。Bruner の3つの認識様式 (sciences/humanities/design) からデザイン固有の認識様式を擁護。abductive reasoning / solution-led approach を特徴とする。

Reflective Practitioner（Reflective Practitioner, 1983年）— Donald Schön。
Donald Schön 1983 book『The Reflective Practitioner』で提示された、専門家がaction-in-presentに reflect-in-action でメタ認知的に学ぶ理論。Technical Rationality 批判として、デザイン・教育・看護・心理療法に広く適用。

Klaus Krippendorff Product Semantics（Klaus Krippendorff + Reinhart Butter Product Semantics, 1984年）— Klaus Krippendorff。

伝達系譜の例

Bauhaus → Mingei: 直接的接触はないが、両者ともArts & Crafts (Morris) を共通祖とし、Bauhaus は産業的に・Mingei は手工芸的に同じ問いに応答した。Bernard Leach + 浜田庄司の St. Ives Pottery (1920) はその両者の交点として機能した。

Bauhaus → Black Mountain College → Stanford d.school: Walter Gropius (Harvard 1937)・Josef Albers (Black Mountain 1933) ・Anni Albers (Yale) という移植経路を経て、David Kelley の Stanford d.school (2005) に系譜が継続している。

Papanek Design for the Real World → Ezio Manzini DESIS → Arturo Escobar Pluriverse: 1971-2018 の50年間で、デザインの社会責任論はsustainable, social, ontological 各方向へ展開している。

第15章 結語 — デザインの概念史の未来

Pluriverse, Transition Design, Design Justice が示す21世紀デザインの方向。DSD-DB が連載・補論・教科書に提供する基盤としての可能性。

本書が示すデザイン概念史を貫く軸は、3つに集約される。第一に、機能 vs 装飾 の振動 (Bauhaus → Memphis → Critical Design)。第二に、西洋中心 vs 多元中心 の重心移動 (国際様式 → 批判的地域主義 → Pluriversal Design)。第三に、デザイナーが扱う対象の階層拡張 (Buchanan の四階層: symbol → object → action → system)。

21世紀のデザインは、これら3軸の交点で動いている。Transition Design (Terry Irwin, 2015 CMU) は機能と装飾の二項対立を脱し sustainability transition という社会変容を設計対象とする。Pluriversal Design (Arturo Escobar, 2018 Colombia) は西洋中心を脱しオントロジー的多元世界の共存を設計する。Design Justice (Sasha Costanza-Chock, 2020 MIT) はsymbol/object/action/system の階層を超え、社会正義そのものを設計対象とする。

本DBの今後: Wave 3 で各サブフィールドを 200-400 concepts まで拡張、Phase 12 で記述深化 (定義 400-600字)、Phase 13.5 で IRR ≥ 0.80 測定、Phase 15 で四半期自動更新 (launchd cron) を実装する。本書はその継続改善ループの一里塚であり、終点ではない。

本DBは、ミラツクの連載 (kurashi / keiei / jigyo / henka / itonami / futures) ・補論 (manufacturing-orchestra / mobility-2030-2100 など FVCP 系) ・教科書執筆 (genshi-cycle / mg-textbook 等) の基盤として、概念と方法論を学術的に裏打ちする役割を担う。同時に edd (editorial-design-db, 紙面実例) ・dsdb (Design Site Database, Webデザインサイト 850件) と並んで、デザイン分野の「概念史 + 実例カタログ + 現代インスピレーション」の三本柱を構成する。
