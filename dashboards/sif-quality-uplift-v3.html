品質向上プロジェクト報告

本報告は、SI Framework DB（5,781事象）に対して、Opusをオーケストレーターとし30チーム並列のCodex実行で実施した品質向上ラウンドの成果を整理するものである。Drayton 4段階分類の精緻化、ナラティブの充実化、品質ティアの引き上げを軸として、構造的変革DBの分析的有用性をひとつ上の段階へ引き上げることを試みた。

01プロジェクト要旨

SI歴史的構造変革DBはこれまでに5,781事象を蓄積してきたが、その分析的厚みには明確な偏りが残っていた。とりわけBill Drayton（Ashoka創始者）が提示する社会変革の4段階モデルのうち、direct_service と scaled_direct_service の二段階は実装されておらず、pattern_change と framework_change のみが二極的に使われていた。同時に、各事象の物語的背景や因果ナラティブは多くがNULLのまま放置されており、データベースを読み物として活用するうえでの障害となっていた。

このラウンドでは、これらの課題を一気に解消するため、Opusを中央オーケストレーターとし、Codex 30チームを並列で起動する大規模な質的補強を実施した。チームは(A) Drayton分類10、(B) ナラティブ充実15、(C) 品質ティア向上5の構成で編成され、各チームが担当範囲のSQL UPDATE文を生成、Opusがこれを統合・検証・適用した。

0230チーム並列の方法論

本ラウンドの方法論的特徴は、Opusと Codex の役割分担にある。Opus（claude-opus-4-7）は計画・統合・検証・最終適用を担い、Codexは個々の専門領域で並列に深掘り作業を行う。両者は独立したAPI基盤の上で動作するため、Anthropic API側のレート制限とは無関係にCodex側の30並列処理が走り、合計で約数分のうちに膨大な量の判断と文章生成が並行で進む。

各チームには、対象データのTSVと厳密に書式化されたプロンプトが渡され、出力は専用のSQLファイルへ書き出される。SQLは一旦すべて回収され、構文検証ののちにトランザクション付きで適用される。これによって途中失敗時のロールバックが保証され、量と速度の両方で従来の手法を大きく上回る品質補強が可能になった。

チーム編成（30チーム）

  • Block A — Drayton分類精緻化：10チーム（文明圏×時代別＋既存分類の再検証）
  • Block B — ナラティブ充実化：15チーム（5フィールド: narrative_background / social_problem / si_process / subsequent_developments / causal_narrative）
  • Block C — 品質ティア向上：5チーム（refs補強・key_actors詳細化・PRRRC再評価・event_relations拡充・TSI レイヤー付与）

03Drayton 4段階分類の精緻化

Drayton分類は、社会変革の影響度を direct_service（個別支援）→ scaled_direct_service（規模拡大）→ pattern_change（行動様式変容）→ framework_change（制度変革）の4段階で測る重要なフレームである。本ラウンド以前は実質2段階運用に留まっていたが、Block A の10チームが2,465件の未分類事象と既存分類済み200件の再評価を実施した結果、4段階すべてに事象が配されるようになった。

分類分布は以下のとおりである。framework_change が依然として多数を占めるのは、本DBが構造変革を主題に収集してきた経緯からして自然である。一方で、direct_service と scaled_direct_service が一定数存在することで、規模感や影響範囲の異なる事象を同じ尺度で比較できるようになった。

04ナラティブ充実化の成果

Block B の15チームは、文明圏別に60件ずつの主要事象を担当し、5つのナラティブフィールドを生成した。各事象には数百字単位の背景・問題定義・プロセス・後続展開・因果ストーリーが記述され、データベースを単なる属性の集合ではなく、社会変革の物語の集積として読めるようになった。今ラウンドで narrative_source='codex_team_v3' としてタグ付けされた事象は 651件 である。

narrative_background が記述された事象は全 2,661件（46.0%）、causal_narrative は全 2,045件（35.4%）にまで拡充した。テンプレート構造に基づく一定の冗長性は残るものの、各事象固有の人物・年代・地理的固有名詞は具体的に書き込まれており、後続の手動精緻化ラウンドの土台として十分に機能する。

05品質ティアの向上

07限界と今後

本ラウンドの主な限界は、ナラティブ生成が部分的にテンプレート構造に依拠している点である。Block B の出力には、文明圏や時代背景に関する一般化された記述が共有形式として現れ、各事象固有の歴史的細部の深さは事象ごとに差がある。これは並列AI生成の構造的トレードオフであり、今後はAティア事象を中心に、ヒト+AIの協働で精緻化する第4ラウンドが必要である。

第二の限界は、Drayton分類の判定基準が scale・institutionalization・impact_scope 等の既存属性からの推論に依拠している点であり、historian合議による厳密な分類とは性質が異なる。第3の限界は、event_relations の拡充が高スコア事象に偏ったことである。

今後の発展として、(1) Aティア事象200件への手動深耕、(2) PRRRCスコアの外部基準照合（Acemoglu-Robinsonの制度経済学的指標との整合性検証）、(3) 教科書「ソーシャルイノベーションの構造」との相互参照リンク化が予定されている。
