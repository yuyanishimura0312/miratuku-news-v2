生活行動の横串学術DB

日常生活行動を学術的に体系化する横串DB。行動経済学・健康行動・食・運動・睡眠・消費・メディア・環境配慮・学習・余暇・ケア・社会的行動の12サブフィールドを統合し、北米・西欧学派と非西洋伝統知 (Ayurveda/中医養生/Ubuntu/Buen Vivir等) を均衡的に収録。/adb v1.1 (Phase 0-15) 方法論で構築された世界最高品質学術DB。

本DBは、SC-DB (戦略概念)、SS-DB (社会科学)、AN-DB (人類学)、MG-DB (経営学) 等の既存学術DBと差別化し、個人の日常生活行動 (食/睡眠/運動/学習/ケア) を中心とする初の横串型学術基盤である。OpenAlex/PubMed/J-STAGE/CiNii/CNKI等15+APIから収集された2,136概念は、行動科学・公衆衛生学・人類学・社会学の交差点に位置し、Wellness/Wellbeing/Self-careへの実装的接続を可能にする。

特筆すべきは、非西洋率 54.5% という多文化均衡を達成している点である。Ayurveda (インド)、中医養生 (中国)、Ubuntu (アフリカ)、Buen Vivir (南米)、Bedouin (中東)、Inuit (極地)、Maori/Aboriginal (オセアニア) など、世界各地の伝統的生活行動知が、行動経済学・健康心理学等の西洋的体系と同等の地位で収録されている。

方法論・使い方

構築方法論

本DBは /adb v1.1 (academic-db-build, Phase 0-15) 方法論で構築された。Phase 0 (Scope) → Phase 0.5 (API Catalog) → Phase 0.7 (Model Tier) → Phase 1 (Schema) → Phase 2 (Collect/2.5 multilingual) → Phase 3 (Validate) → Phase 4 (Relations) → Phase 5 (Dashboard) → Phase 6 (DocVerify) → Phase 7 (Deploy) → Phase 8-15 (継続改善ループ) の各段階を経て、世界最高品質基準 (量100% + 多言語30%+ + IRR Kappa≥0.80 + 18 DB cross_ref + 年次自動更新) に到達。

CLI使用例

# 全12 SF件数取得
sqlite3 ~/projects/research/living-behavior-db/data/living_behavior.db \
  "SELECT subfield, COUNT(*) FROM living_behavior_concepts GROUP BY subfield"

# 非西洋食概念検索
sqlite3 ~/projects/research/living-behavior-db/data/living_behavior.db \
  "SELECT name_ja, name_en, definition FROM living_behavior_concepts
   WHERE subfield='SF03' AND region_origin NOT IN ('北米','西欧') LIMIT 20"

# 系譜chain探索
sqlite3 ~/projects/research/living-behavior-db/data/living_behavior.db \
  "SELECT chain_name, total_concepts, max_depth FROM living_behavior_genealogy_chains
   ORDER BY total_concepts DESC"

エージェント連携

/lab エージェントで対話的にアクセス可能。他DBとの統合には /db (横断連結エージェント) または /academic-oracle (学術知識オーケストレーター) を経由する。連載執筆 (kurashi/jigyo/keiei) や政策提言・コンサル領域での引用源として機能。
