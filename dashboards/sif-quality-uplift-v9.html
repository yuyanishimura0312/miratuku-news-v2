SI歴史的構造変革DB v9
ソトコト5メタ型タクソノミー統合

v9ラウンドは、西村勇也の『ソトコト』連載「未来をつくるソーシャルイノベーション」全60回（2015年3月号〜2020年6月号）から抽出された5メタ型・15サブ型のSIタクソノミーを、SI Framework DB の 7,389 事象に統合した。これによりDBは、文明圏（10）・時代（5）・類型（6+）・Drayton 4段階・教科書20章に加えて、第6の分類軸としてソトコト型タクソノミーを獲得し、5,000年の社会変革史を「型の系譜」として読む基盤が成立した。

01プロジェクト要旨

本DBは v3〜v8 までで量的・構造的・整合性の3次元すべてで完備した学術データセットに到達した。v9は、これに第二の理論的装填を加える試みである。具体的には、独立した一次資料（『ソトコト』連載60回）から構築されたソトコト型タクソノミー（5メタ型×15サブ型）を、DB の 7,389 事象に対して機械的に分類し、新たに `sotokoto_meta_type` および `sotokoto_subtype` の2カラムを追加した。これにより、本DBは2つの独立した分類体系（Drayton モデルとソトコト型）を併走させ、社会変革を異なる視座から読む基盤を獲得する。

025メタ型の理論

ソトコト連載は、現代日本のソーシャルイノベーション事例（NOSIGNER、慶應SDM、芝の家、PIECES等41事例）と暮らしのモノ・コト（カフェ、百貨店、切手、トイレ、公園、石、星座、夢等19事例）の計60ケースから、社会変革の「型」を抽出した。5メタ型は、変革が生起する場面を〈場（場の発生）〉〈媒介者（媒介の創出）〉〈物語（物語と文脈の再結合）〉〈構造（インフラと規格の編集）〉〈拡散（複製と大衆化）〉の5つの局面に整理する。

これら5メタ型は、3つの底流——「『つくる』のではなく『生まれる』」（第18回 芝の家）、「文脈と新結合」（第57回 石）、「見えない領域への投資」（第2部全体）——によって貫かれている。本DBへの統合は、5,000年の社会変革史がこれら5型の繰り返しと組み合わせとして読めるかを実証する仮説検証である。

03統合手法

各事象の type / mechanism / scale / actors / name_jp / description のテキスト特徴に対して、5メタ型ごとのキーワード辞書でスコアリングし、最高スコアのメタ型を割り当てた。たとえば「community」「カフェ」「広場」「結社」等のキーワードは Meta 1（場の発生）に、「learning」「academic」「学派」「NPO」等は Meta 2（媒介の創出）に、「narrative」「物語」「権利章典」「和解」等は Meta 3（物語と文脈の再結合）に、「infrastructure」「規格」「法典」「上下水道」等は Meta 4（インフラと規格の編集）に、「印刷」「mass」「broadcast」「diffusion」等は Meta 5（複製と大衆化）にスコア加点する。

サブ型は、メタ型決定後の二次キーワードマッチで割り当てる。スコア同点や該当キーワードがない場合は、type に基づくデフォルトマッピング（civil_rights→Meta 3、public_goods→Meta 4 等）を採用する。これにより全 7,389 事象が機械的に分類された。本ラウンドは規則ベースの基準分類であり、サブ型の精緻化や境界事例の判定は v10 以降の人手レビューで対応する。

07解釈の方向

v9で得られた分類は、以下のような問いに対する基盤的回答を可能にする。第一に、5,000年の社会変革史は、5メタ型のいずれかに偏るのか、それとも文明圏や時代によって支配型がシフトするのか。第二に、特定のメタ型の事象群は、Drayton モデルの4段階や教科書20章とどう共起するのか。第三に、ソトコト連載の60ケース（現代日本中心）から抽出された型が、古代・中世・非日本圏の事象にも妥当に適用できるのか——適用できる範囲こそが、5メタ型の普遍性の経験的証明である。

本ラウンドの初期結果は、5メタ型が文明圏・時代を越えて適用可能であることを示唆する。Meta 4（インフラと規格）が全文明圏で最多または上位を占めることは、人類社会の歴史的な制度的均衡への強い指向を示している。Meta 3（物語と文脈の再結合）が civil_rights 系事象に集中することは、社会変革の正当化が常に物語的構築を伴うという現代社会理論の知見と整合する。Meta 1（場の発生）の比較的低いシェアは、機械的分類が「場」の発生という現象を捉えにくいこと（多くの場の発生事象は他の型と複合的に記述される）を示し、これは v10 で人手レビューによって補正される。

08今後の展開

v9の限界として、第一に、サブ型分類が .1 系に偏る点がある。これはキーワード辞書の制約であり、各メタ型ごとに100事象のサンプリング・レビューで人手補正することが必要である。第二に、メタ型の境界事例（Meta 1と Meta 3 の中間に位置する事象、Meta 4 と Meta 5 の中間に位置する事象等）の判定は機械的ロジックでは限界があり、複数メタ型のマルチラベル化が望ましい。第三に、ソトコト連載の60ケースとDB の 7,389 事象との直接マッピング（ソトコト連載の各ケースがDB のどの事象に対応するか）は本ラウンドでは未実施である。

v10 以降では、(1) サブ型のサンプリング・レビューと補正、(2) マルチラベル化（1事象に複数メタ型を許容）、(3) ソトコト60ケース ↔ DB 7,389事象の直接対応マッピング、(4) 5メタ型 × Drayton 4段階のクロス集計分析、(5) 後継連載「ソーシャルイノベーションの教養」全50回への執筆素材としての活用、を進める。本ラウンドは、SI Framework DB が単一の量的データセットから、複数の理論的タクソノミーを並走させる「多層的SIメタ知識基盤」へと変貌する第一歩である。
