06 関係ネットワーク

Phase 4 関係構築で 5393 件の概念-概念関係（intra-subfield chain + opposing-concept critique）と 3555 件の cross-subfield 関係（keyword overlap）を生成。関係タイプは extends / derived_from / critiques / empirically_tests / synthesizes / competes_with / applies_to_policy / complements / related_to / influenced / precursor_of / formalizes / generalizes / specializes / refutes の15種類。Wave 2 では Phase 13 ak-relation-normalizer + ak-school-mapper を投入し、関係の方向性・強度・確信度を3軸再評価する。

07 必須理論カバレッジ

Phase 1 で設計した 140件の必須理論チェックリストに対し、Wave 1 では 132/140 (94.3%) を充足。残りの未充足項目は Phase 11 反復ループ（usage limit reset後）で順次収録する。チェックリストは各サブフィールドに「創設者・転換点・現代・批判」の4枠を最低3名ずつ確保し、特に 女性研究者・非西洋研究者 を意識的に組み込んでいる。

09 方法論・出典

本DBは /academic-db-build v1.1 エイリアス /adb 経済学 --full-quality で構築開始。Phase 0-15 のうち Wave 1 として Phase 0-5 を完走し、本ダッシュボードは Phase 5 成果物の一部である。データソースは RePEc IDEAS（経済学 4M+ items 主軸）、OpenAlex（網羅性 247M works）、NBER Working Papers、SSRN Economics、JSTOR Constellate、CiNii Research / J-STAGE（日本経済学）、CNKI Fast View（中国経済学）、HAL-SHS（仏 Régulation学派）、SciELO（中南米構造主義）、OpenCitations（引用ネットワーク）等 16 起点 API を経路として活用。全レコードに primary_source_url + verification_status を付与し、Phase 13.5 で IRR Cohen's Kappa ≥ 0.80 を目標とする。

本DB v1.0 Wave 1 は通過点であり、最終形ではない。Phase 8-15 の継続改善ループ（4並列監査・スナップショット・拡張計画・codex 40+並列拡張・100%反復・記述深化・関係正規化・IRR・18 DB cross_ref・Negative space 探索・年次自動更新）を完遂してはじめて「完成」とする。
