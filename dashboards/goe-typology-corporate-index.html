GOE-DB Typology × Corporate Assessment

三類型による組織卓越性の審査指標

GOE-DB(良い組織・良い企業卓越性 学術知DB)が Phase 7 で導いた8類型のうち、倫理型(Type 5)・在来型(Type 7)・学習型(Type 3)の3つを軸に据え、「良い組織のパターンを出す→実例から当てはまるパターンを選ぶ→要素を抽出する」という発想を、企業を審査するための実行可能な指標へと組み上げる。既存の企業審査指標に接地させ、AR-DB を通じて学術理論との関係を可視化したうえで、実行力あるルーブリックまで到達させる4部構成のレポートである。

SECTION 00

本レポートの狙いと方法

「良い組織とは何か」という問いに単一の正解を与えることは、NPO法人ミラツクの中立性原則が禁じるところである。そこで本レポートは、GOE-DB が15サブフィールド1,784概念を多次元クラスタリングして得た8類型のなかから、性格の異なる3つの類型を選び、それらを「対立させる」のではなく「並置する軸」として扱う。倫理型は目的と多様な利害関係者への責任を、在来型は非西洋に根ざした受託と現場の主体性を、学習型は知識創造と心理的安全性を、それぞれ組織卓越性の別々の顔として提示する。

方法は3段階である。第一に、各類型の構成要素(GOE-DB の representative_concepts)をそのまま台帳化し、類型ごとの思想を概要文で言語化する。第二に、それを企業審査の3軸へ翻訳し、B Corp や ESG 格付、DLOQ、健康経営銘柄といった実在の指標に接地させる。第三に、AR-DB(Agent Registry DB)を経由して各軸が依拠する学術理論DBとの関係を可視化し、その接地の強弱から指標を精緻化する。最後に、証憑を要求し批判に応答する「実行力ある」採点ルーブリックへと落とし込む。

中立性の担保

3軸は優劣ではなく相補として提示する。測定しやすさ(measurement)と批判への強さ(critique resistance)は類型ごとに異なり、そのトレードオフを隠さず数値で示す。指標は「1つの理想企業像」ではなく「どの卓越性をどれだけ備えるかのプロファイル」を返す。

PART 01

第1部 三類型の構成要素と概要

GOE-DB の typology_clusters テーブルは、各類型に対して主サブフィールド構成・文明圏分布・測定可能性スコア・批判耐性スコア・代表構成要素・批判を保持する。ここでは Type 5・7・3 の構成要素を余さず掲げ、それぞれを600〜900字の概要で解題する。数値はすべて DB の実測値である。

構成要素(representative concepts)

Stakeholder Theory (Freeman 1984) Donaldson-Preston 3側面 Mitchell-Agle-Wood Salience Conscious Capitalism 4 Tenets B Corp / B Lab Creating Shared Value (Porter-Kramer) Triple Bottom Line Mazzucato Mission Economy Entrepreneurial State Business Roundtable 2019 WEF Davos Manifesto 2020 Patagonia Purpose Trust (2022) ESG Investment Boom

倫理型は、企業の存在理由を株主利益の最大化から「多様な利害関係者への責任」へと引き上げるパラダイムである。理論的な起点は Freeman のステークホルダー理論(1984)にあり、Donaldson-Preston が記述的・道具的・規範的の3側面を、Mitchell-Agle-Wood が「権力・正統性・緊急性」による利害関係者の顕出度(salience)を与えて、抽象を分析可能な枠組みへと精緻化した。実務側では Mackey のコンシャス・キャピタリズム4原則、Elkington のトリプルボトムライン、Porter-Kramer の共有価値創造(CSV)が「利益と社会善は両立しうる」という命題を広め、B Lab の B Corp 認証がそれを第三者評価に載せた。

制度としての決定打は、2019年の米ビジネス・ラウンドテーブルによる「企業の目的」再定義と、2020年ダボスのステークホルダー資本主義宣言、そしてパタゴニアが2022年に所有権を目的信託へ移した事例である。Mazzucato のミッション・エコノミーは、この倫理型を国家と企業の共創にまで拡張した。測定可能性が0.72と高いのは、ESG格付・B Corp スコア・GRI/SASB といった開示枠組みが整備されているからだ。一方で批判耐性は0.65にとどまる。Friedman ドクトリンの再評価、Bebchuk-Tallarita による「約束は幻想」との実証、グリーンウォッシング、2022年以降のESGバックラッシュが、宣言と実態の乖離を突くからである。この類型を審査に使うときは、宣言の有無ではなく、統治構造・報酬連動・撤退不能性(定款化・信託化)といった「後戻りできない仕組み」の有無を見なければならない。

構成要素(representative concepts)

三方よし(Sanpo-yoshi) 石田梅岩 心学 渋沢栄一 道徳経済合一 京セラフィロソフィ / アメーバ経営(稲盛) TPS / JIT / 自働化 / トヨタウェイ 松下 PHP・本田 三つの喜び Haier 人単合一 1.0-3.0 Huawei 狼性 / 灰度哲学 Alibaba 六脈神剣 儒教 五常 / 道家 無為 Tata Trusteeship Infosys Compassionate Capitalism Jugaad / Kautilya Arthashastra Samsung Way Semco 7-Day Weekend Ubuntu 9原則 / Indaba Tawhid / Maqasid / Mudarabah

在来型は、西洋経営学の枠外で育った経営思想の総体である。文明圏分布が非西洋0.9と、8類型のなかで最も西洋から遠い。日本では近江商人の三方よし(売り手よし・買い手よし・世間よし)、石田梅岩の心学、渋沢栄一の道徳経済合一論が、利益追求と倫理を「対立させない」土台をつくり、稲盛のアメーバ経営や大野耐一のトヨタ生産方式が、現場の一人ひとりを採算と改善の主体に据える具体的な仕組みへと結晶させた。中国では海爾(Haier)の人単合一が従業員と顧客を直結する微小企業群へ組織を解体し、華為(Huawei)の狼性と灰度哲学が競争と均衡を同居させる。インドの Tata は信託による受託者統治(Trusteeship)を、アフリカの Ubuntu は「私はあなたがいるから在る」という関係存在論を経営に持ち込む。

この類型の測定可能性は0.40と低い。三方よしの「世間」や Ubuntu の関係性、灰度哲学のあいまいさは、標準化された尺度に乗りにくいからである。ところが批判耐性は0.80と最も高い。これらの思想は数世紀にわたる実践の淘汰を経ており、短期の流行批判で崩れにくい。ここに在来型を審査軸に据える意義がある。西洋起源の指標は在来型の価値をほとんど測れず、結果として日本企業やアジア企業の固有の強みが評価から抜け落ちてきた。批判としては、Tsui(2007)が指摘する文化的妥当性の検証不足、西洋理論の翻訳問題、そして「日本的経営」を礼賛して長時間労働を正当化する文化決定論の危険がある。したがって審査では、在来型の理念を掲げるだけでなく、それが従業員福祉や長期存続という検証可能な結果に結びついているかを、代理指標を通して問う必要がある。

Learning Organization Senge 5 Disciplines 自己マスタリー / メンタルモデル チーム学習 / システム思考 Argyris Single / Double-Loop Defensive Routines SECI(知識創造) 野中 「場(Ba)」 Garvin 5 Building Blocks Crossan 4I Framework DLOQ Communities of Practice (Lave-Wenger)

学習型は、組織を「知識を生み・更新しつづける主体」として捉えるパラダイムである。Senge の『第五の規律』が自己マスタリー・メンタルモデル・共有ビジョン・チーム学習・システム思考の5つの規律を示し、Argyris はエラーの前提そのものを問い直すダブルループ学習と、それを妨げる防衛的ルーティンを概念化した。日本発の野中の SECI モデルは、暗黙知と形式知が共同化・表出化・連結化・内面化の螺旋を描くと説き、その螺旋が生まれる関係的な「場(Ba)」を組織学習の要件に据えた。Garvin の5つの構成要素、Crossan の4Iフレームワーク、Watkins-Marsick の DLOQ が、それを診断可能な次元へと翻訳している。

この類型の骨格には心理的安全性が組み込まれている。Edmondson が示したとおり、対人リスクを取っても罰されないという確信がなければ、失敗の共有も率直な問い直しも起こらず、学習は形骸化する。ゆえに主SF構成でも SF05(心理的安全性)が0.20の重みを占める。測定可能性0.65は DLOQ や Garvin の学習組織サーベイ、Edmondson の心理的安全性尺度(PSI)といった検証された尺度に支えられ、批判耐性0.70は知識経済という文脈的追い風による。批判は Alvesson-Spicer の「機能的愚かさ」――学習を掲げながら思考を停止する組織――と、学習理念の形骸化、そして Polanyi が指摘する暗黙知の形式知化の限界である。審査では、研修時間や制度の有無ではなく、失敗が語られ・前提が更新され・知が現場から創発しているかという「学習が実際に起きている証拠」を問わねばならない。

3類型の並置(要素抽出の起点)。 測定しやすい倫理型(0.72)、測定しにくいが批判に強い在来型(0.40 / 0.80)、その中間でバランスのよい学習型(0.65 / 0.70)。この非対称こそが、次章で「既存指標が測れている軸/測れていない軸」を切り分ける手がかりになる。

PART 02

第2部 三類型を軸とした企業審査指標

第1部の3類型を、企業を審査する3つの軸へ翻訳する。E軸(倫理・ステークホルダー)、I軸(在来・受託)、L軸(学習・知識創造)である。各軸は複数の下位次元を持ち、それぞれを GOE-DB の measurement_instruments(75件)に登録された実在の審査指標に接地させる。単なる新規発明ではなく、既存指標の「どれが何を測っているか」を地図化したうえで、測り漏れている部分を補う設計をとる。

E軸 ── 倫理・ステークホルダー(Type 5 由来)

E軸は、企業が誰に対して責任を負い、その責任を後戻りできない仕組みとして制度化しているかを審査する。既存の審査指標がもっとも充実している領域であり、B Lab の B Corp インパクト評価(統治・従業員・地域社会・環境・顧客の5領域)、MSCI・Sustainalytics・FTSE・DJSI の ESG 格付、S&P グローバルの企業サステナビリティ評価(CSA)、そして開示規格である GRI・SASB・TCFD・ISSB がここに束ねられる。Ethisphere の倫理指数(EQ)も倫理統治の外部評価として参照できる。

下位次元審査内容接地する既存指標
ステークホルダー統治取締役会・意思決定への利害関係者の反映B Corp(統治)・DJSI CSA・Ethisphere EQ
目的の制度化定款・信託等での目的の後戻り不能な固定Business Roundtable 2019・Patagonia型信託
環境・社会インパクト環境負荷と社会貢献の実測値MSCI ESG・Sustainalytics・GRI・SASB
開示と第三者保証非財務情報の開示水準と外部保証TCFD・ISSB(IFRS S1/S2)・FTSE Russell

I軸 ── 在来・受託(Type 7 由来)

I軸は、企業が長期の受託者責任・現場の主体性・従業員福祉・共同体的意思決定という、非西洋経営が重んじてきた価値をどれだけ体現しているかを審査する。ここが本指標の独自性の核心である。第1部で見たとおり在来型の測定可能性は0.40と低く、既存の国際指標はこの軸をほとんど捉えられない。わずかに接地できるのは、日本の経済産業省による健康経営銘柄・ホワイト500(従業員福祉)、なでしこ銘柄(多様性)、そして ISO 26000 の社会的責任ガイダンス程度である。したがってI軸は「既存指標の空白地帯」であり、代理指標による補完が不可欠になる。

下位次元審査内容接地する既存指標 / 代理指標
三方よし(四方よし)買い手・世間・(未来世代)への配分の均衡健康経営 + 地域投資比率・取引先支払条件
長期受託者責任短期利益より存続を優先する統治(Trusteeship)創業からの存続年数・内部留保方針・同族/信託統治

この軸が要る理由

ESG や B Corp が高得点でも、それは西洋的な倫理・環境の枠組みで測った像にすぎない。日本や東アジアの企業が持つ「長期存続を旨とする受託」「現場の一人ひとりが採算を担う主体性」は、既存指標では不可視化される。I軸はその不可視の卓越性を、代理指標を通して可視化するために置かれる。

L軸 ── 学習・知識創造(Type 3 由来)

L軸は、組織が失敗から学び、前提を問い直し、知を現場から生み出しているかを審査する。心理的安全性を土台に据える点が特徴で、既存指標も比較的そろっている。Watkins-Marsick の DLOQ(学習組織の7次元)、Garvin の学習組織サーベイ(支援的環境・具体的学習プロセス・学習を促すリーダー行動の3ブロック)、Gallup Q12(エンゲージメントを通じた学習環境)、Edmondson の心理的安全性尺度(PSI 7項目)が中核となる。

下位次元審査内容接地する既存指標
心理的安全性対人リスクを取れる度合いEdmondson PSI・Google re:Work・ZENTech
ダブルループ学習前提そのものを問い直す仕組みGarvin LOS・Argyris 型内省の制度
知識創造(SECI/Ba)暗黙知の共有と形式知化の螺旋DLOQ・野中型「場」の設計指標
実験と失敗許容試行・失敗共有・改善の循環DLOQ(継続学習)・Q12(成長機会)

3軸の合成と中立性設計

3軸を合成するにあたり、単一の総合スコアで序列化することは中立性原則が禁じる。したがって最終出力は「E・I・Lの3値プロファイル」を基本とし、用途に応じて重みを可変にする。たとえば投資デューデリジェンスでは E軸を厚く、事業承継や地域企業評価では I軸を厚く、変化適応力の審査では L軸を厚く、というように文脈で配分する。既定は3軸均等(各1/3)とし、いずれか1軸への偏りは「プロファイルの形」として明示的に読ませる。

PART 03 追記

第3部 学術理論との関係可視化

第2部の指標を精緻化するには、各軸がどの学術理論に接地しているかを明らかにする必要がある。GOE-DB は概念ごとに他DBへの参照(cross_db_refs)を185件・23の対象DBに張っており、これを AR-DB(全エコシステムのエージェント・DB統合台帳)の文脈で読むことで、3軸それぞれの学術的な血統が見える。参照関係の型は equivalent(等価)125・related(関連)36・extends(拡張)18・translates_from(翻訳元)6 に分かれ、とりわけ translates_from は在来型の非西洋概念が西洋の哲学・思想へ翻訳的に接続している痕跡である。

3軸 × 学術理論DBの関係マップ

各軸の主サブフィールドに属する概念が、どの学術DBへ何本の参照を張っているかを集計すると、軸ごとに依拠する理論体系がはっきり分かれる。E軸(SF08)は源泉サイクルDB(gc)の三資本論・経済学DB(ec)へ、I軸(SF10)は哲学DB(philosophy)・判断力DB(tlj)・偉人DB(great-figures)へ、L軸(SF06)は知識活性化DB(kas)・知識組織化DB(kos)へと、それぞれ重心を置く。

軸主接地DB(参照型と代表対応)学術的含意
E軸gc(三資本論・Regenerative/Wealth Capitals=related)・mg(Stakeholder Theory=equivalent)・ec(Beyond GDP/Inclusive Wealth=related)倫理型は「資本を多元化する」経済思想に接地。単なる規範でなく、多資本の測定という定量基盤を持つ
I軸philosophy(儒教・道家・Ubuntu・Tawhid=translates_from/equivalent)・tlj(道徳経済合一・儒商=equivalent)・great-figures(渋沢・稲盛)在来型は経営学でなく哲学・判断力・人物伝に接地。西洋の管理科学の外にあり、翻訳を要する
L軸kas(知識活性化=equivalent)・kos(知識組織化)・philosophy(Foucault 権力知批判=equivalent)・mg学習型は知識科学に接地しつつ、Foucault の権力知批判という反省軸も内包する

接地の強弱が指標に与える含意

この可視化から3つの精緻化指針が導かれる。第一に、E軸は経済思想(gc/ec)に強く接地しているため、多資本の定量測定という既存基盤をそのまま採点に転用できる。第二に、I軸は経営学(mg)ではなく哲学(philosophy)に接地しており、参照型に translates_from が集中する。これは「西洋の尺度に翻訳する」際に意味の目減りが起きる領域であることを示し、だからこそ第2部で述べた代理指標が理論的にも要請される。第三に、L軸は知識活性化DB(kas)に等価接続しつつ、哲学DBを通じて Foucault の権力知批判に触れている。学習の礼賛が監視や規律へ転化しうるという反省が、理論の側から埋め込まれている。

精緻化の核心

3軸は等質ではない。E軸は「測れる資本」、I軸は「翻訳で目減りする受託」、L軸は「反省を内包する知」に接地する。ゆえに実行指標は、E軸を定量値で、I軸を代理指標と定性証憑で、L軸をサーベイと反省の証拠で――と、軸ごとに証拠の種類を変えねばならない。これが第4部の設計原理である。

PART 04 追記

第4部 実行力ある指標 ── GOE-Tri 採点ルーブリック

第3部の学術接地を踏まえ、審査担当者がそのまま使える採点ルーブリックへ落とし込む。設計原理は3つ。第一に、各項目に「証憑(evidence)」を必須とし、宣言だけでは加点しない。第二に、軸ごとに証拠の種類を変える(E=定量開示、I=代理指標と定性、L=サーベイと事例)。第三に、批判応答型(Type 8)を減点ゲートとして組み込み、グリーンウォッシングや過重労働の兆候を検出したら加点を打ち消す。総点ではなく3軸プロファイルで返すのは第2部の中立性設計を引き継ぐ。

反証条件と限界

GOE-DB の中立性原則は、すべての主張に反証可能性条件を求める。本指標が「誤っている」と示されるのは、次の場合である。第一に、GOE-Tri の3軸プロファイルが、独立に測った企業の長期存続・従業員福祉・不祥事発生と統計的に無相関であることが示されたとき。第二に、I軸の代理指標(存続年数・離職率等)が在来型の理念とは別の要因で説明し尽くされるとき。第三に、批判応答ゲートが偽陽性・偽陰性を高頻度で生むとき。これらは今後、GOE-DB の executive_cases(実践事例50件)と外部の財務・労務データで検証すべき仮説である。

限界も明示しておく。I軸は測定可能性0.40の領域を代理指標で補うため、他の2軸より推定の不確実性が大きい。また本指標は公開情報と第三者評価に依拠するため、非上場・中小企業では証憑の入手可能性が下がる。したがって GOE-Tri は「唯一の合否判定器」ではなく、3つの卓越性のプロファイルを可視化し、対話と精査の出発点を与える診断ツールとして位置づけられる。単一の理想企業像を強制しないという姿勢こそ、この指標が守るべき核である。
