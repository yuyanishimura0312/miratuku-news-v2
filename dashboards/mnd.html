/mnd エージェント

Claude Code 内で /mnd を実行すると本DBエージェントが起動する。

主要クエリ例:

-- マンダラ概念を SF 別に件数
SELECT subfield, COUNT(*) FROM mnd_concepts GROUP BY subfield ORDER BY 2 DESC;

-- 異領域の構造的同型対応 (Phase 11 で本格構築)
SELECT a.name_canonical, b.name_canonical, i.isomorphism_type, i.confidence
FROM mnd_structural_isomorphisms i
JOIN mnd_concepts a ON a.id = i.concept_a_id
JOIN mnd_concepts b ON b.id = i.concept_b_id;

-- 熊楠系譜・チベット密教系譜・対称性マンダラ系譜の追跡
SELECT chain_name, chain_theme, start_year, end_year FROM mnd_genealogy_chains;
