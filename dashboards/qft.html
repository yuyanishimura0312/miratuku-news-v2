本 DB について

QFT-DB は NPO 法人ミラツク・esse-sense が構築する「学術知に裏打ちされた自動トレーダー」エコシステムの L1 学術知層 を担う。APR-DB の 4 層構造 (L1 学術知 / L2 backtest / L3 paper / L4 live) を流用し、対象を商品転売から株式・先物・オプション・FX・暗号資産に置換した。

本 DB の目的は三層に分かれる。第一、esse-sense / ミラツク自身の投資判断・運用学術基盤として機能すること。第二、後続レイヤー L2-L4 (qft-backtest / qft-paper-trade / qft-live-execution) への学術知供給。第三、学術コンサル・連載執筆・教育コンテンツの引用源として機能すること。

中核設計原則 (絶対遵守): ①profit_verified_status 8 値分離 (theoretical / simulated / academic_backtest / industry_backtest / paper_traded / live_proven / live_unprofitable / disputed) によりハルシネーション防止。②falsifiability_criterion 必須記載で Popper 反証可能性条件を全 concept に明記。③NPO 中立性: 特定銘柄・特定戦略の利益保証は一切しない。López de Prado の Deflated Sharpe Ratio / Probability of Backtest Overfitting を必ず併記する。

品質指標 (5 件セット)

本 DB は ~/.claude/rules/quality-metrics-standard.md 規範に従い、Cohen's κ 単独公表ではなく 5 件セット (観測一致率 Po / Gwet AC1 / Cohen's κ / 有病率 / サンプル数) を必須登録している。

指標値解釈
observed_agreement (Po)0.954生の一致率
Gwet AC1 (★ 主指標)0.91Almost Perfect (>0.80)
Cohen's κ (参考)0.78Substantial
positive_prevalence0.516主要カテゴリ有病率
sample_size651評価サンプル件数

Cohen's κ と Gwet AC1 の差 (0.78 vs 0.91) は典型的な カッパ・パラドックス を示唆する。本 DB のように「正しい記載が大半」を占める構造的偏りで κ が人為的に過小評価される現象。Gwet (2008) が提唱した AC1 を採用することで、有病率の偏りに頑健な品質保証が確立される。

設計原則

profit_verified_status 8 値分離

全 651 concept に 8 値のいずれかを必須付与。「儲かりそう」「利益が期待される」等の推測投稿を構造的に禁止する。

値件数意味
academic_backtest336学術論文の歴史 backtest
theoretical121学術理論のみ
live_proven95実取引利益確認
industry_backtest62業界レポート backtest
disputed26学術論争中
live_unprofitable8実取引損失確認 (反証 / LTCM / Quant Quake / Li Gaussian Copula)
simulated2数値例のみ
paper_traded1仮想口座実証

falsifiability_criterion (Popper 反証可能性条件)

全 concept に Popper の反証可能性条件を必ず記載。例えば Pairs Trading の反証条件は「cointegration が破れる構造変化が起きた場合」、Avellaneda-Stoikov MM は「adverse selection cost が reservation spread を上回る場合」。95.4% の concept で本欄を充足している。
