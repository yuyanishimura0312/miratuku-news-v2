Phase 2 が示した到達点 IN PROGRESS

OpenVLA / GR00T / Helix が スキル横断的に振る舞う。試験運用が世界各地で同時並行で開始し、特定タスクの単発デモから「複数タスクの連続実行」へ評価軸が移動した。

Phase 2 で未達のもの CARRY OVER

30分以上の連続タスクで失敗率が急上昇。エピソード横断メモリ未解決。触覚・布操作・組み立ての汎化遅延。実機データ希少性の構造的問題（critical bottleneck）が解消されないまま Phase 3 入口に。

Phase 3 入口の前提 PROJECTED

マルチタスクの安定運用が前提条件。物流・製造での 実運用フェーズ へ移るには、単タスクのデモではなく「8時間シフト連続稼働」「ライン停止せずに切り替え」が可能であること。商用ヒューマノイド単価が現状の数万-数十万ドルから10倍下がる経路が見えるか。

Phase 4 の影 2027 — 2029

非構造化環境（家庭・小売・医療）への汎化が始まる。失敗コストが 致命的 な領域。安全と信頼性の制度が間に合うかが、Phase 4 の実現速度を直接律速する。

NEXT 2-3 YEARS · TRACK 1

2026-2028 ── 物流・製造でヒューマノイドが「実運用」へ

Phase 3 の本丸は、ヒューマノイドとモバイルマニピュレータが 連続稼働 8 時間 / 複数タスク切替 / 環境変化への適応 をデモではなく実運用で達成すること。原価10倍圧縮と量産規模の達成が同時に問われる。

核となる転換

「特定タスクが上手いロボット」から「複数タスクを 切り替えながら 動くロボット」へ。物流の仕分け、製造ラインの段替え、倉庫のピッキングが代表領域。

VLAの「スキル転移」が学習データ収集ではなく 実機稼働データ として循環する局面に入る。Open X-Embodiment の延長で、実機×実環境のデータ流入量が一桁オーダーで増える。

主要プレイヤー（観測対象）

Tesla Optimus / Figure / Apptronik / Agility（Digit）/ Boston Dynamics（Atlas電動）/ 1X / Sanctuary AI / Unitree / Fourier Intelligence / Xpeng / 川崎重工 / Toyota。

中国勢の量産単価（Unitree H1 が16,000ドル帯）が市場価格を強く律速する。米国・日本の汎用機が原価でついていけるか。

2026-2028 に解決が要る条件

① 機構コスト10倍削減の見通し（現在 critical bottleneck）。
② 実機データの質的多様性（実機 × 環境 × タスクのカバレッジ）。
③ 30分超の長期計画・エピソード横断メモリ。
④ 触覚・力覚の学習データ収集チャネル。
⑤ 「失敗しても停止する」フェイルセーフ機構の規格化。

「成功」の定義が変わる

2024-2025は「デモが綺麗」が評価軸だった。2026-2028は 1ロボット稼働あたりの実機データ蓄積量と歩留まり が評価軸に。

すなわち、論文ベンチマークではなく「物流倉庫1棟あたり何時間稼働してどれだけ仕分け失敗を減らしたか」という産業計測に評価が移る。

NEXT 2-3 YEARS · TRACK 2

2026-2028 ── 家庭・サービス領域への滲み出し

Phase 4（2027-2029）入口の動き。非構造化環境（家庭・小売・医療）への汎化が試行段階に入る。失敗コストが致命的な領域であり、安全検証と社会受容の制度が間に合うかが決定的。

家庭領域の前哨戦

掃除・洗濯物畳み・食器洗い・荷物の運搬。布操作 / 微細操作 / 動的環境 が同時に襲ってくる。実機データの「親密圏での収集」が、プライバシー設計と切り離せないテーマになる。

サービス・小売領域

店舗での棚卸し、夜間清掃、警備、案内。人と並走 する作業が前提となり、人間との接触・回避・譲り合いの設計が中心課題に。視覚＋触覚＋音声の マルチモーダル安全性 が要求される。

医療・介護領域

体位変換、移乗、見守り、リハビリ補助。失敗の身体的影響が直接的 なため、規制と監査の枠組みが先行する必要がある。日本の介護ロボ標準装備化（PHAI-DB予測 2050年）への前哨が、2026-2028 に始まる。

核心リスク CRITICAL

家庭・公道・医療では 1度の失敗が致命的。形式的検証と第三者監査の枠組みは現状未成熟（PHAI-DB bottleneck B-safe, confidence high, debate 0.15）。

規制パッケージ（EU AI Act / 米国EO / 日本AIガバナンス / 中国新規則）の 国際整合性 が間に合わなければ、Phase 4 は後ろ倒し。

社会的受容のラグ

技術的可能性と社会的受容のラグが、Phase 4 の実速度を決める。誰の身体に / 誰の家に / 誰の判断で ロボットが入るかの議論が、技術論より先に必要。

日本では「家庭 = 自律的判断の場」の文化的前提が、ロボット導入の意思決定構造に影響する。

BLIND SPOT 01 · ENERGY TRIANGLE

エネルギーの物理限界が、知能の進歩を律速する

「フィジカルAIは知能の話」と捉えがちな議論の中で、バッテリー密度 × データセンター電力 × ニューロモーフィック合流 の三角形が3-5年の進捗を支配する事実が見落とされる。Stream 8（マテリアル・エネルギー）が事実上のクリティカルパス。

三角形の頂点 ① BATTERY

リチウムイオン 270-300 Wh/kg の物理限界で、ヒューマノイド連続稼働 2-4 時間が天井。固体電池 500 Wh/kg 級の量産化が 2028-2030 に間に合うかが事実上の決定点。間に合わなければ Phase 3 後半（2027-2028）の実運用が3-5年後ろ倒し。

三角形の頂点 ② DATA CENTER

IEA推計でデータセンター世界消費 2022 年 460TWh → 2026 年最大 1050TWh へ倍増。送電網増強の 8-12 年計画と AI 需要急成長の不整合。Physical AI のクラウド推論依存がここに直撃。

三角形の頂点 ③ NEUROMORPHIC

人間脳 20W vs 大規模VLA推論 1kW級の 3桁差。Intel Loihi 3 / IBM NorthPole / SpiNNaker 2 の合流が必須。Stream 6（バイオ・神経模倣）と Stream 8（マテリアル・エネルギー）の 横断合流 が解。

なぜ盲点か

VLA・ヒューマノイドの議論は 知能アルゴリズム層 に集中するが、原価・連続稼働・推論電力は 物理層 の問題。

esse-sense ANSWERで見ても、phai-db への参照は知能側エージェントが中心で、エネルギー・バッテリー専門の独立DBが まだ整備されていない（FTT-DB v2の30領域には含まれるが横断接続が薄い）。

動画は綺麗、物理が破綻する

Sora / Genie / Cosmos / Veo は 長期一貫性・因果性・物理整合性 が不十分。コップが落ちて消える、布が壁を通り抜ける、人が二回まばたきしないままドアの向こうへ移動する、といった破綻が残る。

「箱の中のボール」が解けない

PIQA / ThreeDWorld の物理推論ベンチで、最先端VLAが 人間より30-40%低いスコア。「言葉が物理を知らない」問題。LLM がテキストから学べる物理常識には天井がある。

2つの仮説の対立

仮説A：動画生成が物理を学ぶ
十分なスケールで動画生成すれば物理整合性は emergent に獲得される。Sora / Genie 派。

仮説B：シミュレーションが先
物理エンジン（MuJoCo / Isaac / DRAKE）と接続した学習でないと物理は身につかない。ロボティクス派。

この対立の決着が2026-2027の論点。

盲点としての位置

動画生成側（Hollywood / Adobe / OpenAI）とロボティクス側（NVIDIA / DeepMind / Physical Intelligence）の 研究コミュニティが分離 しており、esse-sense ANSWER でも両者を接続するエージェントが未整備。

BLIND SPOT 03 · TACTILE & SAMPLE EFFICIENCY

触覚・微細操作 ── 日本の現場知が逆に強みになりうる領域

視覚に偏った学習が支配的で、触覚・力覚はデータが不足。布操作・組み立て・繊細物体の汎化遅延（major bottleneck）。1タスク 50-300 デモ × 100タスク = 数万デモが必要な現状。日本の繊細製造現場がデータ収集のホットスポットになりうる。

触覚データの構造的不足

カメラ + LiDAR + IMU は安く揃うが、触覚センサは センサ密度・キャリブレーション・耐久性 の三難。GelSight / DIGIT / TacTip 等の研究があるが、産業用標準が未確定。

日本のロボットハンド（Shadow / Ascent Robotics / Mujin / OMRON）と触覚センサ研究（東大・阪大・東北大）が世界的に進んでおり、データ収集の主導権を握る可能性。

サンプル効率の物理層

1タスクあたり 50-300 デモが必要。100タスクで数万デモ。人間の数千-数百万倍の経験量。シミュレーション + 実機 + 模倣学習のハイブリッドが鍵だが、touch のシミュレーションが特に未成熟。

日本の現場知という伏線

布の畳み方、料理の切り方、組立の段取り、調整作業の暗黙知。職人技として日本に蓄積されている繊細操作の知 が、データ化されていない。

2026-2028 の論点

① 触覚センサの産業標準化（GelSight / DIGIT 後継）
② 触覚を含む大規模実機データセット公開
③ 触覚×視覚×言語の三モーダルVLA
④ 日本の中小製造の暗黙知データ化
⑤ 模倣学習 × ロールアウト × シミュレーションの統合

Soft Robotics の合流可能性

ニューロモーフィックの必然性

BLIND SPOT 05 · COGNITIVE SCIENCE

Stream 7 ── 認知科学・4E認知との接続不足

VLA は「身体を持つ言語モデル」を作ったが、4E 認知（embodied / embedded / enacted / extended）の理論的基盤との接続が薄い。Predictive Coding（Friston）/ Active Inference の実装、World Models と認知科学の橋渡しが2026-2028 の論点。

4E認知の系譜

Embodied（身体性、Varela 1991）
Embedded（環境埋め込み、Clark 1997）
Enacted（行為依存、Thompson 2007）
Extended（拡張認知、Chalmers 1998）

50年以上の哲学・神経科学・心理学の蓄積があるが、VLA研究では これらの参照がほとんど見られない。

Predictive Coding / Active Inference

Karl Friston（UCL）の自由エネルギー原理 = 脳は予測誤差最小化する装置。

World Models（Ha & Schmidhuber 2018 / Dreamer / Genie）が事実上 Active Inference の工学版だが、理論との明示的接続 がまだない。両系統の合流が2026-2027の知的論点。

BMI・脳科学からの逆流

Neuralink / Synchron / Blackrock Neurotech 等の BMI 進展で、身体性のある知能の神経科学的根拠 が更新中。PHAI-DB予測：2070年「認知ケアBMI実装」「生体組織臓器置換期」。

日本では池上高志（東大）/ 國吉康夫（東大）/ 谷淳（沖縄科技大）/ 銅谷賢治（沖縄科技大）の系譜が、認知科学とロボティクスの橋渡しを担う。esse-sense ANSWER に独立エージェント未整備。

なぜ盲点か

工学コミュニティは「動けばいい」、哲学コミュニティは「概念を整理する」、両者の間に 実装可能な理論 が育っていない。

CLOSING

「知能の話」から「身体・エネルギー・現場知の話」へ

2024-2025 が「知能の合流」（VLA / GR00T / Helix）の局面だったとすれば、2026-2028 は「物理基盤の合流」（エネルギー / マテリアル / 触覚 / 認知科学 / 非西洋現場知）の局面へ重心が移る。esse-sense ANSWERが示す盲点は、観察装置自体の拡張余地でもある。

核心命題

フィジカルAIは「VLA + データ + ヒューマノイド」だけで完結しない。残り4系統（シミュレーション / バイオ神経 / 認知科学 / マテリアル・エネルギー）の同時進行がなければ、2030年以降の天井を抜けられない。

本デッキで列挙した7つの盲点は、いずれも 下位4系統の合流遅延 から生じている。エネルギー律速・世界モデル整合性・触覚・バイオ神経合流・認知科学接続・規制・非西洋現場知。

含意：esse-sense ANSWERの拡張余地
