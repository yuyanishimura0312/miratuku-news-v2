百年というスケール — もう一つの定規の発見

前章で導入したCTI v2は、文明転換の規模を測る定規であった。それは「文明の高さ」を六次元で記述し、産業革命と電力化学革命が形成する双子峰プラトーを明らかにした。本章では、もう一つの定規を導入する。文明の高さではなく、文明の時間構造を測る定規である。

七百万年の人類史のうち、最後の三千年間。この三千年間に起きた社会変革は、何千件規模で記録に残っている。それらを集積させて時系列で見ると、何が見えるか。これが本章の問いである。

結論を先に述べれば、社会変動の集積は、平均すると約百年周期で振動する。中央値はちょうど百年。三千年にわたって、この百年というリズムは驚くほど安定している。古代も、古代末期も、中世も、近世も、社会の集積期と崩壊期はおおよそ百年単位で交替してきた。これを本書は「世紀的連鎖モデル（Centennial Cascade Model、CCM v2）」と呼ぶ。

CCM v2 は、SI Framework DB の七千三百八十九事象、Great Figures DB の九千百七十八人物、Tech Acceleration DB の千百九十一技術という、三つの独立した構造化データベースを時系列で統合した結果として浮かび上がった。それぞれのデータベースは、別々の研究チームが、別々の問いから、別々の方法で構築した。それらを縦に重ねたとき、共通のリズムが現れた。それが百年であった。

百年は奇妙な数字である。短すぎず、長すぎない。人間の一生よりやや長く、しかし三世代の生き残りの祖父母から孫までの直接記憶のスパンとほぼ等しい。建物の構造的耐用年限と一致し、新しい技術が実験から標準化へと至る時間ともおおよそ重なる。なぜ百年なのか、という問いには、本章の最後で答える。だがまず、百年の発見そのものが何を意味するのかを、丁寧に追っていきたい。

三千年のリズム — 二十三のピークと十四の谷

分析の対象期間は、紀元前千年から紀元二千年までの三千年とした。これは(1)三つのデータベースで十分な事象密度が確保される最初の時点が紀元前千年前後であること、(2)既存のクリオダイナミクス研究（Peter Turchin、Jack Goldstone、George Modelski）が主に検証してきた範囲と整合すること、の二つの理由による。

各事象を二十五年単位のバケットに集計し、対数変換を施したうえで線形トレンドを除去した残差時系列を作る。これは近代以降の指数的成長を取り除いて、純粋な振動成分だけを取り出すための標準的な方法である。Ian Morris の Social Development Index が示すような長期的な人類進歩は、本書も否定しない。むしろ、その上に重畳する振動成分こそが、CCM v2 の対象である。

残差時系列に対して局所最大値検出を行うと、二十三のピークと十四の谷が検出された。ピークは、社会変動が集積する時代である。谷は、制度的混乱や危機の時代である。両者は約百年の間隔で交替する。

主要なピークと、それに対応する歴史的同定は次のとおりである。紀元前五百年のピークは、孔子・釈迦・ギリシア哲学者・ヘブライ預言者が同時代に活動した、ヤスパースが「枢軸時代」と呼んだ時期に重なる。紀元前三百年のピークは、ヘレニズム文化の総合期、秦の中国統一、マウリヤ朝のインド統一が同時に起きた時代である。紀元後百年のピークは、ローマ五賢帝期、後漢、クシャン朝の三大帝国が同時に最盛期を迎えた時代に対応する。八百年のピークは、カロリング朝のヨーロッパ・アッバース朝のイスラム圏・盛唐の中国が、それぞれ独立に文化的最盛期を経験した「もう一つの大ルネサンス」とも呼ぶべき時代である。千五百年のピークは、ヨーロッパのルネサンス・宗教改革・大航海時代の同時的展開に対応する。そして千八百七十五年のピーク——これは三千年で最大のピークであり、CTI v2 が双子峰プラトーとして検出した時代の中心に位置する。

谷もまた、独立した歴史学的研究で同定されてきた構造的危機期と密接に対応する。四百五十年の谷は、西ローマ帝国の崩壊期と、中国における五胡十六国の混乱期に重なる。八百七十五年の谷——これは三千年で最も深い谷である——は、カロリング朝の崩壊と、ヴァイキング侵入の最盛期にあたる。十三百七十五年の谷は、黒死病後のヨーロッパ社会の混乱期に対応する。十六百七十五年の谷は、Eric Hobsbawm が「十七世紀の一般危機」と呼び、Geoffrey Parker が著書『地球規模の危機』で気候変動と政治混乱の同時進行として描いた時代に正確に重なる。

これらの谷は、統計的なアーティファクトではない。独立した歴史学的研究で「構造的危機」として記述されてきた時代と、機械的に検出されたCCM v2 の谷が一致する。これが、百年周期というリズムの実在性を支える、最も確かな経験的証拠である。

三層連鎖 — なぜ偉人は制度に五十年先行するのか

百年周期の発見と並んで、CCM v2 が見出したもう一つの構造がある。社会変革は、三つの層の連鎖として展開する、という構造である。三つの層とは、個人層（偉人）・物質層（技術）・制度層（社会的制度）である。それぞれの層がいつどのように集積するかを追跡すると、特徴的な時間構造が現れる。

個人層の集積（偉人の出生のクラスター）は、制度層の集積（社会変革事象のクラスター）を、平均して五十年先行する。これは三千年のデータから機械的に抽出された相関構造であり、相関係数は遅延五十年の場合に〇・九〇〇という極めて高い値を取る。同時に、技術層は制度層と同時的に集積する（相関〇・九四五）。すなわち、偉人の登場は技術と制度の両方に約五十年先行し、技術と制度はほぼ同時に成熟する。

この五十年という遅延には、人間発達心理学の観点から自然な説明がある。偉人として歴史的痕跡を残す個人の多くは、二十五歳から五十歳の活動期に主要業績を残す。彼らが乳幼児期・少年期に経験した文化的・物質的環境は、二十五年から五十年後の彼らの成熟期に、制度的革新として結晶化する。すなわち、ある時代の社会構造は次の世代の人格形成を規定し、その世代が成人活動期に入る五十年後に、制度的革新として現出する。緩やかな世代継承メカニズムが、ここに働いている。

このメカニズムは、本書の前章で論じた双子峰プラトーの内的構造を解明する鍵にもなる。十九世紀の事象を十年単位で詳細に見ると、Person Layer（偉人層）は千八百五十年に第一の集積、千八百九十年に第二の集積を持つ。Tech Layer は千八百八十年に主集積、千八百五十年に副集積を持つ。一方、Institution Layer（SI events）は千八百八十年に単一の集積を見せる。この三層の集積パターンが、CTI v2 の二十五年解像度で見ると、千八百五十年と千九百年付近に「双子峰」を作る。

すなわち、双子峰プラトーは、単一の百年周期内における三層連鎖の発露なのである。第一峰の千八百五十年は、Marx・Darwin・Lincoln・Bismarck・福澤諭吉・Pasteur・Maxwell といった世代の人物層集積を映している。第二峰の千八百八十年は、その世代が成熟期に到達し、Edison・Tesla・Bell・ハーバー=ボッシュ・独立国民国家・社会保障制度といった技術と制度の集積を生み出した結果である。両峰のあいだの三十年は、人物層から制度層への結晶化の時間である。CTI v2 の双子峰プラトーは否定されないし、CCM v2 と矛盾もしない。両者は同じ深層構造の異なる断面を捉えている。

四位相の周期内構造 — Crisis から Institutionalization へ

百年の主周期は、内部に四つの位相を持つ。これは Strauss-Howe の世代理論に着想を得て、Turchin のクリオダイナミクスで構造的圧力を、Carlota Perez の Installation/Deployment 二相性を技術層に組み込んだ統合モデルである。

第一位相は Crisis（危機・制度崩壊）である。期間は二十五年。既存制度の機能不全が顕在化する局面である。Turchin が指摘した三つの構造的圧力——人口圧、エリート過剰、財政逼迫——が同時に集積する。Polanyi が記述した二重運動の社会防衛側が活性化する。十七世紀でいえば三十年戦争期、二十一世紀でいえば二〇〇八年金融危機以降の時期に対応する。

第二位相は Reconstruction（再建・人物層集積）である。期間は二十五年。危機後の再建期である。新世代が登場し、批判的な人物が台頭し、技術的試行錯誤が始まる。Schumpeter の創造的破壊の建設的局面である。Marx が亡命先のロンドン大英博物館図書室で『資本論』第一巻を書き上げた一八六七年は、千八百五十年代の Crisis 後の Reconstruction 局面の典型である。

第三位相は Innovation（革新・技術層集積）である。期間は二十五年。技術革新クラスターが形成される。Carlota Perez の言う Installation Phase（金融主導・実験的）に対応する。新しい制度実験が並行的に展開される。Edison のメンロパーク研究所、Tesla の交流電力、ベル研究所の電話事業——これらが千八百七十年代から千九百年代に連鎖したのは、まさにこの局面である。

第四位相は Institutionalization（制度化・安定化）である。期間は二十五年。制度層が結晶化する。Carlota Perez の Deployment Phase（生産主導・大衆化）に対応する。Modelski の Hegemonic Stability の局面でもある。次の Crisis に向けて圧力が再び蓄積され始める。一九〇〇年から一九二五年までの「ベル・エポック」と「短い二十世紀の入口」が、千八百年代の百年周期の Phase 4 に該当する。

これら四位相の循環は、三千年にわたって繰り返されてきた。同じ位相が同じ年月で機械的に繰り返されるわけではない。各位相の長さには変動があり、文明圏ごとに位相のずれもある。だが、Crisis から Reconstruction へ、Reconstruction から Innovation へ、Innovation から Institutionalization へ、そして次の Crisis へ、という循環の構造そのものは、繰り返し現れてきた。

三つのメカニズム共鳴 — なぜ百年なのか

本章の冒頭で立てた問いに、ここで答える。なぜ百年なのか。

本書は三つの相互独立なメカニズムが、百年前後で共鳴する固有振動として、この時間スケールを説明する。

第一は世代記憶のメカニズムである。人間社会で「直接経験者の生存期間」は、おおよそ二十五年から三十年の世代スパンの三世代、すなわち八十年から九十年である。すなわち、ある世代が経験した社会的トラウマや成功体験は、その孫世代までは生きた記憶として伝承されるが、曾孫世代にとっては歴史教科書の記述に過ぎない。百年は、生きた記憶が消失し、構造的反復が可能になる時間スケールである。Strauss-Howe の世代理論は、このメカニズムを米国史で精緻化したが、本書の百年は彼らの八十年 saeculum よりやや長い。これは検証対象の地理的・時代的範囲の違いに由来すると考えられる。

第二は制度的減衰のメカニズムである。憲法、宗教制度、官僚機構、インフラなどの主要制度は、設立後概ね八十年から百二十年で「構造的疲労」を示す。Acemoglu-Robinson の Critical Junctures 概念は、こうした制度的限界点を理論化したものとして再解釈可能である。Turchin の三つの圧力（人口・エリート・財政）は、制度がこれらの圧力を吸収できなくなった瞬間に発生する。

第三は技術習熟のメカニズムである。Carlota Perez が示したように、ひとつの技術革命が Installation（実験期）から Deployment（成熟期）まで完結するのには五十年から六十年を要する。CCM v2 の百年周期は、Perez の一・五サイクルから二サイクルに相当する。技術一サイクル（破壊期）と技術二サイクル（建設期）の複合構造として解釈可能である。

これら三つのメカニズムは、相互に独立ではなく相互強化的である。世代記憶の消失（二十五から三十年×三＝八十から九十年）、制度疲労の限界（八十から百二十年）、技術一・五サイクル（七十五から九十年）——いずれも百年前後で集中する。百年は、これらの異なる時間スケールが共鳴する「人類社会の固有振動数」として現れているのではないか。

共鳴という比喩は重要である。共鳴とは、異なる周波数の振動が一致したときに生じる増幅現象である。世代記憶・制度疲労・技術習熟の三つは、それぞれ独立にゆるやかな振動を持つ。だがそれらの振動が百年前後で重なり合うとき、それぞれの振動が孤立していたときよりも大きな社会変動が生じる。これが、百年が単なる平均値ではなく、構造的時定数として現れる理由である。

十七世紀の一般危機 — 三百五十年前の鏡

百年周期で歴史を読み返すとき、最も豊穣な歴史的アナロジーが現れる年代がある。千六百七十五年である。

この年は、三千年のCCM v2 検出で十四ある谷の一つであり、Eric Hobsbawm が「十七世紀の一般危機（General Crisis of the Seventeenth Century）」として理論化し、Geoffrey Parker が『地球規模の危機（Global Crisis、二〇一三年、ニューヘブン）』で気候変動・政治混乱・人口危機の同時進行として精緻に記述した時代である。

千六百七十五年から二〇二五年まで、ちょうど三・五周期の隔たりがある。すなわち、現代の私たちは、千六百七十五年代の人々と同じ位相にある可能性が高い。両時代の構造的並行性を比較すると、次の表が浮かび上がる。

側面千六百七十年代二〇二〇年代
気候マウンダー極小期（小氷期）気候変動の加速期
経済銀貨流通の地球規模ショック金融グローバル化の限界
地政学三十年戦争後の覇権再編米中欧の規制ブロック化
制度絶対王政の限界・市民革命前夜国民国家の限界・新秩序未定
その後の展開千七百年代の啓蒙と産業革命準備期二〇五〇年代以降のAI制度化期？

もちろん、二つの時代を機械的に重ねることには慎重でなければならない。十七世紀の人々が産業革命を予測できなかったように、二〇二六年の私たちも二〇五八年に何が結晶化するかを予測できない。だが、千六百七十五年が産業革命の準備期であったことを後から振り返って認識できるように、二〇二五年が次の制度結晶化期（CCM v2 では二〇五八年から二〇八三年と推定される）の準備期である可能性を、私たちは認識することができる。

これが、百年周期という定規が、現在を測るときに私たちに与える贈り物である。私たちは、終わりの始まりにいるのではない。次の周期の始まりにいる。十七世紀の一般危機の人々が、三十年戦争の混乱のなかで自分たちの時代が啓蒙と科学革命の準備期であると気づけなかったように、私たちもまた、自分たちが何を準備しているのかを完全には知らないまま、しかし確かに、何かを準備している。

本書全体での CCM v2 の役割 — 二つの定規という方法

本章で導入したCCM v2 は、本書の前章で導入したCTI v2 と並ぶ、第二の定規である。CTI v2 が文明の高さ（六次元×三成分の文明転換指数）を測るのに対し、CCM v2 は文明の時間構造（百年周期×三層連鎖×四位相）を測る。両者は競合するのではなく、補完する。

第一部「来た道」の各章では、両方の定規が並走する。農業革命から産業革命、AI革命までの九つの転換期は、CTI v2 の数値スコアで「高さ」が、CCM v2 の位相位置で「時間構造」が記述される。第二部「知の地層」では、神話・詩学・哲学・SI・偉人の各層が、それぞれ百年周期との関係でも読まれる。第三部「いまの座標」では、二〇二六年の私たちが立つ位置を、両方の定規で測る。第四部「行く道」では、二〇三〇年・二〇五〇年・二一〇〇年への展望に、CCM v2 の四位相が時間構造を補強する。

本書全体を通じて、CTI v2 が文明の「形」を、CCM v2 が文明の「リズム」を描く。この二つは別々の言語で語られているが、同じ現象の別側面である。形を持ったリズム、リズムを持つ形。文明とは、結局そういうものなのだろう。

次章では、CTI v2 の定規を持って、人類が経験した最初の四つの「知の跳躍」を訪れる。農業革命、文字の発明、枢軸時代、中世大学期、そして印刷期である。これら五つの跳躍を、CTI v2 の高さと、CCM v2 の位相位置の両方で読み解いていく。粘土板に楔形文字を刻んだ無名の書記、アレクサンドリアの図書館で写本を整理したヒュパティアの先輩たち、九世紀バグダードの「知恵の館」で古代ギリシアの哲学を翻訳したアラブの学者たち、そしてマインツでグーテンベルクの工房を訪れた最初の印刷職人たち。彼らがそれぞれの時代の Phase 何に立っていたのかを、私たちは新しい目で見ることができる。
