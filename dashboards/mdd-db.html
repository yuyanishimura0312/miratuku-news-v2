01概要

Google の広告マーケットプレイス、Amazon の EC、Uber や Airbnb のプラットフォーム、Alibaba 系の越境 EC は二十一世紀の経済活動の主要部分を担っています。これらの設計判断には、Vickrey の二位価格オークションから始まる七十年の理論蓄積、Gale-Shapley アルゴリズムから派生したマッチング理論、Rochet-Tirole の両面市場理論、Akerlof-Spence-Stiglitz の情報非対称性理論、そして Kahneman-Thaler の行動経済学が必須の基盤として横たわっています。MDD-DB はこれらを「マーケットプレイス設計」という統合的視座で整理した世界初の Production-grade 学術知統合基盤です。

05必須理論 157 件 100% カバー

Wave 1 の最重要成果は、十三サブフィールドの必須理論百五十七件すべてを full concept レコードとして投入し、must_have_theories テーブルとの双方向リンクを完成させたことです。Phase 1 で生成された必須理論チェックリストは must_have_theories.json として永続化され、各レコードに target_concept_id と coverage_status='collected' が付与されています。これにより Wave 2 以降の概念追加が「必須」ではなく「拡充」として明確に位置づけられ、Production 5,500 件への拡張が秩序立てて進行可能になります。

06関係構造 346 件

関係は十二の relation_type で構造化されています。サブフィールド内の発展年代に基づく predecessor_of / successor_of が二百四十四件、同時代の parallel_to が三十四件、サブフィールド横断の applied_in が二十九件、depends_on / specializes / generalizes / contradicts / critiques がそれぞれ理論的に厳選された手作業マッピングで六十八件追加されました。例えば Vickrey オークションは VCG メカニズムへ applied_in で接続し、VCG は GSP に applied_in で接続するなど、産業実装への論理的経路が明示されています。孤立概念はゼロです。

10Wave 2-4 計画

11連携可能な既存 DB (Wave 3)

Wave 3 で構築予定の十八 DB 統合マップは、経済学概念 DB との Nobel 受賞理論共有、経営学 DB との戦略概念共有、Social Sciences DB との行動経済共有、Innovation DB と Startup DB との両面市場拡張、Math DB との Game Theory 数学基盤、WMD-DB との収益化技法共有、IDE-DB との投資 DD 適用、AR-DB との生態系統合を実現します。これにより MDD-DB のスタンドアロン価値を超えて、ミラツク／esse-sense の DB エコシステム全体が Web マーケットプレイス設計の意思決定基盤として束ねられます。

12使い方

Claude Code から /mdd で専属エージェントを起動できます。SQLite クエリで直接アクセスする場合は次のコマンドを使用してください。

# 全体統計
sqlite3 ~/projects/research/marketplace-design-knowledge-db/data/marketplace.db \
  "SELECT subfield, COUNT(*) FROM marketplace_concept GROUP BY subfield"

# Nobel 関連検索
sqlite3 ~/projects/research/marketplace-design-knowledge-db/data/marketplace.db \
  "SELECT name_ja, nobel_year FROM marketplace_concept WHERE nobel_related=1"

# 概念系譜
sqlite3 ~/projects/research/marketplace-design-knowledge-db/data/marketplace.db \
  "SELECT r.relation_type, c1.name_en, c2.name_en
   FROM marketplace_relation r
   JOIN marketplace_concept c1 ON c1.id=r.from_concept_id
   JOIN marketplace_concept c2 ON c2.id=r.to_concept_id"
