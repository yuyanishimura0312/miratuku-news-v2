場所性学術知 DB Placeness Knowledge DB

場所性 = 土地に織り込まれた物語（いわれ・文化・地理に紐づく食・植生・歴史の集合体）を学術的に基盤化する空間軸 DB。
ミラツク/esse-sense エコシステムの時間軸 DB 群 (TC-DB 時間概念史 / CEH 宇宙地球史 / CIRC 循環 / KGH 知の生成史) を補完する。

01サマリ

PLN-DB v0.1.0 Wave 1 Core MVP (2026-05-25 構築) は、場所性に関する世界 15 サブフィールドの核となる 180 概念・116 関係・100 横断参照・51 研究者・10 系譜チェーンを収録する。各 SF 12 概念で均一カバレッジを確保し、非西洋率 31.7%（target 30%+ 達成）・女性研究者率 15.7%（target 15%+ 達成）・cross-DB 接続 25 DB（target 18+ 達成）の品質ベースラインを Wave 1 段階で確立した。Production 目標は concepts 5,500 / relations 22,000 / researchers 1,500 / publications 1,500 / IRR Gwet AC1 ≥ 0.85 で、Wave 2 以降の継続改善ループで到達する。

収録系譜は Heidegger → Casey → Malpas の場所現象学 100 年、Vergil → Norberg-Schulz → Böhme の Genius Loci 2,000 年、和辻 → Berque の風土学 90 年、西田 → 清水博の場所論理 100 年、Aboriginal Songlines 40,000 年など、東西・古今を横断する。

PLN-DB は /adb v1.1 経路 A (academic-db-build) で構築する。Phase 0 (Scope 15 SF 確定) → Phase 0.5 (API 宣言: OpenAlex / Semantic Scholar / CiNii / NDL / WorldCat) → Phase 0.7 (モデルティア: claude-sonnet-4-5 主) → Phase 1 (Schema 16 テーブル) → Phase 2 (ETL Wave 1 Core 180 件) → Phase 3 (Validate: 重複 0 / source_url 100% / verified 100%) → Phase 4 (Relations 116 + Cross-DB 100) → Phase 5 (Dashboard / 本ファイル) → Phase 6-7 (doc-verify + Publish) を Wave 1 で完遂。Phase 8-15 (Continuous Improvement Loop) は Wave 2-N で展開し、Production 5,500 concepts / Gwet AC1 ≥ 0.85 / 多言語 30%+ へ到達する。
