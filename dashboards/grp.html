CH 01 / OVERVIEW

プロジェクトの目的と位置づけ

Global Research Press DB (GRP-DB) は、世界中の大学・研究機関が日々発信する プレスリリースを部局単位で完全収集することを目指す大規模実データ DB。 最終目標は世界 30,000 機関 / 部局 100,000 級 / PR 累計 5,000,000 件。 NPO 法人ミラツク / esse-sense の ANSWER+ レポート生成、ng (Narrative Generator) による 記事化、連載エコシステム (kurashi / keiei / recurrence) のリサーチ素材、 市民出版 (RITE) の参照層を貫通する素材基盤として位置づけられる。

起点は既存の university-pr (UPR) DB であり、その 836 件の日本大学 PR を発展形として 取り込んだ。Phase 0 で機関マスター設計、Phase 1 で Tier 1 9 国 (US / CN / GB / DE / JP / FR / KR / CA / AU) の 926 主要機関の seed と 90 日バックフィル、 Phase 2 で日次パイプライン自動化、Phase 3 で NER 抽出、Phase 4 で foresight シグナル抽出、 Phase 6 で FIH 統合、Phase 7 で 1 年バックフィル拡張を実行した。

CH 05 / SIGNALS

foresight シグナル抽出

Phase 4 で全 press_releases に signal_type と novelty_score を判定した。 SURGE が 1,498 件と最多で、内訳は society 50 機関 / ai 48 機関 / education 66 機関 / medicine 23 機関 / space 20 機関 の 5 つの topic が直近 30 日で 20+ 機関から発信。 CROSSOVER (異分野ペア) は 18 件、SANGAKU_LINK (企業共同研究) は 35 件検出。

CH 06 / FIH
