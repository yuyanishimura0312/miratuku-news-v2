01　概要

WCPS-DB は、Web 上の人間の売買行動を最大化するための学術知見（心理・行動・数理・アルゴリズム・実装）を世界最高品質で集積した学術概念データベースです。行動経済学・消費者行動論・神経マーケティング・コンバージョン最適化・レコメンダーシステムの 13 領域を横断統合し、ピアレビュー論文と公開技術文献を出典として、実装可能技法を学術理論で裏打ちします。

既存の WMD (Web Monetization DB) が収益化「技法カタログ」を扱うのに対し、WCPS-DB は学術論文起点の「心理・行動・数理メカニズム」基盤として差別化されます。両 DB は cross_db_refs で双方向接続されます。

06　倫理境界

SF12 ダークパターン・倫理 を必須サブフィールドとして組込

「売買行動の最大化」を倫理規範（Brignull / Mathur 2019 / Gray 2018 / EU DSA Art.25 / GDPR / 景表法 / 特定商取引法）内に位置づけます。manipulative 技法には ethics_flag を必須付与し、Wave 3 で 100% カバーを達成します。

WCPS12 は WCPS01-11 の各概念に対する境界条件として機能します。例えば WCPS04 価格心理学の「Decoy Effect」自体は学術的に中立ですが、消費者にとって不合理な選択を強制する形で実装すれば Brignull の「Misdirection」分類に該当します。WCPS-DB は学術概念とその倫理境界を分離記述することで、設計者の判断材料を提供します。

07　免責

本 DB は Web 上の売買行動誘導技法を学術知見として整理したものであり、特定の操作的・欺瞞的実装を推奨するものではありません。実装にあたっては EU DSA / GDPR / 景表法 / 特定商取引法 / 業界倫理規範を遵守し、消費者厚生を損なう手法を回避してください。引用した数値・効果は集団傾向であり、個人差・文脈差が大きいことを前提としています。
