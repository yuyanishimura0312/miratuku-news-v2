0. 本レポートの目的

Chapter 7 は「浅い知をAIに渡し、深い知を時代として取り戻す」という Deep Knowledge Foresight の核心命題を提示する章である。本レポートは、その命題が ミラツクのDB体系（実データ）でどこまで支えられているかを10 DBの実クエリ結果で立体化し、(1) 強力に支持される層 (2) 構造上見えていない層 (3) 補強を要する層 を切り分ける。Chapter 7 を「読む」ためでなく、「自分の論として再構築する」ための足場として書く。

1. Chapter 7 の論理構造（5層の再構成）

Chapter 7 は次の5層を順に積み上げる。

層 主張 キーアンカー

3-4. Michael Polanyi（暗黙知）— PHIL-DB に該当なし ← 構造的分断

PHIL-DB を tacit knowledge / personal knowledge / focal vs subsidiary awareness / indwelling で検索しても 0件。Polanyi のヒット3件はすべて兄カール・ポラニー（経済人類学）であり別人。

Michael Polanyi の暗黙知は別DB academic-knowledge-db / innovation_theory に14件存在する: - inno_know_047 暗黙知と形式知（Polanyi 1966） - inno_neo_022 暗黙知の先駆 - inno_know_150 暗黙知のデジタル化 - inno_know_248 タシットナレッジとAIの限界 - inno_know_089 知識の暗黙性とスピルオーバー距離

この分断の意味: 暗黙知概念は哲学史ではなく「経営学・知識経済学」に編入された20世紀後半の制度史的事実を、DB 構造そのものが反映している（Nonaka-Takeuchi の SECI モデル経由の受容）。Chapter 7 は4系譜を哲学的に並置するが、現代の制度では Polanyi だけが 知識管理（KM）/イノベーション論 に組み込まれており、他3者と切り離されている。これは Chapter 7 主張のいわば「裏面」を示す重要な発見である。

11. 結論 — 9つの確信と6つの限界

確信（DB 体系で強く支持される命題）

  1. 過半が AI に代替されない問いである（CQ: ai_invariant + ai_reformulated = 51.6%）
  2. 深い知5サブフィールドが2,615件（35.9%）と最厚層を形成（CQ: 死生680 / 伝統知665 / 聖459 / 身体ケア428 / 創造383）
  3. 2050+ ホライズンの70.8%が深い知（CQ: 1,142 / 1,612 件）
  4. 伝統知の4特徴は DB スキーマで直接識別可能 — 修辞ではなく形式知化可能な属性体系として確立されている（TK）
  5. 非西洋世界観の量的厚みは約9倍（TK 88.7% vs Europe 11.3%）
  6. 古代100% / 中世81%が非西洋 — 西洋優位は近代以降の制度史的逆転に過ぎない（KGH）
  7. 神話の循環時間観は700文化・12.2M構造パラレルで実証（MY）
  8. 源泉サイクル N6/N7/N8 への還流ルートが学術的に整理済み（GC: 47ケース支持率97.9%、反証0）
  9. 身体性の哲学的・人類学的アンカーは厚く実装済み（Mauss → Bourdieu → embodied cognition + Husserl → Merleau-Ponty 14件エッジ）
  10. 時間概念で循環/線形の非西洋率が劇的に逆転（TC-DB: 循環時間63.8%非西洋 vs 線形時間66.5%西洋。Chapter 7「西洋起源の線形未来観」を実数で裏付け）
  11. 「足元の今」の哲学的先例は道元 有時と西田 永遠の今（TC-DB: 道元は東アジア哲学時間概念で唯一の genealogy_narrative 持ち、Heidegger『存在と時間』への接続まで記録）
  12. 「うた・おどり・こえ・いのり」は2,500年の連続蓄積（PT-DB: BC500 ラサ論 → AD850 ドゥヴァニ → AD1197 幽玄 → AD1400 能の花 → AD1760 歌心 → AD2003 オング。AI時代の今、すでに完成度の高い理論伝統が存在）
  13. 詩学詩文層は非西洋56.1%・105言語（PT-DB: サンスクリット・仏典詩偈・アラビア／ペルシア・先住民口承が構造的に組み込み済み。CHAPTER 7 想定14理論家全員 DB 実在）

限界（補強を要する不在）

  1. Signal DB が Chapter 7 主張を現状定量裏付けできない ── rule-based 抽出語彙の再設計と6か月の時系列蓄積が必要
  2. Michael Polanyi が PHIL-DB に未収録 ── innovation_theory に編入されたまま、哲学史的アンカーと切り離されている
  3. Husserl → 西田 / MP → 西田 の関係エッジが未構築 ── 概念上は確実に成立するが DB 上では未接続
  4. Joseph Campbell・Yi-Fu Tuan・アイヌ カムイが AN-DB 未収録
  5. commensality / conviviality 0件 ── 「共に食べる」軸が AN-DB の弱点
  6. 伝統知の世界観・思想層が薄い ── cla_layer=myth_metaphor 1.3% のみ。Dreamtime / カムイ / 七世代の叙述強化が次の課題
