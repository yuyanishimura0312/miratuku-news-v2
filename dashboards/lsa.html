系譜チェーン

RAG lineage (1975–2025)
Spreading Activation Theory → kNN-LM → REALM → Retrieval-Augmented Generation (RAG) → Fusion-in-Decoder (FiD) → Atlas → Self-RAG → Corrective RAG (CRAG) → GraphRAG → HippoRAG → Agentic RAG
非パラメトリックな外部記憶でLLMを拡張する系譜。Collins-Loftusの拡散活性化(1975)が概念ネット上の連想を理論化し、kNN-LM(2020)が学習コーパスの最近傍を生成時に補間、REALM(2020)が検索を事前学習へ統合、RAG(Lewis 2020)がretrieve-then-generateを定式化した。FiD/Atlasが多パッセージ融合を洗練し、Self-RAG(2023)が自己反省トークンで検索の要否を判定、CRAG(2024)が検索評価器で自己修正、GraphRAG/HippoRAG(2024)が知識グラフと連想記憶へ展開、Agentic RAG(2025)が計画・反復・反省のエージェントループに検索を埋め込んだ。この末端は我々のFIH知見供給と還流ループの構造的同型である。
LLM self-improvement lineage (2022–2025)
Chain-of-Thought (CoT) → Self-Consistency → STaR → Self-Refine → Reflexion → Self-Rewarding Language Models → DeepSeek-R1
LLMが自分の出力を改善する系譜。CoT(Wei 2022)が中間推論を露出させ、Self-Consistency(2022)が複数経路の多数決で分散を縮減、STaR(2022)が正答連鎖の自己選別で再学習をブートストラップした。Self-Refine(2023)が追加学習なしの推論時自己フィードバックを、Reflexion(2023)が失敗の言語的反省を記憶に蓄える言語強化学習を導入。Self-Rewarding LM(2024)が判定器と方策を同一モデルに統合し、DeepSeek-R1(2025)が純粋強化学習で推論を自己発現させた。generate→evaluate→refineの閉ループは我々のgmn-feedback 5段ループと同型である。
Self-augmentation substrate → reflux loop (1975–2024)
Spreading Activation Theory → Boundary Objects → SECI Model & Ba → Knowledge-to-Action (KTA) Cycle → Knowledge Graph Refinement → Unifying LLMs and KGs (Roadmap)
自己改善ループの理論的背骨の系譜。拡散活性化(1975)が共活性の認知的祖、境界オブジェクト(Star-Griesemer 1989)が異領域協働の人工物概念、SECI/Ba(野中 2000)が暗黙知と形式知の循環螺旋、KTA(Graham 2006)が知識使用のMonitor→Evaluate→Sustainを定式化した。KG精緻化(Paulheim 2017)が信頼スコア付き仮エッジの規律を与え、LLMとKGの統合ロードマップ(Pan 2024)が推論結果をKGへ書き戻すSynergizedを到達点に置いた。これらは我々の『記録→還流』設計(西村制約=記録のみ/ループは慎重に)の学術的裏打ちであり、AR-DB・kos・kas との橋を成す。
