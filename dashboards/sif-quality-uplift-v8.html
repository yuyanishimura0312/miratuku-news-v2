学術整合性監査レポート

v8ラウンドは v7 までで完備された 7,389 事象に対し、学術データセットとしての品質を担保する3種の追加検証を実施した。引用学者と事象の領域整合性、地名・組織名の表記標準化、そして教科書「ソーシャルイノベーションの構造」20章との相互参照リンクである。Block A は 13,163 引用を 80 名学者DBで監査し、領域横断引用が標準的実践として妥当であることを確認、Block B は40カ国の地名と15の主要組織を標準形へ統一、Block C は全 7,389 事象を教科書章へマッピングした。

01プロジェクト要旨

v7でSI Framework DBは7,389事象の100%が5フィールド学術ナラティブとDrayton 4段階分類を取得し、データ完備の段階を終えた。v8は、この完備データを学術引用可能なデータセットとして公開可能な水準にまで引き上げる「整合性監査」フェーズである。具体的には、(1) 5,056件のCodex生成ナラティブと curatedナラティブに含まれる全 13,163 引用について、引用学者の専門領域と事象の civilization が整合するかを確認、(2) v7 で人名標準化が完了した後の地名・組織名の表記揺れを 40 パターンで一括統一、(3) DB と書籍「ソーシャルイノベーションの構造」を相互参照可能にするため、各事象を最大4章にマッピングした。

02Block A — 学者-事象 領域整合性監査

v3〜v7 で生成された全ナラティブの refs フィールドを解析し、80名の主要学者DBに対して 13,163 件の引用を抽出した。各引用について、その学者の専門領域（civilization）と引用された事象の civilization が整合するかを確認した。結果、12,482件（94.8%）が直接整合し、681件（5.2%）が領域外引用であった。

領域外引用の上位は、Roy O. のイスラム圏引用 176件、Bayly C.A. の cross_civilizational 引用 159件、Hobsbawm の cross_civilizational 引用 131件、Hopkins A.G. の cross_civilizational 引用 131件である。これらは厳密には「領域外」だが、いずれも学術的に正当化された越境的応用である。Roy はもともと中央アジアと並んで現代イスラム政治論の主要研究者であり、Bayly は「グローバル・ヒストリー」の代表的論者として南アジアを越えて世界史を論じる。Hobsbawm の「短い20世紀」概念や Hopkins のアフリカ経済史枠組みは、特定地域に限定されず文明圏横断的に応用される標準的な分析道具である。

真に問題的な誤引用（事象年代以前に死亡した学者の引用、まったく無関係な分野の学者の引用など）は本ラウンドで検出されなかった。引用品質は学術データセットとして合格水準にあると評価する。

03Block B — 地名・組織名の表記標準化

v7では人名表記の統一辞書（ムハンマド・チンギス等の20名）を整備したが、地名と組織名は未統一であった。v8-Bでは、40の主要パターン（コンスタンティノープル、バグダード、ダマスカス、カイロ等の都市；ローマ帝国、ビザンツ帝国、オスマン帝国、モンゴル帝国等の国家；アッバース朝、ウマイヤ朝等のカリフ朝；ラパヌイ、ハワイ王国等の太平洋地名；マウリヤ朝、グプタ朝等のインド王朝；国連、世界銀行、IMF 等の国際機関）を網羅する辞書を整備し、5フィールド全体に一括適用した。

結果として73事象（実質的には複数フィールドを跨いで163箇所）の表記が統一された。最頻置換は IMF（45箇所）、ブハラ（9箇所）、世界銀行（8箇所）、ソ連（8箇所）、エチオピア（7箇所）、フィジー（7箇所）であった。これにより、SI Framework DB のナラティブは人名・地名・組織名の3カテゴリで一貫した表記体系を獲得し、検索性と学術引用可能性が完備した。

04Block C — 教科書との相互参照リンク

SI Framework DB と書籍「ソーシャルイノベーションの構造」（20章）を統合運用するため、各事象を最大4章にマッピングする `textbook_chapters` カラムを追加した。マッピング規則は、(1) 文明圏に応じた地域章（東アジア→Ch.8、南・東南アジア→Ch.9、アフリカ・イスラーム圏→Ch.10、アメリカス・太平洋→Ch.11）、(2) 時代に応じた時代章（古代中世/早期近代→Ch.12 古代の発明、産業革命期→Ch.13 近代の爆発、20世紀/グローバル化期→Ch.14 現代の加速）、(3) 失敗事象→Ch.16 失敗のパターン、(4) Tier-A 現代事象→Ch.19 現代のSI実践、(5) 公共財・市民権・民主的決定→Ch.18 公共財と権利の振り子、(6) 全事象→Ch.2 5000年のSIを見る眼、の6規則である。

これにより、教科書の各章から DB の関連事象群を逆引きできる構造、および DB の各事象から教科書の参照章を特定できる構造の双方が成立した。たとえば「失敗のパターン」章 (Ch.16) から1,675件の失敗SI事象を、「アフリカ・イスラーム圏のSI」章 (Ch.10) から1,237件の事象を即座に引き出せる。

06v3〜v8 累積成果

6ラウンド（v3〜v8）にわたる SI Framework DB の品質向上プロセスは、累積で114のCodexチーム動員 + 9の Python 検証/標準化パイプライン + 1の手動執筆により、6,001件の事象に5フィールド学術ナラティブを付与し、7,389事象すべてに Drayton 4段階分類と教科書章マッピングを与え、人名・地名・組織名の表記を統一し、80名の学者DBで引用整合性を検証する、という多層的品質保証を達成した。最終DBは、学術データセットとして公開可能な水準に到達したと評価する。

07残課題と今後

v8で検出された限界として、第一に、Block A の引用整合性監査は学者の領域整合性を量的に検証したが、引用著作の年代と事象年代の整合性、引用された理論枠組みが事象解釈に妥当に適用されているかの質的判断は未実施である。これらは外部学者によるサンプリング・レビューが必要な水準の検証であり、自動化は困難である。第二に、Block B の表記標準化は40の主要パターンを統一したが、無数の固有名詞（中小規模の地名、人物名、概念名）には未対応のものが残る。第三に、Block C の教科書マッピングは規則ベースの自動マッピングであり、各事象が最も適切に位置づけられる章の選択には人手判断が必要な余地がある。

これらは v9 以降、(1) 外部学者による引用妥当性のサンプリング・レビュー、(2) 表記標準化辞書の継続拡張、(3) 教科書マッピングの人手精緻化、(4) 公開データセットとしての出版（GitHub release、Zenodo DOI 取得、Dataverse 登録）、を進めることで対応する。本DBは現時点で量的・構造的・整合性の3次元すべてで完備した状態にあり、v9 以降は学術コミュニティとの協働フェーズへ移行する。
