Social Innovation Framework v2.0 と Civilizational Transformation Index v2 の統合ビュー

本ページは2層構成です：DBSIF v2.0＝7,389事象のSI歴史的構造変革データベース（収録基盤）／ IDXCTI v2＝このDBと他38DBから合成された文明転換指数（解析応用）。SIF v2.0が「何が起きたか」を、CTI v2が「いつ・どれだけ起きたか」を測定する。両者は同じ素材を異なる粒度で扱う関係にある。

構造的ソーシャルイノベーション事象を、ヒストリカル・ソシオロジー（Skocpol/Tilly/Moore）・制度理論（Ostrom/DiMaggio/North）・トランジション理論（Geels/Meadows/Loorbach）の三伝統と、Drayton/Ashokaのシステム変革理論を統合した操作的定義に基づき同定。7,389件の事象（うち失敗SI 1,675件、22.7%）を5次元PRRRCモデルと新設4カラム（drayton_stage、system_change_score、tsi_layers、tipping_point）で構造化、927件の事象間関係をネットワーク化した。本ダッシュボードはこのDBの全貌（前半セクション）と、それを基盤に構築された CTI v2 文明転換指数の解析結果（後半セクション）を一画面で示す。
全数値は si_events.db および CTI v2 解析スクリプトから直接集計、再現可能。

IDXCTI v2 ／ 文明転換指数

このDBから生まれた解析応用：CTI v2（Civilizational Transformation Index v2）は、SIF v2.0 を含む39DBを統合し、文明転換の構造的衝撃を6次元で測定する指標である。前身となった SIF-SI（同時多発度指数）初版に対する3チーム並列学術検証で同定された7弱点に応えて構築された。Ian Morris（The Measure of Civilization 2013）／ Vaclav Smil（Energy and Civilization 2017）／ Carlota Perez（2002）／ Robert J. Gordon（2016）／ Joel Mokyr（2009/2017）の系譜上に位置する。

PRRRC 5次元 ↔ CTI v2 6次元 — 二層の対応

SIF v2.0 の PRRRC（事象単位ミクロ評価）と CTI v2 の D1-D6（時代単位マクロ評価）は、同じ素材を異なる粒度で扱う。下表は両者の対応関係を示す。

PRRRC（事象軸）主に対応する CTI v2 次元関係性の説明
P 権力構造D6 権力集中 + 部分的に D5 地政学秩序事象単位の権力配分変化を時代横断で集計し、HHI・CR3 等の集中度指標として時代単位に集約
R₁ 制度的ルールD5 地政学秩序 + 部分的に D4 価値観法・規範・条約の累積を Polity IV 多極性指数・Correlates of War と接続
R₂ 資源配分D3 エネルギー + 部分的に D2 労働構造事象に表れる資源配分の組み替えを Morris kcal/day・Smil GJ/cap/yr の時代別エネルギー捕獲量に翻訳
R₃ 社会的関係性D2 労働構造 + 部分的に D5 地政学秩序ネットワーク形成事象が職種多様性（Shannon entropy）と新規職種比率の生成基盤になる
C 認知的枠組みD4 価値観 + 部分的に D1 情報処理Cognition の累積を Inglehart-Welzel WVS 二軸 + ミラツク CLA-DB 神話メタファー層 46,345件で時代別定量化

留意点：PRRRC は事象を 0-25点で評価し、CTI v2 は時代を 0-1スコア × M/C/I 三成分で評価する。粒度・対象・操作的定義が異なるため、対応関係は主従の含意（mainly maps to）として読まれるべきで、機械的な変換式ではない。

CTI v2 公式

CTI v2 — Master Formula CTI(t) = w_M · M(t) + w_C · C(t) + w_I · I(t)
M(t) ＝ 6次元値の幾何平均 (∏ d_i)^(1/6)
C(t) ＝ 6次元時系列の pairwise Pearson 相関の非対角平均（[0,1]rescale）
I(t) ＝ 0.5·I_restore + 0.5·I_path（復元コスト＋Brian Arthur 1989 path dependence 4要素）
デフォルト重み w_M=0.4, w_C=0.3, w_I=0.3
基準化 1850年=100（絶対系列）／ 2026年=100（相対系列）の二系列併記

過去から学べる3つの教訓

LESSON 01
情報処理→価値観のラグは50-100年
グーテンベルク 1455 → ルター95か条 1517 で 62年、近代科学革命の本格化（プリンキピア 1687）まで約200年。AI革命 D4=0.60 暫定値は、価値観転換が進行中であることを示す。Eisenstein-Pettegree-Johns 論争：「技術は条件であり因果ではない」。
LESSON 02
地政学秩序の急変は技術成熟期に発生
1870-1914 の技術発展期は Pax Britannica 下で安定 → 1914年WWI で19世紀的国際秩序解体。Bradford「3規制ブロック」（Brussels/Washington/Beijing）は1880年代帝国主義分割に類比的。「2030年代前半の意思決定の窓」がハイリスク期。
LESSON 03
労働構造変化は2-3世代かかる
手織工 24万人(1820)→4万人(1860)で 40年、英国農業就業比 50%→9% で 200年。Acemoglu (2024)「短期で過大評価／長期で過小評価」。Goldman Sachs 300M職リスクは数十年スパン累積効果として読むべき。

方法論

SIF v2.0 操作的定義: 構造的ソーシャルイノベーション事象とは、ある社会システムの根幹にある構造（権力配分・制度規則・資源配分・社会関係・認知枠組み）を新たな構造に更新する営為であって、(a)複数アクターの協調的・対立的相互作用、(b)制度化と自己強化、(c)5年以上の持続、(d)既存パラダイムと異なる新標準の確立、を満たす事象。

5次元PRRRCモデル: P権力、R₁ルール、R₂資源、R₃関係、C認知。各0-5点、合計25点。Meadowsレバレッジポイント階層（LP1-3→LP10-12）と対応。

v2.0 新設カラム: drayton_stage（pattern_change/framework_change）、system_change_score（0-2、3層同時進行スコア）、tsi_layers（5層TSI統合モデル該当層）、tipping_point（自己維持達成フラグ）。

CTI v2 設計原理: 6次元（D1情報処理／D2労働構造／D3エネルギー／D4価値観／D5地政学秩序／D6権力集中）を Morris 2013・Smil 2017・Hilbert & López 2011・Inglehart & Welzel 2005・Polity V・DOJ HHI 等の既存社会科学指標に錨付け。SIF-SI 初版 (a)×(b)×(c) 積形式の dominance failure を加重和形式で構造的に克服。

CTI v2 二系列基準化: 1850=100（絶対系列、産業革命中期を基準）と 2026=100（相対系列、現代との比較感覚）の双系列併記により presentism リスクを回避。全計算は Python 3.11 + scikit-learn で実装、6次元の操作的定義・下位指標重み・連動強度の計算窓・不可逆性各要素重みを YAML 外部化することで第三者再現可能性を確保する設計。

不可逆性 I の操作化: I = 0.5·I_restore + 0.5·I_path。I_restore は復元コスト法（過去20件の既知転換事例で「100年以内に元に戻ったか」をロジスティック回帰）、I_path は Brian Arthur 1989 の path dependence 4要素（learning effects / coordination / adaptive expectations / network externalities）の発生比率。両者の Pearson 相関 > 0.7 を整合性条件とする。

典拠の管理: 各事象に refs として主要研究文献1-3件を付与。confidence列で high/medium/low を、source列で verified/academic_attested/gf_db_extracted 等を区別。

失敗事例の包含: 制度化に失敗・反転したSI事象も is_failed=1 として包含し、生存バイアスを是正。トランジション理論（Geels）と複雑適応系理論（Holland）に基づく学習価値を保持。
