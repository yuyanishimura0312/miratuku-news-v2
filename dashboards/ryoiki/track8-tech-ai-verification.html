CHAPTER 02

カテゴリ1: スナップショット不整合（5項目）

analysis.html §2 で開示した三系列（ブリーフィング値／Memory値／DB実値）の差異を、ここでは項目別に判定する。

V-01 TAレコード総数の三系列差 問題なし

ブリーフィング値「162Kレコード42テーブル」、Memory値「227Kレコード44テーブル」、DB実値「226,996行・44表（sqlite_sequence除外）」（集計L-01）。差異は明示的にanalysis §2.1で開示・説明済み。差の主因はOECD MSTI 64,890行とSeshat all_variables 25,895行の追加収集と解釈。本レポートはDB実値を採用、判定は「問題なし（明示的に時系列を記録済）」。

V-02 AI Development DB の三系列差 問題なし

ブリーフィング値1,097＋1,139＝2,236、Memory値同値、DB実値同値（集計L-03）。三系列が完全一致。「2,236論文DB」というラベルは正確である。判定: 問題なし。

V-03 AA 言及・出典の三系列差 要解釈

ブリーフィング値「498言及・322ソース」、Memory値「498言及」、DB実値「551言及・464出典」（集計L-05）。差異は53言及・142出典で、無視できない規模。本レポートはDB実値を採用し、ブリーフィング値498は2026年4月後半の追加収集前のスナップショットと解釈。Track 10統合時、ブリーフィング値498を引用する他Trackとの整合は要追跡。

V-04 TA technologies の年代範囲 問題なし

analysis §1.1 で「紀元前700万年〜2025年」と記載。集計L-02 でMIN(year_earliest)=-7,000,000、MAX(year_earliest)=9,500（外れ値）。MAX値の9,500はyear_latest由来の混入と解釈される。実質的な最新は2024年（AIエージェント）であり、analysis での記述は妥当。判定: 問題なし。

V-05 AA confidence_tier 分布の整合 問題なし

analysis §8.3 で「strong 23、moderate 10、tentative 38、insufficient 23、definitive 0」（合計94）と記載。集計L-27 で完全一致。is_ai_accelerated=1 は33件、is_ai_accelerated=0 は61件で合計94、整合。判定: 問題なし。

CHAPTER 03

カテゴリ2: ハルシネーション（4項目）

analysis.htmlで言及した固有名詞・年代・引用数値の真偽を実DB照会で検証する。

V-06 Transformer (2017) の被引用数 95,000 問題なし

analysis §6.5 で「Attention Is All You Need (2017) — 95,000引用」と記載（集計L-21）。AGI papers.db にてSELECT title, year, citation_count FROM papers ORDER BY citation_count DESC LIMIT 1を実行。結果: title="Attention Is All You Need", year=2017, citation_count=95,000で完全一致。判定: 問題なし。

V-07 AGI timeline 14マイルストーンの実在性 問題なし

analysis §7.1 で14のマイルストーン（1950 Turing、1956 Dartmouth、1974/1982 AI冬、1997 Deep Blue、2011 Watson、2012 ImageNet、2016 AlphaGo、2017 Transformer、2018 BERT/GPT、2020 GPT-3、2022 ChatGPT、2023 GPT-4、2024 マルチモーダル成熟）を提示。AGI papers.db timeline表のSELECT *で14件全件と一致（集計L-22）。判定: 問題なし。

V-08 7段階AGIクリティカルパスの操作的構築 要解釈

analysis §7.2 で7段階を提示。AI Development DBに直接の表として実装されておらず、本Track が approach_category 21分類とtimeline 14件から操作的に構築。これは推定であり、別の段階区分（5段階・10段階）も成立しうる。analysis §7.3で本旨を明示しているが、Track 10統合時は「Track 8 操作的構築」と記載すべき。

V-09 AAメカニズム件数 13件の実在性 問題なし

analysis §8.1 で13メカニズムを提示。SELECT * FROM taxonomy_mechanisms で13件確認（集計L-24）。HYPOTHESIS_GEN 313件・WORKFLOW_AUTOMATION 134件など、件数も完全一致。判定: 問題なし。

CHAPTER 04

カテゴリ3: カバレッジギャップ（4項目）

本Track のDB が構造的にカバーしない領域、または推論で補完するしかない部分を明示する。

V-10 very-far（2081-2100）が3DB全て射程外 構造的ギャップ

TAは2025年まで、AI Development DBは2025年まで、AAは2026-2030年代の予測言及にとどまる。very-far ホライズン（2081-2100）は3DB全てが直接の根拠を持たない。analysis §10.3・§11 で明示済み。本Trackはvery-farに対して直接答えられない。判定: 構造的ギャップ。Track 1（FK）／Track 2（CLA）／Track 6（GPT-QoL）/ Track 4（Anthropology）等との統合で補完する必要あり。

V-11 CTL-V／CTL-G／CTL-S の構造的少数性 構造的ギャップ

3DB全体としてCTL-T（技術・知）に圧倒的集中。AAでもCTL-T系（COMP-SCI/LIFE-SCI/PHYS-SCI等）が60%以上、CTL-V（HUMANITIES 14件・CREATIVE 19件）／CTL-G（LAW-POLICY 15件）／CTL-S（SOC-SCI 26件・EDUCATION 25件）は20%未満。LLM論文1,097件のうち倫理系（Safety/Bias/Privacy/Societal Impact等）合計は10%未満。本Track は技術発展の「実態」は精緻に語れるが、「社会的・倫理的含意」は推論レベル。Track 7（哲学）／Track 2（CLA）／Track 1（FK values領域）必須。判定: 構造的ギャップ。

V-12 AA 2024-2025年への集中バイアス 構造的ギャップ

AA 551言及のうち2024年275件＋2025年133件＝408件が74%を占める（集計L-08）。これはAA が〈直近2年間のAI加速言説の集積〉という性質を強く持つことを意味する。Track 3（megatrend）が指摘した「過剰的中」概念の対象になりうる解釈。本Trackの加速ドメインTOP30判定は、この集中バイアスを引き継ぐ可能性が高い。判定: 構造的ギャップ。Track 3「過剰的中」枠組み・Track 5（Signal）の予測力評価で再検証必要。

V-13 tech_to_tech 354件の網羅率 要追跡

TA technologies 1,191件に対し、tech_to_tech 354件・science_to_tech 133件は連鎖関係として少数。可能な関係数（n×(n-1)/2 ≒ 70万件）の0.05%（集計L-12）。「enables 関係」（221件・62.4%）の網羅性は限定的。analysis §4.3 で〈過去の技術発展は積層的〉と主張するが、その根拠強度はやや弱い未検証。判定: 要追跡。Track 6（GPT-QoL）が tech_to_tech 拡張を行う場合は、本Track の主張を再検証可能。

CHAPTER 05

カテゴリ4: チーム間不整合（3項目）

他Track（Track 1 FK、Track 2 CLA、Track 3 megatrend、Track 5 Signal、Track 7 academic）の主張と本Track の主張に矛盾がないか検証する。完了済みTrackは1/2/3/5/7。

V-14 Track 3「過剰的中」概念との整合 要追跡

Track 3 は「生成AI（Dai 14）が総論的中・速度規模超過＝過剰的中」と判定。本Trackも analysis §7.3 で「Stage 5 以降の進展は2017年Transformer時点での予測を質的・量的に上回っている可能性」と解釈を提示。両Track は同方向の主張だが、本Track は「過剰的中」の用語を分析中で導入していない。Track 10統合時は「Track 3定義の過剰的中＝Track 8 Stage 5-6の量的超過」として接続記述を追加すべき。判定: 要追跡。

V-15 Track 1（FK）「AI領域90%占有・values 0.45%空白」との関係 要追跡

Track 1（FK）は「AI領域90%占有・values 0.45%空白」を発見。本Track の analysis §3.2・§6.3・§8.2で「3DB全体としてCTL-T主軸、CTL-V／CTL-G／CTL-Sは少数」と述べる。両Trackは独立に〈AI領域の言及過剰と価値観・倫理領域の薄さ〉を確認している。これはMサイン（複数Track合意）の有力候補。Track 10統合時は「Track 1とTrack 8の独立的合意」として強調するべき。判定: 要追跡。

V-16 Track 5（Signal）のメインストリーム化年数推定との整合 要追跡

Track 5 は AA を補完DBとして使用、メインストリーム化年数推定（5次元予測力評価）を実施。本Track は AA を主軸DBの一つとして使用。両者の AA 言及の解釈に差が出る可能性あり未検証。本Track の near ホライズン加速ドメインTOP30 と Track 5 のメインストリーム化年数推定が整合するか、Track 10で照合必要。例: Track 8「2030 主流化完了 = 生成AI／LLM」と Track 5 のメインストリーム化年数推定の対応を確認。判定: 要追跡。
