CHAPTER 00

本検証の目的

本書は track4-historical-analysis.html（解析レポート）に対する自己検証文書である。Track 1（FK）verification.html、Track 3（MT）verification.html を参照モデルとし、4カテゴリ16項目の独立検査を実施する。

検証カテゴリは次の4つ。カテゴリ1（スナップショット不整合）では、ブリーフィング値・公開値・DB実値の三系列差を再記録し、各系列の判定（問題なし／要解釈／要追跡／要修正／構造的ギャップ）を付与する。カテゴリ2（ハルシネーション）では、analysis.html 本文中の固有名詞・数値・引用が DB に実在するかを照合する。カテゴリ3（カバレッジギャップ）では、4DBが構造的に扱えない領域・時代・文明圏を開示する。カテゴリ4（チーム間不整合）では、Track 1/2/3 との数値・解釈の矛盾候補を提示する。

本検証はLead Researcher自身が実施しているため、独立性は限定的である。後続の /doc-verify エージェントおよび sentinel エージェントによる完全独立検証を経て、最終的に Track 10 統合の入力となる。

CHAPTER 03

カテゴリ3: カバレッジギャップ

V-14: SIF 2027-2029 未来日付レコードの品質課題

SIF DB に対して以下を実行：

SELECT name_jp, year_start, type FROM si_events
WHERE year_start>=2027 ORDER BY year_start DESC LIMIT 20;
-- 平手友梨奈による女性社会運動 / 2029 / civil_rights
-- 樋口新葉による女性社会運動 / 2029 / civil_rights
-- 本田真凜による女性社会運動 / 2029 / civil_rights
-- 山下美夢有による女性社会運動 / 2029 / civil_rights
-- 廣中璃梨佳による女性社会運動 / 2028 / civil_rights
-- ... (推定数十件)

これらは 女性スポーツ選手の名前と将来日付がペアで civil_rights に分類されたレコード群。内容と類型のミスマッチ、未来日付（DB作成時点で未来）の含有は、SIF収集パイプラインのテストデータ混入または分類器エラーと推定される。判定: 構造的ギャップ。本Track 4ではこれらを除外せずそのまま使用したが、Track 10統合時には除外推奨。

V-15: SIF civilization ラベルの異常分類（doc-verify 追加確認: 体系的問題）

analysis.html 第3章 L-17・L-18 で確認したように、ジョン・デューイ（米国）・W.E.B.デュボイス（米国）・ベーデン＝パウエル（英国）等の 欧米の知識民主化人物が civilization=east_asian に分類されている。デューイ（1859-1952）はバーモント州出身、デュボイス（1868-1963）はマサチューセッツ州出身であり、east_asian 分類は明確に誤りである。シュメール（V-07）の islamic 分類と合わせ、SIF DBは civilization カラムに体系的なラベリングエラーが存在すると判定される。判定: 構造的ギャップ。

doc-verify 独立照会による追加確認（2026-05-09）: SIF prrrc TOP10 を独立照会した結果、TOP10中8件が east_asian に誤分類されていることが確認された。具体的には、マハトマ・ガンディー（正: south_asian）・W.E.B.デュボイス（正: western/americas）・ジョン・デューイ（正: western）・ブッカー・T・ワシントン（正: western/americas）・カーター・G・ウッドソン（正: western/americas）・ヤヌシュ・コルチャック（正: western）・レイチェル・マクミラン（正: western）・マーガレット・マクミラン（正: western）の8件が east_asian に誤分類されており、唯一正しいのは南梅吉（east_asian 実在）の1件のみであった。知識民主化（knowledge_democracy）系で Western pioneers が east_asian に集中的に誤分類される傾向が確認されている。誤分類の規模は10%前後と推定されるが、knowledge_democracy 系で特に高頻度であり非一様分布である。

影響: 本Trackの「文明圏分布」（集計L-03）の east_asian=1,725 は実際には誤分類が含まれるため、東アジアの真の事象数は推定値より少ない可能性がある解釈。とくに TOP10 #03「非西洋認識論」の C=4 評価への影響: 軽微〜中程度（SIF civilization 誤分類により C=4 は上限値、実質的には C=3〜4 の範囲。east_asian 過大計上を含む可能性があるため、非西洋系シェア計算への SIF civilization カラムの直接使用は慎重を要する）。Track 10 統合時には「SIF civilization カラムは要正規化、非西洋系シェア計算には civilization カラムを使用しない」のフラグを立てることを推奨する。

V-16: SIF type ラベルの過剰分類

L-04 の SI類型分布で、複数の小カテゴリ（power=52 / knowledge=32 / rights=31 / identity=28 / crisis_response=28 / rules=26 / rule=13 / knowledge_production=9 / resource=8 / infrastructure=8 / technology=5 / redistribution=3 / resource_change=2）が存在する。これらは元来「公共財型／社会的保護型／市民権型／知識民主化型／民主的意思決定型／複合型」の6類型に整理されるべきだが、後発の収集パイプラインで新カテゴリが追加された結果と推定される。合計245件（3.3%）。判定: 要追跡。Track 10統合時に正規化が必要。

V-17: HIC の文明圏偏り

HIC 20ケースの地域分布を再集計すると：欧米8（Medici/VOC/Rockefeller/Carnegie/Coca-Cola/Disney/Bogle/Newton/Copernicus/Luther/Napoleonic/Apollo＝12ケース）／東アジア5（Mitsui/Iwasaki/Keju/JackMa/Jam一部）／中東・古代地中海3（Alexander/Christianity/Gandhi はインド）／南アジア1（Gandhi）。欧米偏重（60%以上）であり、Track 3 修正版18MT R18「非西洋認識論」を補強する材料は限定的。判定: 構造的ギャップ。

V-18: GF 文明圏偏り

L-27 の region_primary 分布で Europe + North America = 3,705人物（40.4%）、アジア合計 2,730（29.7%）、アフリカ・中南米合計 1,011（11.0%）。欧米偏重はSIFよりも強い。判定: 構造的ギャップ。

V-19: TA 古代技術の薄さ

L-43 で paleolithic+neolithic+prehistoric = 93件（7.8%）に対し、digital+industrial+modern = 793件（66.6%）。古代5万年（旧石器時代）が93件、近代250年が793件という極端な記録偏差。これは「歴史記述自体の近代偏重」と「DB収集アクセシビリティの差」が重なる結果と解釈される。判定: 構造的ギャップ。

V-20: CTL-Env（環境・気候）の薄さ

4DB横断で環境・気候を直接扱うレコードは TA owid_co2 50,411行・owid_energy 23,232行に限られ、これらも1750年以降の単一系列指標である。過去5,000年スパンの環境変動が DBレベルで構造化されていない。SIF にも環境SIタイプは存在しない（type=resource は8件のみ）。判定: 構造的ギャップ。

V-21: 共通スパン（near/mid/far/very-far）の直接マップ困難

本Trackの主軸4DBはほぼ全件が「過去」であり、共通スパン4ホライズンに直接マップできるレコードはほぼ存在しない。SIF 2027-2029 レコードは V-14 の品質課題により実質的に使用不能。本Trackは 過去サイクルからの外挿を主たる手法とせざるを得ない。判定: 構造的ギャップ。これは本Trackの方法論的特性であり、Track 1（FK 23,274予測）・Track 8（PESTLE 196,714ニュース）等とは根本的に異なる。Track 10統合時に「歴史外挿型」と「実DB件数型」の方法論的差異を明示する必要がある。

CHAPTER 04

カテゴリ4: チーム間不整合

V-22: Track 1 「FK 23,274予測の2030近傍56.4%集中」と本Track 「過去5,000年で1700-1900に57.2%集中」

両者は 異なる時間軸での「集中」現象を別々に観察している。Track 1は 未来予測の集中、本Trackは 過去事象の集中。両者は矛盾しないが、Track 10統合時に「集中の二重構造（過去近代＋未来近傍）」として整理する必要がある。

判定: 要追跡（Track 10統合時に二重構造として明示）。

V-23: Track 2 (CLA) 「物語の交代期（5系統失効＋5系統萌芽）」と本Track 「サイクル A 500年認知転換」

両者は方法論が異なるが、「現代がパラダイム転換期である」という結論で部分的に一致する。Track 2は1900-2026年の127年スパン、本Trackは過去5,000年スパン。Track 2の「物語の交代期」を本Trackのサイクル A の文脈に位置づけると、AI革命2017以降の認知転換が4-50年の急速な変化として進行中と解釈できる。両者の連動を深く検証することは Track 10 の課題。

判定: 問題なし（むしろ補完関係）。

V-24: Track 3 (修正版18MT) 「過剰的中（生成AI）パターン」と本Track 「双子峰プラトー (AI革命=産業革命×1.05倍)」

Track 3は「生成AIが総論的中・速度規模超過」と判定したが、本TrackはCTI v2を引いて「AI革命は産業革命を1.05倍だけ上回るに過ぎない（双子峰）」と提示する。2つの主張は時間スケールで両立する：Track 3は短期（10年）の現象、本Trackは長期（5,000年）の構造変革強度。

判定: 要解釈（両論を併置し、Track 10で「AI革命の評価軸が時間スケールで変わる」として整理する）。

V-25: Track 3 R17「世代間正義」R18「非西洋認識論」と本Track 「サイクル A 認知転換軸」

Track 3が新設したR17・R18は、本Trackのサイクル A（500年認知転換）の射程上で 2070-2100年に顕在化するテーマ群として位置づけられる。とくに R18「非西洋認識論」は本Trackの「Asia + Africa + Americas + Pacific 計2,624件（SIF 35.5%）」と接続する基盤がある（V-18の欧米偏重課題はあるが、SIFはGFよりも非西洋を厚く扱う設計）。本Trackは Track 3 の R17・R18 と 強連結。

判定: 問題なし（Track 3との連結は M サイン候補）。

V-26: Track 3 R5「少子化加速・人口減少社会」と本Track 「サイクル B 帝国・組織興亡」

Track 3はR5を「near/mid/far/very-far 全ホライズンで重要度H」と評価。本TrackのサイクルB（150-300年制度興亡）の射程に入るが、SIF・HIC・GFには直接「人口減少」を扱う事象が極めて少ない（SIFで「人口」キーワード検索でも限定的）。本Trackは Track 3 R5 を補強する力が弱い。

判定: 要追跡（Track 6（人材軌道）または Track 8（PESTLE）が補完するべき）。

V-27: 本Track「TA technologies AI=10件」とTrack 1「Generative AIに関する予測」

本Trackは TA technologies のAI領域がわずか10件と確認した（L-44）。一方Track 1のFKでは生成AIに関する予測が多数記録されている。これは 「TAの技術記録は学術論文・特許起点（既成立技術）、FKは将来予測（未成立技術）」という収集設計の差異を反映する解釈。両者は矛盾せず、相補的に機能する。

判定: 問題なし（収集設計の差異）。

6.2 主要発見

第一に、4DB全てに「近代以降に集中する記録バイアス」が存在することが共通して確認された。SIF（1700-1900で57.2%）、GF（1800-1900で35%）、TA（digital+industrial+modern で66.6%）、HIC（1500-1900で14ケース・70%）。これは本Trackの方法論を制約する基底条件である。

第二に、SIF DB に体系的なラベリングエラー（civilization の異常分類、type の過剰分類、未来日付レコード）が確認された。本Trackではこれらを除外せずに集計したため、analysis.html の数値には軽度のノイズが含まれる。Track 10統合時には、SIF DB管理者と協働して正規化することが望ましい。

第三に、本Track独自の長期サイクル仮説（A・B・C）はいずれも外挿的解釈を含む。500年認知転換サイクル、150-300年制度興亡サイクル、産業革命以降250年プラトーは、4DB集計から数値的根拠を持つが、その「周期性」自体は時系列分析の統計的検証を経ていない。Track 10で必要に応じて統計家による独立検証を求める。

6.3 Track 10 統合への送り（VETO候補）

本Trackから Track 10 統合プロセスへ送る重要事項：

  1. SIF DB品質課題の認知（V-14・V-15・V-16）：Track 4 の数値はノイズを含むため、Track 10 のメタ統合で SIF を引用する際は注意喚起が必要。
  2. 4DBの「近代偏重バイアス」（V-19）：歴史記述自体の構造的偏りを Track 10 メタ統合レポートで明示すべき。
  3. 本Trackの「歴史外挿型」方法論（V-21）：Track 1（実DB件数型）・Track 8（リアルタイムニュース型）と異なる方法論であることを Track 10 で類別する必要がある。
