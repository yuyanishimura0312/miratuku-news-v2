## 0. 第二弾の核心方針（西村氏の指示）

1. **第一弾と同じ内容では意味がない** — 内容の重複ではなく、第一弾を踏み台にした深化と新軸の追加で意味を成立させる
2. **7+1の問いを「より深く問う」** — 第一弾が「展開・翻訳」した問いを、第二弾では「掘り下げ・反転・解体」する
3. **読者が「より深い問いを身につけるプロセス」を加える** — 100話を読む行為自体が「問う力の習得カリキュラム」になる設計

## 1. 第一弾と第二弾の関係（差別化マトリクス）

| 軸 | 第一弾「Futures」 | 第二弾「Futures II（仮）」 |
|---|---|---|
| **編集者視点** | Translational Editor（翻訳） | **Cultivation Editor（育成・深化）** |
| **問いとの関係** | 7+1問を**展開する** | 7+1問を**深化させ・問い返す** |
| **読者の位置** | 翻訳された未来洞察の受け手 | **自ら深く問う主体への移行者** |
| **構造軸** | LP5部 × 8問 × 書籍13章（三軸織り） | **深化軸 × プロセス軸 × 問いの解体軸（三軸織り）** |
| **エピソード機能** | 1話=1テーマの翻訳 | **1話=1つの深化動作＋1つの稽古** |
| **末尾要素** | SIGNAL + KEY REF + QUESTION | SIGNAL + KEY REF + **問いの稽古プロンプト** + 問い直し記録 |
| **学術アンカー** | 哲学25 / 人類学20 / 文学20 / 神話15 / 伝統知20 | **問いの哲学（ハイデガー・ガダマー）／対話・教育（フレイレ・P4C）／東洋（禅・道元）／心理（ナラティブ）／実践（Theory U）** を再配分 |
| **読了後の到達点** | 7+1の問いを「知っている」状態 | 7+1の問いを「自分のものとして問える」状態 |
| **第一弾参照** | 独立完結 | **第一弾の特定話を「問い直し対象」として明示参照** |

## 2. コンセプト案（3候補・意思決定要）

### 案A: 「問いを、もう一度問う」
- 副題: 「Futures II — 我々が選んだ問いの、もう一段奥へ」
- 強み: 第一弾との連続性が直感的、「もう一度」が読者を招き入れる
- 弱み: 「もう一度」は反復のニュアンスを含み、深化を強調しきれない

### 案B: 「問いを生きる」
- 副題: 「Futures II — 深い問いと共に在るための100話」
- 強み: プロセス軸（読者の問う力育成）を前面化、実存的トーン
- 弱み: 第一弾との関係が見えにくい

### 案C: 「問いの問いへ」（推奨）
- 副題: 「Futures II — 7+1の問いを深く生きる100話」
- 強み: 問05「問いの問い」がもともと第一弾の中核にある。それを連載全体に拡張するロジックが立つ。深化軸とプロセス軸を同時に表現
- 弱み: 抽象度が高く読者選好を狭める可能性

**推奨: 案C**（西村氏の最終判断待ち）

## 3. 構造軸の設計

### 3.1 深化軸（"the question behind the question"）

第一弾の各問に対し、**問いの背後にある前提・問いの構造・問い手の立場**を問い返す層を加える。例（リサーチ完了後に精緻化）:

| 第一弾の問い | 第二弾で問い直す層（暫定） |
|---|---|
| 問01 未来世代の声を聞くか | **私たちは未来世代を「声を持つ主体」として想像できているか／聞く側の枠組みごと書き換えられるか** |
| 問02 先住民の知恵を学べるか | **「学ぶ」という関係そのものが既に植民地的ではないか／対等とは何の比較における対等か** |
| 問03 「どこにいるか」が大事 | **「場所」を語る私たちはどこに立っているか／場所性の語り自体が場所を失わせていないか** |
| 問04 複数の世界観が並び立つか | **「並び立つ」を構想する一元的視点が残っていないか／不可通約性をどう生きるか** |
| 問05 自分の問いを問えているか | **問えていないことを、どう知るのか／問いの不在の感触をどう感じ取るか** |
| 問06 ケアを学ぶ教育 | **教育という枠でケアを語ることの限界／ケアは学べるのか、それとも身に染みるのか** |
| 問07 西洋以外の知を認められるか | **「認める」主体が依然として西洋的構造に立つ問題／「認める／認められる」の非対称性をどう解体するか** |
| 問08 ひとつの自分でなくていい | **「ひとつ」と「複数」の二項が既に近代的か／自己を数えること自体への問い** |

> リサーチ結果（ハイデガー・ガダマー・道元・フレイレ等）の確定後、各セルの哲学的根拠と具体的展開を上書き。

### 3.2 プロセス軸（読者の問う力カリキュラム）

100話を通じて読者の問う力が段階的に深まる。暫定モデル（リサーチ完了後にDreyfus・Theory U・P4Cと突合し決定）:

| 段階 | 話数 | 読者状態の遷移 | 主な稽古動作 |
|---|---|---|---|
| **発掘** | 1-20 | 自分の問いに気づく | 既知の問いを書き出す／避けている問いを発見する |
| **深化** | 21-50 | 7+1問それぞれを深く問い直す | 前提を疑う／反転させる／主語を入れ替える |
| **解体** | 51-70 | 「問うている自分」を問い直す | 問いの自己言及／問いの不在を感じる |
| **共同化** | 71-85 | 他者と問いを生きる | 場づくり／対話／問いの場 |
| **継承** | 86-100 | 問いを次世代に手渡す | 残す／継ぐ／2100年への手紙 |

### 3.3 問いの解体軸（メタ機能）

各話に**「この話で問い直されている前提」**を明示し、第一弾の対応話を参照リンクで示す。読者は「第一弾のあの話のここを掘っているのか」と読む。第一弾を読まずに第二弾を読むこともできるが、両方読むと立体化する設計。

## 4. 100話の章立て案（5部構成・第一弾の5部とは別軸）

### 第1部 「問いを発掘する」（1-20話）
**主題**: 自分が何を問い、何を問わずに来たかに気づく。
- 1-3: 問いとは何か（哲学的導入）
- 4-10: 7+1の問い各話を「自分の問いとして引き受ける」稽古
- 11-15: あなたが避けている問い（「不在の問い」の感触）
- 16-20: 第一弾を「問い直し対象」として読む読書法

### 第2部 「問いを深める（前半・規範系）」（21-50話）
**主題**: 問01・02・04・07・08（規範系）を深化させる。
- 21-26: 問01深化（未来世代の構築可能性／時間の他者）
- 27-32: 問02深化（学ぶことの植民地性／対等の非対称性）
- 33-38: 問04深化（不可通約性／複数性の倫理）
- 39-44: 問07深化（認める主体の解体）
- 45-50: 問08深化（自己を数えることの起源／前-自己論）

### 第3部 「問いを深める（後半・実装系＋メタ）」（51-70話）
**主題**: 問03・06（実装系）と問05（メタ問い）を深化させる。
- 51-56: 問03深化（場所を語る場所／場所性の語りの落とし穴）
- 57-62: 問06深化（教育という枠の限界／浸透するケア）
- 63-70: 問05深化（問いの不在／問いの自己言及／問いの問い）

### 第4部 「問いを共同で生きる」（71-85話）
**主題**: 問いを一人で持つことから、他者と共に問う場へ。
- 71-75: 対話の系譜（ボーム／フレイレ／P4C／Theory U）
- 76-80: 場の作法（茶道／円座／開かれた問いの場）
- 81-85: AI時代の問い（人＋AI／問うAIではなく、AIと問う人間）

### 第5部 「問いを残し継ぐ」（86-100話）
**主題**: 問いを次世代に手渡す。問いそのものを未来に残す。
- 86-90: 「答えない」という応答（残された問いの倫理）
- 91-95: 2050・2070・2100への手紙（各時間軸への問い）
- 96-99: 7+1の問いを次の世代に手渡す（各問の最終回）
- 100: 問いの問いを、あなたが問う番（読者への引き渡し）

## 5. 1話の構造（第一弾フォーマットからの拡張）

```
[冒頭シーン 200-250字] — 具体的場面から
[本文展開 1,000-1,100字] — 6段落、深化動作1つ・前提の暴き1つ
[SIGNAL] — 2024-2026の実例（第一弾と同形式）
[KEY REF] — 古典＋現代の2本立て（第一弾は1本中心、第二弾は古今2本で深化を強調）
[第一弾対応話] — 第一弾の何話を問い直しているかリンク（新設）
[問いの稽古] — 読者が自分で1問立てる/反転する/書き出す具体プロンプト（新設）
[QUESTION] — 次話に繋がる問い（第一弾と同形式、ただし読者の問いの記録欄を視覚化）
```

合計1,500-1,800字（第一弾より少し長い）。

## 7. 第一弾との独立性と接続性

- **独立性**: 第二弾は単体で完結する。読者は第一弾を読んでいなくても入れる
- **接続性**: 各話に「第一弾◯話を問い直す」明示参照を置く。両方読んだ読者は立体的な経験を得る
- **書籍展開**: 第一弾は書籍13章と対応した。第二弾は**新書籍「問いの問いへ」（仮）13章と対応**させ、書籍2冊で対をなす設計を推奨

## 付録: 用語

- **深化軸**: 第一弾の問いを掘り下げ、問いの前提や問い手を問い返す軸
- **プロセス軸**: 読者が100話を通じて問う力を獲得するカリキュラム軸
- **問いの解体軸**: 各話で問い直されている前提を明示するメタ機能
- **問いの稽古**: 各話末尾の、読者が自分で問いを立てる実践プロンプト
- **Cultivation Editor**: 翻訳ではなく、読者の問う力を育てる編集者視点
