## 統括所見

### 共通する強み

1. **暮らしの場面から始める** という編集理念がいずれも体現されている（駅前の桜／産院の窓）。Translational Editor の作法を Writer チームが内面化していることがうかがえる。
2. **DEEPER の学術系譜編集**が両話とも一段落で50年〜80年の蓄積を凝縮できており、典拠の年表記もすべて完備。**ハルシネーション疑義はほぼゼロ**（ただし Ep3 の EU Commissioner 2024 議論入りは一次ソース要追加）。
3. **SIGNAL の並列構造**が両話とも機能しており、固有名詞・年・組織名すべて記載。
4. **字数規定**（本文1,500字±200／DEEPER 400-500／SIGNAL 200）を完璧に守っている。
5. **段落構成6段落・冒頭の具体性・英字濃度**は両話ともガイドラインA級水準。

### 共通する弱点

1. **【致命級・連載横断課題】文体規定の不徹底**: ガイドライン A-2 は「Futures は常体（だ・である調）原則、kurashi はですます調」と明記しているが、両話とも全面ですます調。これは執筆者個別の問題ではなく、**Writer チームへの執筆オーダー（プロンプト）に常体指示が抜けていた可能性**が高い。Ep4以降に持ち越す前に**執筆オーダーテンプレートの修正が必要**。
2. **【規定逸脱・連載横断課題】漢数字の混入**: 両話とも「一つ」「三つ」「一度」など熟語ではない数詞に漢数字が使われている。これは feedback_arabic_numerals ルールおよびガイドライン A-2 の明確な違反。執筆オーダーに「漢数字は『一人ひとり』『四半世紀』等の熟語以外は不可」を明記する必要がある。
3. **構造9要素のうちメタ情報が原稿に明記されていない**: 対応Q／書籍章／人文知領域／既存8話Q詳細記事リンクが原稿レベルで欠落。HTML 公開時に hero box のメタ表示部に補完される設計かもしれないが、**原稿マークダウン段階で frontmatter または冒頭メタブロックに明記する運用に変更**することを推奨。
4. **pullquote 不在**: 両話とも pullquote が配置されていない。ガイドラインB-2は「推奨」のためB級項目だが、連載の象徴となる核心命題（Ep2「坂を上り終わったわけでも下り終わったわけでもない」／Ep3「70年は予測の単位ではない、責任の単位だ」）は pullquote として独立配置すべき強度を持つ。
5. **KEY REFERENCE 短文解説の有無で連載内フォーマットが揺れている**: Ep2 は省略、Ep3 は完備。**Ep3 の形式（書誌＋30-60字短文解説）を標準フォーマットに固定**することを推奨。

### 次話以降への申し送り事項
