# Codex 執筆ブリーフ — LAB セクション追加

連載「未来のかたち」の各話には、人文知（哲学・人類学・文学・神話・伝統知）を本文に織り込んだうえで、DEEPER（人文知の学術系譜）と SIGNAL（直近の現実世界の動き）の追記欄がある。今回はそこに新たに **LAB（科学の知から）** を加える。各話の本文テーマを踏まえ、対応する **自然科学・工学** の研究者・概念・年代を 400-600字で書く。

## 必須条件
- **字数: 400-600字**（1段落 or 短い2段落、合計）
- **文体**: 「〜である」調、主語「我々」（連載と統一）
- **領域**: 神経科学／認知科学／環境心理学／生態学／地球科学／医療工学／建築工学／情報科学／通信工学／AI・ロボティクス／システム工学／統計物理 などから、本文テーマに対応するものを選ぶ
- **必ず**: 研究者名 + 論文/書籍名 + 年代（西暦）の組を **最低3組** 入れる
- **平らな日本語で、具体的に**: 暮らしの言葉に翻訳しつつ自然科学・工学の系譜を示す

```

### 第27話「川が裁判所に立つ日 — 法人格を持つ自然」
- 人文知: 伝統知（マオリの「ワカ＝祖先川」）／哲学（ブルーノ・ラトゥール『自然の政治』）
- 学術領域: 環境法／ポストヒューマン政治理論
- 本文（BODY）:
```
朝の川べりに立つと、水はただ流れているだけではない。岸の草を濡らし、石の角を丸め、漁の記憶を運び、子どもの長靴を冷やす。大雨のあとには濁りを抱え、渇水の夏には底石をあらわにする。2017年、ニュージーランドのワンガヌイ川は法人格を得た。川が人のように暮らすわけではない。だが法の上では、権利と利益を持つ存在として扱われるようになった。水面の光が条文の中に入り、川は背景ではなく制度が応答すべき相手として現れた。

この制度は突然生まれたものではない。マオリの人々にとって、ワンガヌイ川は単なる資源ではなく、祖先であり、系譜の一部である。「私は川であり、川は私である」という言葉は比喩ではなく関係の記述である。西洋法は長く、土地や水を所有物として扱ってきた。Te Awa Tupua Act 2017は、その言葉を組み替え、祖先川を一つの法的人格として迎えた。植民地化の歴史の中で奪われた関係を、完全ではないにせよ、法の内側で結び直そうとしたのである。

制度の工夫は、二人の守護者を置いた点にもある。政府側とマオリ側から選ばれた者が、川の声を代表する。もちろん、川は会議で発言しない。だから代表者は、流域の生態、歴史、儀礼、漁、暮らしを聞き分けなければならない。Christopher Stone『Should Trees Have Standing?』（1972）が投げた問いは、ワンガヌイで制度の形を得た。法人格とは川を人間に似せることではない。人間の側が、川に応答する席を法の中に設けることである。

哲学者ブルーノ・ラトゥールは『自然の政治』（1999）で、自然と社会を別々の箱に入れてきた近代の癖を問い直した。環境問題では、科学者が自然を語り、政治家が社会を語るという分業だけでは足りない。川、土、微生物、漁師、子ども、行政官が絡み合う場を、どう政治の中に作るか。ワンガヌイ川の制度は、その問いを具体化した。近代法の所有の言葉と、マオリのファカパパの言葉が緊張しながら同じ条文に入ったとき、自然は沈黙した対象から、翻訳を必要とする参加者へ移った。

エドゥアルド・コーン『森は考える』（2013）は、人間だけが意味を作るという前提を揺らした。森の生きものは、匂い、足跡、鳴き声、気配を通じて互いに応答する。川もまた、濁り、氾濫、魚の減少、岸辺の崩れを通じて語る。インドのガンジス川判決やコロンビアのアマゾン流域をめぐる判断は、この感覚を別の法文化で試した。だが声を聞く人間の制度は、つねに権力を持つ。誰が川の声を翻訳するかという問いは、法人格の中心に残り続ける。

> 川に権利を与えるとは、人間の法を川の流れに近づけることである。

日本で翻訳するなら、すぐに難しさが見える。河川は治水、利水、発電、農業、観光、信仰の結び目である。大雨の夜に堤防を見回る人もいれば、鮎を追う人、川辺で祖父を思い出す人もいる。川の権利を語るには、抽象的な自然愛では足りない。流域の生活をまるごと聞き、誰が代表し、誰に説明するかを決める制度がいる。権利という言葉は強いが、その実務は河川台帳、漁協、自治会、学校、神社、工事計画をつなぐ地味な作業である。子どもが遊ぶ浅瀬を残すことも、増水時の避難路を整えることも、川の声の翻訳に含まれる。

川が裁判所に立つ日は、人間が退く日ではない。むしろ人間が、自分の位置を少しずらす日である。我々は川を守る善意の管理者ではなく、川に生かされる関係者である。法は人間のためだけに作られてきたのか。その問いに、ワンガヌイ川は静かに、しかし長い流れで答えている。自然に法人格を与えるとは、人間中心主義を一夜で終える魔法ではない。人間の制度を、非人間の時間と傷に向けて開く手続きなのである。
```

### 第28話「環境訴訟の最前線 — Urgenda判決とその後」
- 人文知: 哲学（ハンス・ヨナス『責任という原理』）／文学（クライメート・フィクション、Kim Stanley Robinson『未来省』）
- 学術領域: 環境法／法哲学
- 本文（BODY）:
```
夏の夜、寝室の窓を開けても熱が抜けない。高齢の親は眠れず、子どもの水筒は朝から空になる。遠い北極の氷や海面上昇は、こうして台所の温度計と救急搬送の数字に変わる。オランダのUrgenda判決は、この気候の危険を裁判所の木の机に載せた。2015年に地裁が国に削減を命じ、2019年に最高裁で確定したのである。気候変動は、遠い自然現象から、国家の義務を問う事件へ移った。空の暑さが、政策の遅れを測る証拠になったのである。

判決の中心にあったのは、注意義務という考え方である。国家には、市民の生命と生活を守る義務がある。気候変動の危険が十分に知られているのに必要な対策を怠るなら、それは政策判断の範囲を超える。裁判所は政府に代わって政策を作ったのではない。政府が守るべき最低限の責任を、法の言葉で確認したのである。ここで問われたのは、気候政策の好みではなく、危険を知りながら放置することの正当性であった。

気候訴訟が難しいのは、被害と原因が遠く広く散っているからである。今日の排出が、どこかの島の高潮になり、未来の子どもの熱中症になる。煙突の前に立つ一人の加害者を見つけることはできない。だが、だから責任が消えるわけではない。我々は責任を一本の線ではなく、網の目として考え直す必要に迫られている。Urgenda判決は、その網の目の中で国家が持つ太い糸を見逃さなかった。市場や家庭の努力だけでは届かない領域に、法は公共の義務を見たのである。

ハンス・ヨナスは『責任という原理』（1979）で、技術文明の力が大きくなった時代には、倫理も未来へ伸びなければならないと論じた。近くの相手にだけ配慮する古い倫理では、原子力や気候変動の規模に届かない。まだ生まれていない者の壊れやすさを、現在の行動の前に置くこと。気候訴訟は、この哲学を法廷の言葉に翻訳している。ジョン・ロールズ『正義論』（1971）の世代間正義も、ここで新しい切実さを帯びる。未来は抽象名詞ではなく、今日の排出枠に押し込められた自由なのである。

Kim Stanley Robinson『未来省』（2020）は、未来世代のための省が気候危機に向き合う世界を描いた。そこでは政策、金融、科学、外交、暴力が入り乱れる。現実の裁判は小説ほど劇的ではないが、同じ問いを抱えている。誰が未来を代表し、どの程度まで国家に行動を求められるのか。ドイツ連邦憲法裁判所の2021年気候保護法判決は、将来世代の自由を先に食いつぶす政策を問題にした。文学が未来の制度を想像し、法が現在の義務を引き寄せる。その往復が、気候訴訟の想像力を支えている。

> 気候訴訟とは、未来の被害を現在の責任へ引き戻す技法である。

この抽象を暮らしに翻訳すれば、訴訟は地球を守る大きな言葉だけではない。通学路に日陰がないこと、豪雨のたびに地下道が沈むこと、電気代を恐れて冷房を切ること、漁の季節がずれることを、国家の責任として語り直す行為である。自治体の避難計画、学校の校庭の木、鉄道の止まり方、病院の熱中症対応も、気候政策の内側にある。気候政策は排出量の表だけでなく、眠れる夜、働ける昼、逃げられる道を守る制度なのである。訴えるとは、生活の小さな異変を公共の義務へつなぎ直すことである。

Urgenda以後、裁判所は気候政策の外野ではなくなった。もちろん、すべての訴訟が勝つわけではない。司法がどこまで踏み込むべきかという慎重な議論も必要である。だが市民が国を訴える道が開かれたことで、気候政策は「できれば望ましい努力」から「怠れば問われる責任」へと、少しずつ重心を変えている。未来世代の声は法廷で直接話さないが、原告、市民団体、科学者の証拠を通じて、現在の政府の前に立つのである。
```

### 第29話「子どもが議会に立つ日」
- 人文知: 哲学（ハナ・アレント『人間の条件』）／文学（小川洋子『博士の愛した数式』に見る世代の橋渡し）
- 学術領域: 政治学／子ども社会学
- 本文（BODY）:
```
朝の横断歩道で、ランドセルの列が信号を待っている。車の水はね、低いガードレール、見通しの悪い角、重い教科書。子どもは政策の対象として毎日そこにいる。けれど多くの制度では、決定の参加者ではない。議会の傍聴席には座れても、議場の真ん中にはなかなか立てない。投票権を持たない人たちの声を、政治はどう聴くのか。問いは遠い未来ではなく、今朝の通学路から始まっている。歩幅の小ささは、公共空間の欠陥を見つける鋭い尺度でもある。

大人はすぐに「まだ早い」と言う。たしかに、税制や外交を子どもに丸投げするわけにはいかない。だが通学路の危険、校則、居場所、気候不安、地域の遊び場について、子ども以上に身体で知っている人はいない。政治的判断の成熟とは、年齢だけで測れるものではない。暮らしに触れていることもまた、判断の根拠である。子どもが知らないことは多いが、大人が忘れてしまったことも多いのである。我々は保護と沈黙を、あまりにも簡単に結びつけてきた。

スコットランドでは、16歳から投票できる制度が根づいてきた。学校教育と選挙参加が近づくことで、政治は遠い大人の世界ではなく、自分の暮らしに関わる行為になる。エクアドルなどでは、子ども議会の試みが続く。日本でも、こども家庭庁が子どもや若者の意見を政策に反映する仕組みを広げている。Roger Hart『Children's Participation』（1992）は、名ばかりの参加と実質的な参加を分ける梯子を示した。声を聴く制度は、参加した気分を作るだけでは足りない。提案がどこで扱われたかを、子ども自身が追えることが必要である。

ハナ・アレントは『人間の条件』（1958）で、人間が新しく始める力を「出生性」として考えた。生まれてくる者は、ただ保護される存在ではない。世界に新しい始まりを持ち込む存在である。子どもを政治に招くとは、大人の会議にかわいい意見を添えることではない。世界がまだ始まり直せるという事実を、制度の中に入れることである。ジョン・ロールズ『正義論』（1971）の公正な制度論も、将来世代へ受け渡される社会の条件を問い続けていた。アレントの始まりとロールズの公正は、子ども参加を保護政策から民主主義の課題へ押し出す。

小川洋子『博士の愛した数式』（2003）には、記憶を失う博士と家政婦の息子ルートのあいだに、世代を越えた静かな橋がかかる。知識は上から下へ渡されるだけではない。子どものまなざしが、大人の世界をもう一度やわらかくすることもある。政治参加にも同じことが言える。子どもは未来の大人ではなく、現在を生きる市民である。子どもの声は、将来のための参考意見ではなく、いまの公共を作る一部なのである。文学が描く世代の橋は、議会や行政にも必要な橋である。

> 子どもの声を聴くとは、世界の始まりを制度の中心に迎えることである。

暮らしの言葉に翻訳すれば、子ども参加とは、会議室で一度発表させることではない。校則を変えるとき、なぜ変えるのかを子どもに説明する。公園をなくすとき、使っていた子どもに代替の場所を聞く。給食や居場所の議論で、困っている子が名乗らなくても意見を出せる回路を作る。参加とは拍手ではなく、返事が返ってくる経験である。採用されない意見にも理由を返すとき、子どもは政治を大人の都合ではなく共同の作業として学ぶ。学校の児童会、地域のユース議会、オンライン意見箱は、その練習場になりうる。

もちろん、子どもの声を利用する危険はある。大人が聞きたい言葉だけを選び、写真を撮り、報告書に載せるだけなら参加とは言えない。必要なのは、どの声が採用され、どの声が採用されず、その理由は何かを返す仕組みである。子どもが議会に立つ日とは、政治が子どもに説明責任を負う日である。未来世代の代弁を考える前に、我々はまず、すでに隣にいる若い市民の声を制度の中心に置く練習をしなければならない。
```

### 第30話「代弁の倫理 — 沈黙する者の声を聴くとは」
- 人文知: 哲学（ガヤトリ・スピヴァク『サバルタンは語ることができるか』）／文学（多和田葉子『地球にちりばめられて』）
- 学術領域: ポストコロニアル理論／批判理論
- 本文（BODY）:
```
会議で「若者の声を代表して」と誰かが言う。その瞬間、部屋の空気が少し軽くなることがある。聞くべき声を聞いた気になるからである。だがその言葉の後ろに、来られなかった人、呼ばれなかった人、言葉を選び直す時間を与えられなかった人がいる。祖父母の介護で家を離れられない若者も、母語ではない言葉で意見を求められる人も、議事録の外側に残る。善意の代表は、しばしば部屋を安心させるために使われる。そこに代弁の最初の危うさがある。

「あなたの代わりに語る」ことは、しばしば「あなたの声を奪う」ことになる。これは代表をすべて拒むという意味ではない。むしろ我々は、誰かが語らなければ議題にも上がらない現実を知っている。未来世代は投票所に来られず、先住民の経験は多数派の制度に翻訳されにくい。だからこそ代弁は必要であり、同時に疑われなければならない。誰の痛みを選び、どの言葉を削り、どの沈黙を都合よく「同意」と読んでいるのかが問われる。

ガヤトリ・スピヴァクは「サバルタンは語ることができるか」（1988）で、抑圧された人々に声がないのではなく、その声を聞こえるものとして認める回路が壊されていると論じた。Edward Said『Orientalism』（1978）は、他者を語る知が支配のまなざしと結びつく構造を示した。ここでの問題は、外部の知識人がよい説明を足せば解けるという単純な話ではない。説明する位置そのものが権力を帯び、沈黙を救うつもりで別の沈黙を作るからである。未来世代を語る我々も、この構造の外にはいない。

未来世代は、さらに徹底した沈黙の中にいる。まだ存在しないため、発言の訂正も、代表者への抗議もできない。だから未来を語る人は、つねに自分を疑う必要がある。自分の価値観を未来の声として押し出していないか。現在の利益を、きれいな責任の言葉で包んでいないか。スピヴァク『ある学問の死』（2003）が問うた、他者へ近づくときの不均衡は、未来世代にも向け直される。代弁者は未来の通訳者ではなく、暫定的な仮説を差し出す者に過ぎない。
