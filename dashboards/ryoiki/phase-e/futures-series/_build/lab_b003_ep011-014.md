# Codex 執筆ブリーフ — LAB セクション追加

連載「未来のかたち」の各話には、人文知（哲学・人類学・文学・神話・伝統知）を本文に織り込んだうえで、DEEPER（人文知の学術系譜）と SIGNAL（直近の現実世界の動き）の追記欄がある。今回はそこに新たに **LAB（科学の知から）** を加える。各話の本文テーマを踏まえ、対応する **自然科学・工学** の研究者・概念・年代を 400-600字で書く。

## 必須条件
- **字数: 400-600字**（1段落 or 短い2段落、合計）
- **文体**: 「〜である」調、主語「我々」（連載と統一）
- **領域**: 神経科学／認知科学／環境心理学／生態学／地球科学／医療工学／建築工学／情報科学／通信工学／AI・ロボティクス／システム工学／統計物理 などから、本文テーマに対応するものを選ぶ
- **必ず**: 研究者名 + 論文/書籍名 + 年代（西暦）の組を **最低3組** 入れる
- **平らな日本語で、具体的に**: 暮らしの言葉に翻訳しつつ自然科学・工学の系譜を示す

## 出力形式
各話を `=== EPNNN ===` で区切る。LAB 本文のみ書く（frontmatter なし、見出しなし）。

```
=== EP004 ===
場所の重さは、神経科学の言葉でも裏付けられつつある。ジョン・オキーフは1971年、海馬に特定の地点で発火する「場所細胞」を発見し、メイ＝ブリットとエドヴァルト・モーザーは2005年、内嗅皮質に空間を幾何学的に符号化する「格子細胞」を見出した。三人は2014年にノーベル生理学・医学賞を受けている。エレノア・マグワイアの『PNAS』2000年論文は、ロンドンの道を覚え続けたタクシー運転手の海馬後部が物理的に大きくなることを示した。場所を歩き覚えるという経験は、脳の構造そのものを書き換えている。

建築と通信の側でも、場所は具体性を取り戻している。ロジャー・ウルリッヒの『Science』1984年論文は、病院の窓から木が見えるだけで術後の回復が早まることを実証し、エドワード・O・ウィルソン『Biophilia』（1984）以来のバイオフィリック・デザインへとつながった。MIT Senseable City Labのカルロ・ラッティはセンサーデータから場所の使われ方を可視化し、IPFSやティム・バーナーズ＝リーのSolidは、データを再び土地と関係に結び直す試みを始めている。場所は哲学だけでなく、神経・建築・通信のレイヤーで同時に語られはじめている。

=== EP005 ===
（次の話）
...
```

- 各話 400-600字（少なすぎ・多すぎ不可）
- 思考過程・解説は出力しない、本文のみ
- Web検索を絶対に使わない（内部知識で書く）

### 第11話「看取りを学ぶ教室 — 死がある場所」
- 人文知: 哲学（マルティン・ハイデガー『存在と時間』）／文学（三好春樹『介護とは何か』）
- 学術領域: 死生学／教育人類学
- 本文（BODY）:
```
病室の窓辺で、午後の光が白いシーツに落ちている。見舞いに来た子どもは、何を話せばよいかわからず、祖父の手を握ったまま黙っている。死は、最初に教えられる事柄ではない。小さな子どもにいきなり死を語ることには慎重さがいる。けれど最後まで教えられないままでよいのか。沈黙だけでは、別れのそばに立つ作法は育たない。死を知らないことより、死の前で一人にされることのほうが深い孤立を生むのである。

学校は長いあいだ、死を扱うことを避けてきた。死は重すぎる、家庭の問題である、宗教に触れるかもしれない。そうした理由には一理ある。だがケア教育の核心には死がある。介護も医療も福祉も、死を遠ざけるだけではなく、死が近づく時間をどう共に過ごすかを問う営みである。死を隠す教育は、弱っていく人の前で子どもを孤立させることがある。我々は命を大切にせよと言いながら、命が終わる場面を語る言葉を渡してこなかった。

マルティン・ハイデガーは『存在と時間』（1927）で、人間を「死へとかかわる存在」として考えた。難しい言い方だが、要するに我々は、いつか終わるという事実を抱えながら生きているということである。死を思うことは暗くなるためではない。限りある時間を、誰と、どこで、どう使うのかを問い直すためである。死は未来の端にあるだけでなく、今日の選び方を照らす光でもある。教育がこの光を避け続ければ、生の学びもまた薄くなる。

エリザベス・キューブラー＝ロス『死ぬ瞬間』（1969）は、死にゆく人の心理過程を社会に開いた。シシリー・ソンダースのホスピス運動は、痛みを身体だけでなく精神や関係の苦しみとして捉えた。三好春樹『介護とは何か』（1992）が教えてくれるのも、介護を単なる作業にしない視線である。体を起こす、食事を支える、排泄を助ける。その一つひとつは、死に向かう人の尊厳とつながっている。哲学の死と、介護の死は、抽象と実務の違いを越えて同じ人間の有限性を見ている。

死を学ぶ教室は、子どもに悲しみを押しつける場所であってはならない。むしろ、悲しみを一人で抱えなくてよいことを学ぶ場所である。アルフォンス・デーケン『死とどう向き合うか』（1986）が広げた死生学も、死の知識を覚えるためではなく、生と別れを語る言葉を持つためにあった。亡くなった人を語ってよいこと、泣く人のそばに黙っていてよいこと、別れのあとにも関係は形を変えて残ること。こうした小さな作法が、将来のケアの土台になる。

> 死を学ぶとは、終わりを知ることで生の手触りを取り戻すことである。

暮らしの言葉に翻訳すれば、看取りを学ぶとは、最後の日の正解を覚えることではない。弱った人の食欲が落ちたとき、無理に励まさずそばにいる。思い出話を聞き、眠っている時間を尊重し、家族が疲れていることにも目を向ける。子どもが病室に入るなら、何を言えばよいかだけでなく、黙って手を握るだけでもよいと伝える。死の教育は、死を説明する授業ではなく、別れに耐える関係を育てる学びである。子どもは死を知らないのではなく、大人が語る言葉を持たないだけなのかもしれない。

死を隠し続ける社会では、生も薄くなる。老い、弱り、別れていく過程を暮らしから消し去れば、我々は完全で元気な人間だけを標準にしてしまう。死がある場所を教育の中に戻すことは、弱さと有限性を含んだ人間を、もう一度社会の中心に置くことである。看取りを学ぶ教室は、死を早く理解させる場所ではなく、命が終わるまで人は関係の中にいると学ぶ場所である。そこから、教育は生き方の訓練ではなく、共にいる力の稽古へ向かう。
```

### 第12話「動かない人の知 — 定住の知恵」
- 人文知: 伝統知（アボリジニのソングライン／ハワイのアフプアア）／哲学（鶴見俊輔『限界芸術論』）
- 学術領域: 文化地理学／土着知識研究
- 本文（BODY）:
```
漁港の朝は、時計より先に潮のにおいで始まる。畑では、土の乾き方を指で確かめる人がいる。祭りの準備では、誰の家に人手が足りないかを、名簿を見る前に知っている人がいる。移動できる人が強い時代である。転職できる人、都市を渡れる人、国境を越えられる人。だが動かない人の知恵には、地下水脈のように長く流れ続ける力がある。そこに残る身体は、速度の遅い変化を記憶する器でもある。

移動はたしかに自由を開く。新しい仕事に出会い、違う文化に触れ、閉じた関係から抜け出せる。けれど、自由を移動だけで測ると、残る人、待つ人、守る人の知が見えなくなる。そこにいるからこそ見える変化があり、離れないからこそ守れる関係がある。定住とは停止ではなく、長い観察の形式である。動かない人は変化しない人ではなく、変化を長く見届ける人なのである。我々はその知を、古いものとしてではなく、未来の基礎技術として読み直す必要がある。

アボリジニのソングラインは、土地を歌でたどる知である。歌は道であり、地図であり、祖先の記憶でもある。ブルース・チャトウィン『ソングライン』（1987）は、この世界を広く紹介した。学術的には慎重な読みが必要だが、土地が単なる所有物ではなく、歌い歩かれる記憶の媒体であることを印象づけた。デボラ・バード・ローズ『ディンゴはわれらの兄弟』（1992）も、先住民の土地関係を生命の相互性として描いた。所有する土地ではなく、歌い継がれる土地という見方は、近代の地図を揺さぶる。

ハワイのアフプアアは、山から海までを一つの生活圏として束ねる土地区分である。水、森、畑、海を切り離さず、定住の中で循環を保つ知恵がそこにある。デヴィッド・アブラム『感応する身体』（1996）は、身体が環境と感応しながら知を形づくることを論じた。流域の上流で何をするかが、海の魚に影響する。動かない人は狭い世界に閉じているのではない。山と海のつながりを、日々の暮らしとして知っている。定住は閉鎖ではなく、場所の全体性を身体で読む方法でもある。

鶴見俊輔『限界芸術論』（1967）は、専門家だけが芸術を作るのではなく、職人、農民、子ども、生活者の日常の中に芸術があると考えた。宮田登『日本の民俗学』（1974）が扱った祭りや信仰や生業も、定住知の宝庫である。ソングラインやアフプアアが土地を歌と流域で捉えるなら、鶴見は日常の手つきの中に創造性を見た。異なる伝統は、知が大学や行政文書の外側にも宿ることを教えている。道具の扱い、季節の読み方、隣人への声のかけ方の中に、長い時間をかけて磨かれた知がある。

> 動かないことは停滞ではなく、変化を長く見届ける力である。

暮らしの言葉に翻訳すれば、動かない人の知とは「毎年の少し違う」を見分ける力である。今年の雪は重い、今年の梅は早い、あの家の灯りが最近遅い。こうした気づきは、データになる前に地域を支える。もちろん定住はいつも美しいわけではない。役割に縛られ、外へ出る自由を奪われることもある。だからこそ、称賛ではなく再評価が必要である。動ける自由と、残れる尊厳を同時に守らなければならない。残ることが罰にならず、移ることが裏切りにならない社会がいる。

動かない人の知は、速度の遅い未来を教えてくれる。森は一代で育たない。水路は一度壊れると戻すのに時間がかかる。祭りの意味も、何十年も続けるうちに身体へ入る。移動の時代だからこそ、我々は定住が持つ長い時間の知恵を、社会の中心に戻す必要がある。未来をつくるのは、速く動く人だけではない。そこに居続け、変化を見届け、手入れを続ける人もまた、未来の担い手なのである。
```

### 第13話「場所がケアになる、ケアが場所になる」
- 人文知: 哲学（フランコ・バザーリア『精神病院を否定する』）／文学（柳美里『JR上野駅公園口』）
- 学術領域: 環境心理学／精神医療史
- 本文（BODY）:
```
病室の窓から木の葉が見えるだけで、呼吸が少し深くなることがある。デイサービスの台所から味噌汁のにおいが流れ、庭先で洗濯物が揺れ、誰かが新聞をたたむ音がする。薬や手技だけでは説明できない回復が、場所の手触りから立ち上がる。ある場所にいること自体が、人を支えることがある。場所は背景ではなく、ケアの一部なのである。病院の白い壁の外にも、治療を静かに助ける風景はある。

近代の医療は、治療の場と暮らしの場を分けてきた。病院は治す場所、家は休む場所、施設は預かる場所。分けることで専門性は高まり、多くの命が救われた。だが、その線引きの中で、暮らしそのものが持つ治癒の力は小さく扱われてきた。人は身体だけでなく、場所との関係の中で傷つき、回復する。治療の成功は、退院後にどこへ戻れるかにも左右される。退院先が孤立した部屋なら、回復はそこで細くなる。

フランコ・バザーリアは『精神病院を否定する』（1968）で、精神病院を隔離の装置として批判した。イタリアのトリエステで進んだ精神医療改革は、病む人を施設の外へ出し、地域の中で暮らす権利を取り戻そうとした実践である。治療とは人を閉じ込めることではなく、関係の中へ戻すことであった。この流れは1978年のイタリア法律180号へつながり、病院中心の前提を大きく揺さぶった。制度の扉を開くことは、同時に街の側を変えることであった。

ロベルト・メッツィーナらの後継的実践は、病院のベッド数を減らすだけではなく、住まい、仕事、友人、街路を治療の一部として扱った。環境心理学では、ロジャー・ウルリッヒの病室の眺望に関する研究（1984）が、窓から見える自然が回復に影響する可能性を示した。北欧で語られる治癒の景観も、自然が自動的に人を治すという話ではない。光、音、庭、動線、人との距離が回復を妨げないように設計されているということである。風景は気分の飾りではなく、身体をほどく条件である。

柳美里『JR上野駅公園口』（2014）には、居場所を失った人の声が、上野公園という具体的な場所に重ねて描かれる。場所は人を癒すこともあれば、社会の排除を露わにすることもある。だから「場所がケアになる」と言うとき、我々は美しい風景だけを思い浮かべてはいけない。ハンナ・アーレント『人間の条件』（1958）が公共空間を人が現れる場として考えたように、場所は人を見えなくすることも、もう一度現れさせることもできる。そこにいる人が関係へ戻れるかが問われるのである。

> 場所がケアになるのは、そこにいる人を関係の中へ戻すときである。

暮らしの言葉に翻訳すれば、場所のケアとは「ここにいてよい」と身体が感じられる環境である。座る場所がある、台所の音が聞こえる、外へ出る道がある、名前で呼ばれる、失敗しても追い出されない。富山型デイサービスや宅老所が示してきたのは、制度上の区分よりも、同じ場所で過ごす時間が人を支えるという事実である。子ども、高齢者、障害のある人が一緒にいる場では、役割が一方向に固定されにくい。介助される人が野菜を選び、子どもを見守り、別の誰かの安心になることもある。

場所とケアを分けない社会を作るには、制度も変わらなければならない。病院だけでなく、家、商店街、図書館、銭湯、公園が回復の一部になる。ケアは特定の部屋で提供されるサービスではなく、場所を通じて人を関係へ戻す営みである。場所がケアになり、ケアが場所を育てる未来は、すでに始まっている。その未来では、治療とは病を消すことだけでなく、生きる場所を取り戻すことを意味する。我々はその場所を、専門職だけに任せず、日々の設計として育てる必要がある。
```

### 第14話「移民とケア — 国境を越える手のひら」
- 人文知: 人類学（アーリー・ホックシールド『感情労働』）／文学（温又柔『真ん中の子どもたち』）
- 学術領域: 移民研究／グローバル・ケア・チェーン論
- 本文（BODY）:
```
朝六時の介護施設では、まだ外の光が青い。廊下には消毒液と味噌汁の匂いが混じり、夜勤明けの職員が記録用紙に小さな字を書いている。車いすのブレーキを確かめ、湯気の立つ粥を運び、眠そうな声で名前を呼ぶ。その手は、フィリピンから、ベトナムから、ネパールから来ていることがある。我々はその姿を見ているようで、まだ十分に言葉にしていない。ケアの現場には、すでに国境を越えた朝がある。

ケアの仕事は、体を支えるだけではない。相手の不安をほどき、怒りを受け止め、沈黙のなかで待つ仕事でもある。日本の介護は人手不足という数字で語られがちだが、現場で起きているのは、言葉、宗教、家族、送金、試験、夜勤が重なった暮らしの再編である。国境を越えて来た人を労働力と呼ぶだけでは、そこで動いている時間の厚みが見えない。誰かの老いを支える人にも、離れた場所で続く生活がある。

社会学者アーリー・ホックシールドは『管理される心』（1983）で、笑顔や落ち着きや親しみが賃金労働の一部になることを「感情労働」と呼んだ。航空機の客室だけでなく、介護ベッドの横にもこの概念は深く届く。利用者の不安に合わせて声の高さを変え、拒否を責めず、認知症の混乱に同じ説明を繰り返す。その注意深い感情の調整は、記録表には残りにくい労働である。しかも移民労働者の場合、そこに発音への緊張や文化差の翻訳も加わる。

ホックシールドらが編んだ『グローバル・ウーマン』（2002）は、豊かな国の家庭や施設が移民女性のケアを受け取るとき、別の場所でケアの穴が開くことを描いた。日本で誰かの親を支える人には、母国に残してきた子どもや祖父母がいるかもしれない。ケアは一つの国の中で完結しない。送り出し国、受け入れ国、家族、仲介業者、資格制度がつながる連鎖の中を移動している。レイチェル・パレーニャス『サーヴァンツ・オブ・グローバリゼーション』（2001）が描いた越境家族の痛みは、この連鎖の内側にある。

日本の介護現場では、外国人介護福祉士、技能実習生、特定技能の労働者が増えている。彼らは単なる穴埋めではない。遠い家族に仕送りをしながら、方言を覚え、利用者の好きな湯加減を知り、夜勤明けの駅で眠そうに電車を待つ生活者である。日本語の敬語を間違えないよう緊張し、母語で弱音を吐ける場所を探しながら、他者の身体に毎日触れている。サスキア・サッセン『グローバル・シティ』（1991）が見た都市の陰の労働は、地方の施設にも形を変えて現れている。

温又柔の『真ん中の子どもたち』（2017）は、言葉と国籍のあいだで育つ子どもの揺れを描いた。移民ケア労働者の多くもまた、いくつもの言葉の真ん中で働いている。利用者の「ありがとう」を覚える一方で、母国の家族には疲れを隠すことがある。日本社会が彼らを「やさしい外国人」として消費するとき、その人の怒り、疲労、野心、祈りは見えにくくなる。ケアの国際分業を語るとは、手の温かさだけでなく、その手が背負う不均衡を見ることである。

> ケアを受け取る社会は、その手の向こうにある暮らしまで見なければならない。
```
