# Codex 執筆ブリーフ — LAB セクション追加

連載「未来のかたち」の各話には、人文知（哲学・人類学・文学・神話・伝統知）を本文に織り込んだうえで、DEEPER（人文知の学術系譜）と SIGNAL（直近の現実世界の動き）の追記欄がある。今回はそこに新たに **LAB（科学の知から）** を加える。各話の本文テーマを踏まえ、対応する **自然科学・工学** の研究者・概念・年代を 400-600字で書く。

## 必須条件
- **字数: 400-600字**（1段落 or 短い2段落、合計）
- **文体**: 「〜である」調、主語「我々」（連載と統一）
- **領域**: 神経科学／認知科学／環境心理学／生態学／地球科学／医療工学／建築工学／情報科学／通信工学／AI・ロボティクス／システム工学／統計物理 などから、本文テーマに対応するものを選ぶ
- **必ず**: 研究者名 + 論文/書籍名 + 年代（西暦）の組を **最低3組** 入れる
- **平らな日本語で、具体的に**: 暮らしの言葉に翻訳しつつ自然科学・工学の系譜を示す

朝の電車で、我々は何度も自分を着替える。会社へ向かう顔、保育園からの電話を待つ顔、親の通院を気にする顔、昨夜の友人との会話を反すうする顔。改札を抜ける身体は一つでも、その内側にはいくつもの自分が同時に動いている。自分らしさを探すほど苦しくなるのは、自分は一つでなければならないという前提が重すぎるからである。むしろ我々は、場に応じて現れる複数の自分を抱えて、毎日の小さな判断を続けている。

近代の社会は、一貫した個人を求めてきた。名前、住所、職業、履歴、意見。矛盾のない自分であることが、信用の条件になった。履歴書には一本の線で人生を書き、行政の書類には一つの住所を置き、SNSでは自分の考えをはっきり示すことを求められる。だが、人はそんなに単純ではない。昨日の自分と今日の自分でさえ、同じ言葉では言い切れない。社会が求める一貫性のほうが、人間の揺れや成長より狭いのである。

西田幾多郎は『善の研究』（1911）から『場所的論理と宗教的世界観』（1945）に至るまで、自己を孤立した点ではなく、経験や関係が立ち上がる場所の中で考えた。自己とは内側に閉じた核ではなく、世界との関係の中で立ち現れるものなのである。和辻哲郎は『風土』（1935）で、人間を個人だけでなく、人と人とのあいだに生きる存在として捉えた。チャールズ・テイラーは『自我の源泉』（1989）で、近代的自己が歴史的に作られたものであることを示した。ひとつの自分は、自然な事実ではなく、近代が強く求めた形式でもある。

別の系譜から見れば、複数の自己は病理ではなく、関係の豊かさである。ヘイゼル・マーカスと北山忍は「文化と自己」（1991）で、独立的自己と相互協調的自己の違いを論じた。木村敏は『人と人との間』（1972）で、自己が他者とのあいだに現れることを精神医学の側から考えた。西田が語る場所、和辻が語る間柄、マーカスと北山が語る文化的自己は、同じ結論ではない。だが、いずれも自分を単独の箱としてではなく、関係の結び目として見る道を開いている。

問08は、ばらばらな自分を統一せよという問いではない。複数の自分が、互いを壊さずに同居できる社会をどう作るかという問いである。介護する自分と働く自分、移住者としての自分と市民としての自分、オンラインの自分と地域の自分が、制度の中で同時に認められる必要がある。西田の場所は、内面の深さだけを語る概念ではない。人がどの場でどのように現れるかを支える、社会の設計の問題でもある。制度が一つの顔だけを本物と見なすとき、我々は生活の一部を隠すことになる。

> 私は一つの核ではなく、いくつもの関係が結ばれる場所である。

暮らしの言葉にすれば、これは一つの名刺では足りないという感覚である。会社の肩書では説明できない地域の役割があり、戸籍の続柄では表せないケアの関係があり、アカウント名では見えない古い記憶がある。制度が一つの自分だけを求めると、人は残りの自分を隠さなければならない。複数の自分を認めるとは、気分の問題ではなく、手続きと居場所の問題である。窓口、学校、職場、医療の場が、複数の自己を扱えるかどうかで、人の安心は大きく変わる。

我々は、強い個人を作ることを長く目標にしてきた。だがこれから必要なのは、複数の関係を持つ人を支える社会である。一つの自分を証明できない人を不安定だと見なすのではなく、いくつもの場に応答して生きる人として受け止める。私は私たちでできている。その当たり前を、制度と言葉の中へ戻す時期に来ている。自分が複数であるなら、次に名前もまた一つでは足りないことが見えてくる。
```

### 第52話「名前は、私を守るのか縛るのか」

- 学術領域: ジェンダー研究／文学思想
- 本文（BODY）:
```
病院の待合室で本名を呼ばれ、少しだけ肩がこわばる。職場のメールには旧姓が残り、友人は昔のあだ名で呼び、画面の中では別の名前でやりとりをする。名前は人を呼ぶためにある。だが時に、名前は人を一つの形に固定してしまう。我々は、いくつもの呼ばれ方のあいだを移動しながら生きている。呼ばれた名前に返事をするたび、どの自分としてそこに立つのかを選ばされている。その小さな緊張は、日常のあちこちにひそんでいる。

私たちは名前で社会に入る。学校、病院、銀行、旅券、SNS。名前がなければ、手続きは進まない。名前は人を守る。権利を届け、責任を確かめ、迷子になった記録を結び直す。しかし、名前はいつも自分にぴたりと合うわけではない。むしろ生活の節目で、名前とのずれが現れる。制度上の名は同じでも、働く名、親しい名、選び取った名は、それぞれ別の時間を抱えている。名簿の一行は、本人の歴史を全部は運べないのである。

アーシュラ・K・ル・グィンの『ゲド戦記』第一巻『影との戦い』（1968）では、真の名を知ることが、相手の力に触れることでもある。ジュディス・バトラーは『ジェンダー・トラブル』（1990）で、自己が固定された本質ではなく、社会的な呼びかけや行為の反復の中で形作られることを示した。ミシェル・フーコーは『性の歴史I 知への意志』（1976）で、制度が身体と身分を分類し、主体を作る力を論じた。名づけは文学の魔法であると同時に、現実の制度の技法でもある。

別の角度から見ると、名前は記憶の保存装置であり、分類の道具でもある。アーヴィング・ゴッフマンは『スティグマ』（1963）で、社会的なラベルが人の自己経験を変えることを明らかにした。ル・グィンの真の名は、相手を深く知る敬意にも、支配の入口にもなりうる。バトラーの呼びかけは、名前が人を社会の中へ招き入れながら、その人の振る舞いを型にはめる力を示す。名前は透明な札ではない。誰が、どの場で、どんな声で呼ぶかによって、守りにも拘束にも変わる。

問08は、名前を軽く扱う問いではない。むしろ、名前が人の存在を支え、同時に狭める力を持つことを見つめる問いである。制度は一つの本名を求める。だが生活は複数の呼ばれ方でできている。通称を使うこと、旧姓を使うこと、選んだ名前で呼ばれることは、わがままではなく、自己の複数性を保つ方法である。ル・グィンの名の倫理、バトラーの呼びかけの理論、フーコーの分類の思想は、名が世界を作る力と危うさを別の角度から照らしている。

> 名前は居場所を作るが、居場所を一つに狭めることもある。

暮らしの言葉にすれば、名前は鍵である。正しい鍵なら扉を開け、違う鍵なら目の前で手続きが止まる。だが、その鍵が本人の手になじまないこともある。学校の名簿、職場の名札、銀行口座、論文の著者名がそれぞれ別の時間を持つとき、人は説明を何度も求められる。名前を尊重するとは、書類上の正しさだけでなく、本人が生きている呼ばれ方を扱うことである。小さな表記欄の設計が、人の安心を左右する。

我々は、名前を確認するたびに、その人をどの形で社会へ迎えるかを決めている。書類の都合だけで呼ぶのか、本人の呼ばれ方を尊重するのか。その差は小さく見えて深い。名前は私を守るのか、縛るのか。答えは、名前そのものではなく、名前を扱う社会の作法の中にある。名前が複数なら、次に身体もまた一つの意味に閉じられないことが見えてくる。
```

### 第53話「身体はひとつ、意味はいくつも」
- 人文知: 哲学／ジュディス・バトラー、身体と規範
- 学術領域: 身体論／ジェンダー哲学
- 本文（BODY）:
```
朝の洗面台で、我々は自分の顔を昨日の続きとして見る。けれど、まぶたの重さ、髪の薄さ、薬を飲む手の震えは、昨日と同じ身体などないことを静かに告げる。駅の階段で息が切れ、健康診断の数値に目が止まり、服の売り場で性別の棚の前に立ちつくす。身体は私そのものである。同時に、他者の視線や制度の言葉が意味を書き込む場所でもある。痛み、成長、病、老いは、自己の輪郭を毎朝少しずつ描き直している。

身体は変わる。成長し、傷つき、病み、老い、時に医療やケアによって形を変える。そのたびに、自分の感じ方も、周囲からの見られ方も変わる。若い頃には気づかなかった段差が、ある日から街の性格を変える。病名を得た瞬間に、未来の予定表は別の紙面になる。性別をめぐる違和感が言葉を得ると、子どもの頃の写真まで違って見える。その時、過去の自分は消えるのではなく、別の意味を帯びて戻ってくる。問08が見つめるのは、この変化が自己を壊すだけでなく、複数の自分を開く契機にもなるという現在地である。

ジュディス・バトラーは『ジェンダー・トラブル』（1990）で、性別が内側の本質から自然に表れるのではなく、規範に沿う行為の反復を通じて成立すると論じた。さらに『問題＝物質となる身体』（1993）では、身体の物質性そのものが社会的な言葉や制度の中で意味づけられる過程を考えた。シモーヌ・ド・ボーヴォワールは『第二の性』（1949）で、人は女に生まれるのではなく女になると述べた。これらの議論は、身体を否定するのではなく、身体に貼られた唯一の説明を疑うための道具である。

別の系譜から見れば、身体は近代社会が分類し、管理し、標準化してきた対象でもある。ミシェル・フーコーは『監獄の誕生』（1975）で、学校、軍隊、病院、監獄が身体を訓練し、従順な身体を作る仕組みを描いた。スーザン・ソンタグは『隠喩としての病い』（1978）で、病が道徳的な欠陥や人格の表れとして語られる暴力を批判した。健康な身体、若い身体、生産できる身体を基準にした社会では、病むことや老いることまで失敗として読まれる。我々の身体は、自然と制度のあいだで意味を負わされてきたのである。

この視点は、障害学やケアの思想とも対話する。ローズマリー・ガーランド＝トムソンは『異常な身体』（1997）で、障害や外見の差異が視線の制度によって作られることを示した。エヴァ・フェダー・キテイは『愛の労働』（1999）で、依存を例外ではなく人間の条件として捉え直した。バトラーが性別規範の反復を問うなら、障害学は標準的身体という舞台そのものを問う。二つの伝統は、自由に身体を作り替えよと命じるのではなく、身体を一つの価値に閉じ込める社会を変えよと告げている。

> 身体は一つでも、そこに書き込まれる意味は一つではない。

暮らしの言葉にすれば、身体はいつも周囲と交渉している。階段しかない駅では、足の痛みが個人の能力不足に変えられる。長く座ることを前提にした会議では、痛む腰や集中の揺らぎが怠けとして読まれる。性別欄が二つしかない書類では、身体の経験が制度に合わないものとして扱われる。声を出しにくい身体、速く歩けない身体、食事に制限のある身体は、本人の弱さではなく、環境が誰を想定して作られたかを映す。自分を責める前に、場の設計を疑うことが必要である。

我々は、標準的な身体を前提に社会を作ってきた。長く働ける身体、すぐ移動できる身体、はっきり話せる身体、決められた性別欄に収まる身体である。しかし実際の身体は、月経、妊娠、更年期、慢性痛、手術、服薬、介助、老いの中で揺れ続ける。身体はひとつである。けれど、その身体を生きる意味はいくつもある。それは弱さの承認ではなく、生き方を増やす公共の技術である。その複数性を認めることが、自分を一つに閉じ込めない社会への道である。身体が複数の意味を持つなら、次に記憶もまた一つではないことが見えてくる。
```

### 第54話「記憶は、私の中だけにない」
- 人文知: 文学／宮沢賢治、土地と記憶
- 学術領域: 記憶研究／環境人文学
- 本文（BODY）:
```
雨上がりの川沿いを歩くと、護岸のコンクリートに水位の跡が薄く残っていることがある。子どものころはただの汚れに見えた線が、祖母の話を聞いたあとでは、町をのみ込んだ水の高さに変わる。曲がり角の地蔵、橋の名前、坂の上に家が多い理由。そうしたものは、我々が経験していない時間を、足裏から静かに入れてくる。土地は黙っているようで、実はずっと語り続けている。

自分とは、何を覚えているかでできている。台所の味噌汁の湯気、通学路の金木犀、誰かに言われた一言は、確かに私の内側にしまわれている。だが耳を澄ませば、その記憶にはまだ会ったことのない人の声が混じる。祖父母から聞いた戦争の話、川の氾濫を示す石碑、祭りで何度も歌われる節回しが、我々の現在を別の時間へ開いている。記憶は私有物に見えて、いつも少しだけ共同である。

モーリス・アルヴァックスは『集合的記憶』（1950）で、記憶は孤立した頭の中に保存されるのではなく、家族や地域の枠組みの中で形を得ると論じた。ピエール・ノラは『記憶の場』（1984-1992）で、記念碑、博物館、地名、儀礼が社会の記憶を支える場になると考えた。アライダ・アスマンは『想起の空間』（1999）で、保存される記憶と忘れられる記憶の制度的な差を問うた。つまり我々の記憶は、脳だけでなく、町の曲がり角にも置かれている。

宮沢賢治の作品には、岩手の風土が深く刻まれている。『注文の多い料理店』（1924）では、山は背景ではなく、人間の傲慢を見返す存在として立ち上がる。『銀河鉄道の夜』（1934）に流れる寂しさも、個人の心情だけではない。農の手触り、冷たい風、星の光、死者との静かな交感が、人間を土地と宇宙のあいだに置いている。賢治において、自己は自然や死者から切り離された点ではなく、関係の網の中で震える場所である。

この視点は、近代的な個人主義と対話している。ジョン・ロックが『人間知性論』（1690）で、人格の同一性を意識と記憶の連続に結びつけたとき、記憶は自己の内部をつなぐ力として考えられた。けれどアルヴァックスやノラの議論は、その内側がすでに外部によって作られていることを示す。さらに石牟礼道子『苦海浄土』（1969）は、水俣の海と病の記憶が、個人の苦痛を超えて共同体の言葉になる過程を描いた。
