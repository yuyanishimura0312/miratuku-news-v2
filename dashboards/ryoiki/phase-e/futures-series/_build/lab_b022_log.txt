### 第87話「会議室にいない人の席」
- 人文知: 哲学・レヴィナス「他者」
- 学術領域: 倫理学／世代間倫理
- 本文（BODY）:
```
市役所の会議室で、長机の上に名札が並ぶ。課長、専門家、地域代表、事業者、委員長。発言する人の前には水の入った紙コップがあり、資料には議題が整然と印刷されている。けれど、その決定で通学路が変わる子ども、夜勤明けで説明会に来られない介護者、十年後にその町で働く若者の名札はない。何かを決める場には、いつもいない人がいる。会議室の静けさは、しばしば参加できなかった人の沈黙でもある。空いていない席の数だけ、問いはまだ閉じきっていない。

いない人のことを考えるのは難しい。彼らの代わりに簡単に語ることはできない。未来世代はまだ意見を述べないし、遠くの人の暮らしをこちらから完全に知ることもできない。声を出しにくい人の沈黙を、我々の都合よく解釈してしまう危険もある。だが、いないから考えなくてよいわけではない。むしろ、いない人がいることを忘れない仕組みが必要である。空席は、想像力のための制度である。そこに座る誰かを勝手に作るのではなく、まだ聞けていない声があると場に刻むのである。

哲学者エマニュエル・レヴィナスは『全体性と無限』（1961）で、他者を自分の理解の中に閉じ込めないことを倫理の起点にした。『存在の彼方へ』（1974）では、他者への応答が存在論に先立つと考えた。他者は、我々が知り尽くせる対象ではない。顔を向けられたとき、我々は説明より先に応答を求められる。マルティン・ブーバー『我と汝』（1923）も、他者を対象ではなく呼びかけの相手として捉えた。未来世代や沈黙する人々は、直接顔を見せない他者である。だからこそ、我々の理解に回収しないまま応答する形が問われる。

この視点は、会議の設計を変える。空席を置くとは、誰かが勝手に代弁する椅子を作ることではない。それは、場全体に「ここにいない人がいる」と知らせる記号である。都市開発の会議で、将来そこを歩く子どもの時間を考える。災害復興の議論で、避難所に来られない在宅避難者を思い出す。気候政策を語る場で、まだ生まれていない人の生活を想像する。デレク・パーフィット『理由と人格』（1984）が示した未来世代への責任の難問は、ここで日常の会議に降りてくる。ハンス・ヨナス『責任という原理』（1979）の警告も、技術の影響が長く残る時代の席順を問い直している。

我々はしばしば、参加している人の合意をもって公共の合意だと見なす。だが、参加できること自体がすでに条件に恵まれている場合がある。夜の会議に出られない介護者、資料を読みにくい人、交通費を払えない人、日本語で話しにくい人。参加の扉を開くだけでは足りない。扉まで来られない人の存在を、問いの中に入れる必要がある。公共性は、席に着いた人の数だけでは測れない。レヴィナスの他者と、パーフィットの未来世代を並べると、いない人は抽象的な空白ではなく、我々の決定にすでに巻き込まれた相手なのである。

> 空席は代弁の椅子ではなく、未聴の声を忘れないための形である。

暮らしの言葉に翻訳するなら、空席を置くとは、話し合いの前に「今日ここに来られなかった人は誰か」と声に出すことである。町内会なら、子育て中の人、障害のある人、遠くへ出た若者を思い出す。会社なら、非正規の人、夜勤の人、退職した人の経験を考える。家族の決めごとでも、まだうまく言えない子どもの沈黙を、賛成として扱わない。施設の改修なら、杖をつく人、耳が聞こえにくい人、暑さに弱い人の通り道を先に歩いてみる。空席は、決定を少し遅くし、問いを広くする道具である。沈黙を都合よく使わないための小さな儀式でもある。

未来を考えるとは、見えない人を都合よく美化することではない。理解しきれない他者がいることを認め、その不完全さのまま場を設計することである。我々が会議室に一つの空席を置くとき、問いは少し変わる。「何が最も効率的か」だけでなく、「誰がまだこの問いに触れられていないか」と問えるようになる。その問いが、未来を閉じない作法になる。そして次には、空席を置いた我々自身が、語りすぎていないかを点検する必要が生まれる。他者の席を置くことは、他者の声を所有することではなく、我々の発言を一歩控えめにする訓練でもある。
```

### 第88話「語りすぎる私を止める」
- 人文知: フェミニスト哲学・ジュディス・バトラー／ジョアン・トロント
- 学術領域: ケア倫理／政治哲学
- 本文（BODY）:
```
避難所の床に段ボールが敷かれ、受付の机には物資の一覧表が置かれている。外から来た支援者は、必要なものを早く届けようと動く。水、毛布、薬、充電器。どれも大切である。けれど、隅で黙っている人が本当に必要としているものは、表にはまだ書かれていないかもしれない。よかれと思う言葉や行動が、相手の声をふさいでしまうことがある。支援の速度が、聞く時間を奪うこともある。

我々は語る力を重んじてきた。会議で意見を言える人、文章で訴えられる人、数字で説明できる人が、しばしば場を動かす。だが、聞く力はそれ以上に難しい。相手がすぐに言葉にできないこと、昨日と今日で気持ちが変わること、支援を受けながらも抵抗を感じること。その揺れを、自分の都合のよい説明にまとめすぎない力がいる。聞くとは黙ることだけではない。相手の応答によって、自分の問いを直す準備を持つことである。

ジュディス・バトラーは『生のあやうさ』（2004）で、誰の生が公共に悼まれ、誰の傷つきが見えないままにされるのかを問うた。ジョアン・トロントは『Moral Boundaries』（1993）で、ケアを個人のやさしさではなく、社会を支える実践として考えた。さらに『Caring Democracy』（2013）では、ケアを民主主義の中心問題として論じた。キャロル・ギリガン『もうひとつの声』（1982）も、道徳を抽象的原理だけで測る見方を揺さぶった。聞くことは感情ではなく、政治の技術でもある。

トロントにとってケアは、相手の必要に気づき、引き受け、行い、相手の応答を受け取る過程である。ここで大切なのは、ケアする側の満足ではない。立派な支援計画を作っても、相手が息苦しさを感じているなら、問いは修正されなければならない。「何をしてあげるか」ではなく、「何が必要だと聞こえているか」。主語が少し動くだけで、相手をこちらの物語に閉じ込める危険が減る。ネル・ノディングズ『Caring』（1984）が重視した応答関係も、この点で重要である。

代弁が必要な場面はある。声を上げにくい人のそばで、制度に届ける言葉を作ることは大切である。だが、代弁は常に仮の言葉でなければならない。本人の応答、隣にいる人の違和感、時間がたってから出てくる訂正によって、いつでも直される余地を残す必要がある。支援する側、研究する側、政策を作る側が、自分の正しさに酔いすぎると、聞く耳はすぐに鈍くなる。我々は「ために語る」ことが、相手を自分の物語の登場人物にしてしまう危うさを忘れてはならない。

さらに難しいのは、相手の声がいつも一つではないことである。避難所に残りたい人と、親族の家に移りたい人が同じ家族の中にいる。静かにしてほしい人と、話を聞いてほしい人が同じ部屋にいる。外部の支援者に感謝しながら、同時に疲れている人もいる。聞く技術は、こうした矛盾を一つの「被災者の声」へ回収しない技術である。声を集めることと、声を平均化することは違う。我々は、複数の声が並んだまま制度に届く道を考えなければならない。

> 聞く力とは、相手の応答で自分の問いを変える力である。

暮らしの言葉に翻訳するなら、聞く技術とは、相手の言葉を自分の結論へ急いで運ばないことである。家族が「大丈夫」と言ったとき、本当に大丈夫なのか、言うしかなかったのかを少し待つ。地域の会合で「困っている人のために」と言う前に、その人が何を困りごととして語るのかを聞く。職場で若い人を代表して語る前に、その言葉が本人の応答で直される余地を残す。聞くとは、相手に自分の問いを変えてもらうことである。沈黙もまた、返事の一部として扱う必要がある。

未来を語る場でも同じである。子どものため、地域のため、地球のためと言うとき、その言葉は本当に相手に向かって開かれているだろうか。聞く技術を持つとは、語りをやめることではない。語ったあとで立ち止まり、返ってくる沈黙や違和感に触れ、問いを直すことである。未来のかたちは、よく語る人だけでなく、よく聞き直す人によって支えられる。そして聞く相手は、人間だけに限られるのかという次の問いが始まる。
```

### 第89話「石にも川にも、問いがある」
- 人文知: 人類学・デスコラ／伝統知・アンデスの自然観
- 学術領域: 環境人類学／存在論
- 本文（BODY）:
```
雨の翌朝、川沿いの道には泥の匂いが残り、橋脚の根元には流木が引っかかっている。いつもは細い水音が、その日は低く太い音を立てる。通勤する我々はスマートフォンの防災通知を見て、水位の数字を確かめる。もちろん数字は必要である。けれど、川は数字だけではない。濁り、匂い、岸辺の草、魚の姿もまた、我々に何かを知らせている。川は背景ではなく、暮らしに応答を迫る相手である。

我々は自然を背景として扱いがちである。町の外にある山、管理すべき川、利用できる森、守るべき景観。治水や農業やエネルギーのために自然を扱う技術は必要である。だが、「自然をどう利用するか」という問いだけが前に出ると、世界はいつの間にか人間の都合だけで組み立てられる。川は流域の相手ではなく、水量の数字になる。自然保護でさえ、人間が守る対象としてだけ語られると、関係の複雑さを失う。

一方で、世界には山や水を関係の相手として見る知がある。アンデスの一部の伝統では、アプと呼ばれる山々が、人々の暮らしと結び合う存在として考えられてきた。パチャママへの感謝は、自然崇拝という一語では収まらない。水は運ばれる資源である前に、共同体の儀礼や記憶とつながる相手である。マリソル・デ・ラ・カデナ『Earth Beings』（2015）は、アンデスの山々が政治の外にある自然ではなく、交渉の相手として現れる場面を描いた。重要なのは、その見方を借り物の装飾にしないことである。

人類学者フィリップ・デスコラは『自然と文化を越えて』（2005）で、人間と自然を分ける近代的な世界観が普遍ではないことを示した。エドゥアルド・ヴィヴェイロス・デ・カストロは『食人の形而上学』（2009）で、アマゾンの遠近法主義を論じた。ブルーノ・ラトゥール『虚構の「近代」』（1991）は、人間と非人間を分ける近代の建前そのものを疑った。そこでは、人間、動物、植物、山、川の関係が、近代の自然観とは違う仕方で組み立てられる。

川を「管理対象」と見ると、問いは水害をどう防ぐか、どれだけ使えるかに向かう。川を「ともに暮らす相手」と見ると、流域の森、魚、田畑、下流の町、子どもの遊び場までが問いに入ってくる。石や川が人間の言葉で話すわけではない。それでも、水位の変化、魚の減少、濁り、岸辺の匂いは、我々に何かを知らせている。聞くべき声は人間だけに限られない。自然を擬人化するのではなく、応答すべき関係として捉えるのである。

この見方は、科学を捨てることではない。水位計、気象データ、地質調査、衛星画像は、川や山を知るための大切な道具である。問題は、それらの道具が世界をすべて測り終えたかのように振る舞うことである。地元の漁師が覚えている魚の季節、子どもが知っている水遊びの浅瀬、田畑を持つ人が感じる土の乾きは、数値と対立する迷信ではない。それらは、流域の関係を読む別の知である。近代の管理知と生活の経験知を対話させるとき、人間中心の問いは少しほどける。

> 問いの主語を人間だけに閉じると、未来の景色も狭くなる。

暮らしの言葉に翻訳するなら、人間中心をほどくとは、身近な自然を「使うもの」だけで呼ばないことである。水路を掃除するとき、排水の効率だけでなく、そこに戻る虫や草を見る。公園の木を切るか残すかを考えるとき、管理費だけでなく、夏の日陰、鳥の巣、子どもの記憶を問う。家庭の庭でも、雑草を敵としてだけ見ず、土の状態を知らせる相手として読むことができる。問いの言葉を少し変えるだけで、日々の手つきも変わる。

未来の社会を考えるとき、我々は「誰のための未来か」と問う。その誰に、川や森や土を含めることはできるだろうか。法制度の上でどう扱うかは簡単ではない。だが、問いの入口で自然を物としてだけ置くか、関係の相手として置くかによって、選ぶ道は変わる。石にも川にも問いがあると感じることは、詩的な飾りではなく、未来を狭めないための実践である。そして人間を中心から少しずらすと、次には「私」という単位そのものも揺れ始める。
```

### 第90話「ひとつの私でなくても、問える」
- 人文知: 文学・ボルヘス「分岐する小径」
- 学術領域: 文学／自己論
- 本文（BODY）:
```
夜の電車で窓に映る自分の顔を見ると、昼の会議で話していた自分とは違う人のように見えることがある。職場では落ち着いて賛成したのに、帰り道では胸の奥に小さな反対が残っている。家に帰れば親としての自分が待ち、古い写真を見れば子どものころの自分が顔を出す。「私はこう考える」と言うとき、その私は本当に一つなのだろうか。窓に映る顔は、一枚の輪郭の中にいくつもの声を重ねている。

近代社会は、一貫した個人を前提に制度を作ってきた。名前、住所、職業、資格、ID。もちろん、社会を動かすにはその整理が必要である。だが、整理された一人の内側には、複数の履歴が重なっている。ある場面では強く言える人が、別の場面では黙ってしまう。昨日の自分が信じていたことを、今日の自分はうまく信じられない。自己は一本の棒ではなく、折れ曲がる道である。問いを立てる主体もまた、安定した核だけではない。

作家ホルヘ・ルイス・ボルヘスの「分岐する小径の庭」（1941）は、時間を一本の流れとしてではなく、いくつにも枝分かれする迷宮として描いた。『伝奇集』（1944）に収められた物語群は、分身、偽書、無限の書物を通じて、現実が一つに定まるという安心を揺さぶる。マルセル・プルースト『失われた時を求めて』（1913-1927）も、記憶の中で自己が何度も組み直されることを示した。ポール・リクール『他者のような自己自身』（1990）は、自己を物語的同一性として捉え直した。

我々の自己もまた、分岐する小径のようにできている。会社員としての問い、親としての問い、市民としての問い、かつて傷ついた者としての問いが、それぞれ別の方向を向く。自己診断というと、本当の自分を探すことだと思われやすい。けれど、奥に一つの本質が隠れていて、それを掘り当てればよいとは限らない。必要なのは、複数の声を聞き分けることである。チャールズ・テイラー『自己の源泉』（1989）が言う道徳的地平も、我々の中で単数ではなく重なっている。

> ひとつにまとまらない私の中にも、未来を問う力はある。
```
