# Codex 執筆ブリーフ — 連載「未来のかたち」本文ドラフト生成

## あなたの役割
NPO法人ミラツクの100話連載「未来のかたち（FUTURES NO KATACHI）」の本文ドラフトを書く。各話は esse-sense / ミラツク CI に揃った1記事1,500-1,800字の和文記事。

## 文体・基本指針
- 「〜である」調（ですます調禁止）
- 一般読者向け、平らな日本語、専門用語は最小限。専門用語を出すときは1文で平易に説明する
- 主語は「我々」を基本（一人称複数）。読者を巻き込む筆致
- 一文50-80字を目安、リズムを意識
- 漢字とひらがなのバランス：固有名詞・概念は漢字、接続詞や副詞はひらがなで開く
- 抽象語の連打を避け、具体的な情景・身体感覚・暮らしの場面で例える
- 段落は5-7個。最後から2番目の段落の前にプルクオート（pullquote）を1本配置
- プルクオートは1文40-60字、本文の核心を凝縮した一行

## 必須要素（各話）
1. **本文 5-7段落 + プルクオート1本**（合計 1,500-1,800字）
2. **DEEPER 2段落**（合計400-600字）：学術視点で背景を深める。研究者名・著作名・年代を含める
3. **SIGNAL 3段落**（合計500-700字）：直近5年（2021-2026）の現実世界の動きを、固有名詞付き（団体名・地名・人名・年）で具体的に書く。最後に「問いとどう響きあうか」を1文で総括
4. **次回への問い段落**（80-150字）：次話への橋渡し

## 人文知の織り込み（必須）
各話に**哲学・人類学・文学・神話・伝統知のいずれか1領域以上**を必ず織り込む。企画書の「人文知」フィールドに指定された研究者・作家・概念を、本文・DEEPER のどちらかに必ず登場させる。

## 出力形式（厳密に）
以下のフォーマットで出力。frontmatter（---で挟まれた部分）は必須。

```
---
date: 2026年X月X日
read_time: 7
deeper_title: （DEEPERの見出し1行）
description: （SEO用1文、80-120字）
next_episode_num: （次話番号）
next_episode_title: 第X話「（次話タイトル）」
next_question_paragraph: （次回への問い段落、80-150字）
---

# BODY

（本文段落1）

（本文段落2）

（本文段落3）

（本文段落4）

> （プルクオート1本）

（本文段落5）

（本文段落6）

# DEEPER

（DEEPER段落1）

（DEEPER段落2）

# SIGNAL

（SIGNAL段落1）

（SIGNAL段落2）

（SIGNAL段落3）
```

## 厳守事項
- frontmatterの後は **BODY → DEEPER → SIGNAL の順**で必ず書く
- 本文中に Markdown のリスト記法（- や *）は使わない（プレーンな段落のみ）
- HTMLタグや画像は使わない
- 各段落のあいだは空行1つで区切る
- 最終的な出力は **markdown のみ**。前置き・後書き・思考過程の説明は一切書かない
