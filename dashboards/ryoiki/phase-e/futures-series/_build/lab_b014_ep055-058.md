# Codex 執筆ブリーフ — LAB セクション追加

連載「未来のかたち」の各話には、人文知（哲学・人類学・文学・神話・伝統知）を本文に織り込んだうえで、DEEPER（人文知の学術系譜）と SIGNAL（直近の現実世界の動き）の追記欄がある。今回はそこに新たに **LAB（科学の知から）** を加える。各話の本文テーマを踏まえ、対応する **自然科学・工学** の研究者・概念・年代を 400-600字で書く。

## 必須条件
- **字数: 400-600字**（1段落 or 短い2段落、合計）
- **文体**: 「〜である」調、主語「我々」（連載と統一）
- **領域**: 神経科学／認知科学／環境心理学／生態学／地球科学／医療工学／建築工学／情報科学／通信工学／AI・ロボティクス／システム工学／統計物理 などから、本文テーマに対応するものを選ぶ
- **必ず**: 研究者名 + 論文/書籍名 + 年代（西暦）の組を **最低3組** 入れる
- **平らな日本語で、具体的に**: 暮らしの言葉に翻訳しつつ自然科学・工学の系譜を示す

## 出力形式
各話を `=== EPNNN ===` で区切る。LAB 本文のみ書く（frontmatter なし、見出しなし）。

```
=== EP004 ===
場所の重さは、神経科学の言葉でも裏付けられつつある。ジョン・オキーフは1971年、海馬に特定の地点で発火する「場所細胞」を発見し、メイ＝ブリットとエドヴァルト・モーザーは2005年、内嗅皮質に空間を幾何学的に符号化する「格子細胞」を見出した。三人は2014年にノーベル生理学・医学賞を受けている。エレノア・マグワイアの『PNAS』2000年論文は、ロンドンの道を覚え続けたタクシー運転手の海馬後部が物理的に大きくなることを示した。場所を歩き覚えるという経験は、脳の構造そのものを書き換えている。

建築と通信の側でも、場所は具体性を取り戻している。ロジャー・ウルリッヒの『Science』1984年論文は、病院の窓から木が見えるだけで術後の回復が早まることを実証し、エドワード・O・ウィルソン『Biophilia』（1984）以来のバイオフィリック・デザインへとつながった。MIT Senseable City Labのカルロ・ラッティはセンサーデータから場所の使われ方を可視化し、IPFSやティム・バーナーズ＝リーのSolidは、データを再び土地と関係に結び直す試みを始めている。場所は哲学だけでなく、神経・建築・通信のレイヤーで同時に語られはじめている。

=== EP005 ===
（次の話）
...
```

### 第55話「忘れることにも、かたちがある」
- 人文知: 神話／ギリシャ神話、レーテーの川
- 学術領域: 記憶倫理／トラウマ研究
- 本文（BODY）:
```
夜明け前に目が覚め、同じ場面がまぶたの裏でくり返されることがある。音、匂い、廊下の暗さ、誰かの声の震え。終わったはずの出来事が、身体の中では終わっていない。忘れてはいけないことがある一方で、忘れなければ今日のご飯を炊けないこともある。記憶は人を支えるが、近すぎる記憶は息をふさぐ。だから我々は、忘却をただの欠落として扱うだけでは足りない。

ギリシャ神話には、死者が渡るレーテーの川がある。その水を飲むと、前の生を忘れるとされた。ヘシオドスの『神統記』（紀元前8世紀頃）が語るレーテーは忘却を司る女神でもあり、プラトン『国家』（紀元前4世紀）のエルの物語では、魂が新しい生へ向かう前に忘却の水を飲む。忘れることは、失うことだけでなく、次へ進むための通路でもあった。記憶をすべて背負ったままでは、新しい生は始まらない。

もちろん、忘却は危うい。戦争、災害、暴力、差別の記憶を社会が都合よく忘れれば、同じ傷はくり返される。けれど強い傷を持つ人にとって、すべてを鮮明に覚え続けることは、現在を奪うことがある。電車の音、病院の消毒液、ある言葉の響きが、過去を今ここへ連れ戻す。忘却とは記憶の消去ではなく、距離の作り直しである。その距離がなければ、台所に立つことも、玄関を開けることも難しくなる。

フロイトは『快原理の彼岸』（1920）で、傷ついた経験が反復として戻ることを考えた。ジュディス・ハーマンは『心的外傷と回復』（1992）で、回復には安全、想起、再接続の過程が必要だと述べた。キャシー・カルースは『経験されなかった経験』（1996）で、トラウマをその場で理解されず遅れて回帰する出来事として読んだ。ベッセル・ヴァン・デア・コーク『身体はトラウマを記録する』（2014）は、記憶が脳だけでなく筋肉や呼吸にも残ることを示した。

ここで対話させるべきなのは、記憶の義務と忘れる権利である。ポール・リクール『記憶・歴史・忘却』（2000）は、過去を記録し証言する責任と、赦しや忘却の難しさを同時に論じた。ハンナ・アーレント『人間の条件』（1958）は、人間が行為の不可逆性を抱えるからこそ、赦しが必要になると考えた。社会が責任を曖昧にする忘却と、個人が生き延びるための忘却は、同じ名前で呼ばれてもまったく違う。

問08の複数の自己は、過去の自分をそのまま抱え続けることだけでは成り立たない。あのとき震えていた自分、怒っていた自分、何も言えなかった自分を、今の自分が少し離れた場所から抱え直す必要がある。昔の自分を否定するのではない。別の語り方を見つけ、新しい関係の中で、自分の輪郭を作り直すのである。記憶の内容は変わらなくても、記憶との位置関係は変えられる。

> 忘却は過去を捨てることではなく、現在を生きる距離を作ることだ。

暮らしの言葉で言えば、忘れるとは、写真を捨てることだけではない。箱にしまい、見る日を自分で選ぶことである。語れる人が語り、語れない人は沈黙しても責められない場を作ることである。追悼の日を持ちながら、毎日その前で立ち止まらなくてもよい道を残すことである。記録は社会が引き受け、距離は個人が選ぶ。家族や学校や職場に必要なのは、話すことを急がせない時間であり、話さないことを裏切りと呼ばない作法である。

問題は、社会が都合よく忘れることと、個人が生き延びるために忘れることを混同しないことだ。被害を受けた人に「もう忘れなさい」と言う社会は、責任を水に流しているだけである。検証し、記録し、制度を変える責任は社会に残る。そのうえで、個人には傷との距離を選ぶ権利がある。忘却にも、責任あるかたちがある。我々が作るべきなのは、記憶を強制する社会でも、忘却を命じる社会でもなく、そのあいだを支える器である。
```

### 第56話「変身する者は、嘘をついているのか」
- 人文知: 神話／記紀神話、変身譚
- 学術領域: 神話学／自己変容論
- 本文（BODY）:
```
久しぶりに会った友人の名刺の肩書が変わっている。髪型も、話し方も、暮らす町も違う。昔の呼び名で呼びかけると、少しだけ空気が止まる。変わる人は、信用できないのだろうか。我々は「前と違う」というだけで身構える。けれど人生を長く眺めれば、変わらない人などいない。変わらないふりを覚えた人がいるだけである。変化は例外ではなく、暮らしの基本条件である。

神話には、変身する存在が多い。鳥になる神、蛇になる神、魚の姿で現れる者、見知らぬ旅人として家の戸をたたく者。『古事記』（712）や『日本書紀』（720）にも、人間と神、動物と自然の境界が揺れる場面がある。ヤマトタケルは衣を替え、姿を変えて敵の宴に入り込む。トヨタマビメは出産の場面で異形の姿を見られ、海の世界と人間の世界の隔たりを露わにする。変身は奇術ではなく、境界を越えるための知恵である。

オウィディウスの『変身物語』（8年）では、人は木になり、鳥になり、星座になる。そこでは変化は罰であり救いでもある。ジェイムズ・フレイザー『金枝篇』（1890）は、儀礼と神話の中で生命が形を変えながら循環する構造に注目した。折口信夫は『古代研究』（1929）で、神が外から訪れる「まれびと」の感覚を論じた。見慣れた姿ではないものが共同体へ入り、秩序を揺らし、更新する。変身する者は、境界の危うさと可能性を同時に運んでくる。

近代社会は、変わらない自己を信頼の条件にしてきた。同じ名前、同じ住所、同じ職業、同じ履歴。書類の上では、一貫した個人ほど扱いやすい。けれど、環境が変わり、関係が変われば、自己の形も変わる。転職、移住、改名、信仰の変化、性別の移行、介護による生活の変化。人は何度も姿を変えながら生きる。変わった人を疑うだけの社会では、変化が必要なときほど沈黙が増える。

この問題は、同一性の哲学ともつながっている。ジョン・ロック『人間知性論』（1690）は、人格の同一性を意識の連続に見た。ポール・リクール『他者のような自己自身』（1990）は、同じであり続ける同一性と、物語を通じて保たれる自己性を分けて考えた。前者は変化を疑い、後者は変化の中で応答を続ける力を見る。神話の変身譚は、近代の身分証明がこぼしてしまうこの自己性を、古い物語のかたちで保存している。

問08は、変化を一貫性の欠如として責めるのではなく、変化の中にも誠実さがありうると考える問いである。昨日の自分と同じことを言い続けるだけが誠実ではない。見える景色が変わったとき、前の言葉を握りしめたままにしないことも誠実である。変身とは、自分を捨てることではなく、自分を生かす形を探し直すことである。大切なのは、変わらなかったふりではなく、変わったあとにどの約束を結び直すかである。

> 変身は嘘ではなく、環境と関係に応答するための知恵である。

暮らしの言葉にすれば、変身はもっと身近である。親になった日、退職した日、病名を告げられた日、離婚届を書いた日、通称名で呼ばれ始めた日。我々はそのたびに、前の自分を消すのではなく、新しい服に袖を通すように関係を結び直す。周囲にできることは、古い呼び名で相手を縛らないこと、変化の理由を詮索しすぎないこと、必要な手続きや呼称を静かに更新することである。変身は舞台上の出来事ではなく、役所の窓口、職場の名札、家族の食卓で起きている。

変身する者をすぐに嘘つきと呼ぶ社会では、人は必要な変化まで隠すようになる。弱ったこと、迷ったこと、信じるものが変わったことを言えなくなる。成熟した社会は、同じであり続ける人だけを信じるのではない。変わりながら約束を扱い直し、関係を結び直す人を信じる作法を持つ。神話の変身譚は、その古い手がかりである。変わる自己を受け止めることは、共同体自身が変わる準備をすることでもある。
```

### 第57話「ふるさとは一つでなくてもいい」
- 人文知: 人類学／ディアスポラ研究、移動と帰属
- 学術領域: 移民研究／社会人類学
- 本文（BODY）:
```
空港の到着口で、スーツケースに貼られた古いタグが何枚も重なっている。家に帰る人もいれば、帰るという言葉がどの場所を指すのか、少し迷う人もいる。どこ出身か、と聞かれて答えに詰まるのは、根がないからではない。生まれた町、親の国、育った団地、いま働く都市へ、根が複数の方向に伸びているからである。改札を出た瞬間に懐かしい匂いを感じる場所が一つでない人は、すでに珍しい存在ではない。

ふるさとは一つであるべきだと思われがちである。履歴書にも、会話の最初にも、出身地という欄や問いがある。けれど移動の時代、人は複数の場所に結ばれて生きる。生まれた町、親の国、今暮らす都市、遠くの親族、オンラインでつながる共同体。どれか一つだけを本物とし、残りを薄いものとして扱う必要はない。我々が問うべきなのは、どの場所が本当かではなく、複数の場所がどう一人の生活を支えているかである。

ディアスポラ研究は、移動した人々が失った故郷を懐かしむだけでなく、新しい場所で混ざり合う文化を作ることを示してきた。ウィリアム・サフランは「Diasporas in Modern Societies」（1991）でディアスポラの特徴を整理し、ジェイムズ・クリフォードは『ルーツ』（1997）で、移動と接続の中に文化を見た。スチュアート・ホールは「Cultural Identity and Diaspora」（1990）で、アイデンティティを固定した起源ではなく、語り直される位置として捉えた。ふるさとは、出発点だけでなく、通過点でも作られる。

別の角度から見れば、近代国家は人を一つの住所、一つの国籍、一つの母語へと整えようとしてきた。学校は標準語を教え、役所は戸籍や住民票で人を管理し、国境は入る者と出る者を分ける。ベネディクト・アンダーソン『想像の共同体』（1983）は、国民が印刷物や制度を通じて想像される共同体であることを示した。その視点から見れば、ふるさとが一つであるという感覚も、自然な事実だけでなく歴史的に作られた形式である。移動する人は、その形式の隙間から別の共同体の作り方を見せている。

台所には親の国の香辛料があり、学校では日本語で学び、地域の祭りでは神輿を担ぐ。家庭では別の暦で祈り、職場では別の祝日に合わせる。そこに矛盾はない。ひとつの身体が、複数の場所の時間を持っているだけである。リンダ・バッシュ、ニナ・グリック・シラー、クリスティーナ・ブラン＝サントン『越境する国民』（1994）は、移民が一つの国に吸収されるだけではないことを示した。人は暮らす場所を変えても、関係まで置き去りにはしない。

> ふるさとが複数あることは、根の浅さではなく関係の深さである。

暮らしの言葉で言えば、ふるさとは役所が一つに決めるものではない。帰ったときに靴を脱ぐ家、名前を呼んでくれる人、墓や祈りの場所、好きな食べ物の匂い、もう住めないが忘れられない道。子どもが給食の献立と家のスープの両方を好きでいることを、矛盾と呼ばなくてよい。夏休みに祖父母の国へ行き、秋には日本の運動会で走る。その往復の中で、子どもはどちらかを選ぶ前に、どちらにも応答する力を覚えていく。

もちろん、複数のふるさとを持つことは、きれいな多様性の物語だけではない。帰省の費用、在留資格、親族への送金、差別的なまなざし、祖父母と言葉が通じなくなる寂しさがある。だからこそ、複数の帰属を本人の努力や家族の美談に閉じ込めてはならない。学校、職場、自治体、医療機関が、複数の背景を持つ人を前提に手続きを整える必要がある。ふるさとの複数性は、感情の問題であると同時に制度の問題である。

社会が求める「あなたは何人か」という問いを、少し緩める必要がある。その問いは便利だが、ときに人の暮らしを狭く切り取る。子どもに一つの国への忠誠だけを求めれば、家庭で受け取った言葉や記憶は恥ずかしいものになる。我々の社会は、移動する人を例外として扱う段階を終えつつある。複数のふるさとを前提に、制度と言葉を作り直す時代である。その作り直しは、移動した人だけでなく、移動しないと思っていた我々自身の帰属も自由にする。
```

### 第58話「母語は、母だけのものではない」
- 人文知: 文学／多和田葉子、越境する言葉
- 学術領域: 言語文化論／多言語教育
- 本文（BODY）:
```
夕方のスーパーで、子どもが親に別の言葉でねだり、レジでは日本語で「袋はいりません」と言う。その切り替えは、翻訳機のボタンではない。声の高さ、目の合わせ方、甘え方まで変わる。言葉が変わると、自分の身体の向きも変わる。多言語で生きる人は、同じ内容を別の記号に置き換えているだけではない。店の通路を歩きながら、子どもは二つの世界を軽やかに渡っているように見えるが、その背後には、聞き分け、言い換え、黙ることを選ぶ細かな判断が積み重なっている。

母語という言葉には、温かさと重さがある。母から受け取った言葉、家の中で最初に聞いた言葉。けれど母語は、母だけのものではない。祖父母の声、地域の音、学校の標準語、友人との混じった言い方も、我々の言葉を作る。移動する人にとっては、家庭の言葉と社会の言葉が違うことも珍しくない。むしろ問いは、一つの正しい声に早くそろえることではなく、複数の声を持つ人が、どの場でどの言葉を使えるかである。

多和田葉子の文学は、母語と外国語のあいだで、言葉が身体をずらす感覚を描いてきた。『エクソフォニー』（2003）では、母語の外へ出ることが不自由であると同時に、新しい感覚を開く経験として語られる。『献灯使』（2014）では、言葉と身体と国家の境界が揺らぎ、正しい日本語という安心が静かにほどけていく。エヴァ・ホフマン『Lost in Translation』（1989）も、移住によって言葉を失い、別の言葉で自己を組み直す痛みを記した。言葉は道具である前に、記憶と感情の住まいである。

別の角度から見ると、言語は世界の分け方そのものに関わっている。エドワード・サピア『言語』（1921）は、言語を文化の形式として捉え、ベンジャミン・リー・ウォーフ『言語・思考・現実』（1956）は、言語が思考の習慣に影響する視点を広めた。もちろん、人は言葉に完全に閉じ込められるわけではない。けれど、怒りを表す言い回し、敬意を示す距離、冗談が許される範囲は、言葉ごとに少しずつ違う。多言語の自己は、その違いを身体で知っている。

ミハイル・バフチンは『小説の言葉』（1930年代）で、言葉には複数の声や社会的な響きが入り込むと論じた。ジム・カミンズは1980年代から、子どもの第一言語の発達が第二言語の学習にも関わることを示した。つまり家庭の言葉は、学校の言葉を邪魔するものではない。むしろ考える力を支える根である。ここで多和田の文学と多言語教育は対話する。前者は言葉が自己を揺らす感覚を描き、後者はその揺らぎを学びの資源として制度化しようとする。

> 複数の言葉は自己を分けるのではなく、世界への窓を増やす。
```
