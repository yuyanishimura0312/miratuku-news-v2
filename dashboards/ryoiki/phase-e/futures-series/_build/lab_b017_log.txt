# Codex 執筆ブリーフ — LAB セクション追加

連載「未来のかたち」の各話には、人文知（哲学・人類学・文学・神話・伝統知）を本文に織り込んだうえで、DEEPER（人文知の学術系譜）と SIGNAL（直近の現実世界の動き）の追記欄がある。今回はそこに新たに **LAB（科学の知から）** を加える。各話の本文テーマを踏まえ、対応する **自然科学・工学** の研究者・概念・年代を 400-600字で書く。

## 必須条件
- **字数: 400-600字**（1段落 or 短い2段落、合計）
- **文体**: 「〜である」調、主語「我々」（連載と統一）
- **領域**: 神経科学／認知科学／環境心理学／生態学／地球科学／医療工学／建築工学／情報科学／通信工学／AI・ロボティクス／システム工学／統計物理 などから、本文テーマに対応するものを選ぶ
- **必ず**: 研究者名 + 論文/書籍名 + 年代（西暦）の組を **最低3組** 入れる
- **平らな日本語で、具体的に**: 暮らしの言葉に翻訳しつつ自然科学・工学の系譜を示す


### 第67話「知識は白衣だけを着ていない」
- 人文知: 伝統知／イヌイットの海氷知識、職人知
- 学術領域: 科学技術社会論／知識論
- 本文（BODY）:
```
冬の朝、整備士はエンジンをかけた瞬間に眉を動かす。数値はまだ警告を出していないが、音の底にかすかな乱れがある。漁師は港の匂いで潮の変わり目を知り、陶工は土を握った重さで水分を読む。台所では、味噌汁の湯気と鍋の音だけで火加減を直す人がいる。知識という言葉を聞くと、我々は白衣、実験室、計測器、論文を思い浮かべる。だが世界には、手のひらや耳や足裏に宿る確かさがある。

現代社会は、測定できる知識を強く信頼してきた。温度、濃度、速度、確率、偏差、リスク。数字で示された知は、遠く離れた人にも伝えられ、何度も確かめられる。これは社会を支える大切な力である。けれど、世界の変化はいつも数字になって現れるわけではない。氷の音がいつもと違う。風の匂いに湿り気がある。木材を削る手応えが重い。数値に変換される前の変化を、身体が先に受け取ることがある。

イヌイットの海氷知識は、その代表的な例である。氷の厚み、割れ目の走り方、風向き、潮の流れ、雪面の色、足を置いたときの沈み方。これらを読み違えれば、移動は命に関わる。衛星画像は広い範囲を見せてくれるが、今日ここを歩けるかどうかは、土地に根ざした知が教えることも多い。科学と生活の知は、競争相手ではなく、異なる距離から世界を見る目である。片方だけでは、危険の輪郭を取り逃がすことがある。

ドナ・ハラウェイは「状況づけられた知識」（1988）で、誰の場所にも属さない視点という客観性を問い直した。マイケル・ポランニーは『暗黙知の次元』（1966）で、人は語れる以上のことを知っていると述べた。サンドラ・ハーディング『科学のなかのフェミニズム』（1986）も、知識を生み出す位置と権力を見えるようにした。知は無色透明ではない。誰が、どこで、何を守るために知っているのか。その問いを抜きにして、確かさを語ることはできない。

近代の制度は、しばしば現場の知を標準化し、書類に載る知へと変えてきた。ジェームズ・C・スコットは『国家のように見る』（1998）で、国家が土地や労働や森林を読みやすくする過程で、地域の複雑な実践が失われる危うさを描いた。これは科学への批判だけではない。統治や管理が、見えるものだけを世界だと思い込むことへの警告である。地図は必要であるが、地図の余白で人は暮らしている。

職人知もまた、研究室の外にある確かさである。陶工は土の湿りを手で知り、漁師は潮の変わり目を体で覚え、整備士はエンジン音の乱れを聞き分ける。これらは曖昧な勘ではない。長い反復の中で鍛えられた判断であり、言葉にしにくいが再現性を持つ知である。失敗の記憶と身体の訓練が、そこに積もっている。研究者の実験ノートがあるように、職人の手にも、無数の試行錯誤の履歴が刻まれている。

中村雄二郎は『臨床の知とは何か』（1992）で、普遍的な理論知だけでなく、場面に応答する知の重要性を論じた。柳田國男『遠野物語』（1910）や宮本常一『忘れられた日本人』（1960）は、生活者の観察を社会の知として残した。ハラウェイが知の位置を問うなら、中村や宮本は知が立ち上がる場面を日本語で示している。科学技術社会論と民俗学は、遠く離れているようで、生活の中の確かさをどう扱うかという一点で深くつながる。

> 科学を広げるとは、数字になる前の変化を聞くことである。

暮らしの言葉に翻訳すれば、知識の入口を机の上だけに置かないことである。畑の土を触る、海の色を見る、機械の音を聞く、祖母の漬物の塩梅を覚える。子どもが祖父の道具箱から、音や重さの違いを学ぶこともある。その経験を「なんとなく」と片づけず、記録し、比べ、研究者の測定と並べる。科学を否定するのではない。科学だけに通訳を任せきることの危うさを減らすのである。

70年後の社会では、知識の服装はもっと多様になっているはずだ。白衣を着た知もあれば、防寒具を着た知、作業着を着た知、台所に立つ知もある。知識は特定の建物に閉じ込められない。我々が未来を少し広い目で見るためには、研究室の外で育った確かさに、正面から席を用意する必要がある。その席は、飾りではなく、判断を変える力を持つ席でなければならない。
```

### 第68話「教室に森を入れる」
- 人文知: 哲学／ジョン・デューイ、ケアの教育
- 学術領域: 教育哲学／環境教育
- 本文（BODY）:
```
雨上がりの校庭で、子どもが靴の裏についた泥を見ている。教室では土壌と水の循環を習ったばかりだが、その泥の冷たさや匂いは教科書の図とは違う。窓の外の森、通学路の川、近所の畑、祖父母が覚えている地名もまた、学びの場所である。廊下に貼られた時間割は、世界を教科に分けて整える。けれど世界そのものは、理科だけでも社会だけでもできていない。教室は、黒板と机だけでできているわけではない。

学校は長いあいだ、世界を教科に分け、正解を早く選ぶ力を育ててきた。その力は必要である。計算ができること、文章を読めること、科学の基本を知ることは、社会を生きる土台になる。けれど、複数の世界観が並ぶ社会では、それだけでは足りない。同じ場所をいくつもの見方で読む力がいる。森を資源として見る目、生態系として見る目、神話の舞台として見る目、遊び場として見る目を、子どもが同時に持てるかが問われている。

森は資源であり、生態系であり、神話の舞台であり、子どもの遊び場でもある。ひとつの森に入り、木の種類を調べる。土の匂いをかぐ。地域の人から昔の利用を聞く。地図で水の流れをたどる。祭りや伝承を読む。鳥の声を録音し、落ち葉の厚みを測り、古い写真といまの景色を比べる。そこでは理科、社会、国語、総合学習が、ばらばらの棚から降りて、ひとつの場所に集まる。学ぶとは、世界の層を重ねて読むことである。

ジョン・デューイは『民主主義と教育』（1916）で、学びを生活と社会参加の過程として考えた。経験はただ体験することではなく、結果を受け取り、考え直す循環である。パウロ・フレイレ『被抑圧者の教育学』（1970）は、学びを一方的な注入ではなく、世界を読む対話として捉えた。ネル・ノディングズ『ケアリング』（1984）は、教育の中心に関係性と応答を置いた。三者は違う場所から、学びを閉じた知識の受け渡しではなく、世界との関係を作り直す営みとして見ている。

注意したいのは、伝統知を飾りとして扱わないことである。授業の最後に少し昔話を添えるだけでは、世界観は変わらない。地域の語り、観察、科学、歴史を同じ重さで扱う工夫が必要である。たとえば古い地名を聞くなら、その由来を地形と照らし、災害の記録と比べ、そこに住んできた人の記憶も聞く。子どもは、ただ知識を受け取るのではなく、異なる見方の間を歩きながら、自分の問いを育てていく。正解は消えるのではなく、問いの中で位置を変える。

環境教育の系譜は、自然を教材として利用するだけでは足りないことを教えている。レイチェル・カーソン『センス・オブ・ワンダー』（1965）は、子どもが世界へ驚く力を守ることの大切さを語った。デイヴィッド・オア『地球を念頭に置く教育』（1994）は、教育が環境破壊の前提を作ることもあると警告した。デューイが経験を、フレイレが対話を、ノディングズがケアを重んじたなら、森を教室に入れる教育は、知識と関係と責任を同時に育てる営みである。

ここで東アジアの学びの伝統も響きあう。宮沢賢治『農民芸術概論綱要』（1926）は、農と芸術と地域の幸福を切り離さずに考えた。日本の生活教育や郷土教育の蓄積には、地域を素材にしながら、地域を閉じた誇りにしない難しさも刻まれている。森を教室に入れるとは、地域を美化することではない。植林の歴史、開発の記憶、獣害、観光、所有の問題まで含めて学ぶことである。複数の世界観は、都合のよい物語だけを並べることでは育たない。

> 教育は、正解を急がず世界の層を読む練習である。

暮らしの言葉に翻訳すれば、教室に森を入れるとは、遠足を増やすことだけではない。給食の米がどの田から来たのかを知る。川の水位を毎月測る。古い地名を地図に書く。地域の人の話を聞き、科学の言葉で確かめ、詩や絵で残す。校庭の木を一年見続け、葉の開く時期や虫の姿を記録する。知識を頭の中だけのものにせず、身体、場所、他者との関係の中で育てるのである。

70年後の学校は、いまより少し外へ開いているだろう。教科書は残るが、教科書だけが世界ではなくなる。地域の人、川の水位、季節の星、古い地名、土の手触りが教材になる。子どもたちは、一枚の正解表を埋めるのではなく、重なった世界を傷つけずに歩く技術を身につけていくのである。その技術は、未来の市民が異なる価値のあいだで判断するための基礎体力になる。
```

### 第69話「暦は誰のものか」
- 人文知: 神話／マタリキ、記紀神話の季節感
- 学術領域: 時間論／文化史
- 本文（BODY）:
```
年末のスーパーで、しめ縄と決算セールの札が並んでいる。同じ一日でも、会社にとっては四半期の締め日であり、学校にとっては学期の終わりであり、農家にとっては雨を待つ日であり、誰かにとっては亡くなった人を思い出す日である。壁のカレンダーには同じ数字が印刷されている。だが、その数字の下で流れている意味はひとつではない。時間は時計の針だけでなく、暮らしの物語でできている。

現代社会は、時計とカレンダーで動く。締切、年度、任期、会計、列車の時刻表、納期、予約枠。これらは社会をそろえるために役立つ。だが、便利な時間はしばしば強い時間になる。予定表に入らない待つ時間、祈る時間、回復する時間、祖先とつながる時間は、効率の外側へ押し出されやすい。速く測れる時間だけが公的な時間になると、季節の遅れや身体の回復、喪の沈黙は、社会の中心から見えにくくなる。

世界には、別の時間の読み方がある。星の出を待つ時間、雨季と乾季の時間、鮭が戻る時間、稲が実る時間、死者を迎える時間。マオリのマタリキは、星の巡りと新年、祖先の記憶、収穫への感謝を結ぶ。日本の記紀神話にも、国生み、稲作、海と山の神の物語を通じて、季節と世界の始まりが重なっている。神話は、単なる古い物語ではない。世界がどのように始まり、めぐり、受け継がれるかを語る時間の装置である。

エドワード・トンプソンは「時間、労働規律、産業資本主義」（1967）で、時計時間が労働と社会秩序を組み替えた過程を描いた。ミルチャ・エリアーデは『永遠回帰の神話』（1949）で、神話が始まりの時間を反復し、現在を更新する働きを論じた。バーバラ・アダム『時間と社会理論』（1990）は、社会が複数の時間を生きることを示した。三者を重ねると、近代の時計時間と神話的な反復時間は、対立するだけでなく、社会の中で絶えずせめぎ合っていることが見えてくる。

未来を考えるとき、我々はすぐに何年後という数字を置く。2030年、2050年、2100年。数字は必要である。政策目標も予算も、時間を区切らなければ動きにくい。だが、それだけでは足りない。どの季節をめぐる未来なのか。どの記憶を背負う未来なのか。誰に引き渡す時間なのか。未来は直線の先にだけあるのではなく、めぐりながら戻ってくるものの中にもある。稲の循環、祭りの反復、命日の沈黙は、未来を別の形で数えている。

折口信夫は『古代研究』（1929）で、まれびとや祭祀を通じて、来訪と反復の時間を読み解いた。柳田國男『年中行事覚書』（1955）は、地域の暮らしが季節の行事によって編まれていることを示した。和辻哲郎『風土』（1935）は、人間の存在が気候や風土と切り離せないことを論じた。トンプソンが近代の時計を、折口や柳田が祭りの時間を見たとすれば、我々の社会はその両方の緊張の中で未来を数えている。制度は直線を求め、暮らしは循環を覚えている。

この緊張は、環境危機の時代にいっそう切実になる。気候目標は2050年のような年号で語られるが、森は会計年度では育たない。川の回復には、予算の周期より長い時間が必要である。土壌の厚みや海の豊かさは、祖父母の記憶と孫の暮らしをまたぐ。だから複数の暦を制度に入れるとは、休日を増やすことだけではない。短い任期の判断を、長い世代の時間へ接続する作法を作ることである。

> 暦は日付の表ではなく、世界との約束の並べ方である。

暮らしの言葉に翻訳すれば、暦を問い直すとは、予定表の余白を見直すことである。種をまく日、山に入らない日、祖先を迎える日、体を休める日、子どもに昔話を渡す日。会計年度だけで森を見れば、木は短期の収益になる。何世代もの暦で見れば、森は手渡す相手になる。家族の命日や地域の祭りを、単なる私的な予定としてではなく、共同体が時間を保つ仕組みとして見直すこともできる。どの暦で数えるかは、何を守るかを決めている。

70年後を考えるとは、直線の先を見ることだけではない。循環しながら続く時間を、制度の中に取り戻すことでもある。神話は、古い話として片づけられやすい。だが、社会が時間をどう理解してきたかを示す装置である。我々が未来を数える手つきには、まだ別の暦を重ねる余地がある。その余地を開くことは、過去へ戻ることではなく、未来への責任をより深い時間に結び直すことである。
```

### 第70話「都市の下に眠る村」
- 人文知: 伝統知／アイヌ、琉球、都市の民俗知
- 学術領域: 都市論／記憶研究
- 本文（BODY）:

```
駅前の新しい舗装を、雨水が妙な曲線を描いて流れていく。地図にはもう川の線はない。だが足元の低さは、暗渠になった水の道を覚えている。都市は新しい場所のような顔をしている。ビルが建ち、道路はまっすぐ引かれ、地名は再開発の名前に置き換えられる。それでも坂の名、祭りの順路、町内の境目に、昔の村の形が残っている。朝の通勤で誰も立ち止まらない角にも、かつて橋があり、井戸があり、畑へ向かう細い道があったかもしれない。

我々は都市を、過去をならして未来を建てる場所として見がちである。効率よく移動できること、土地を高度に利用すること、人口を集めること。それらは都市の大切な機能である。けれど、その機能だけで都市を見ると、先に住んでいた人々の記憶、消された水辺、祈りの場所、移住者の経験は見えにくくなる。便利な駅前広場の下に、誰かが立ち退いた家の間取りがあり、忘れられた墓地の方向があり、子どもたちが遊んだ水路の音が眠っている。

ピエール・ノラは『記憶の場』（1984年以降）で、近代化によって生きた記憶が失われるなか、記念碑、文書、儀礼、地名が記憶を支える場になると論じた。アルド・ロッシ『都市の建築』（1966）は、都市を集合的記憶の器として読んだ。ドロレス・ハイデン『場所の力』（1995）は、女性や労働者、移民の記憶を都市空間に刻み直す実践を示した。都市は単なる容器ではない。忘却と保存、開発と追悼がぶつかりながら、層を重ねてできる記憶の地形なのである。

アイヌや琉球の土地の記憶は、国家の地図や都市計画の中でしばしば薄められてきた。地名には、動物、川、岬、風、暮らしの行為が刻まれている。そこには、土地を所有物として切り分ける前の関係が残る。都市の民俗知も同じである。古い商店街の祭礼や、暗渠の上の曲がった道は、公式の歴史書とは別の記憶を運んでいる。開発の図面は直線を好むが、暮らしの記憶は曲線で残る。道が少し折れる理由をたどるだけで、都市は別の顔を見せ始める。

柳田國男の地名研究や宮本常一『忘れられた日本人』（1960）は、中央の歴史に残りにくい生活の記憶を拾い上げた。陣内秀信『東京の空間人類学』（1985）は、近代都市の表面の下にある水路、寺社、職人町の構造を読んだ。ノラやハイデンが記憶の公共性を問うなら、柳田、宮本、陣内は足元の地形と語りから都市を読み返す技術を与える。両者を重ねると、都市計画は建物の配置だけではなく、記憶をどの高さで、どの声で、誰に開くかを問う仕事になる。

都市が複数の世界観と共に生きるには、開発を止めるか進めるかの二択では足りない。新しい建物を作るときに、土地の記憶をどう読み込むか。地名をどう残すか。語られなかった人々の歴史を、公共空間でどう聞けるようにするか。都市計画は、経済効率だけでなく、記憶の扱い方を問われている。古いものを飾りとして残すだけでは不十分である。記憶が現在の意思決定に触れ、設計条件のひとつとして働くとき、街はようやく過去と同じ机につく。

> 都市の豊かさは、高さではなく足元の物語を聞く力で測られる。

暮らしの言葉に翻訳すれば、都市の記憶を聞くとは、いつもの駅名を声に出して考えることである。その名は川か、村か、神社か、誰かの姓か。雨の日に水がたまる場所、祭りの山車が曲がる角、外国料理店が並ぶ通り、戦災を免れた路地を、開発前のノイズではなく都市の本文として読むのである。マンションの掲示板、学校の校歌、バス停の名前、古い写真を持つ近所の人の話も、都市を読むための小さな資料になる。我々は専門家でなくても、足元の歴史に耳を置くことができる。

70年後の都市は、もっと高く、もっと速くなっているかもしれない。だからこそ、足元に降りる技術が必要になる。消えた川筋を示す舗装、先住の地名を学べる駅、祭りの記憶を残す広場、移住者の声を刻む図書館。都市の未来は、過去を消して白紙にすることではなく、消えなかった記憶と共に設計されるのである。次に我々が向き合うのは、その記憶を運ぶ言葉である。土地の名や祈りの語は、いつもきれいに翻訳できるわけではない。
```
