# Codex 再延長執筆ブリーフ v2 — 連載「未来のかたち」本文の最終長尺化

## あなたの役割
NPO法人ミラツクの100話連載の本文を、**最終公開水準（本文1,600-1,800字）まで延長する**最終ラウンド。前回延長版でも本文が1,100字前後にとどまっており、目標にあと500-700字足りていない。

## 絶対厳守の字数（厳格化）
- **本文（BODY）: 1,600-1,800字。1,600字を絶対に下回らないこと**
- **DEEPER: 500-700字 / 2段落。500字を絶対に下回らないこと**
- **SIGNAL: 600-800字 / 3段落。600字を絶対に下回らないこと**

## 字数確認の手順
本文を書き終えたら、必ず文字数を数えて、**1,600字未満なら段落をさらに追加**してから出力する。短いまま提出することは認めない。

## 段落構成（厳密）
本文 = 7-9段落 + プルクオート1本（最後から2番目の段落の前）
- 段落1: 暮らしの場面・身体感覚・歴史的事象から入る（200字）
- 段落2: 問いの導入と現在地（200字）
- 段落3: 人文知の研究者・概念・著作の導入（220字、固有名詞・年代必須）
- 段落4: 別角度・対比・歴史的系譜の深掘り（220字）
- 段落5: 別の研究者・別の伝統との対話（200字）
- プルクオート（40-60字、本文の核心を凝縮）
- 段落6: 翻訳の段落（暮らしの言葉）（200字）
- 段落7: 着地・次への橋（180字）

## 必須内容
1. **人物・著作・年代の固有名詞**：本文中に研究者名+著作名+年代の組を **最低3組** 挙げる
2. **対比的な視点**：本文中で2人以上の異なる思想・伝統を対話させる
3. **暮らしの場面**：抽象論で終わらせず、必ず読者の具体的な日常に落とし込む段落を入れる
4. **DEEPERは学術系譜＋日本語圏蓄積**：研究者名+著作+年代を最低5組
5. **SIGNALは国際/国内/響きあい**：固有名詞付きで2021-2024年の動きを示す

## 文体
- 「〜である」調（ですます調禁止）
- 主語は「我々」を基本
- 一文50-90字、長すぎず短すぎず
- 漢字とひらがなのバランス：固有名詞は漢字、接続詞・副詞はひらがなに開く

## 厳守事項
- 各話を上記の段落構成と字数で必ず守る
- BODY 1,600字未満は不可。書き終わったら文字数を確認し、不足なら追記する
- Markdown のリスト記法（- や *）は使わない（段落のみ）
- HTMLタグ・画像は使わない
- 思考過程を出力しない、最終Markdownのみ
- **Web検索を絶対に使わない**
