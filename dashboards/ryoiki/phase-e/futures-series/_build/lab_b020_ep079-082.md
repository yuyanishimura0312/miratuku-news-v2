# Codex 執筆ブリーフ — LAB セクション追加

連載「未来のかたち」の各話には、人文知（哲学・人類学・文学・神話・伝統知）を本文に織り込んだうえで、DEEPER（人文知の学術系譜）と SIGNAL（直近の現実世界の動き）の追記欄がある。今回はそこに新たに **LAB（科学の知から）** を加える。各話の本文テーマを踏まえ、対応する **自然科学・工学** の研究者・概念・年代を 400-600字で書く。

## 必須条件
- **字数: 400-600字**（1段落 or 短い2段落、合計）
- **文体**: 「〜である」調、主語「我々」（連載と統一）
- **領域**: 神経科学／認知科学／環境心理学／生態学／地球科学／医療工学／建築工学／情報科学／通信工学／AI・ロボティクス／システム工学／統計物理 などから、本文テーマに対応するものを選ぶ
- **必ず**: 研究者名 + 論文/書籍名 + 年代（西暦）の組を **最低3組** 入れる
- **平らな日本語で、具体的に**: 暮らしの言葉に翻訳しつつ自然科学・工学の系譜を示す

## 出力形式
各話を `=== EPNNN ===` で区切る。LAB 本文のみ書く（frontmatter なし、見出しなし）。

```
=== EP004 ===
場所の重さは、神経科学の言葉でも裏付けられつつある。ジョン・オキーフは1971年、海馬に特定の地点で発火する「場所細胞」を発見し、メイ＝ブリットとエドヴァルト・モーザーは2005年、内嗅皮質に空間を幾何学的に符号化する「格子細胞」を見出した。三人は2014年にノーベル生理学・医学賞を受けている。エレノア・マグワイアの『PNAS』2000年論文は、ロンドンの道を覚え続けたタクシー運転手の海馬後部が物理的に大きくなることを示した。場所を歩き覚えるという経験は、脳の構造そのものを書き換えている。

建築と通信の側でも、場所は具体性を取り戻している。ロジャー・ウルリッヒの『Science』1984年論文は、病院の窓から木が見えるだけで術後の回復が早まることを実証し、エドワード・O・ウィルソン『Biophilia』（1984）以来のバイオフィリック・デザインへとつながった。MIT Senseable City Labのカルロ・ラッティはセンサーデータから場所の使われ方を可視化し、IPFSやティム・バーナーズ＝リーのSolidは、データを再び土地と関係に結び直す試みを始めている。場所は哲学だけでなく、神経・建築・通信のレイヤーで同時に語られはじめている。

=== EP005 ===
（次の話）
...
```

### 第79話「やさしさを制度にする」
- 人文知: 哲学／ジョアン・トロント、ケアの倫理
- 学術領域: ケア倫理／社会政策
- 本文（BODY）:
```
夜中の台所で、薬の袋を切る音がする。眠い目で水をくみ、熱を測り、布団を直し、明日の仕事の段取りを考える人がいる。役所の窓口では、通訳を探して付き添う人がいる。駅では、階段の前で車いすを押す人が立ち止まる。保育園の連絡帳を書きながら、親の通院予定を思い出す人もいる。誰かを大切にする力を、家庭や善意だけに任せると社会は壊れるのである。そこには愛情の不足ではなく、時間と人手と休息を私的な偶然へ押し込める設計の失敗がある。

複数の世界観が並ぶ社会では、違いを認めるだけでは足りない。その違いを生きられる条件を整える必要がある。言語が違う人、老いを迎えた人、障害のある人、土地を追われた人、祈りの習慣を持つ人。それぞれが尊重されるには、時間、場所、通訳、介助、休息がいる。理念だけでは、疲れた身体は支えられない。会議で多様性を語っても、そこに休憩、移動、食事、沈黙の余白がなければ、参加できる人だけが未来を決めてしまう。

ジョアン・トロントは『モラル・バウンダリーズ』（1993）で、ケアを女性や家庭の役割に閉じず、民主主義の中心課題として論じた。さらに『ケアする民主主義』（2013）では、ケアを社会の周辺に置く政治そのものを問い直した。ケアには、気づく、引き受ける、行う、応答を受け取るという段階がある。社会が何に気づき、誰に責任を負い、どう応答を修正するのか。そこに政治の質が現れるのである。気づかない制度は、暴力的でなくても人を取り残す。応答を聞かない制度は、善意であっても相手の世界を狭める。

キャロル・ギリガンは『もうひとつの声で』（1982）で、抽象的な正義だけでは見えにくい関係と責任の声を示した。エヴァ・キテイ『愛の労働』（1999）は、依存を人間の例外ではなく条件として考えた。ネル・ノディングズ『ケアリング』（1984）も、応答する関係の内側から倫理を組み立てた。自立した個人だけを制度の標準にすれば、幼い人、老いた人、病む人、介助する人が周辺へ押し出される。ここで正義の伝統とケアの伝統は対立するだけではない。権利はケアを恣意から守り、ケアは権利を生きた関係へ戻す。

やさしさを制度にするとは、感情を法律で命じることではない。疲れた人が休める設計、聞こえにくい声が届く仕組み、介護する人が孤立しない地域、病院で本人の言葉が尊重される手順を作ることである。上野千鶴子『ケアの社会学』（2011）が示したように、家族の内側へ隠された労働を公共の設計へ戻す必要がある。トロントの政治倫理と日本の介護研究は、善意を称賛するだけの社会から、負担の分配を問う社会へ我々を押し出す。誰が休めず、誰が無償で調整し、誰の都合が標準時刻になるのかを問うことが、制度設計の出発点になる。

> ケアは美徳ではなく、違いを生きられるようにする社会の基盤である。

暮らしの言葉でいえば、ケアの制度化とは「困ったら頑張って頼む」社会をやめることである。電話が苦手な人には別の連絡手段がある。日本語が読めない人には翻訳がある。介護者には休む権利がある。支援を受ける人は、ただ管理されるのではなく、嫌なことを嫌と言える。制度は助けるだけでなく、助け方を直せるものでなければならない。窓口の椅子、予約の取り方、書類の言葉、家族以外が同席できる手順も、世界観を支える小さな装置である。朝のごみ出しを代わる近所の仕組み、宗教食を選べる給食、付き添いを欠勤扱いにしない職場も、同じ問いの中にある。

70年後の共生社会は、理念より先に身体を支える社会である。眠る場所があり、薬が届き、通訳がいて、祈る時間があり、ひと息つける椅子がある。複数の世界観は、抽象的な尊重だけでは並び立たない。日々の疲れを受け止める制度があって初めて、人は自分の世界を手放さずに隣人と生きられる。次に問われるのは、その制度の内側へ入る技術が、誰の普通を広げ、誰の声を細らせるのかである。
```

### 第80話「AIはどの世界を標準にするのか」
- 人文知: 哲学／技術哲学、バトラーの規範論
- 学術領域: AI倫理／情報社会論
- 本文（BODY）:
```
スマートフォンの画面に短い文章を打ち込むと、AIはすぐに返事をする。翻訳し、画像を作り、申請を審査し、病気の兆しを探し、働き方を変えていく。音も匂いもない返答は中立に見える。だが、その便利さの奥には、どの言葉を自然とし、どの顔を典型とし、どの暮らしを普通とするかという物差しが埋め込まれている。朝の検索結果から夜の推薦動画まで、我々の視界は少しずつ整えられていく。このとき標準は、命令ではなく提案の顔をして現れる。

AIは、学習した言葉や画像や制度の癖を引き受ける。多数派の言葉を自然にし、少数言語をぎこちなく訳し、都市の暮らしを標準として返すことがある。名前、肌の色、性別、家族の形、祈りの習慣、土地との関係。人間社会の偏りがデータに残っていれば、技術はそれを静かに増幅してしまう。問題は、間違いが起きることだけではない。間違いを誰が見つけ、どの言葉で訴え、どの速度で直せるのかである。モデルの出力を見て、自分の言い方が古いのか、地域の表現が間違いなのかと迷う人もいる。

マルティン・ハイデガーは「技術への問い」（1954）で、近代技術が世界を利用可能な資源として立ち現れさせると論じた。ラングドン・ウィナーは『鯨と原子炉』（1986）で、人工物には政治があると述べた。AIも単なる道具ではない。文章の候補、採用の順位、リスクの分類を通じて、人間の見方と行為を形作る。技術は外から使う器具ではなく、世界をどう見るかを先回りして整える環境でもある。何度も選ばれる候補は、やがて自然な言い方や正しい姿勢のように感じられる。

ジュディス・バトラーは『ジェンダー・トラブル』（1990）で、何が普通とされるかが身体や生き方を縛ることを示した。普通の家族、普通の声、普通の市民。こうした標準は、目立たないからこそ強い。AIがその標準を自動化すると、誰かの違和感は個人の問題として処理され、制度の偏りが見えにくくなる。ミシェル・フーコー『監獄の誕生』（1975）が描いた規律の力は、ランキングやスコアの形で、より柔らかく日常へ入り込む。標準化の力は、外から押しつけるだけでなく、内側の自己修正として働く。

問題は、AIを使うか使わないかだけではない。誰のデータで学び、誰が評価し、どの文化の違和感を修正できるのかである。ドン・アイディ『技術と生活世界』（1990）が示したように、技術は知覚と経験を媒介する。ルーシー・サッチマン『プランと状況的行為』（1987）は、行為が現場の文脈の中で組み立てられることを示した。ある共同体の知識は、公開データにしてよいものではないかもしれない。技術の設計には、境目を聞く力がいる。監査、説明、異議申し立て、データの由来の表示は、技術に対する付属品ではない。それらは複数の世界を残すための基本設計である。

> AIの問いは性能ではなく、どの世界を標準として返すのかにある。

暮らしに翻訳すれば、AIを使うとは、便利な助手を入れるだけでなく、判断の机に新しい癖を座らせることである。翻訳結果が変なら直せるか。申請が落ちた理由を聞けるか。少数言語や方言を笑わない設計か。地域の専門家や当事者が評価に入れるか。多様性を飾りとして入れるのではなく、標準そのものを複数にする必要がある。学校の作文支援、病院の問診、自治体の相談チャットも、その場にいる人の言葉へ戻せる回路を持たなければならない。便利さの裏で黙らされた違和感を、故障ではなく改善の入口として扱うのである。

AIは世界をひとつに縮める道具にも、翻訳の橋にもなりうる。遠くの言葉を近づけ、見落とされていた資料を探し、医療や教育の入口を広げる力もある。だからこそ我々は、技術をただ恐れるのではなく、どの世界を広げ、どの世界を狭めているのかを問い続ける必要がある。複数の世界観を守るAIは、速さよりも応答性を重んじる技術である。次に残るのは、そもそもデータにならない沈黙や気配をどう扱うかという問いである。
```

### 第81話「データにならないものの重さ」
- 人文知: 文学／宮沢賢治、詩と感受性
- 学術領域: 価値論／評価研究
- 本文（BODY）:
```
夕方の川辺で、子どもが黙って石を投げている。水面に輪が広がり、橋の下から涼しい風が来る。そこに入場者数はなく、売上もない。けれど、家へ帰る前のその十数分が、子どもの心をほどいていることがある。古い団地のベンチで、誰にも報告されない会釈が一日の支えになることもある。測れるものは大切である。費用、効果、満足度、来場者数、排出量、待ち時間。だが、測れないものが軽いわけではない。評価の場に呼ばれない価値は、しばしば効率化の名で静かに消える。

社会は判断のために数値を使う。数値は比較を助け、説明を可能にし、不公平を見つける手がかりにもなる。病院の待ち時間、学校の欠席率、排出量の変化は、数えなければ見逃される。問題は、数値が強すぎることである。表に載らないものが、存在しないもののように扱われるとき、世界の手触りが薄くなる。予算の会議では、語りにくい価値ほど後回しにされ、静かな場所や長い関係は、削ってもよい余白に見えてしまう。

宮沢賢治の『春と修羅』（1924）には、科学と詩、農と宇宙、個人の苦しみと全体の幸福が同時に現れる。『銀河鉄道の夜』（1934）では、星々の遠さと人の悲しみがひとつの旅の中で響き合う。賢治の世界では、人間、動物、鉱物、風、光が互いに無関係ではない。世界は測定対象である前に、感じ取られる関係の場である。羅須地人協会の実践にも、農業技術と祈りのような感受性を分けない態度があった。古い道具の手触り、盆の帰省で火をともす所作、海の色で天候を読む感覚も、暮らしの判断を支えている。

アマルティア・センは『不平等の再検討』（1992）で、豊かさを所得だけでなく、人が何をでき、どんな生を送れるかとして考えた。マーサ・ヌスバウム『女性と人間開発』（2000）も、ケイパビリティの視点から生活の質を論じた。マイケル・サンデル『それをお金で買いますか』（2012）は、市場の物差しが価値そのものを変える危うさを指摘した。価値は価格や効用に閉じない。生き方の幅、尊厳、関係、感受性もまた公共の判断に入る。数値は入口であり、結論ではない。

森に入った時の安心を、我々はどう測るのか。祖父母の言葉が残る場所を、どんな単位で数えるのか。祭りの準備で生まれる関係、死者を思う時間、朝の井戸端で交わす一言。見田宗介は『現代社会の理論』（1996）で、近代社会の欲望と意味を問い直した。内山節『自然と人間の哲学』（1988）は、山村の暮らしから自然との関係を考えた。たとえば防潮堤の高さを決めるとき、被害想定は不可欠である。けれど、海を見ながら生きてきた人の向き、墓地から見える水平線、祭りの道筋は、損益表だけでは残せない。軽かったのではない。測り方を持っていなかったのである。

> 測れないものを軽く見る社会は、失ってから重さを知る。

暮らしに翻訳すれば、データにならないものを守るとは、数字に反対することではない。数字の横に、語り、写真、地図、聞き書き、歩いて確かめる調査、子どもの絵、儀礼の記録を置くことである。住民の「なんとなく嫌だ」を未熟な感情として捨てず、何が失われる感覚なのかを聞く。言葉になるまで待つ時間も、評価の一部である。公園の木を切る前に、その木陰で待ち合わせた記憶を聞くことも、政策の外ではなく中に置かれるべき作業である。測れない価値を扱うとは、曖昧さを放置することではない。誰が何を大切にしているのかを、急いで一つの単位へ押し込まず、複数の記録として残すことである。

70年後の社会は、データの量がいまよりはるかに増えているだろう。だからこそ、データにならないものの重さを見失いやすい。何を測り、何を測らず、測れないものをどう語るのか。複数の世界観が並ぶ社会では、沈黙の知を消さずに公共の場へ運ぶ言葉と作法が必要になる。そのためには、専門家だけでなく、黙っていた人が話し始める場の設計がいる。次に問われるのは、その重さを抱えたまま、豊かさの名前をどれだけ増やせるかである。
```

### 第82話「豊かさの名前を増やす」
- 人文知: 伝統知／ブータンのGNH、アンデスのBuen Vivir
- 学術領域: 幸福研究／公共政策
- 本文（BODY）:
```
朝の電車で、疲れた顔の人がスマートフォンの経済ニュースを眺めている。株価は上がり、観光客は増え、駅前には新しいビルが建つ。けれどその人は眠れていない。近くの川では子どもが遊べなくなり、祭りの担い手は減り、祖母が話していた言葉を聞く機会も減った。豊かさをひとつの数字で呼ぶと、見えなくなる暮らしがある。明るい広告の下で、我々は何を得て、何を失ったのかをまだ十分に数えていない。

経済成長は、多くの人の生活を支えてきた。道路、医療、教育、住まい、食料の安定は、成長の力なしには広がらなかった。だから成長を軽く見ればよいわけではない。問題は、成長率だけが社会の羅針盤になることである。羅針盤がひとつだけだと、別の方角にある豊かさを見落とす。便利になったのに、暮らしが痩せることがある。所得は増えても、休む時間が消え、近所の顔が見えず、土や水の回復が遅れるなら、我々は豊かさの一部だけを拡大している。

ブータンの国民総幸福、GNHは、1970年代に第4代国王ジグミ・シンゲ・ワンチュクの言葉として広がり、のちに政策指標として整備された。精神的幸福、文化、環境、良い統治などを含めて豊かさを考える。アンデスのBuen Vivirは、アルベルト・アコスタ『Buen Vivir』（2013）に整理され、エクアドルやボリビアの憲法議論でも注目された。そこでは人間だけが発展の主人公なのではなく、自然、共同体、祖先との調和が豊かさの条件として考えられる。

リチャード・レイヤードは『幸福』（2005）で、所得の増加だけでは幸福を説明できないことを公共政策へつないだ。ジョセフ・スティグリッツ、アマルティア・セン、ジャンポール・フィトゥシは2009年の報告で、GDPの限界を指摘した。アマルティア・セン『不平等の再検討』（1992）は、豊かさを財の量ではなく、何をなし得るかという能力から捉え直した。これらの議論は、個人の所有を否定するのではない。所有だけでは、関係の質、時間の余白、環境の回復力を表せないと教えるのである。

ケア、休息、地域の結びつき、生態系の回復、文化の継承。これらは短い期間の生産性では測りにくい。森が戻るには時間がかかる。言葉が次の世代に渡るにも時間がかかる。広井良典『定常型社会』（2001）は、成長後の福祉、環境、コミュニティを同じ視野で論じた。宇沢弘文『社会的共通資本』（2000）も、市場だけに委ねてはならない基盤を示した。GNHとBuen Vivirと社会的共通資本は、出自は異なるが、豊かさを関係の厚みとして見る点で対話できる。

> 豊かさの名前が少ない社会では、守るべきものまで少なく見える。

暮らしの言葉に翻訳すれば、豊かさの名前を増やすとは、家計簿に載らない大切なものへ名前を与えることである。よく眠れる豊かさ、よく弔える豊かさ、土が戻る豊かさ、子どもが失敗できる豊かさ、少数の言葉で夢を見られる豊かさ。名前がなければ、政策の会議で呼び出せない。呼び出せなければ、守る順番にも入らない。保育の待ち時間、介護する人の孤独、川べりの涼しさ、商店街の挨拶は、暮らしの物差しに入ったとき初めて公共の課題になる。
```
