# Codex 執筆ブリーフ — LAB セクション追加

連載「未来のかたち」の各話には、人文知（哲学・人類学・文学・神話・伝統知）を本文に織り込んだうえで、DEEPER（人文知の学術系譜）と SIGNAL（直近の現実世界の動き）の追記欄がある。今回はそこに新たに **LAB（科学の知から）** を加える。各話の本文テーマを踏まえ、対応する **自然科学・工学** の研究者・概念・年代を 400-600字で書く。

## 必須条件
- **字数: 400-600字**（1段落 or 短い2段落、合計）
- **文体**: 「〜である」調、主語「我々」（連載と統一）
- **領域**: 神経科学／認知科学／環境心理学／生態学／地球科学／医療工学／建築工学／情報科学／通信工学／AI・ロボティクス／システム工学／統計物理 などから、本文テーマに対応するものを選ぶ
- **必ず**: 研究者名 + 論文/書籍名 + 年代（西暦）の組を **最低3組** 入れる
- **平らな日本語で、具体的に**: 暮らしの言葉に翻訳しつつ自然科学・工学の系譜を示す

## 出力形式
各話を `=== EPNNN ===` で区切る。LAB 本文のみ書く（frontmatter なし、見出しなし）。

```
=== EP004 ===
場所の重さは、神経科学の言葉でも裏付けられつつある。ジョン・オキーフは1971年、海馬に特定の地点で発火する「場所細胞」を発見し、メイ＝ブリットとエドヴァルト・モーザーは2005年、内嗅皮質に空間を幾何学的に符号化する「格子細胞」を見出した。三人は2014年にノーベル生理学・医学賞を受けている。エレノア・マグワイアの『PNAS』2000年論文は、ロンドンの道を覚え続けたタクシー運転手の海馬後部が物理的に大きくなることを示した。場所を歩き覚えるという経験は、脳の構造そのものを書き換えている。

建築と通信の側でも、場所は具体性を取り戻している。ロジャー・ウルリッヒの『Science』1984年論文は、病院の窓から木が見えるだけで術後の回復が早まることを実証し、エドワード・O・ウィルソン『Biophilia』（1984）以来のバイオフィリック・デザインへとつながった。MIT Senseable City Labのカルロ・ラッティはセンサーデータから場所の使われ方を可視化し、IPFSやティム・バーナーズ＝リーのSolidは、データを再び土地と関係に結び直す試みを始めている。場所は哲学だけでなく、神経・建築・通信のレイヤーで同時に語られはじめている。

=== EP005 ===
（次の話）
...
```

### 第59話「画面の向こうの私も、私である」
- 人文知: 哲学／アリストテレス、人格と行為
- 学術領域: 情報倫理／デジタル社会論
- 本文（BODY）:
```
夜の電車で、誰も声を出していないのに、車内には無数の会話が走っている。親指が画面を滑り、短い返信が誰かの眠りを軽くし、別の一言が誰かの胸を刺す。アカウント、アバター、ユーザー名。画面の中の自分は遊びでもあり、現実でもある。我々は座席に座ったまま、誰かの世界へ入り込んでいる。通知の小さな光は軽く見えるが、その向こうには、待っている人、怒っている人、救われる人がいる。

デジタル空間では、人は複数の自己を持ちやすい。仕事用の名前、趣味のアカウント、ゲームの姿、匿名の発言。オンラインの自己は、現実の自分から切り離された仮面のように見える。けれど、そこで交わされる言葉は誰かを支え、傷つけ、関係を作る。画面の薄さは、行為の重さを消してくれない。むしろ顔が見えないぶん、我々は行為の重さを自分で想像し、引き受ける必要がある。

アリストテレスは『ニコマコス倫理学』（紀元前4世紀）で、人柄は行為の積み重ねによって形作られると考えた。勇敢な行為を重ねることで勇敢な人になり、節度ある行為を重ねることで節度ある人になる。ならば、オンラインの行為もまた自己を作る。別名で書いた言葉も、アバターで行ったふるまいも、反復されれば癖になる。シェリー・タークル『スクリーン上の生活』（1995）は、オンライン空間が自己の多重性を可視化することを示した。分身は逃げ場であると同時に、習慣の練習場でもある。

別の角度から見ると、デジタルな自己は近代的な本人確認の制度とも衝突する。銀行口座、行政手続き、職場のIDは一人を一つの識別子へ結びつけようとする。だが、趣味の創作、病気の相談、性別や家族の悩みを語る場では、実名から距離を置けることが命綱になる。ハンナ・アーレント『人間の条件』（1958）は、行為が人々のあいだに現れ、関係の網を作るものだと論じた。現れる名前が戸籍名でなくても、そこでの行為は関係を作っている。

ルチアーノ・フロリディ『第四の革命』（2014）は、人間が情報環境の中で生きる存在になったことを示した。デジタルな分身は、現実から逃げる影ではなく、情報環境の中で他者と関わる行為の場所である。ここでアリストテレスの習慣論とフロリディの情報倫理は対話する。前者は行為が人格を作ることを教え、後者はその行為の舞台がもはや街路や家だけではないことを示す。自己は画面の外で完成し、画面の中へただ投影されるのではない。画面の中でも、自己は作られている。

> 画面の向こうの私は、軽い仮面である前に、誰かに届く行為である。

暮らしの言葉にすれば、投稿ボタンの前で一呼吸置くことだ。相手の顔が見えなくても、相手の夜はある。匿名で相談できる場を守りながら、匿名の攻撃は止める。実名だけを正義にしない。通報、ブロック、年齢確認、コミュニティの約束を整える。複数の名前を持つ自由と、誰かを傷つけない責任を同じ画面に置く必要がある。家族に見せる自分、同僚に見せる自分、ゲームの仲間に見せる自分が違っていてもよい。ただし、そのどれもが他者の時間に触れている。

問08は、デジタルな分身を禁止する問いではない。複数の自己を持つことには、自由がある。病気や障害、性別、趣味、政治的意見を、日常の名前から少し離して語れる場がある。匿名だからこそ助けを求められる人もいる。問題は、分身を持つことではなく、それぞれの場でどんな責任を引き受けるかである。匿名性は無責任の免許ではなく、弱い声を守るための制度にもなりうる。その境界を設計することが、情報社会の倫理である。

画面の向こうの私も、私である。けれど、それは戸籍名と完全に同じでなければならないという意味ではない。行為が関係を作り、関係が自己を作るという意味である。我々はこれから、デジタルな分身を持つことを前提に倫理を考えなければならない。複数の顔を持ちながら、誰かを壊さない生き方を学ぶ時代である。その学びは、法律や規約だけでなく、毎日の返信、削除、沈黙、謝罪の中で形を持つ。
```

### 第60話「ケアする私、ケアされる私」
- 人文知: 哲学／ジョアン・トロント、ケアの倫理
- 学術領域: ケア倫理／福祉社会論
- 本文（BODY）:
```
冬の朝、発熱した子どもの額に手を当てる人がいる。同じ時間に、病室では看護師が点滴の落ちる速さを見ている。駅の階段では、杖をつく人の肘に誰かがそっと手を添える。人はいつも自立しているわけではない。赤ん坊だったころ、我々は誰かに抱かれなければ生きられなかった。その事実を、社会はよく忘れる。けれど忘れているあいだにも、食事を作る手、薬を確認する目、夜中に起きる耳が、誰かの一日を支えている。

自立した個人という理想は強い。自分で決め、自分で稼ぎ、自分の責任で生きる。もちろんそれは大切である。けれど、子ども、病人、高齢者、障害のある人だけでなく、誰もが人生のどこかでケアを必要とする。ケアする側も、いつかケアされる側になる。親の介護をしていた人が病に倒れることもある。自己の位置は固定されていない。我々の人生は、強い自分だけで進む一直線の物語ではなく、支える私と支えられる私が何度も入れ替わる時間である。

キャロル・ギリガンは『もうひとつの声で』（1982）で、道徳を抽象的な規則だけでなく、関係への応答として考える視点を示した。ネル・ノディングズ『ケアリング』（1984）は、教育と倫理の基礎にケア関係を置いた。ジョアン・トロントは『モラル・バウンダリーズ』（1993）で、ケアを家庭や女性の私的な仕事に押し込める政治的境界を批判した。ケアは優しさの美談ではなく、民主主義の中心に置くべき営みである。誰が世話をし、誰が報酬を受け、誰の疲労が見えなくされるかは、政治の問いである。

別の角度から見れば、近代社会は依存を一時的な例外として扱ってきた。健康な成人男性を標準にして制度を作れば、育児、介護、障害、病気、老いは周辺へ追いやられる。マーサ・ヌスバウム『Frontiers of Justice』（2006）は、障害と依存を正義論の中心課題に置く必要を論じた。エヴァ・フェダー・キテイ『Love's Labor』（1999）は、依存する人だけでなく、依存する人を支える人への正義を問うた。自立と依存を対立させる発想そのものが、人間の現実を狭くしている。

トロントは『ケアする民主主義』（2013）で、ケアを気づく、引き受ける、実行する、応答を受け取る過程として整理した。相手が何を必要としているかに気づき、誰が責任を持つかを決め、実際に手を動かし、そのケアが相手にどう届いたかを聞く。そこには時間、技術、お金、制度、そして相手を一人の人として見る注意力が必要である。ギリガンが聞き取った関係の声と、トロントが論じた民主主義の制度は、ケアを個人の性格ではなく社会の基盤として考える点で響きあう。

> ケアは弱い人の例外ではなく、人間が互いに形を変える場である。

暮らしの言葉にすれば、助けてと言える場所を作ることだ。介護で疲れた人が眠れるように、ショートステイや相談窓口を使いやすくする。育児をする人が孤立しないように、地域で子どもの声を迷惑だけにしない。支援を受ける人が遠慮で小さくならないように、選べるサービスと言葉を用意する。病院で説明を聞き返せる時間、職場で介護休暇を取りやすい空気、家族でない人にも頼れる制度を用意する。ケアは家庭の中の根性論ではない。

問08の複数の自己は、ケアの場でよく見える。親である私、子である私、患者である私、介護者である私、支援を受ける私。それらは人生の中で入れ替わる。病室のベッドに横たわったとき、昨日までの強い自分は少し後ろへ退く。誰かの手を待つ自分が前に出る。それもまた、まぎれもない私である。だから、弱る自分を恥じる文化は、未来の自分を追い詰める文化でもある。

複数の自己を認める社会とは、弱る自分を恥じなくてよい社会でもある。今日は支える側にいても、明日は支えられる側にいるかもしれない。その入れ替わりを前提に、働き方、住まい、医療、福祉、地域の関係を作る。ケアする私と、ケアされる私。その両方を含めて初めて、人間の姿は現実に近づく。次に問うべきなのは、生きている者どうしのケアを越えて、死者や未来世代との関係が自己をどう形作るかである。
```

### 第61話「死者は、未来の会議に出席している」
- 人文知: 伝統知／マオリ、 whakapapa
- 学術領域: 先住民研究／世代間倫理
- 本文（BODY）:
```
会議室の長机には、名札が並ぶ。自治体職員、専門家、企業の担当者、住民代表。議事録に残るのは、たいてい生きている人間と法人の名前である。だが、川の堤防を決める会議に、昔そこで魚を取っていた祖父母や、百年後に水を飲む子どもは本当にいないのだろうか。近代の出席者名簿は、時間を短く切りすぎている。声を出せる身体を持つ者だけが、未来を決める資格を持つわけではないのである。

我々は、誰を関係者として数えるのかという問いの前に立っている。議決権を持つ人、税を払う人、契約書に署名する人だけが関係者なら、制度は扱いやすい。けれど、山を削る決定、川を直線化する決定、森を売る決定は、いま生きている人間だけで閉じない。問07は、死者や祖先との関係を迷信として退けず、知として受け取れるかを問う。問08は、我々の自己を、皮膚の内側だけに閉じない方向へ押し広げる。

マオリのwhakapapaは、単なる家系図ではない。人、土地、川、山、祖先、未来世代を結ぶ関係の網である。リンダ・トゥヒワイ・スミスは『脱植民地化の方法論』（1999）で、先住民の知が西洋近代の研究制度によって収奪されてきた歴史を批判した。アピラナ・マフイカ『The Endless Genealogy』（1998）は、whakapapaをマオリ社会の歴史、権威、土地との結びつきを支える根として論じた。知は標本ではなく、関係を守る責任の形式なのである。

近代の制度は、生きている個人や法人を意思決定の主体にしやすい。選挙で選ばれた代表、登記された会社、権利を持つ個人。もちろんそれらは重要である。けれど、川や祖先や未来世代を関係者として考えると、判断の時間軸は大きく変わる。ハンス・ヨナス『責任という原理』（1979）は、技術文明の時代には未来の生命への責任が倫理の中心になると論じた。whakapapaは、その責任を抽象的な未来ではなく、名を持つ関係の中に置く。

この視点は、死者を崇拝せよという命令ではない。むしろ、我々が現在を過大評価しすぎる癖をほどく知である。マーガレット・ミード『Coming of Age in Samoa』（1928）が、西洋の成長観を相対化したように、先住民研究は近代社会の当たり前を外側から照らす。マオリの伝統と世代間倫理を対話させると、所有は責任へ、資源は親族へ、合意形成は長い時間の応答へと姿を変える。そこに、政治や法が学ぶべき知がある。

さらに重要なのは、祖先を数えることが、過去への服従を意味しない点である。祖先は、変えてはならない命令の発信者ではなく、我々が何を受け取ってしまったのかを知らせる記憶の相手である。エディス・ブラウン・ワイス『In Fairness to Future Generations』（1989）が未来世代への公平を法の問題として論じたとき、彼女はまだ生まれていない者の利益を現在の制度に入れようとした。whakapapaは、その未来への公平を、死者からの継承と結び合わせる。

> 死者と未来世代を会議に迎えると、決定の時間は深くなる。

暮らしの言葉に翻訳すれば、家を建てる前に昔の水路を調べることだ。森を売る前に、墓や祭りや子どもの遊び場のことを考えることだ。予算を組むとき、今年の収支だけでなく、次の世代が払う費用を見える場所に置くことだ。食卓で祖父母の話を聞くことも、地域の古い地名を残すことも、過去への郷愁だけではない。いまの都合だけで世界を使い切らないための作法である。我々の日常は、見えない出席者の声を聞く練習場なのである。

死者は、未来の会議に出席している。声を出さないから、いないことにはならない。我々がその席を用意できるかどうかが問われている。議事録に残る名前だけでなく、地名、墓、川の流れ、受け継いだ歌、まだ生まれていない子どもたちを関係者として数える。そのとき、未来を決める会議は、人間の身勝手から少し自由になる。次の問いは、その卓に人間以外の存在まで迎えられるかである。
```

### 第62話「人間だけが考えているわけではない」
- 人文知: 人類学／ヴィヴェイロス・デ・カストロ、アマゾンの多自然主義
- 学術領域: 人類学／環境思想
- 本文（BODY）:
```
森に入ると、こちらが木々を見ているつもりで、いつのまにか見られているような感覚になる。葉のこすれる音、足元を横切る虫、遠くで鳴く鳥。近代の知は、人間が世界を見ることを前提にしてきた。観察し、分類し、測り、説明する。だが、世界の側もまた人間を見ていると考える知がある。森はただの背景ではない。人間の足音を聞き、人間のふるまいに応答する、関係の場なのである。

我々は、人間だけが考えているという前提をどこまで緩められるのだろうか。近代の学問は、対象を距離のあるものとして扱うことで力を得てきた。植物は標本になり、動物は個体数になり、森は面積や炭素量になる。もちろん、その測定は必要である。けれど、問07が促すのは、測る知の外にある関係の知を切り捨てないことである。森や動物や精霊を、奇妙な信仰として外に置くだけでは、環境危機の時代の知は細くなる。

アマゾン先住民の世界観をもとに、エドゥアルド・ヴィヴェイロス・デ・カストロは多自然主義を論じた。『食人の形而上学』（2009）で彼が示したのは、人間だけが主体なのではないという視点である。動物や精霊も、それぞれの視点から世界を生きている。ジャガーにはジャガーの世界があり、精霊には精霊の関係がある。そこでは、誰が人間で誰が動物かという区分は、身体と視点の配置によって変わる。主体は人間の専有物ではない。

近代の考え方では、文化は多様だが自然は一つだとされやすい。人間社会にはいろいろな解釈があるが、自然そのものは同じものとして存在する、という考えである。多自然主義は、その前提を揺さぶる。存在ごとに、世界の現れ方が違う。フィリップ・デスコラは『自然と文化を越えて』（2005）で、人間と自然を分ける枠組みが普遍ではないことを示した。ブルーノ・ラトゥール『虚構の「近代」』（1991）も、人間と非人間を分ける近代の自己理解を批判した。

この議論は、科学を捨てる話ではない。熱帯雨林の炭素量を測ることも、衛星で伐採を追うことも、感染症の媒介を調べることも重要である。だが、それだけでは森との関係を語りきれない。グレゴリー・ベイトソン『精神と自然』（1979）が示したように、心は頭蓋骨の中だけにあるのではなく、生態的な関係の中に広がる。デスコラ、ラトゥール、ヴィヴェイロス・デ・カストロを対話させると、自然は沈黙した対象ではなく、応答の網として見えてくる。

多自然主義が揺さぶるのは、自然観だけではない。我々が自分を何者として語るかも変わる。人間を、考える主体として世界の外に立たせるなら、森は管理対象になる。けれど、人間も森の視線の中に置かれるなら、我々は判断する者であると同時に、判断される者でもある。これは責任の形式を変える。破壊する前に説明を求められる相手が増え、利用する前に応答すべき関係が増えるのである。
```
