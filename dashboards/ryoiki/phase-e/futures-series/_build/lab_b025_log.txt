# Codex 執筆ブリーフ — LAB セクション追加

連載「未来のかたち」の各話には、人文知（哲学・人類学・文学・神話・伝統知）を本文に織り込んだうえで、DEEPER（人文知の学術系譜）と SIGNAL（直近の現実世界の動き）の追記欄がある。今回はそこに新たに **LAB（科学の知から）** を加える。各話の本文テーマを踏まえ、対応する **自然科学・工学** の研究者・概念・年代を 400-600字で書く。

## 必須条件
- **字数: 400-600字**（1段落 or 短い2段落、合計）
- **文体**: 「〜である」調、主語「我々」（連載と統一）
- **領域**: 神経科学／認知科学／環境心理学／生態学／地球科学／医療工学／建築工学／情報科学／通信工学／AI・ロボティクス／システム工学／統計物理 などから、本文テーマに対応するものを選ぶ
- **必ず**: 研究者名 + 論文/書籍名 + 年代（西暦）の組を **最低3組** 入れる
- **平らな日本語で、具体的に**: 暮らしの言葉に翻訳しつつ自然科学・工学の系譜を示す

## 出力形式
各話を `=== EPNNN ===` で区切る。LAB 本文のみ書く（frontmatter なし、見出しなし）。

```
=== EP004 ===
```

### 第99話「まだ名のない読者へ」
- 人文知: 文学・谷川俊太郎／哲学・世代間倫理
- 学術領域: 文学／世代間倫理
- 本文（BODY）:
```
夜、机の引き出しから便箋を出す。相手の住所は分からない。名前も分からない。けれど、2100年のどこかでその人は、我々の残した言葉や制度や風景を読むかもしれない。読むといっても、本を開くとは限らない。暑くなった夏の夜、変わった海岸線、壊れやすくなった橋、残された森、古い議事録。そうしたものを通じて、我々という時代を読むのである。未来世代への手紙は、すでに我々の行為によって書かれ始めている。便箋に置く一文字より先に、道路、電力、学校、税制が長い文章になっている。

その人は、我々をどう呼ぶのだろうか。気候を変えた世代としてか。技術を急ぎすぎた世代としてか。便利さのために多くを見落とした世代としてか。それとも、遅すぎたとしても最後まで問い直そうとした世代としてか。未来の読者を思い浮かべると、いまの言葉は少し変わる。言い訳は薄くなり、説教は重くなり、沈黙にも責任が生まれる。まだ返事をもらえない相手に向ける言葉ほど、現在の姿勢を露わにするものはない。相手が反論できないからこそ、我々は自分たちの都合だけで物語を閉じてはならない。

谷川俊太郎の詩は、日常の言葉で、時間や存在の深い問いに触れてきた。谷川俊太郎『二十億光年の孤独』（1952）以来、空、朝、ことば、からだ、沈黙といった平らな言葉から、宇宙的な時間へ手を伸ばした。大げさな概念を持ち出さなくても、人が生きている不思議に届く言葉がある。未来世代へ語るときにも、そのような言葉が必要である。抽象的な責任を、台所や川辺や学校で読める言葉へ戻す力である。2100年の誰かに向ける言葉は、難しい理論より先に、水を飲み、息をし、誰かを待つ身体へ届かなければならない。

哲学では、ジョン・ロールズ『正義論』（1971）が、世代間の公正を貯蓄原理として論じた。ハンス・ヨナス『責任という原理』（1979）は、技術文明の力が未来へ及ぶ以上、倫理は遠い時間を含まなければならないと考えた。デレク・パーフィット『理由と人格』（1984）は、未来の人々の同一性や責任を難しい問いとして示した。エディス・ブラウン・ワイス『将来世代への公正』（1989）は、世代間の公平を国際法の視点から論じた。未来の人は、いま投票も抗議もできない。だが、我々の決定の影響を確実に受ける。その不在の相手へどう語るかが問われている。

手紙を書くとき、我々は相手を想像する。顔は見えなくても、相手が読む時間を思う。急いでいるかもしれない。疲れているかもしれない。怒っているかもしれない。まだ名のない読者へ書くとは、抽象的な未来を、語りかける相手として近づけることである。すると、「未来のため」という言葉が、少しだけ体温を持つ。制度の説明や成果の報告だけでは足りない。何を恐れ、何に迷い、それでも何を選んだのかを伝える必要がある。謝罪だけでも、自慢だけでも、継承は成り立たない。迷いの記録こそ、次の読者が考え直す足場になる。

> 未来世代とは、遠い概念ではなく、まだ返事を書けない読者である。

この抽象を暮らしの言葉に直せば、いま決めることを、返事の来ない相手への手紙として扱うことである。ごみをどこへ置くか、森を切るか、川を固めるか、学校で何を教えるか、借金を誰に残すか。その手紙には、謝らなければならないことがある。先送りしたこと、見ないふりをしたこと、便利さの陰で傷つけたもの。そして、託したい道具もある。完全な答えではなく、問いを続ける力である。日々の選択は、小さな文字で未来の封筒に入っていく。買い物の選択、投票、職場の会議、子どもへの説明も、その封筒の中身を少しずつ変える。

第99話は、最終話の前に置く手紙である。未来へ語るとは、自分たちを美しく見せることではない。限界を含めて、次の読者に差し出すことである。まだ名のない誰かに向けて書くとき、我々の現在は少し広がる。その人の場所を空けておくことが、未来への責任の始まりである。2100年の読者に対して、我々は答えよりも、問い直し続けた痕跡を残せるかを問われている。次の最終話では、その問いを閉じず、読者の手元へ渡すことになる。
```

### 第100話「未来は、あなたの問いの中で続く」
- 人文知: 哲学・中島隆博「共生の哲学」／伝統知
- 学術領域: 公共哲学／未来学
- 本文（BODY）:
```
最後のページを閉じるとき、机の上にはまだ鉛筆の削りかすが残っている。読み終えた本、途中で折ったメモ、飲みかけの湯のみ、窓の外の夕方の光。終わりとは、すべてが片づく瞬間ではない。むしろ、手元に残ったものが見える時間である。100話の終わりに我々の前に残るのも、未来の答えではない。まだ使い続ける問いである。閉じた画面のあとにも、明日の予定、誰かの声、返信しそびれた言葉、台所の水音は続いている。その続きの中で、未来は静かに息をしている。

第1話で、未来は当てるものではなく描くものだと始めた。そこから我々は、場所、ケア、未来世代、先住民の知、複数の世界、複数の自己、問いそのものをめぐって歩いてきた。100話という数は、長いようで短い。未来を言い切るには足りず、問いを手渡すには十分な長さであったのかもしれない。重要なのは、ここまで読んだ我々が、未来を自分の外にある予報としてではなく、自分も関わる問いとして持ち直すことである。未来は、専門家の表の中だけで決まるものではなく、暮らしの判断が積み重なる場所でも決まる。

最終話で言えるのは、未来は一つの完成図ではないということである。完成図には、見る人と作る人が分かれている。線はきれいで、部品は整い、余白は少ない。だが現実の未来は、もっと不揃いである。中島隆博『共生のプラクシス』（2022）が論じる共生の哲学は、違いを消して同じになることを求めない。異なる知や生き方を、一つの正解に溶かし込まない。むしろ、歴史、宗教、身体、土地、言語の差が緊張を含んだまま、関係を続けるための思考を開く。未来を描くとは、きれいな合意を急ぐことではなく、差異が傷に変わらない場を作ることである。

この視点は、公共哲学と未来学の系譜にもつながっている。ジョン・デューイ『公衆とその諸問題』（1927）は、公共を最初からある共同体ではなく、共有された問題に応答する中で立ち上がるものとして論じた。ハンス・ヨナス『責任という原理』（1979）は、現代技術の力が未来世代への責任を新しくしたと考えた。エルンスト・ブロッホ『希望の原理』（1959）は、未来を閉じた予測ではなく、まだ実現していない可能性として読んだ。ここで対話しているのは、共同の問題から公共を作る思想、未来への責任を問う倫理、未完の希望を守る哲学である。

この連載で扱ってきた問いも、一つの答えに収まるものではなかった。未来世代への責任と、いま困っている人への支援。地域の記憶と、新しく来た人の自由。先住民の知と、科学技術の知。自然の声と、人間の暮らし。どちらかを消せば簡単になるが、その簡単さは未来を貧しくする。我々に必要なのは、難しさを保ったまま考え続ける力である。伝統知と未来学、文学と政策、個人の痛みと公共の制度を、同じ場に置く力である。答えを急ぐ社会では、問いを保つことそのものが、未来を守る作法になる。

> 未来は答えの中ではなく、問いを続ける関係の中で育つ。

この抽象を暮らしの言葉に翻訳するなら、最後に問うべきことは単純である。あなたは、誰と、どこで、何を問い続けるのか。職場の小さな会議でかもしれない。地域の集まりでかもしれない。家族の食卓、学校の教室、病院の待合室、畑のあぜ道、オンラインの画面の向こうかもしれない。場所は大きくなくてよい。問いが続くなら、そこに未来の入口がある。まず一人の名前を思い浮かべ、次に一つの場所を決め、最後に今日の問いを一行だけ置けばよい。その一行は、制度をすぐ変えないかもしれない。だが、沈黙を少し変え、関係の向きを変える。

100話は、未来の答えを示すためではなく、問いを手渡すためにあった。終わりは、きれいな幕引きではない。読者の手元で、別の言葉に書き換えられるための区切りである。今日、あなたが誰かに問いを差し出す。その問いを誰かが受け取り、少し変えて返す。その往復の中で、未来は続く。連載はここで閉じる。しかし、あなたの問いの中で、まだ開き続ける。次の70年は、遠い年表の上にだけあるのではない。明日の会話の中に、すでに小さく始まっているのである。
```
