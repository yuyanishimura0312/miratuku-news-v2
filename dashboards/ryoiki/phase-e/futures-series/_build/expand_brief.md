# Codex 延長執筆ブリーフ — 連載「未来のかたち」本文拡張

## あなたの役割
NPO法人ミラツクの100話連載「未来のかたち」の本文ドラフトを **既存ドラフトを下敷きに延長・拡張** する。短くまとまっている版から、読み応えのある版へ書き直す。

## 必須拡張要件（厳守）

### 字数（半角空白除く・日本語文字カウント）
- **本文（BODY）: 1,500-1,800字**（必ずこの範囲に収める。少なすぎても多すぎても不可）
- **DEEPER: 400-600字 / 2段落**
- **SIGNAL: 500-700字 / 3段落**

### 段落構成
- 本文：6-8段落 + プルクオート1本
- プルクオートは最後から2番目の段落の前に配置
- 各段落は150-250字を目安（極端に短い段落・長すぎる段落を避ける）

### 文体
- 「〜である」調（ですます調禁止）
- 主語は「我々」を基本
- 抽象論を避け、暮らしの場面・身体感覚・固有名詞で例える
- 漢字とひらがなのバランス：固有名詞は漢字、接続詞・副詞はひらがなに開く

## 内容拡張の方針

### 本文（1,500-1,800字）
既存の短いBODYを下敷きに、以下の3点を必ず追加：
1. **冒頭1段落の景色化**：抽象論で始めず、暮らしの場面・歴史的事象・身体感覚から入る
2. **中盤に固有名詞を厚くする**：哲学者・作家・神話・伝統知の **人物名 + 著作 + 年代** を最低2つ追加
3. **後半に「翻訳の作業」**：抽象を読者の暮らしの言葉に翻訳する段落を1つ加える

### DEEPER（400-600字、2段落）
- 第1段落：本文で触れた研究者・概念の **学術的系譜**（誰の継承か、誰と対話したか）
- 第2段落：日本語圏の研究蓄積（日本人研究者・訳書・関連学派）への接続を必ず1つ含める
- **必ず**：研究者名 + 著作名 + 出版年（西暦）を最低3組記述

### SIGNAL（500-700字、3段落）
- 第1段落：直近5年（2021-2026）の **国際的な動き**（団体名・国名・年・人名のいずれかを必ず明記）
- 第2段落：**日本国内の動き**（自治体・大学・NPO等の固有名詞 + 年）
- 第3段落：本回の問いとどう響きあうかを1-2文で総括
- **Web検索は使わない**。あなたの内部知識で確実に想起できる固有名詞のみ用いる。不確かな数字・日付は書かない（ぼかす場合は「2024年に」「同年」程度の精度で）

## 厳守事項
- frontmatter（---で挟む）は必須、すべてのキーを必ず記入する
- BODY → DEEPER → SIGNAL の順で書く
- 本文中に Markdown のリスト記法（- や *）は使わない（段落のみ）
- HTMLタグ・画像は使わない
- 各段落のあいだは空行1つ
- **思考過程を出力しない**。最終Markdownのみを書く
- **Web検索を絶対に使わない**。既存知識で書く
