## 0. 編集理念（Translational Editor）

本連載は「未来を当てる」のではなく「描く」連載である。読者は研究者ではなく、企業の方・行政の方・地域の実務者・学生・専門外の関心読者である。学術の蓄積と暮らしの言葉の橋渡し（Translational Editor）を全話で徹底する。

3つの底流原則:

1. **暮らしの場面から始める** ― 抽象論・統計・大きな概念から始めない。今日の食卓・通勤の途中・会議室の片隅から入る。
2. **学術の系譜を背骨に持つ** ― 暮らしのシーンを起点としても、本文の背骨には査読研究・古典文献・国際機関データが通っていなければならない。
3. **読者に問いを手渡して終える** ― 答えを差し出す連載ではない。100話を読み終えた読者の机に「折りたたまれた地図」が残ることを目指す。

## A. 執筆品質基準

### A-1. 字数規定

| 要素 | 字数 | 許容幅 | 備考 |
|---|---|---|---|
| 本文（リード除く） | 1,500字 | ±200字（1,300-1,700字） | 6段落構成 |
| ヒーローリード | 150-180字 | 1段落・1-3文 | hero box 内 |
| DEEPER（学術コラム） | 400-500字 | 上限600字 | 2-3段落 |
| SIGNAL（時事兆し） | 200字 | 上限300字 | 1-2段落、散文 |
| KEY REFERENCE | 2-3冊 | 最大4冊 | 著者・年・短文解説 |
| 次の問い（リード文） | 50-80字 | 1-2文 | 次話橋渡し |
| 次の問い（次話タイトル） | 第N話「タイトル ― サブタイトル」 | 1行 | 表記統一 |

合計の本文+補足字数: 約2,200-2,600字。kurashi ep001 は本文1,180字+DEEPER 470字+SIGNAL（中に統合）でやや短め。Futures では「70年先」のテーマ規模を踏まえて本文を1,500字基準に設定する。

### A-2. 文体規定

- **基本人称**: 「我々」もしくは「私たち」を主語とした第一人称複数。読者への呼びかけは「あなた」「読者」を併用。
- **語尾**: 原則として常体（だ・である調）。kurashi が「ですます調」を採用しているのに対し、Futures は「企業の方・行政の方・地域実務者」が読者層であり、70年先という時間規模を扱うため、常体で重みを担保する。ただし読者への直接の問いかけ・最終段落の語りかけはですます調も可。
- **段落構成**: **6段落基本**（リード→展開3-4段落→転換1段落→着地1段落）。kurashi は6段落、既存 Futures ep001 は7段落+引用ボックス。
  - 第1段落（リード本文）: 暮らしの場面・具体的な発話・現場の問いから始める
  - 第2-3段落（展開）: 70年という時間規模・現在地の見立て・坂のメタファ等の核心提示
  - 第4段落（転換）: 引用ボックス（pullquote）または学術系譜への接続
  - 第5段落（応答）: 連載がやろうとしていることの宣言・読者への提案
  - 第6段落（着地）: 「正解は提示しない」「机の隅に折りたたまれた地図」の比喩で締める
- **一文の長さ**: 60-80字を上限の目安とする。100字を超える文は分割。
- **英字濃度**: 最小限。固有名詞（Wellbeing of Future Generations Act / Tulevaisuusvaliokunta 等）と必要不可欠な学術用語のみ。本文1,500字に対して英字句は5-7個まで。サブタイトル英訳（Hero 部）は別枠。
- **数字表記**: アラビア数字を原則とする。「2026年」「8つ」「第7章」「70年」「1,500字」。漢数字は固有名詞・熟語のみ例外（「四半世紀」「一人ひとり」「三つの層」「数年がかり」）。
- **学術用語**: 専門用語は原則1段落に1個まで。導入直後に必ず暮らしの言葉で言い換える。例: 「フォーサイト（未来を当事者の手で描く実践）」「メタ認知（自分の考えを自分で観察する力）」。
- **絵文字・アイコン**: 一切使用しない（共通ルール feedback_no_icons_websites）。

### A-3. 冒頭の作法（最重要）

冒頭1段落は連載品質の80%を決める。以下を厳守する。

- **OK パターン**:
  - 場面提示 ― 「朝、通勤の途中でニュースアプリを開くと…」（kurashi ep001）
  - 現場発話 ― 「『2095年の社会は、どうなっていますか』。我々が研究の現場で…」（Futures ep001）
  - 具体的な問い ― 「子どもの『なぜ』は、いつから消えるのか」
  - 単一固有事象 ― 「2024年7月、京都府が未来世代政策研究会を立ち上げた」
- **NG パターン**:
  - 抽象論・大きな主語 ― 「現代社会は…」「人類は…」「テクノロジーが…」
  - 定義から始まる ― 「フォーサイトとは…」「未来世代とは…」
  - 統計・数字の羅列 ― 「世界の論文数は300万本を超え…」（DEEPER 内なら可）
  - 連載の自己紹介 ― 「本連載では…」（最終段落でのみ可）
  - 引用から始まる ― 著名人の言葉から始めない（読者の場面より優先しない）

### A-4. 学術用語の扱い

- 専門用語は**初出時に必ず暮らしの言葉で並記**する。例: 「フォーサイト（未来を当事者の手で描く実践）」。
- 哲学・人類学・神話学などの**人文知配分は v2.0 企画書に従う**（哲学25話/人類学20話/文学20話/神話15話/伝統知20話）。各話は最低1領域、必要に応じて2領域を併記する。
- 古典理論を引く場合は **著者名+書名+年** を本文中で簡潔に示す。例: 「ヨナスは『責任という原理』（1979）でこう述べた」。
- カタカナ専門用語の濫用を避ける。「ウェルビーイング」「サステナビリティ」「レジリエンス」等は3話に1度以下。

## B. 構造規則

各話は以下の9要素から構成される。**順序を変えない**。

### B-1. ヒーロー部（hero box）

- **エピソード番号**: PROLOGUE / PART I-V / FINAL の所属表示+「第N話」
- **メインタイトル**: 13-22字。記憶に残る短さ。「未来は『当てる』ものではなく『描く』もの」「学問のドアは、暮らしから開けることができる」。
- **サブタイトル**: ― 副題（短い説明）。20-35字。「70年先を考えるとは、どういうことか」。
- **英訳**: English subtitle（1行）。学術連載としての品位を担保する。
- **リード文**: 150-180字。本文核心の予告であり、読者への招待状。「本連載は、その問いを100回かけて、ひとつずつほどいていく旅である」のような連載自身の自己紹介を必ず含める。
- **メタ情報**: 著者名+所属／公開日／推定読了時間／学術領域（人文知配分のうち本話の主担当）／対応する書籍章（ch1-ch13）／対応する問い（Q1-Q8）。

### B-2. 本文（リード→本文→締め）

6段落構成。1,500字±200字。各段落の役割は A-2 に記載。

- 第1段落の冒頭1行は、必ず**具体的場面・発話・固有事象**から始める。
- 段落間の論理接続は明示的に（「そもそも、なぜ」「我々は数年がかりの調査で」「こう書くと壮大に聞こえるが」）。
- 中盤（第3-4段落のあいだ）に**引用ボックス（pullquote）を1つ**配置することを推奨。ボックス内は短い1-2文の核心命題（「未来を『当てる』ことはできない。けれど、誰と一緒に何を描きたいかは、今日から始められる」）。
- 締めの1段落は **「正解を提示しない」「読者の机に残る小さな地図」** という連載共通の姿勢を再確認する文で終える（毎話同じ言い回しは避ける）。

### B-3. DEEPER（学術コラム）

- **配置**: 本文末の直後、`<details>` 折り畳みボックス内。
- **字数**: 400-500字、2-3段落。
- **役割**: 本文の暮らし言葉では入れきれなかった**学術的背景・系譜・最新動向**を補う。読者は折り畳みを開かなくても本文だけで完結すること。
- **必須要件**:
  - 引用文献は**著者名+書名（または論文名）+年**を必ず記す（年欠落は C評価差戻し）。
  - 「歴史社会学・経済史・未来学の交差点」のような**3系譜の交差**を意識する書き方を推奨。
  - 1段落目: 本連載が立つ学術的位置 / 2段落目: 方法論的依拠 / 必要なら3段落目: 補足。

### B-4. SIGNAL（2023-2026年の具体事例）

- **配置**: DEEPER と同じ折り畳み形式（独立したセクションとして）。
- **字数**: 200字（2-3事例で構成する場合は最大300字）。
- **形式**: **散文で書く**。kurashi ep001 のように箇条書き（SIGNAL 01/02/03）でも可だが、Futures は本文の散文性を踏襲する**散文連結**を基本とする。
- **必須要件**:
  - **2023-2026年の具体事例**を1-3件。年・組織名・固有名詞を必ず明記。
  - リサーチチーム成果物 `_FUTURES_SIGNAL_RESEARCH_v2.md`（150件超）を一次素材とする。
  - 「世界各地で別々に起きている動きが、共通する方向性を持つ」という**並列の構造**で書く。例: フィンランド未来委員会（1993-）／英国ウェールズFGA（2015-）／京都府未来世代政策研究会（2024-）の3点配置。

### B-5. KEY REFERENCE

- **配置**: SIGNAL の直後（kurashi 形式準拠）または DEEPER 内末尾（既存 Futures ep001 形式）。**v2.0 では独立セクション化**を採用する。
- **件数**: 2-3冊（最大4冊）。
- **必須項目**: 著者・書名・出版社（または学術誌）・**年**。短文解説（30-60字）を併記。
- **構成**: 古典1冊+現代研究1冊+一次資料1件 が理想。

### B-6. QUESTION FOR NEXT（次の問い）

- **配置**: 本文+補足の最末尾。
- **構成**:
  - リード文（50-80字、1-2文）: 次話で扱う問いを暗示する散文。
  - 次話エピソード番号+タイトル+サブタイトル
  - 「次の話を読む →」リンク
- **書き方**: 次話の見出しを単に予告するのではなく、**今話の問いが次話の問いにどう繋がるか**を1文で示す。例: 「戦後80年という時間の地層に、我々はまだほどけずに残された結び目をいくつも抱えている。次回はその結び目の姿を、3つの層に分けてもう一度見つめなおしたい」。

### B-7. 既存「未来の分岐点」全8話との接続

各話の本文先頭または DEEPER 冒頭で、対応する Q1-Q8 詳細記事への参照を明示する。

```
> この回は、8つの問いの「Q3 場所性」と関わります。
> 詳しくは: https://journal.emerging-future.org/8-questions/eight-questions-q3-detail.html
```

接続マップは v2.0 企画書を参照。

### B-8. ヒーロー数値（ep番号表示）

`01.` / 100 のような形式で配置。Futures ep001 の `--display: "Judson"` フォントで `font-size: 80px` 表示。100話通しで一貫させる。

### B-9. TOC（目次サイドバー）

LP 5部構成（PROLOGUE / PART I-V / FINAL）を**全話で同じ並び**で表示する。現在地はハイライト表示（赤帯+`● 現在地`ラベル）。

## C. 評価グレード（編集主幹判定）

各話の納品時、編集主幹（あるいは /kurashi-editor 派生エージェント）が以下の基準で**A/B/C** の3段階判定を行う。

### C-1. A評価（即公開可）

すべて満たすこと。

- [ ] 本文1,500字±200字以内
- [ ] 6段落構成（明確な役割分担）
- [ ] 冒頭が具体的場面・発話・固有事象から始まる
- [ ] DEEPER 400-500字、引用文献に**年が明記**されている
- [ ] SIGNAL 200字±100字、2023-2026年の事例が1-3件、年・組織名・固有名詞すべて記載
- [ ] KEY REFERENCE 2-3冊、著者・書名・年すべて揃う
- [ ] 次の問いが今話と次話の橋渡しとして機能している
- [ ] 英字濃度が本文1,500字あたり5-7個以下
- [ ] 数字はアラビア数字、漢数字は固有名詞・熟語のみ
- [ ] 専門用語は初出時に暮らしの言葉で並記
- [ ] 絵文字・アイコン未使用
- [ ] v2.0 企画書の人文知配分・8問配分・書籍章対応に整合
- [ ] ファクトチェック合格（数値・年・人名・機関名すべて一次ソース確認）

### C-2. B評価（軽微修正で公開可）

A評価の必須項目のうち**軽微な誤りが3項目以下**で、**致命的な品質欠陥がない**場合。

- 字数超過/不足が±300字以内
- 英字濃度が10個以下
- 専門用語の言い換え漏れが2-3箇所
- KEY REFERENCE の解説文が短すぎる/長すぎる
- 次の問いの接続が弱い
- pullquote の配置位置が不適切

→ 編集主幹が当日中に手直し可能。執筆者にはフィードバックを返し、次話以降に反映させる。

### C-3. C評価（差戻し・再執筆）

以下のいずれかに該当する場合。

- 冒頭が抽象論・定義・統計羅列から始まっている（**致命**）
- DEEPER の引用文献に**年が欠落**している（**致命・ハルシネーション疑義**）
- SIGNAL に2023-2026年の具体事例がない、または年・固有名詞が欠落
- 数値・人名・機関名にファクト誤りがある（**致命**）
- 字数が±400字を超えて逸脱
- 段落構成が崩れて読みづらい
- 専門用語が3個以上連続して言い換えられていない
- 絵文字・アイコンが含まれている
- 引用文献が架空・誤帰属（**致命・ハルシネーション**）
- 連載全体の語り口（第一人称複数+常体）から大きく外れている

→ 執筆者に差戻し、最大3回までのリライトを認める。3回目で改善されない場合は、編集チームが原案を再構築する（kurashi-team の差戻しフロー準拠）。

### C-4. ファクトチェック必須項目

公開前に編集主幹+ファクトチェッカーが以下を一次ソース確認:

1. **すべての年号**（法律施行年・著作出版年・組織設立年・条例制定年）
2. **すべての人名**（生没年・所属・専門領域）
3. **すべての機関名**（正式名称・設立年・所在地）
4. **すべての数値**（論文数・予算規模・人口・指標）
5. **法令・条約・国際宣言の名称と年**（FGA 2015、CARE Principles 2019、ヨナス『責任という原理』1979 等）

出典が不明確な記述は**そのまま残さない**。確認できなければ削除または「複数の研究で示唆されている」のような hedging 表現に書き換える。

## D. NG事項（共通）

### D-1. 表記・スタイル

- 絵文字使用（共通ルール、Webサイト全般 feedback_no_icons_websites）
- アイコンフォント・装飾アイコン使用
- 数字の漢字化（「八つの問い」「七十年」は不可。「一人ひとり」「四半世紀」など熟語のみ例外）
- カタカナ専門用語の濫用（「ウェルビーイング」「サステナビリティ」等は3話に1度以下）
- 英字句が本文1,500字あたり10個を超える

### D-2. 構成

- 抽象論・定義・統計羅列からの開始
- 連載の自己紹介から始まる冒頭
- 著名人の引用から始まる冒頭
- 引用ボックス（pullquote）が3つ以上
- DEEPER 内の引用文献の**年欠落**（致命）
- SIGNAL 欄の年・固有名詞欠落
- 段落間の論理接続が不明（接続詞・指示語の欠落）
- 次の問いが次話タイトルの単なる予告にとどまる

### D-3. 学術的厳密性

- 引用の架空・誤帰属
- 数値の出典不明確
- 一次ソース未確認のまま記載
- 専門用語を暮らしの言葉に翻訳しないまま放置
- 哲学・人類学・神話学等の概念を表面的に消費する書き方
- 「最新の研究によると」「ある調査では」のような出典曖昧表現

### D-4. 連載トーン

- 答えを断定する書き方（「未来はこうなる」「正しいのは…」）
- 教師-生徒の上から目線（「みなさんに教えます」）
- 過度に詩的・抒情的な装飾（「希望の星」「光輝く未来」等の常套句）
- 政治的・宗教的立場の表明
- 特定企業・団体の宣伝色

## E. v2.0 三軸織りとの整合チェック

各話の執筆前・執筆後に、企画書 `_FUTURES_SERIES_PLAN_v2.md` と以下の整合を確認する。

| 軸 | 確認項目 |
|---|---|
| LP5部（時間軸） | 第N話が PROLOGUE / PART I-V / FINAL のどこに位置し、その部のテーマ（現在地／問いを問う／系譜／担い手／未来のかたち）と整合するか |
| 8問（テーマ軸） | 主担当する Q1-Q8 が明示され、企画書の配分（Q1=13話、Q2=12話、Q3=11話 等）に整合するか |
| 書籍13章（思考軸） | 対応する書籍章（ch1-ch13）が指定され、その章の主題と本文が呼応しているか |
