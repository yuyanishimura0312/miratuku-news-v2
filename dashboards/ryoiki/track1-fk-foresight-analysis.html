CHAPTER 01

テーブル構造としては、レポートを源流とし、そこから個別の予測（quantitative／qualitative／conditional／scenario_element）と、独立にトレンド・シナリオが派生する三本立ての構成である。さらに、3層タクソノミー（L1=15領域・L2=70サブ領域・L3=238トピック）が予測へと prediction_themes テーブルで紐付けられ、22,598件の予測−テーマ関係を形成する※集計L-14。これに加え、トレンド間・予測間の cross_references（77,932件）が支持・矛盾・前提・帰結関係を記述する横糸として走る※集計L-47。

すなわちFK DBは、〈フォーサイト機関〉〈彼らが発表したレポート〉〈そこから抽出された予測単位〉〈テーマ分類〉〈横断関係〉という五層をもつ知識グラフであり、量的な解析と概念的な集約のいずれにも耐えるよう設計されている。本トラックの目的は、この五層を時間軸（ホライズン）と主題軸（テーマ／VeSTEG／GTA）の二次元で切り出し直すことにある。

CHAPTER 02

テーマ分布の俯瞰：技術が突出した一極構造

FK DBに登録されたフォーサイトのテーマ分布は、極めて非対称な一極構造を示す。技術ドメインへの集中が顕著で、第二位以降との差は一桁乗を超える。

23,274件の予測を domain 列で集計した結果、technology が10,133件で全体の43.5%を占め、governance 3,850件（16.5%）、economy 2,477件（10.6%）、environment 1,463件（6.3%）と続く※集計L-06。下位は energy 444件（1.9%）、education 587件（2.5%）まで一桁台の比率で並ぶ。値NULLが79件（0.3%）と極小であることから、この一極構造はラベリング欠落の人為的偏りではなく、データの実質的偏りである。

VeSTEG分類（values／economy／society／technology／environment／governance）でも同様の傾向が現れる。technology 10,245件、governance 4,407件、society 3,251件、environment 2,086件、economy 1,985件、values 105件※集計L-07。注目すべきは values が105件（0.45%）と極端に少ないことである。VeSTEGの「V」は本来、技術・経済・社会・環境・ガバナンスの動向を支える「価値観」レイヤーとして導入されているはずだが、現状のFK DBはここがほぼ空白に近い。

L2レベルで予測件数を取ると、人工知能・機械学習が7,938件と全テーマの3分の1超を占める※集計L-18。これに地域紛争1,893件、貿易・サプライチェーン1,436件、気候変動1,018件、金融イノベーション808件、マクロ経済779件、生物多様性639件、パンデミック・感染症523件、デジタルインフラ385件、格差・不平等375件、教育変革330件、再生可能エネルギー321件と続く。

第7章で詳述するが、source.type別にL1テーマを切り直すと、academic（学術論文）と international_org（国際機関）でテーマ偏在のパターンが大きく異なることが確認できる。FK DBが捉えているテーマ分布を「ある一つの分布」として論じるのではなく、〈学術主導の分布〉と〈実務主導の分布〉の二重構造として論じるのが、本レポートの基本姿勢である。

CHAPTER 03

ホライズン構造：予測の85%は時間軸が明示されていない

FK DBにおいて、予測の時間ホライズンは〈レポート単位の time_horizon ラベル（near_2030／medium_2040／far_2050plus の三択）〉と、〈予測単位の time_horizon_year（連続値）〉の二つの粒度で表現される。本章では両者を突き合わせ、ホライズン分布の実像を確定する。

共通スパン定義と FK 固有ラベルのマッピング

領域策定プロジェクトの横断プロトコル（_PROTOCOLS.md 1.2-1.3）は、9トラック共通のスパン名（near / mid / far / very-far / beyond / unspecified）を規定している。FK DBは独自の time_horizon ラベル体系（near_2030 / medium_2040 / far_2050plus）を用いているため、両者の対応を以下に明示する。未明示率（84.4%）は後続の分布論と合わせて読む必要があり、ここで先に開示する。

第一の構造的発見

予測単位で時間軸が明示された3,628件のうち、2030年単年が全体の56.4%を占める。「2030」は世界のフォーサイトにとって事実上の標準ホライズンである。これはSDGsの2030達成期限・WEFの「Future of Jobs 2030」など主要レポートが2030を共通アンカーに採用してきた制度的経緯と整合する。【解釈】

レポート単位ラベルでの再確認

レポート単位の time_horizon ラベルでも同方向の偏りが確認できる※集計L-04。76,548レポート中、near_2030（〜2030）17,180件、medium_2040（〜2040）286件、far_2050plus（2050+）11,783件、未指定47,299件。未指定が61.8%という巨大な空白がここでも現れる。意外なのは medium_2040 の極端な少なさ（0.4%）で、これはレポート群が「短期（2030）か遠期（2050+）か」の二極化した時間設計をしているためである【解釈】。

予測単位の time_horizon_year（年明示）と、レポート単位の time_horizon（ラベル）を突き合わせると※集計L-11、far_2050plus（2050+）ラベルがついたレポートに紐付く予測は3,476件あるが、そのうち年明示は約8%しかなく、大多数は「2050以降の何時か」を漠然と指す抽象記述で構成されている。これに対し near_2030 ラベルのレポートは予測2,513件と相対的に少ないが、年明示率が高い。

ホライズンの「二極＋未指定」三元構造

以上を統合すると、世界のフォーサイトのホライズン構造は次の三元として整理できる。

  1. 2030近傍の濃密層：年明示2,262件＋レポート17,180件。SDGs／Industry 4.0／企業中期計画と接続する〈実装可能な未来〉。FK DB全体で最も詳細な記述が集中する層。
  2. 2050遠期の輪郭層：年明示516件＋レポート11,783件。気候・人口・エネルギー・宇宙が中心。年明示率は低いが、レポート単位では十分な数が揃っている層。
  3. 2070／2100の希薄層：年明示38件（2051-2070）＋39件（2071-2100）＋レポート単位ラベルが「far_2050plus」へ統合されているため、独立した層として識別不可能。

第三層の希薄さは深刻である。2071年から2100年までの予測は、FK DB 23,274件中わずか39件（0.17%）に過ぎない。サンプルを取り出すと、UAE Centennial 2071、世界人口10.3億のピーク（2080-2086）、IPCC RCP8.5シナリオでの2080年気温上昇、Sub-Saharan Africa 2100年人口、といった〈長期人口予測〉と〈気候モデルの長期出力〉に集中している※集計L-40。社会・経済・ガバナンスの2070-2100予測はほとんど存在しない。

列ごとの読解

2030列では、テクノロジー（707）と経済（409）が突出する。AI・自動化が労働・経済成長と接続する形で議論される〈短期実装〉領域がここに集中する。具体的な予測を例示すると、「Generative AI will automate 30% of work tasks by 2030」「Machine learning and automation will increase productivity by 1.4% annually」「By 2030, at least 30% of current jobs are at high risk of automation」のような、定量的・指標連動型の言明が支配的である※集計L-62。

2050列では、テクノロジー（103）と環境（79）の比率が拮抗する。経済（43）は依然として一定の存在感を持つが、2030と比較するとシェアは大きく低下し、代わって環境・エネルギー・社会の比重が増す。具体例としては「Net zero emissions will be achieved globally by 2050」「by 2050 due to climate change and natural hazards」「by 2050, SAF has emerged as the most promising solution」のような、〈構造転換目標〉と〈気候・エネルギー長期軌道〉の言明が中心となる。

2070列は全領域合計で14件しかない希薄層である。出現が確認できるのは技術5・社会2・環境1・地政学1・経済0・ガバナンス0・健康0で、ほぼ「人口動態」と「単発の地政学言明」（例: Africa 2060）の領域に限定される。

2100列は全領域合計で19件。最大は環境9件、地政学6件、技術2件、社会1件、経済1件である。具体例は「World population to reach 10.1 billion by 2100」「Sub-Saharan Africa to be major driver of global population growth through 2100」のような、UN World Population ProspectsやIPCC AR6の長期出力に基づく予測である※集計L-40。

行ごとの読解

テクノロジーは「2030一極＋2040／2050尾」の典型的短期型。2070以降はほぼ消失する。これは技術予測が〈現有の研究投資→製品化〉という10-20年の時間スケールに自然に収まり、それ以上は方法論的に確実な予測が立てにくいことを反映している。【解釈】

環境・気候は唯一、2030より2050が厚い〈遠期型〉領域である。さらに2100まで予測が9件残っており、他領域と比べて時間軸の伸びが顕著である。これは気候モデル（IPCCのRCPシナリオ等）が物理過程の長期積分を本質的に行うため、予測ホライズンが2100以上まで自然に伸びる方法論的特性を持つためである。

社会・人口動態もまた長期方向への伸びを持つが、2030・2040・2050の三層がほぼ均等に並ぶ〈定常型〉である。これは人口統計の予測が10-50年スケールで安定的に行われていることに対応する。

ガバナンス・制度は逆に2030に集中（64／75=85.3%）し、2050以降は4件で消失する。これは政策の予測ホライズンが本質的に短期である（選挙周期・政権交代）ことに対応する。

未明示列（19,646件）の存在を踏まえると、上記マトリクスは〈ホライズン明示派の予測〉だけを切り出した部分像であり、第3章で見たようにレポート単位のtime_horizonラベルでは2050+に11,783件が分類されている。明示／未明示・年単位／ラベル単位の両軸を持つことで、FK DBは時間構造に対し相補的な分析を可能にしている。

CHAPTER 05

FKが強みとするホライズン領域はどこか

本章は、領域策定プロジェクトの必須4要素のうち〈DBが強みとするホライズン領域の宣言〉に対応する。FK DBがどの時間スパンの問いに最も答えられるか、を実数値から導出する。

「強み」を定量化するため、二つの観点を立てる。第一は密度（そのホライズンに紐付く記録単位の数）、第二は多様性（カバーされる主題領域・出典・方法論の幅）である。

密度の観点

密度の絶対値はそのまま第3章のホライズン分布である。年明示単位での密度は2030年単年が2,046件で最大、続いて2050年478件、2025年282件、2040年186件、2035年153件、2026年127件、2027年53件、2100年30件である※集計L-09。レポート単位では near_2030 が17,180件、far_2050plus が11,783件、未指定47,299件、medium_2040 が286件である※集計L-04。

多様性の観点

多様性を測るため、各ホライズンビンにおいてL1領域のうち何領域がカバーされているかを集計した（前章の表を再利用）。2030は15領域中15領域、2040は15領域中14領域、2050は15領域中14領域、2070は15領域中6領域、2100は15領域中6領域である。2030と2040／2050は領域多様性で同等だが、密度は2030が圧倒的に厚い。

結論：FKの強みホライズンは「2030近傍 ＋ 2050遠期」の二焦点

FK DB 強みホライズンの宣言

FK DBが最も答えられる時間スパンは、2030近傍（〜2030）と2050遠期（2050+）の二焦点である。

前者は密度・多様性ともに最大（年明示2,262件＋レポート17,180件＋全15L1領域カバー）。後者は予測の年明示数こそ少ないが、レポート単位で11,783件、シナリオ5,099件の中核母集団がここに分布し、かつ気候・エネルギー・人口動態のような長期軌道分析が可能。

逆に、2070-2100ホライズンはFK DBの構造的弱点であり、年明示はわずか46件（2051-2100）。この層を強化する追加収集が領域策定の前提となる。

強み領域内での解像度

2030ホライズンに限定して、source.type別の予測分布をとると※集計L-50＋L-39、academic（学術論文）が3,200レポート、international_org（国際機関）が9,312レポート、government（政府機関）が4,044レポートと、出典の三層が揃っている。これは2030ホライズンの強みが〈論文の積み上げ〉だけでなく〈実務的な政策・戦略文書〉でも担保されていることを意味する。

2050+ホライズンでは、academic 3,102レポート、international_org 8,475レポートに対し、government が141レポートしかない。2050+の議論は学術と国際機関に偏り、政府機関は撤退しているのが現実である。これは政府の予測ホライズンが本質的に短い（次期政権・任期内）という制度的事情の反映であり、ミラツクが「未来に向けて問うべき領域」を扱う際、政府発の論拠は2050+では当てにならないことを示す重要な構造特性である。【解釈】

CHAPTER 06

VeSTEG／GTAサブ領域構造：技術領域の内訳

L1で見た「技術一極化」が、L2サブ領域では実際に何によって駆動されているかを明らかにする。

テクノロジー・デジタルL1領域（合計8,810予測）の内訳を見ると※集計L-18、人工知能・機械学習が7,938件、ロボティクス・自動化236件、デジタルインフラ385件で、AIが領域内の90%（7,938/8,810）を占める。残る量子技術・サイバーセキュリティ・半導体は合計しても250件程度である。

このAI集中は、Crossref／OpenAlexのキーワード検索パイプラインがAI論文を大量に引き寄せた結果でもあるが、同時にもう一つの解釈を許す。すなわち、世界のフォーサイト言説そのものが、ここ5年でAIに収斂したのではないか、という解釈である。実際、source別にみるとTechnological Forecasting and Social Change誌（OpenAlex経由）から2,804件、Foresight誌（Emerald／OpenAlex）から3,283件、Foresight誌（Crossref）から1,820件と、フォーサイト系の代表的学術誌3誌だけで7,907件の予測が抽出されている※集計L-27b。これらの多くが直近5年（2020-2025）の刊行であることは、母集団の出版年プロファイルが2020年以降急増している事実と整合する※集計L-12。

非技術L2サブ領域の上位

テクノロジー以外のL1領域でL2上位を抽出すると、地政学・安全保障の中では地域紛争1,893件（うちロシア-ウクライナ・中東・台湾海峡が中心）、経済・金融では貿易・サプライチェーン1,436件・金融イノベーション808件・マクロ経済779件、環境・気候では気候変動1,018件・生物多様性639件、社会・人口動態では格差・不平等375件・移民・難民283件・人口動態266件、健康・医療ではパンデミック・感染症523件、労働・教育では教育変革330件・労働の未来236件などが上位を占める※集計L-18。

注目すべきは 世代間正義（Intergenerational Justice）が223件で、倫理・価値観領域内では最大、L2全体でも18位に入っていることである。これは「2070／2100世代の正義」という長期倫理問題が、AI／気候／経済の量的議論の影で着実に積み上がっていることを示す【解釈】。

VeSTEG×L1の整合性

L1テーマの各vesteg_primaryと、予測の vesteg_category を突き合わせると※集計L-45,L-07、L1経由のVeSTEG分布は technology 8,443・economy 3,124・society 2,969・governance 2,614・environment 2,505・values 479。一方、predictions.vesteg_category 直接ラベルは technology 10,245・governance 4,407・society 3,251・environment 2,086・economy 1,985・values 105・NULL 1,195。

この二系列を比較すると、governance（4,407 vs 2,614）と economy（1,985 vs 3,124）でラベルの食い違いが顕著である。これはタクソノミー層（L1のvesteg_primary）と、予測の自由ラベル層（vesteg_category）が独立に付与されているためで、〈経済問題の地政学化／ガバナンス化〉という近年の議論潮流が、ラベル層では「ガバナンス」に流れ込み、テーマ層では依然「経済」に分類される、という二重ラベリングの現れと解釈できる【解釈】。

values が直接ラベル層で105件と極端に少ないのは、予測単位の自然言語からvalues系を読み取る分類器の弱さを示している可能性が高い【未検証】。L1経由では479件取れているため、〈values は実在するが、ラベル付けの段階で漏れている〉と見るのが妥当だろう。

CHAPTER 10

研究の限界（自己認識）

本解析が抱える構造的限界を、後工程の検証エージェントが検出する前に、Track 1自身が明示する。

1. ホライズン年明示率の低さ

23,274件の予測のうち、time_horizon_year に値が入っているのは3,628件（15.6%）に過ぎない。本解析の第3章・第4章のマトリクスは、この明示派の3,628件を母集団としており、未明示の19,646件のホライズン分布は推定不能である。レポート単位の time_horizon ラベル（near_2030／medium_2040／far_2050plus）でも61.8%が未指定であるため、〈未指定の中身〉が偏っていれば、本レポートのホライズン構造の結論は揺らぐ。

2. テーマ自由度の問題

prediction_themes 関係22,598件は、22,598/23,274 = 97.1% の予測がテーマ紐付済であり、カバレッジは非常に高い。しかし、各予測に対して紐付くテーマ数がほぼ1（22,598/23,274 ≒ 0.97）であり、複合テーマ予測の二重カウントは行われていない。これは「AIと労働の交差」「気候とジェンダー」のような交差領域を取り出すには不向きである。

3. 出典バイアス

academic（学術論文）が68.8%を占め、特に Crossref／OpenAlex 経由のキーワード検索が母集団を支配している。これはAI関連論文を実態以上に拾い上げる方向のバイアスを生んでいる。AI／機械学習L2の7,938件という突出は、現実の言説優位を反映する一方、収集パイプラインによる増幅でもある。

4. 地理バイアス

Africa／Middle East／Latin America 合計で76レポート（76,548中の0.10%）。これは「世界のフォーサイト」と呼ぶには深刻に偏っている。本レポートのテーマMAPは事実上「西洋＋日本＋国際機関」のフォーサイトMAPと読み替えるべきである。

5. 値の整合性問題

ブリーフィング記載の数値（309機関・45,323レポート・23,272予測）と、本DBの実値（463・76,548・23,274）の差は、生成スナップショットの時系列差である。具体的には、リポジトリ同梱の dashboard.html 内 DATA オブジェクトは2026-04-24時点のスナップショット（323／50,322／23,274）であり、それ以降に collect_batch6_global_expansion.py 等の追加収集が走り、現在の463／76,548／23,274に至っている※集計L-58,L-60。本解析は最新値を採用したが、過去文書と参照する際は時点を明記する必要がある。

6. シナリオの desirability 空白

5,099シナリオの96.5%が desirability 未付与であり、〈望ましい未来／望ましくない未来〉の二値判別がDB側でできない（NULL=4,920件、実値=179件）。これは「未来に向けて問うべき領域」の選定における規範的判断を、本DBに自動的に頼ることができないことを意味する。

7. epistemological_frame ラベルの未完了

463機関中、epistemological_frame ラベルが入っているのは40件（8.6%）に過ぎない。FK DB設計者が意図した〈解釈学的・脱植民地的・自然主義的〉の三層認識論ラベルは未完成である。

SELECT
  CASE
    WHEN time_horizon_year IS NULL THEN 'unspecified'
    WHEN time_horizon_year <= 2025 THEN 'past_or_now(<=2025)'
    WHEN time_horizon_year <= 2030 THEN '2026-2030'
    WHEN time_horizon_year <= 2040 THEN '2031-2040'
    WHEN time_horizon_year <= 2050 THEN '2041-2050'
    WHEN time_horizon_year <= 2070 THEN '2051-2070'
    WHEN time_horizon_year <= 2100 THEN '2071-2100'
    ELSE 'beyond_2100'
  END AS bucket, COUNT(*) cnt
FROM predictions GROUP BY bucket ORDER BY cnt DESC;

L-17: prediction_themes をL1集約

WITH pt_l1 AS (
  SELECT pt.prediction_id,
    CASE WHEN t.level=1 THEN t.id
         WHEN t.level=2 THEN t.parent_id
         WHEN t.level=3 THEN (SELECT parent_id FROM theme_taxonomy WHERE id = t.parent_id)
    END AS l1_id
  FROM prediction_themes pt JOIN theme_taxonomy t ON pt.theme_id = t.id
)
SELECT t1.code AS l1_code, t1.name_ja, t1.vesteg_primary, COUNT(*) cnt
FROM pt_l1 ptl1 JOIN theme_taxonomy t1 ON ptl1.l1_id = t1.id
GROUP BY t1.code, t1.name_ja ORDER BY cnt DESC;
-- 第2章の表を出力

L-19: ホライズン×L1テーマMAP

WITH pt_l1 AS (...)  -- L-17と同じCTE
SELECT t1.name_ja,
  SUM(CASE WHEN p.time_horizon_year BETWEEN 2026 AND 2030 THEN 1 ELSE 0 END) AS h2030,
  SUM(CASE WHEN p.time_horizon_year BETWEEN 2031 AND 2040 THEN 1 ELSE 0 END) AS h2040,
  SUM(CASE WHEN p.time_horizon_year BETWEEN 2041 AND 2050 THEN 1 ELSE 0 END) AS h2050,
  SUM(CASE WHEN p.time_horizon_year BETWEEN 2051 AND 2070 THEN 1 ELSE 0 END) AS h2070,
  SUM(CASE WHEN p.time_horizon_year BETWEEN 2071 AND 2100 THEN 1 ELSE 0 END) AS h2100,
  SUM(CASE WHEN p.time_horizon_year > 2100 THEN 1 ELSE 0 END) AS h_beyond,
  SUM(CASE WHEN p.time_horizon_year IS NULL THEN 1 ELSE 0 END) AS unspec
FROM pt_l1 ptl1
JOIN predictions p ON ptl1.prediction_id = p.id
JOIN theme_taxonomy t1 ON ptl1.l1_id = t1.id
GROUP BY t1.id ORDER BY (h2030+h2040+h2050+h2070+h2100) DESC;
