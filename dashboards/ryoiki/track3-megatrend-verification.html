Track 3 自己検証 — 4カテゴリ × 14項目

Track 3 analysis.html の主要主張に対し、Track内で発見可能な誤り・不整合・限界を網羅的に自己検査する。後工程の doc-verify／sentinel 独立検証の前段として、本Trackリードが先行的に開示する。

生成日: 2026-05-09 担当: Track 3 リード 検証項目: 14項目 判定区分: 4階層
PURPOSE

本検証の目的と方法

本検証は、_PROTOCOLS.md §8 の判定区分に従い、Track 3 analysis.html の各主張に対して、本Trackリードが自ら誤り・不整合を発見・開示することを目的とする。

検証は4カテゴリ × 各3項目以上、合計14項目で構成する。各項目には判定区分（問題なし／要解釈／要追跡／要修正／構造的ギャップ）を付与し、後工程の doc-verify エージェント・sentinel エージェントが対応すべき優先度を明示する。Track 1 では23項目の検証が実施されたが、Track 3 は対象データ規模が小さい（553カード／20マッピング）ため、14項目に絞り込んだ。

判定区分意味後続アクション

要解釈数値・構造に問題はないが、解釈に注意report.htmlで注記

CATEGORY 01

スナップショット不整合（4項目）

複数のデータ源からの数値が一致するか、時点・粒度の差で食い違いがあるか、を検査する。

V-01
予測総数：ブリーフィング 1,141件 vs DB実値 553件

検査内容：_TRACK3_MT.md および Memory（reference_miratuku_future_materials.md）に記載の「1,141予測」と、現行 futurology_data.json 内の「553カード（announce 557）」の差を検証。

結果：約2倍の差が存在。analysis.html §2 で 【推定】「1,141件は GTA構造化前の生データ件数または別バージョン」とした。本Trackでは確定不能。

判定: 要追跡 — 1,141件版の生データが別所にあるかを Track 10 統合時に再確認。本Trackは553カードを採用。

V-02
書籍数：Memory 15冊 vs json実体 19冊 vs subtitle 約30冊

検査内容：書籍数の三系列を比較。Memory に「15冊」、json実体に「19冊」、json subtitle に「約30冊」と記述。

結果：Memory「15冊」は A系列10冊（1A〜10A）+ 主要D系列+B/C で15冊と推測【推定】。subtitle「約30冊」は未収録分（B/C/D の派生プレフィックス）を含めた集計値とみられるが、json内 books辞書には19件のみ定義。

判定: 要解釈 — analysis.html §2 で19冊を採用、subtitle「約30冊」を補助情報として保留した点を report.html で再注記すべき。

V-03
タクソノミーDB の20件 vs ユニーク18件

検査内容：taxonomy_megatrend_mapping は20行を持つが、ユニーク・メガトレンド名は18件。

結果：「資源のスマートコントロール」が MD-1副 と MD-4主 の双方に、「バイオ技術のフロンティア」が MD-1主 と MD-2副 の双方にマッピングされ、合計で +2行。これは設計通りの「複数ドメイン跨ぎ」処理であり、不整合ではない。

判定: 問題なし — analysis.html §1 で「20マッピング・18ユニーク」と明示済み。

V-04
カード件数の不一致：announce 557 vs 実カウント 553

検査内容：futurology_data.json の stats.cards_count = 557 と、本Trackで Python 集計した実カウント 553 の差4件。

結果：差4件の原因は、stats フィールドが「subtitle 用の概算値」であり、実際の dai_items 内 cardsByChu の合計が553件であること【推定】。差は0.7%で、本Trackの結論には影響しない。

判定: 問題なし — analysis.html §1 で「553カード」を採用、announce「557」を併記済み。

CATEGORY 02

ハルシネーション（4項目）

analysis.html の数値・固有名詞・引用が、実DBの内容と一致するかを検査する。

V-05
「553カード」と各大項目別件数の整合

検査内容：18大項目の件数（67+54+50+45+44+42+41+36+34+32+29+28+22+11+8+5+5+0）の合計と全体「553」の整合。

結果：合計 = 553。一致。Python 検算済み【検証済】。

判定: 問題なし — Track 1 と同様の Python 直接検算で確定。

V-06
「カード "6A43"」（フリードマン引用）の実在性

検査内容：analysis.html §5.3 で引用したカード「アメリカとロシア間で世界的対立激化し再び冷戦が起こるが、ロシアは戦わずして自壊する」（出典 6A43）が futurology_data.json 内に実在するかを Python検索で確認。

結果：Dai 1「イノベーションの分散と都市国家の誕生」内 chu「イノベーションの分散化」内 nen「〜2030」のカードに、card_id="6A43"・book="6A"・text="2020年までにアメリカとロシア間で世界的対立激化する。再び冷戦が起こるが、ロシアは戦わずして自壊する。" が実在を確認【検証済】。

判定: 問題なし — 引用内容と DB実体が一致。

V-07
キーワード言及件数（COVID 0件、AI 8件、ロシア 10件）

検査内容：analysis.html §6.1 のキーワード言及件数の Python 再検算。

結果：再検算で完全一致。「中国 14件、ロシア 10件、AI/人工知能 8件、温暖化 3件、気候 2件、パンデミック 1件、地政学 1件、冷戦 1件、生成 1件、ChatGPT 0件、COVID 0件、感染症 0件、ウイルス 1件」【検証済】。

判定: 問題なし — 再現可能な集計、ハルシネーションなし。

V-08
「553カード中181件が的中項目（33%）」の算術

検査内容：analysis.html §5.2 の「的中項目（Dai 3, 7, 8, 10, 11, 14, 18）に属するカード合計181件」の検算。

結果：22+8+34+5+32+36+44 = 181件。一致【検証済】。181/553=32.7%（≒33%）も一致。

判定: 問題なし — 算術検算 OK。

CATEGORY 03

カバレッジギャップ（4項目）

本Trackの主軸DBがカバーしていない領域、構造的にカバー不能な領域を明示する。

V-09
19書籍の認識論的フレーム偏在

検査内容：19書籍を5認識論的フレーム（EP-NAT/ECO/PCO/IND/INT）に振り分ける。

結果：A系列10冊のうち少なくとも7冊が EP-NAT（カク、ディアマンディス、カーツワイル、ロス）。10A『地球に残された時間』のみ EP-ECO。BCシャーマー『U理論』は EP-INT。D系列7冊はほぼ EP-NAT。EP-PCO（ポストコロニアル）・EP-IND（先住民・ローカル）の書籍は事実上ゼロ。

判定: 構造的ギャップ — 認識論的フレーム偏在は本Track単独で解消不能。修正版18MT R18「非西洋認識論」を新設して補完する設計とした。Track 4（人類学・場所性）連携で補強推奨。

V-10
Dai 17「閉じる国家と停滞する社会」のカード0件

検査内容：Dai 17 の cardsByChu が空（cardCount=0）であり、chuFromYosoSheet のみ仮置きラベル「u1: 国家による変化の阻害」を持つ状態を確認。

結果：分析者が概念的にメガトレンドを立てたが、19書籍からカードを抽出できなかった構造的空白。修正版で R5（少子化・人口減少社会）に統合したが、これは強引な救済である【解釈】。

判定: 構造的ギャップ — 18MT のうち1項目（5.6%）が完全空白。本Trackで開示し、report.html「研究の限界」で再記載必須。

V-11
想定外要素の捕捉不能（COVID-19、生成AI、ウクライナ侵攻）

検査内容：2015-2025年の重要事象のうち、553カードでほぼ未予測の要素を抽出。

結果：COVID-19（言及0件）、生成AI/ChatGPT（具体名0件）、ウクライナ侵攻（具体予測なし、「ロシア自壊」と逆方向）、Web3/暗号通貨バブル崩壊（言及わずか）、SNS分極化、少子化加速、EV中国主導 — いずれも具体予測ゼロまたは方向性が逆。

判定: 構造的ギャップ — 「ブラックスワン型事象」「技術非線形ブレイクスルー」「反応的・対抗的現象」は書籍ベース読書会方式では原理的に拾えない。本Trackの最大の自己発見であり、修正版18MT R4・R9・R15 を新設して部分的に補完する設計。

V-12
CTL-Eco（経済・労働・産業）が主CTLとしてゼロ

検査内容：18大項目の主CTL-1割当（analysis.html §3.2）で CTL-Eco を主CTLとする項目が0件であることを再確認。

結果：原版18MT は CTL-Eco を独立カテゴリとして立てず、CTL-T（技術）か CTL-S（社会）の文脈に混入させる構造。Track 1（FK）が「経済・金融」を独立 L1 として持つのと対照的【解釈】。

判定: 要解釈 — 構造的ギャップではあるが、修正版で R8（エネルギー転換）・R14（EV・サプライチェーン）・R15（暗号通貨/Web3）に分散させて部分的に補完。Track 5（投資シグナル）連携で経済領域を強化推奨。

CATEGORY 04

チーム間不整合（2項目）

他Track（とくにTrack 1 FK）の主張と本Trackの主張が矛盾しないかを検査する。

V-13
Track 1 「FKの57メガトレンドはmegatrend DB 18体系を【推定】内包する」との関係

検査内容：Track 1 report.html §6 の「FKの57メガトレンドは、megatrend DB（Track 2/旧3）の18体系を【推定】内包する」記述と、本Track の「Foresight Taxonomy 18メガトレンド + Futurology Cards 18大項目」の関係を検証。

結果：本Trackの集計で確認したのは 2系統の18MT（タクソノミー側・カード側）であり、Track 1 が指摘する「megatrend DB の18体系」と完全一致するわけではない。両者の関係は次の通り：

  • Foresight Taxonomy 18件（taxonomy_megatrend_mapping のユニーク名）
  • Futurology Cards 18件（dai_items）
  • 名称完全一致は約6件、部分対応は約8件、片側のみは約4件

Track 1 の表現「megatrend DB 18体系」が、上記2系統のいずれを指しているか判定不能。Track 1 と Track 3 の合同セッションで再確認すべき【未検証】。

判定: 要追跡 — Track 10 統合時に Track 1 リードと合同で「Foresight Taxonomy 18 vs Futurology Cards 18 vs FK 57メガトレンド」の三層マッピングを実施推奨。

V-14
Track 1 強みホライズン「2030近傍＋2050+の二焦点」 vs 本Track「2030主軸＋2050副次」

検査内容：Track 1 report.html の「FKの強みホライズンは2030（2,262件）と2050+（11,783件）の二焦点」と、本Track analysis.html §9 の「near 主軸、mid 副次、far 弱、very-far 構造的弱点」の比較。

結果：両Trackとも「2030を主軸とし、2050前後まで延長可能」という大きな構造は一致。違いは Track 1 が「2050+」を二焦点の一方として明示するのに対し、Track 3 は「mid 副次」と相対化している点。これは Track 1 が「FK reports.time_horizon = far_2050plus 11,783件」のレポート単位で集計するのに対し、Track 3 はカード単位（年代「〜2070」が195件で2050前後混在）で集計する粒度差に由来する【解釈】。

判定: 問題なし — 両Track とも整合的、粒度差を Track 10 統合時に明示すれば解消可能。
