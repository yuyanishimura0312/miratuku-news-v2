EXECUTIVE SUMMARY

本レポートの要旨

CLA DBは、1900-2026の127年間にわたって、社会の四層（litany 表層／system 構造／worldview 世界観／myth 神話）を一貫した粒度で記録した、世界的に類例の少ないデータ基盤である。本Trackはその91,550レコードを四つの問いから読み解いた。本レポートはその主要発見を四つの命題に集約する。

命題1: 現代（2020-2026）は「文明モデルそのものの転換期」にある。CLA は2020年「分裂統合する煙に包まれた危機転換点」、2025年「加速する要塞の中での関係性への渇望」、2026年「加速と置き去りの狭間で模索する転換期」と各年の zeitgeist を記録している。さらに 2026年Q1の key_tension は「グローバル統合モデルの同時的崩壊」と記述する。これらは単なる景気循環ではなく、近代以降の文明モデルそのものが機能不全に達したことを示す※集計L-15, L-16, L-24。

命題2: 失われつつある神話と立ち上がりつつある神話が、それぞれ5系統で並走している。失われつつあるのは「進歩・成長の直線神話」「啓蒙的普遍主義」「市場による救済」「科学技術の中立性」「国民国家の統治能力」の5系統。立ち上がりつつあるのは「循環と帰還の物語」「ケア・創造・共生の三位一体」「場所に根ざした相互依存」「身体・精神性の復権」「多神的・脱近代的な知識体系の共存」の5系統※集計L-26, L-27。

命題3: CLAが強みとするホライズンは mid（2036-2055）が中核、過去126年が独自強み。cla_predicted_signals 900件のうち56.9%が medium ホライズン（5-15年）に集中し、過去9年代の平均ラグ（systemic 9.2y／narrative 10.7y／worldview 11.0y／myth 12.2y）は2026年起点で2035-2050に到達する。一方、very-far（2081-2100）は本DBの直接予測射程外であり、過去軸 1900-2025は126年分連続で他Track非追随の絶対的強み ※集計L-29, L-30, L-31。

命題4: CLAは Track 1（FK）の構造的弱点 values（0.45%）を補完する独自強みCTL-Vを持つ。worldview 1,348件＋myth 1,510件＝2,858件のキーワード、126年分の物語転換軌道、Thompson Motif Index 45,496件、UNESCO ICH 849件を擁する。CTL-V（価値観・倫理・文化）はCLAが他Track非追随で提供できる中核領域である※集計L-07, L-10。

これら四命題は、analysis.htmlの集計L-01〜L-40、verification.htmlの21項目検証を踏まえて確定されている。本report.htmlは領域策定プロジェクトの成果物として、Track 10統合およびミラツク経営判断に提示される。

CHAPTER 01

CLAから見る現代の立ち位置

CLA は、Sohail Inayatullah が体系化した未来洞察の方法論であり、現象を「litany 表層 → systemic 構造 → worldview 世界観 → myth 神話・比喩」の四層に分けて解読する。本Trackの主軸DBは、この四層を1900-2026の127年間にわたって毎年継続的に記録した、世界的に類例の少ないデータ基盤である。本章では、その記録から現代社会の立ち位置を診断する。

1.1 127年の zeitgeist 系譜

integrated_cla テーブルは、各年について四層の解釈と zeitgeist（時代精神を一行で凝縮した記述）を持つ。10年ごとに抽出すると次のような縦断像が得られる※集計L-15。

これら9個のzeitgeistは「対立軸の二極化と中間層の希求」という共通構造を反復している。「帝国 vs 郷土」「破滅 vs 創造」「秩序 vs 創造的分裂」「解放 vs 混沌」「統合の約束 vs 断裂」「分裂 vs 統合」「加速 vs 関係性」「加速 vs 置き去り」——いずれも二項対立の同時進行を捉えており、各時代の人間が 「両極を生きる」 という構造を反復している【解釈】。

1.2 2020-2026 の連続診断

とりわけ現代（2020-2026）の7年は1年単位で記録されており、近年の社会精神の起伏が読める※集計L-16。2020「危機転換点」→ 2021「制度崩壊下での生存的連帯の萌芽」→ 2022「免疫システム過剰反応による構造的自己破壊」→ 2023「制御と解放の狭間で分裂する再生への意志」→ 2024「制度的回復と生活的破壊の同時進行」→ 2025「加速する要塞の中での関係性への渇望」→ 2026「加速と置き去りの狭間で模索する転換期」。

この軌道を要約すれば、2020年代前半「危機の自覚」→中盤「自己破壊と再生の闘争」→後半「要塞化と置き去り」という三段階で進んでいる。とくに 2025-2026 のキーワード「要塞」「置き去り」は、近代的進歩物語が機能不全に陥り、新たな物語が立ち上がる前の 空白期 を示唆している【解釈】。この空白期こそが、ミラツクが「問うべき領域」を構築する戦略的タイミングである【解釈】。

1.3 現代の支配的 worldview と key_tension

integrated_cla の worldview 列を 2026年で参照すると、現代の支配的世界観は 「技術的解決主義と自己責任型選択」として記述される※集計L-23。AI・再生可能エネルギー・金融工学によってシステム問題は解決可能であり、個人は多元化した選択肢の中で自律的に人生設計すべきという二重の前提が支配的である。一方、生活世界では「自由と不安定性」「進歩と破壊」の背反を当然視する感覚が浸透している。

2026年Q1の analyses_v2 はさらに踏み込んで、「グローバル統合モデルの同時的崩壊」「人権・法治・気候対応 vs 国家理由・経済利益・技術覇権の根本的葛藤」を中核矛盾として記述する※集計L-24。これは現代が単なる景気変動や政治変動ではなく、文明レベルの転換期にあることを示している【解釈】。

2.3 列ごとの読解

ヒートマップから三つの構造的特徴を抽出する。第一に、past 1900-2025 列の CTL-V が圧倒的に強い（2,858件のキーワード＋126年分の物語転換）。これは Track 1（FK）が values 0.45%（105件）の構造的弱点としていた領域を CLA が補完できることを意味する【解釈】。第二に、mid 2050 列が全 CTL-1 で最大規模を持つメインホライズン。Political 126件、Technological 92件、Social 90件、Economic 89件、CTL-G 合計194件など、本Trackの予測射程の中核がここに集中する。第三に、very-far 2100 列が全 CTL-1 で空白。CLAは2081-2100を直接予測射程に持たず、過去軌道のアナロジー的射程か、別Trackの補完が必要となる。

CHAPTER 03 / 必須要素②

CLAが強みとするホライズン領域宣言

analysis.html 9章での導出を踏まえ、CLAが強みとするホライズン領域を改めて宣言する。これは過去126年データから導かれた定量根拠に基づく。

3.1 三観点からの定量根拠

強みホライズンは次の三観点から定量的に判定された。第一に、cla_predicted_signals のホライズン分布は medium (5-15y) 512件（56.9%）／short (1-5y) 202件（22.4%）／long (15-30y) 186件（20.7%）であり、medium ホライズンが過半を占める※集計L-05。第二に、cla_narrative_verification 360件のうち realized 201件＋partially_realized 144件＝95.8%が実現または部分実現に到達しており、方法論的予測精度が高いことが事後検証で確認されている※集計L-32。第三に、過去126年の cla_signal_lag_analysis 9年代分から深層別の平均ラグが安定しており（systemic 9.2y／narrative 10.7y／worldview 11.0y／myth 12.2y）、2026年起点で2035-2050が最も高密度な予測射程となる※集計L-29, L-31。

3.4 「物語の交代」を捉える射程

本Track固有の方法論的強みは、「物語の交代」を 10-30年スパンで捉えられる点にある※集計L-29。systemic 層は9-10年で実現するため near スパンの観測対象であり、narrative 層と worldview 層は11年前後で実現するため mid スパン、myth 層は12-25年で実現するため mid-far スパンとなる。これは Track 1（FK）が予測する「2030年の AI普及」「2050年のネットゼロ」のような 定量的予測 とは異なる、「2040年代に worldview が転換する」「2050年代に myth が交代する」という 定性的・構造的予測 である【解釈】。

4.3 物語交代の二系統認識

失われつつある神話5系統と立ち上がりつつある神話5系統を対比すると、両者は単純な「新旧交代」ではなく、現代に 二系統の相反する力学 として並走していることがわかる【解釈】。

第一系統「テクノ加速」は 2025年「回転する要塞都市」と 2026年「加速する変身」に集約される、AI・再生可能エネルギー・金融工学による劇的変身の物語である。これは「進歩物語」の機能不全を「より速い加速」で乗り越えようとする力学であり、Track 1（FK）が捉えた「テクノロジー90% AI集中」の予測群と整合する【解釈】。

第二系統「場所性回帰」は 2024-2026 の emerging_narrative「地域主権／ケア・創造・共生／場所に根ざした相互依存」に集約される、身体・場所・関係性・循環の物語である。これは Track 1（FK）には希薄な values 領域であり、ミラツクの三本柱（領域横断・対等な探究・暗黙知の形式知化）と直接接続する【解釈】。

  4. LLM由来の二次的ハルシネーションリスク: integrated_cla・myth_metaphor・worldview・emerging_narrative の各列は claude-sonnet-4 が pestle.db / cultural_intelligence.db から自動生成した記述。LLM由来の二次的ハルシネーションが上流データに含まれる可能性は本Track単独では完全に排除できない【未検証】。
  5. 「物語の交代の終点」が現時点で確定していない: 「テクノ加速 vs 場所性回帰」のいずれが主流物語になるかは未確定。次回再構築時（2030年頃【推定】）に判定可能。
  6. worldview_data の HDI偏在: HDI 28,204件が圧倒的多数で「Human Development」の単一指標に偏る。文化価値観の多次元（権威 vs 民主、伝統 vs 革新、集合 vs 個）の網羅性は限定的。
  7. archetype_tags の現代未対応: Thompson Motif Index 由来の archetype_tags は古典神話原型に集中し、AI神話・気候神話・データ神話・身体神話など現代の集合的無意識を直接表すタグは含まれない。現代分析には integrated_cla.myth_metaphor 列の方が直接的根拠となる。
