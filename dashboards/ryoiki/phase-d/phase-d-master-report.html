Phase D の位置と読み方 — 主は書籍、従は羅針盤

2026 年の春、ある観測者が、机の上に二冊の書物を並べた。一方は『深い知が拓く 2100 年』と題された 304,999 字の書籍。もう一方は『ミラツクが描く未来社会への羅針盤』と題された四位一体マスター図つきの内部資料。前者は読者の手に届ける物語であり、後者は研究室の壁にかけられた地図である。

この二つの間に橋が必要だった。地図のままでは外に出ないし、物語のままでは現場で使えない。橋とは、地図上の核心問いを物語の中の章に重ね、双方の間を読者が自分の足で行き来できるようにする小冊子のことである。Phase D は、その小冊子をつくる試みである。

本マスターレポートは、その小冊子の表紙であり、目次であり、解説でもある。けっして単独で完結する書物ではない。書籍の章を読み返し、羅針盤の象限を見直し、八つの問いの背景解説を一つずつ手にとって、読者は自分の現場の問いをひとつ生成する。本書はそのための入口である。

領域策定プロジェクトは、Phase A（9 トラック・31+ DB 横断・15 メタテーマ抽出）、Phase B（6 トラック・71 独立問い ID + 926 派生 = 997 単位）、Phase C（7 トラック・四位一体マスター図 + 統合ナレッジマップ・great_actions.db v0.2 140 件）と階段を上り、22 トラック合計 1,200 余単位の知見集積となっている。Phase D は、この羅針盤を deep-knowledge 書籍『深い知が拓く 2100 年』（序+18 章+終 = 20 章 / 26 DB 統合 / 304,999 字）と接合し、配布資料・企画決定用コンセプト資料・関係者向け重要資料として組み直す段階である。

Phase D の特徴は、deep-knowledge 書籍を 主、ryoiki-index（Phase A/B/C 統合）を 従 として運用する点にある。Phase A〜C は内部解析の三層階段だが、Phase D は外部読者と同じ机の上に羅針盤を置く段階である。書籍が立てている物語の枠を借り、その枠の中に羅針盤の核心問いを差し戻す。つまり、書籍の章 ch11〜ch15（第三部「人類学・哲学・伝統知」）が「答えに近い系譜」を書いているなら、Phase D の問いはそこに「まだ答えがない問い」を貼り付ける役割を担う。

1.1 なぜこの問いか

世代間正義の規範論述は、Hans Jonas の責任原理（1979）、Derek Parfit の人格同一性論（1984）、Toby Ord の崖（2020）と、半世紀の哲学的厚みを持つ。先住民知の側でも、Iroquois 連邦の七世代律（Seven Generations Principle）は数百年の時間軸の倫理を継承する。制度雛形については、ニュージーランドのワンガヌイ川法人格（2017）、エクアドル自然の権利憲法（2008）、ボリビア生存自然の権利法（2010）、コロンビア憲法裁判所アマゾン法人格判決（2018）の 4 制度が、自然権制度として「未来世代と非人間の代表」を制度化している。さらに、ウェールズ未来世代福祉法（2015）、フィンランド未来委員会、シンガポール戦略的フューチャー局など、行政過程に未来世代の利益を組み込む制度も現代登場中である。にもかかわらず、これらの個別制度を統合し、世代間正義そのものを憲法・基本法に明文化する動きは 戦略的空白 として残されている。Phase B 装置観測では、本問いは opportunity 15 件 / warning 0 件 / mainstream 0 件 という著しい非対称を示す。

1.2 8 問構成における位置

2.1 なぜこの問いか

本問いの核心は、知識主権を「外部承認の獲得」として制度化するか、それとも「翻訳しない参照」として制度化するか、という形態選択にある。前者は西洋的法制度の枠の中で先住民知識を保護する設計だが、後者は 世界そのものが複数あること を法制度の側が認める設計を意味する。Eduardo Viveiros de Castro の視座主義（perspectivism）が示した「ジャガーが見ている血は、ジャガーにとってはマニオク酒である」という存在論的多元性を、法制度が「翻訳して同質化する」のではなく「異なるまま参照する」設計に書き換えうるか。Phase B B-2 では Pluriverse 群として 18 件の wisdom が紐付き、Phase C C-3 では系列 3（UNDRIP → Whanganui → TK 主権国際標準化）として 14 件の偉業が並ぶ。

Phase D の完了は、領域策定プロジェクトが「内部解析の三階層（Phase A〜C）」と「外部接続の結晶化（Phase D）」の四階層を完成したことを意味する。残された問いは、この配布資料が 誰の机の上に置かれ、どの会話を生み、どの現場で動き出すか である。これは Phase D の責務ではなく、Phase E の責務である。Phase D は地図と物語の間に橋を架けたが、橋を渡る人を呼ぶことはしない。橋に立つ人を観察し、その人の歩幅に合わせて橋の手すりを調整するのが、Phase E の仕事となる。

終-2 Phase E 暫定構想 — Futures コミュニティ

Phase E は暫定的に Futures コミュニティとして構想される。8 問の背景解説 HTML を読んだ読者が、自分の現場の問いを Phase D 8 問のいずれか（または複数）に紐付けて報告し、その報告が次の問い設計に再帰的に組み込まれる場である。これは Phase B B-2 wisdom 抽出で蓄積された 5 traditions（5 系統の伝統知）の現代的更新作業に相当する。具体的なコミュニティ運営形態（オンライン / オフライン / 頻度 / 参加条件）は Phase E 設計段階で決定される。

終-3 Phase D 4 段階の sentinel verdict

Phase D 4 段階（D-0 結合性分析 / D-1 問い候補選定 / D-2 各問い背景解説 / D-3 統合 + 配布資料化）はそれぞれ独立した sentinel verdict による APPROVED を取得することを目標とする。本書（D-3 統合 + 配布資料化）は、D-0/D-1 が既に APPROVED されており、D-2 が部分完了 3/8（DQ-01〜03 完成、DQ-04〜08 並走中）の状態で先行起動した。最終 sentinel APPROVED は D-2 全 8 問完成 + D-3 三層検証（doc-verify / sentinel / refinement-coordinator）を経て確定する。

終-4 G-V03 自己診断 — 本書自身は妥当だったか

DQ-05 G-V03 自己言及メタ問いを Phase D 全体の自己診断軸として運用する設計に従い、本書の終章で本書自身の妥当性を自己診断する。本書は、deep-knowledge 書籍を主としながら、ryoiki-index を従として運用したか。8 問は Phase A〜C の集積を結晶化させた構成だったか。配布資料・コンセプト資料・読者ガイドの三役割を一書で兼ねる構造は、配布対象別の使い分けを混乱させなかったか。これらの自己診断問いは、Phase D 完了後 5 年（2031 年）と 10 年（2036 年）の節目で再評価され、その評価が次の領域策定サイクルに組み込まれる。
