Part I

序論と選定方法

1.1 本トラックの位置と目的 — 32 候補プールから 8 問への絞り込み

本トラックは Phase D 4 段階構造の Wave 1（D-1 問い選定）として、D-0 結合性分析が提示した 32 問候補プールから、deep-knowledge 物語との結合性 × Phase C ミラツク優先課題 × ミラツク独自視点の三軸で 5-10 問の核心問いを選定する責務を担う。Phase C Wave1-3 すべての完了（C-1 サイクル螺旋 / C-2 4 軸再ランキング / C-3 great_actions.db v0.1 140 件 / C-4 great_actions.db v0.2 + warning17/opportunity50 / C-5 担い手 4 軸 + 第 5 類型「翻訳者型」が 5 sentinel APPROVED 確定）を経て、本トラックは「30-50 問の中から 5-10 問選定」という負荷を「20 問プールから 8 問確定」に縮小した状態で起動する。

D-0 リード本体の 32 問候補プールに対して、Phase C 確定値統合再評価により以下の調整を行った。第一に、Q-M07（多元的人格の社会）は C-2 4 軸再ランキングで TOP6 位、概念整合「第四変容期」の代表問いとして A → S 昇格。第二に、G-F05（人間-AI 共進化と「個人」概念の境界）は C-3 偉業数が確認できず C-2 TOP10 にも入らず S → A 格下げ。第三に、Q-N04（場所性回帰の制度化）は C-2 4 軸再ランキング 1 位かつ B-6 発見 1 で唯一全 Track 貫通する真M問いとして必選確定。この調整により、Tier S+/S 8 問 + A 5 問 + B 7 問 = 20 問プールに絞り込みが可能となった。

1.2 三段論選定基準 — 物語結合 + Phase C 優先 + ミラツク独自視点

本トラックは各問いの選定根拠を 三段論で構成する。第一段は deep-knowledge 物語結合性。D-0 結合性分析で確認された強連結 50 問に該当するか、主章重複が最小化される構成に貢献するか、章末扉が問いを直接呼ぶ構造を持つか、を評価する。第二段は Phase C ミラツク優先課題。C-2 4 軸再ランキング TOP10 に入るか、戦略的空白 13 問に含まれるか、C-3 偉業 140 件で十分な系譜厚を持つか、C-4 zone マッピングで Hot/warning 特性を持つか、を評価する。第三段は ミラツク独自視点。第 5 類型「翻訳者型」が中核担い手として登場するか、概念整合「第四変容期」の代表性を持つか、自己言及メタ問いとしてミラツク後継組織の引継装置として機能するか、を評価する。

本三段論は各 DQ カード内の「選定根拠」セクションで明示的に展開され、読者が各問いの選定理由を独立に検証可能な構造を持つ。さらに、各 DQ には Phase B/C 接続 ID（C-1/C-2/C-3/C-5）を併記することで、D-2 並列背景解説 HTML 作成時の入力資料指定が単一仕様として運用される設計である。

DQ-01 G-M04 Tier S+

国は世代間正義を憲法・基本法に明文化するか — 戦略的空白筆頭の制度化

背景

世代間正義の概念は 50 年前から規範論述として蓄積されてきた。Hans Jonas の責任原理（1979）、Derek Parfit の人格同一性論（1984）、Toby Ord の崖（2020）など、未来世代への倫理責任を問う哲学的伝統は厚みを持つ。先住民の伝統知においては、北米イロコイ連邦の七世代律（Seven Generations Principle）が長い時間軸の倫理として現代に継承されている。制度的雛形としては、ニュージーランドのワンガヌイ川法人格（2017）、エクアドル自然の権利憲法（2008）、ボリビア生存自然の権利法（2010）、コロンビア憲法裁判所アマゾン法人格判決（2018）の 4 制度が、自然権制度として「未来世代と非人間の代表」を制度化している。さらに、ウェールズ未来世代福祉法（2015）、フィンランド未来委員会、シンガポール戦略的フューチャー局など、未来世代の利益を行政過程に組み込む制度も現代登場中である。しかし、これらの個別制度を統合し、世代間正義そのものを憲法・基本法に明文化する動きは戦略的空白として残されている。

選定根拠

第一段（物語結合）: deep-knowledge ch14 第三節「自然権制度の系譜」+ ch19「夜の作法 — 長い時間と痛みの物語化」+ ch13「長い時間軸の知」の 3 章直結で強連結。NZ・EC・BO・CO 4 制度の系譜が制度的雛形として ch14 で展開される。第二段（Phase C 優先）: C-2 4 軸再ランキング第 2 位、C-3 great_actions.db で 15 件（最多）の偉業系譜（七世代律 → ウェールズ未来世代法 → 憲法化）、戦略的空白 13 問の筆頭、ミラツク TOP10 第 1 位。第三段（ミラツク独自視点）: B-4 装置観測完全不能（N/A）の構造を制度雛形と対比することで「規範論述は 50 年前から、制度雛形は 10-20 年前から、しかし装置で観測されない」というミラツク独自視座を読者に手渡す。第 5 類型「翻訳者型」が制度翻訳者として中核担い手となる。

先住民圏の知識主権はどの形態で制度化されるか — 翻訳しない参照の倫理

背景

先住民知識主権の制度化は、UNDRIP（先住民族の権利に関する国連宣言、2007）を出発点として 20 年弱の制度蓄積を経てきた。CARE 原則（Collective Benefit / Authority to Control / Responsibility / Ethics、2020）と FAIR 原則（Findable / Accessible / Interoperable / Reusable）の併用、Whanganui 川法人格（NZ 2017）、Berta Cáceres を象徴とする中米の伝統知守護運動、Vincent Lingiari を象徴とするオーストラリア先住民土地権運動、トンブクトゥ図書館の伝統知保存などが現代登場中の偉業系譜を形成する。制度化の形態については、(a) UNDRIP 拡張、(b) WIPO 政府間委員会での独自原則、(c) CBD（生物多様性条約）の Nagoya Protocol 連携、(d) UNESCO ICH（無形文化遺産）枠組みの拡張、の複数経路が並走している。期待される未来は TK 主権の国際標準化（2030-2035 想定）である。
