SECTION 01

Phase D 配布資料は基幹 3 ファイル（マスターレポート + 配布パッケージ + Phase D Index）+ 個別 8 ファイル（DQ-01〜08 背景解説）の 11 ファイル構成。本書はその一覧と配布対象別ガイドを提供する。

本パッケージは Phase D 配布資料の カタログ である。Phase D マスターレポート（phase-d-master-report.html）が「配布資料の表紙・目次・解説」を担うのに対し、本書は「配布資料の在庫一覧 + 配布対象別の使い分け + 印刷／PDF 化ガイド」を担う。マスターレポートが 地図 であるなら、本書は 地図のショーケース に相当する。

SECTION 05

印刷・PDF 化ガイド

基幹 3 ファイル + 個別 8 ファイルはすべて @media print スタイルを実装。ブラウザの印刷機能で A4 縦印刷向けに自動最適化される。

5.1 印刷スタイル仕様

本パッケージの全 HTML ファイルは @media print スタイルを実装しており、以下の挙動を持つ。

  • サイドバー（toc-sidebar）と上部固定バー（top-bar）は印刷時に非表示
  • 本文は A4 縦印刷で読みやすい 11pt フォントサイズに自動調整
  • 章セクション（chapter-section）は break-inside: avoid 指定で章途中の改ページを抑制
  • 個別問いカード（pkg-card / dq-box）は同様に break-inside: avoid で分断を抑制
  • 本文の text-indent と行間（1.95）は印刷時も維持

5.2 PDF 出力手順

PDF 出力は OS 標準のブラウザ印刷機能で行う。Chrome / Safari / Firefox いずれも同等の出力品質となる。具体手順は次の通り。

  1. HTML ファイルをブラウザで開く
  2. 「ファイル → 印刷」（または Cmd+P / Ctrl+P）を実行
  3. 送信先を「PDF として保存」に設定
  4. 用紙サイズ A4、向き 縦、余白 標準を選択
  5. 背景のグラフィックを印刷する（ヘッダー・フッター除く）
  6. 保存先と PDF ファイル名を指定して出力

マスターレポートは約 38,000 字で PDF 約 60-80 ページの想定。配布パッケージ（本書）は約 12,000 字で約 20-25 ページ。Phase D Index は約 10,000 字で約 15-20 ページ。個別背景解説 HTML は各 3,000-4,000 字で 5-8 ページ。配布対象に応じて必要部数を出力する。

5.3 印刷物として配布する場合の留意事項

印刷物配布時は次の点に留意する。第一に、内部リンクは印刷物では機能しないため、紙面上で参照するファイル名を脚注として補記することを推奨する。第二に、ダークモードは印刷時に自動でライトモードに切り替わるため、印刷前にライトモード表示を確認すること。第三に、ロゴと CI（赤白 #CC1400）は印刷品質に影響するため、カラー印刷を推奨する。モノクロ印刷でも本文は読めるが、強調部分（em タグの赤白アンダーライン）は識別できなくなる。
