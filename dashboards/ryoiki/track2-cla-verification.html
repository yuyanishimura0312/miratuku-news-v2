INTRODUCTION

検証の目的と方針

本verification.htmlは、analysis.htmlで提示した主張に対して、自己検証の責任を果たすことを目的とする。プロトコル8節の判定区分（問題なし／要解釈／要追跡／要修正／構造的ギャップ）を採用し、各検査項目を明示的に判定する。

検証範囲は、analysis.htmlで報告した主要数値（91,550／46,345／34,212／127年など）、cla_predicted_signals 900件のホライズン・深層集計、127年の zeitgeist 系譜、現代（2020-2026）の四層解読、強みホライズン宣言（mid 2036-2055）、強みCTL-1宣言（CTL-V）の各項目を含む。

判定区分は次の通りである。問題なし 検査クリア。要解釈 数値・構造に問題はないが解釈に注意。要追跡 本Track判定保留・後続Track／Track 10で再検証。要修正 report.html訂正必須。構造的ギャップ DBの構造的限界・本Track単独で解消不能。

1.2 二テーブル並存の取り扱い

analyses（930件）と analyses_v2（216件）が並存する点、および ci_cla（127件）と integrated_cla（127件）が同件数で並ぶ点について、analysis.html では「integrated_cla を一次採用、analyses系列は補助参照、ci_cla は相互検証用」と宣言した。これは 要解釈 判定とする。理由は、二系統の並存自体は「DBの進化過程」として正当だが、Track 10統合時に誤って分析対象を analyses（930件・PESTLE分割版）にしてしまうと、四層深層解析の意図と整合しない結果になるリスクがあるためである。Track 10統合では本verification記述に従い、integrated_cla を一次参照とすべきである。

1.3 「CLA Rebuild CI 2020年まで完了」記述との整合

メモリには「CLA Rebuild CI 2020年まで完了」と記録されているが、実DBでは ci_cla テーブルに127件（1900-2026）すべてが格納されており、メモリ記述と矛盾する可能性がある。analysis.html 1.3節では「実値では1900-2026全期間がカバーされている。整合的」と注記したが、これは 要追跡 項目とする。理由は、ci_cla の generation_version が3で揃っているため整合性が見かけ上確認できるが、メモリと実DB値のどちらが「正しい現状」かを本Track単独で判定できないためである。Track 10統合時、または次回のメモリ整合チェック時に再評価する必要がある。

1.4 db_meta の last_synced と last_rebuilt の差

db_meta テーブルには last_rebuilt: 2026-04-25T14:55:52（rebuild_version=2.0）と last_synced: 2026-05-06T04:00:02 の二記録があり、両者の間に約11日の差がある。本Track作成は 2026-05-09 であり、最新の sync から3日後の状態を分析している。これは 問題なし 判定とする。差異は通常の更新サイクルの範囲内である。

CATEGORY 3

カバレッジギャップ

本DBが構造的にカバーしない領域、または特定の偏りで他の領域を見落としている可能性を検査する。

3.1 地理カバレッジのギャップ

判定: 構造的ギャップ。paradigm_shifts と myths_timeline は region='global' と region='japan' のみで構成されており、グローバルサウス（アフリカ・ラテンアメリカ・東南アジア・中東）の固有文脈が独立カテゴリとして存在しない。具体的には以下の構造的限界がある。

  • region='global' は事実上「西洋＋日本＋一部の国際機関視点の global」として機能している可能性が【未検証】。Brexit、トランプ、ボルソナロといった西洋政治イベントが頻出する一方、アラブの春の二次的影響、サブサハラアフリカの政治変動、ラテンアメリカの国家プロジェクト、東南アジアの開発主義などが薄い。
  • region='japan' は5期間で記録されているが、他の特定国（韓国・中国・インド・ブラジル等）について同等の粒度での記録は存在しない。
  • worldview_data 1,460件は google_ngram（en-2019 英語コーパス）由来の語彙頻度時系列のみで、各国固有の物語転換は記録していない。193カ国・1990-2024年の定量データは別テーブル social_indicators（34,212件）が担う。

これは Track 1（FK）が「Africa／Middle East／Latin America 合計0.10%」と発見した構造的限界と 同型であり、領域策定プロジェクト全体としての構造的弱点を示唆する。Track 10統合では、Track 9（哲学／神話DB）または独立の「グローバルサウス補正Track」での補完が望ましい【解釈】。

3.2 神話原型のギャップ

判定: 要解釈。myth_data 46,345件のうち45,496件（98.2%）が Thompson Motif Index 由来であり、archetype_tags は人類普遍の神話原型に集中する。これは強みでもあるが、現代分析には適していない。具体的には：

  • archetype_tags 上位10種（trickster／magic／creation／otherworld／social／hero_journey／animal／fate／death／monster）は古典神話の構造であり、AI神話・気候神話・データ神話・身体神話など現代の集合的無意識を直接表すタグは含まれない。
  • UNESCO ICH 849件は「現代の無形文化遺産」として登録された儀礼・口承伝統だが、これも「世代継承された伝統文化」中心で、現代の物語転換そのものは扱わない。
  • 現代分析のためには、本Trackは integrated_cla.myth_metaphor 列（127年分の各年の支配的メタファー記述）を一次データとして用いた。analysis.html の 6.1節以降の現代分析はこれに依拠している。

これは構造的ギャップではなく、データの正しい使い分けの問題である。analysis.html 11.1節の限界3で明示済み。

3.3 very-far ホライズン（2081-2100）のギャップ

判定: 構造的ギャップ。cla_predicted_signals の最大ホライズンが long (15-30y) であり、2026年起点で2056までが射程内、2081-2100は本DBの直接予測射程外である。analysis.html 9.2節で明示済み。Track 6（GPT-QoL／Tech Acceleration の700万年史視座）または Track 9（哲学／神話DBの長期文化軌道）への接続が必要。

3.4 文化価値観の多次元性カバレッジ

判定: 要解釈。worldview_data 1,460件の実ソースは google_ngram（en-2019 英語コーパス、語彙頻度時系列）であり、193カ国・多次元文化価値観を記録するものではない。HDI 28,204件・World Bank 6,008件は別テーブル social_indicators のソース別件数（doc-verify 指摘を受け analysis.html 3.4節・L-14 で修正済み）。

本Trackで「現代の支配的世界観は『技術的解決主義と自己責任型選択』」と診断したが、これは integrated_cla.worldview 列のテキスト記述に依拠した【解釈】であり、世界価値観調査（World Values Survey）のような多次元定量データで裏付けたものではない。Track 10統合時、World Values DB（メモリ参照）との連結で精度を上げることが望ましい。

3.5 metaphor_frames（0件）と cla_deep_links（0件）の機能未実装

判定: 要追跡。スキーマには存在するが0件の二テーブルは、本来「四層を異なる文化メタファーフレームで再分析する拡張機能」として設計されている。本Trackでは利用不可能。これは構造的ギャップというよりDB拡張の優先順位の問題で、Track 9（哲学／神話DB）が実装する場合は本Trackと連携可能となる。

3.6 2020-2026 「危機」キーワード集中の偏り

判定: 要追跡。analysis.html 11.1節 限界6でも開示したが、2020以降の zeitgeist が連続して「危機」「破壊」「断絶」のキーワードで満ちている。これは時代特性の真正な反映である可能性が高い（COVID／戦争／インフレ／地政学緊張が客観的に集中している）が、分析パイプラインのバイアス（claude-sonnet-4 系列のLLMが「危機」キーワードを優先抽出する）も【未検証】排除できない。

検証手段としては、 1) 1990-1999年の zeitgeist と比較（「境界溶解と根拠地探求の二重螺旋」など、1990年代も「動揺」キーワードを含む）、 2) 同時期のニュース密度を Track 8（PESTLE Daily）で対比、の二経路がある。本Track単独では判定保留。Track 10統合時の課題とする。
