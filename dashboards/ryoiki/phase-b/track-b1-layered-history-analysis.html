PROLOGUE

本Track の位置づけ

Track B-1 は Phase B（統合的解析プロジェクト）の Wave 1 に位置する基盤層トラックである。Phase A の9トラックが「各DBが何を語るか」を抽出したのに対し、本Track は「それらを多層構造化し、問い群として再構築する」役割を担う。後続の Wave 2-3（B-2 すでにある未来 / B-3 善い社会の経路 / B-4 変化検出装置 / B-5 動きの状況測定）は、本Track の出力した41の問いと多層マトリクスを共通の入力として参照する。

Phase A から Phase B への移行

Phase A 9トラックの最終統合（ryoiki-master-report.html、約30,000字）は、全トラック横断のメタテーマ15個（M01-M15）・ホライズン×メタテーマ統合MAP（15×4=60セル）・9×9連結マトリクス・Mサイン階層分類（真M 1件・準M 3件・概念整合 1件）・ミラツク独自知見7件を提示した。これらは「問うべき領域」の素材を提供する一方、「どう問うか」の構造化は次フェーズに委ねていた。Phase B は、この空白を埋める。

本Track が担う基盤層の作業は、三つの操作に分解される。第一に、Phase A の素材を「人類史」と「将来予測」の二系列に明確に分け直す。Phase A はトラック単位（FK／CLA／SI／Signal等のDB単位）で構造化されており、人類史と将来予測は各トラックの内部で混在していた。本Track はこれを軸変更で再整理する。第二に、再整理した二系列をそれぞれ「多層」に分解する。人類史は4層（文明圏／時代／パラダイム／神話）、将来予測は4層（VeSTEG／CTL-1／Mサイン階層／ホライズン）である。第三に、多層構造から「問い群」を抽出する。射程別（2030/2050/2070/2100）・確度別（真M/準M/概念整合/単独）・領域別（V/S/T/Eco/Env/G）の三軸で問いを並べる。

多層構造の妥当性

「なぜ多層構造化が必要か」の問いに対しては、Phase A の構造的限界から答えられる。Phase A 第8部は、9トラックの主要DBが共通して抱える「近代偏重バイアス（1700年以降の記録集中）」「FK 84.4% 共通スパン未指定」「同一プロジェクト派生間の独立性問題（pestle-signal-db / great_figures.db / ai_acceleration_evidence.db の共有）」を限界として記録した。これらは「単一の時間軸・単一の領域分類で問いを並べる」と問いの解像度が下がる構造的要因である。多層化は、これらの限界を「複数軸への分散による補償」で吸収する設計である。解釈

PART 01

多層人類史 — 4層の解析

本章では、Phase A 9トラックが扱う人類史的素材を、4層（文明圏／時代／パラダイム／神話）に分解して解析する。Phase A の主要素材は、Track 4（SIF 7,389事象・GF 9,178人物・TA 226,996レコード・HIC 20ケース）、Track 6（GF・JPMS v2 832校・PST 600偉人・ET 12,958人物）、Track 7（Academic 17,547概念・5領域）、Track 9（PHIL 10,292概念・LIT 11,115概念・MY 11,936物語・TK 3,002グループ）の人類史的記録である。本Trackはこれらを軸変更で再整理する（集計L-01〜L-08）。

1.1 Layer A: 文明圏層 — 6文明圏の不均等な記録

人類史の第一層は文明圏である。Phase A の主要DBで採用される文明圏分類は、Track 9 PHIL DB（8文明圏：西洋・東アジア・南アジア・イスラーム・ラテンアメリカ・アフリカ・先住民・横断）と Track 4 SIF DB（10civ：west_industrial・east_asian・global_south・etc）が代表的である。本Track ではこれらを6文明圏（西洋／東アジア／南アジア／イスラーム／グローバルサウス／先住民）に正規化して扱う（集計L-02）。

文明圏別の記録密度は構造的に大きく不均等である。Track 9 handoff §2 の集計L-08（PHIL文明圏別概念総数）によれば、PHIL DB 10,292概念のうち西洋 5,008（48.7%）・東アジア 1,938（18.8%）・横断 750（7.3%）の三系統が大半を占め、先住民・アフリカ・ラテンアメリカは合計でも数百件規模に留まる。Track 7 handoff §11 が指摘した「西洋49.1% / 非西洋50.9%」（cross_domain_relations 18,733件ベース）と粒度差で微差があるが、両者とも「西洋とその他がほぼ拮抗、ただし非西洋内訳は東アジアが突出」という構造を示す。

この記録不均等は、Phase A 第8部「9DBの近代偏重バイアス」と並んで、本Track が前提として継承する構造的特徴である。本Track の人類史 4層解析では、各文明圏セルに「記録密度」を h-1〜h-5 で表記し、密度が薄い領域は「構造的空白」として明示する。解釈

1.2 Layer B: 時代層 — 5時代の事象密度

第二層は時代である。Phase A の歴史DBは多くが 8区分（Track 4 TA: paleolithic / neolithic / ancient / medieval / early_modern / industrial / modern / digital）または era_category 6区分（Track 7 PHIL: 古代・中世・近世・近代・20世紀・21世紀）を採用するが、本Track は4ホライズン将来予測との対称性のために5時代（前近代〜1500／近世1500-1800／近代1800-1900／20世紀1900-2000／21世紀2000-2025）に正規化する（集計L-03）。

時代別の事象密度には極端な集中が観察される。Track 4 handoff §12 の集計L-09（SIF 100年刻み事象分布）によれば、SIF 7,389事象のうち1700-1900で4,223件（57.2%）、1500-1900で4,868件（65.9%）、古代BC500-AD500合計は約250件（3.4%）に留まる。Track 4 handoff §12 集計L-30（GF events 100年刻み）でも、1500-2000合計5,596件（55.8%）対1500以前数百件という同様の構造が観察される。Track 4 handoff §12 集計L-43（TA technologies era別）も、digital+industrial+modern合計793件（66.6%）対 prehistoric+paleolithic+neolithic合計93件（7.8%）の不均衡を示す。

これは Phase A 第8部「9DBの近代偏重バイアス」の構造的事実そのものである。本Track の Layer B 解析では、近代以前の事象密度の薄さを「補完情報源（神話・伝統知・哲学的論述）」で補強する設計を採る。具体的には、Track 9 のMY 11,936物語・TK 36,360項目・PHIL の古代-中世概念（PHIL 古代2,107件・中世1,380件、Track 9 handoff §13 集計L-13）が、SIF/GF/TA の近代偏重を補う独立母集団として機能する。解釈

1.3 Layer C: パラダイム層 — 7パラダイムの生成と現在の揺らぎ

第三層はパラダイムである。本Track が抽出した7パラダイムは、Track 9 handoff §11 の「Track 7 + Track 9 = CTL-V 双子Track」フレームに従い、PHIL/LIT/MY/TK の規範的論述と Track 4 SIF の社会イノベーション類型から導出される。具体的には、進歩（progress）・啓蒙（enlightenment）・市場（market）・国民国家（nation-state）・科学中立性（scientific neutrality）・人間中心主義（anthropocentrism）・西洋普遍主義（western universalism）の7パラダイムである。

このうち、本Track の現在診断（第3部）では3パラダイムが同時に揺らいでいる構造が浮上する。Track 2 CLA handoff §9 の「物語の交代期」5系統失効診断のうち、進歩・科学中立性・西洋普遍主義の3パラダイムは、Track 5 SG handoff §9 の「物語転換期の三重定量証拠」（disruption 7.49・paradigm 20.4%・myth 11.1%）と独立に整合する。Phase A 第6部 §6.2 が「真Mサイン認定領域=物語転換期」として認定したのと同じ構造現象である。

残る4パラダイム（啓蒙・市場・国民国家・人間中心主義）は揺らぎが部分的に観察されるが、Phase A 第6部の Mサイン認定基準（独立3母集団以上）には届かない。市場パラダイムは Track 5 「労働再編」「主権回復・場所性回帰」シグナルで部分的揺らぎが観察され、国民国家パラダイムは Track 5「気候災害誘発の大規模強制移民と国境空白」で揺らぎ徴候があるが、Phase A 段階では準Mサイン以下に留まる。推定

1.5 4層を統合した人類史の構造的特徴

4層を統合すると、人類史は次の構造的特徴を示す。第一に、文明圏層（Layer A）と時代層（Layer B）は、いずれも「西洋・近代の記録集中」というバイアスを共有する。これは独立な構造ではなく、近代西洋がDBの記録様式そのものを規定したという認識論的事実の反映である。第二に、パラダイム層（Layer C）は、文明圏層と時代層が記録した「事象」の上位構造として、認識論的枠組みを提供する。本Track は7パラダイムを抽出したが、このうち3パラダイム（進歩・科学中立性・西洋普遍主義）は現在の真Mサイン認定領域「物語転換期」と直結する。第三に、神話層（Layer D）は、パラダイム層よりさらに深層の認識構造として機能する。Track 2 の四層深化（litany→system→worldview→myth）の最深部であり、転換速度が最も遅い。

4層の関係を図式化すれば次のようになる。事象（Layer A・B）→ パラダイム（Layer C）→ 神話（Layer D）の三層上昇は、Track 7 CLA四層深化と整合する。本Track は、これに文明圏分散（Layer A）の独立軸を加えることで、Track 7 単独より一層細かい分解能で人類史を扱う設計を採る。

PART 02

4ホライズン予測の多層構造

本章では、Phase A 9トラックが扱う将来予測的素材を、4層（VeSTEG／CTL-1／Mサイン階層／ホライズン）に分解して解析する。Phase A 第3部の「ホライズン×メタテーマ統合MAP（15×4=60セル）」と第6部「Mサイン階層分類」が主要素材である。本Track はこれらを四つの軸に分解し、それぞれの軸での予測の重みづけを再可視化する（集計L-09〜L-15）。

2.1 Layer 1: VeSTEG層 — 6軸での予測偏在

第一層は VeSTEG の6軸（Values / Society / Technology / Ecology / Environment / Governance）である。Phase A 第3部 §3.4 のMAP分析が示したとおり、Phase A の15メタテーマを VeSTEG 6軸に再分類すると、CTL-V（価値観・倫理・文化）に主担当が集中する（M01, M02, M03, M04, M05, M08, M11, M13, M14 の9メタテーマ）構造が浮上する。これは Track 1 FK が指摘した「世界フォーサイトの values 0.45%空白」とは対照的に、ミラツクの31+DB横断では values 中心の問いが浮上する構造的差異の確認である。

本Track はこの構造を、CTL-1 メガドメイン別の「メタテーマ件数 × ホライズン分布」マトリクスとして再可視化する（集計L-09）。CTL-V は near 9件・mid 8件・far 5件・very-far 4件の合計26セル、CTL-T は near 4件・mid 3件・far 2件・very-far 1件の合計10セル、CTL-G は near 5件・mid 3件・far 2件・very-far 1件の合計11セルとなる。CTL-V の very-far 4件は、Phase A 第3部 §3.4 が指摘した「values領域の問いが技術領域より時間スケールで頑健」という観察の B-1 側での再確認である。

2.2 Layer 2: CTL-1層 — 6カテゴリの問い分布

第二層は CTL-1 メガドメインそのものである。Layer 1 が VeSTEG の6軸（メタテーマ件数による集計）であるのに対し、Layer 2 は本Track が抽出する41問の問い群を CTL-1 別に再分類した結果である（集計L-10）。問い群総数41問のうち、CTL-V 13問（31.7%）、CTL-T 8問（19.5%）、CTL-G 8問（19.5%）、CTL-Env 5問（12.2%）、CTL-S 4問（9.8%）、CTL-Eco 3問（7.3%）の分布となる。

この分布は、Layer 1 のメタテーマ件数分布（CTL-V 9件中9件・60%）と比較して、CTL-V の比重がやや低下し、CTL-T と CTL-G の比重が上昇する。理由は二つある。第一に、Layer 1 はメタテーマの主担当を一意に割当てるのに対し、Layer 2 は問い単位で扱うため、CTL-Vメタテーマから CTL-T や CTL-G の問いが派生する場合がある（例: M01「第四変容期」から CTL-T「AI×倫理」と CTL-V「主体の解体」の両問いが立つ）。第二に、本Track は Track 5「AIガバナンス空白」や Track 8「AIガバナンスと地政学」のように、CTL-T と CTL-G が交差する問いを独立に立てている。解釈

2.3 Layer 3: Mサイン階層層 — 真M / 準M / 概念整合 / 単独T

第三層は Mサイン階層である。Phase A 第6部 §6.2 が確立した「真Mサイン（独立3母集団以上）／準Mサイン（独立2-3母集団・共有DB問題一部残存）／概念整合（合意広いが定量根拠は概念的）」の三階層に、本Track は「単独Track由来（1トラックのみが独自に提示した問い）」を加えて4階層化する（集計L-11）。

4階層別の問い分布は次のとおり：真M由来 6問（14.6%）／準M由来 14問（34.1%）／概念整合由来 13問（31.7%）／単独T由来 8問（19.5%）。最大は準M由来であり、これは Phase A 第6部 §6.2 の準M認定3領域（世代間正義・非西洋認識論・AI革命の制度反作用）が、それぞれ複数のホライズンと CTL-1 にまたがる派生問いを生むためである。例えば、世代間正義は CTL-V（near「世代間倫理の制度化前駆」）／CTL-G（mid「世代間正義の制度設計」）／CTL-V（far「2070世代間正義の本格制度化」）／CTL-V（very-far「2100神話的長期記憶」）の4問を派生する。解釈
