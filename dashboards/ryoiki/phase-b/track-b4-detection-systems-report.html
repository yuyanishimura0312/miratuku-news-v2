Track B-4 レポート — 7 変化検出装置 × 24 問のカバレッジ

Phase B Track B-1 が策定した 41 問のうち、24 問について、シグナル DB・大学PR・企業R&D PR・政策・企業IR・資金調達・産学連携の 7 変化検出装置の予測的応答力を評価する。168 セルのカバレッジマトリクスを構築し、装置間の補完関係と領域別 Initiatives ピックアップを提示する。

生成日: 2026-05-09 担当: Track B-4 リード 方法論: _PROTOCOLS.md v1.0 / 7 装置 × 24 問軽量カバレッジ評価 図表: 6-10 点
PROLOGUE

本レポートの位置

本レポートは、Phase B 第 4 トラック（実装層）の最終成果である。Track B-1 が「未来に向けて問うべき 41 問」を設計し、その中で「変化検出装置で観測可能」と判定された 24 問を本Track が引き継いで評価する。本Track の核心問いは三つである。第一に、ミラツクが既存に保有する 7 変化検出装置は、これら 24 問にどの程度応答しているか。第二に、装置別・問い別の応答力に系統的なパターンがあるか。第三に、装置間に補完関係があり、ある問いに対して複数装置の合意が成立する領域はどこか。

本Track の構造

本Track は三つのHTMLファイルと一つの新規 SQLite データベースで構成される。本レポート編 track-b4-detection-systems-report.html は、24 問 × 7 装置 = 168 セルのカバレッジマトリクスと装置別レポート、領域別 Initiatives ピックアップを提示する成果物である。解析編 track-b4-detection-systems-analysis.html は、装置選定・キーワード設計・スコアリング規則・集計ログを記録する作業ノートである。検証編 track-b4-detection-systems-verification.html は、4カテゴリの自己検証結果と sentinel 引継ぎ事項を収載する。新規DB ~/projects/research/initiatives-db/initiatives.db は、24 問・7 装置・168 カバレッジスコア・代表 Initiatives レコードを蓄積する。

本レポートの構成

本レポートは八部で構成される。第 1 部「168 セルの全体像」は、24 問 × 7 装置のマトリクス全体の集計サマリーを示す。第 2 部「カバレッジ・マトリクス」は本レポートの中核成果物で、24 問 × 7 装置のヒートマップを提示する。第 3 部「装置別の予測的応答力」は、各装置の平均スコア・分散・ホライズン別応答パターンを示す。第 4 部「装置別レポート」は、7 装置それぞれの詳細レポートと代表 Initiatives を示す。第 5 部「装置間の補完関係」は、ある問いに対する複数装置の合意パターンを 5 類型として提示する。第 6 部「領域別 Initiatives ピックアップ」は、24 問それぞれに対する代表 3-5 件の取り組みを提示する。第 7 部「主要発見と連結ID」は、Track B-5 / B-6 への引継ぎ事項を整理する。第 8 部「研究の限界」は本Track の留保を率直に開示する。

PART 04

装置別レポート

本章では、7 装置それぞれについて、本Track での評価結果と代表 Initiatives を要約する。

4.1 SG（Signal DB）— 7,668 シグナル

Signal DB は本Track で最も高い応答力を示す装置である。24 問のうち {SG_N3} 問で score 3 以上、平均スコア {SG_AVG}。特に強く応答する問いは Q-N01（AIガバナンス、score {Q-N01_SG}）・Q-N02（AI制度反作用、score {Q-N02_SG}）・Q-N03（テクノ加速×場所性、score {Q-N03_SG}）・Q-N04（場所性回帰、score {Q-N04_SG}）・Q-N05（民主主義、score {Q-N05_SG}）の 5 問で、Phase A Track 5 が独自に認定した「弱いシグナルとしての物語転換期」が直接寄与する構造を示す。一方 Q-V02（双子峰プラトー終端後、score {Q-V02_SG}）・Q-V06（10億規模強制移民、score {Q-V06_SG}）は score 中位で、very-far 領域への応答は限定的。

SG の構造的強みは「composite_score（5 次元評価）と PESTLE カテゴリ・CLA depth の構造化」にあり、score 5 のシグナルは「強力な早期警戒装置」として機能する。本Track ではその強さを定量的に確認した。

4.2 UPR（大学プレスリリース）— 41,760 件

大学プレスリリースは、研究系 near 問い（Q-N07 科学AI / Q-N09 主体・人格 / Q-N10 非西洋認識論 / Q-N12 values）に対して中程度（score {UPR_NEAR_AVG}）の応答を示す。一方、規範系問い・very-far 問いに対しては score 0-1 に留まる。これは大学PR が「既達成の研究成果の発信」を扱うため、未来的概念問いの観測には設計上不向きであることを反映する。

UPR の代表 Initiatives は、教育・研究成果系の問いに集中する。Q-N13（教育126年ラグ）に対しては {UPR_Q-N13_TOP} 等の大学が score {UPR_Q-N13} で応答する。Q-N09（主体・人格）に対しては人文学系プレスリリースが該当するが、件数は限定的である。

4.3 SGRD（企業 R&D PR）— 36,734 件

企業 R&D プレスリリースは、技術系 near 問い（Q-N07 科学AI / Q-N08 自律AI / Q-M10 創薬AI）に対して中-高程度（score {SGRD_TECH_AVG}）の応答を示す。GTA 48 コードと 23,762 テーマの構造化により、装置の問い空間との相性は良好。一方、規範系・far/very-far 系問いに対しては score 0-1 に留まる。SGRD の集計 JSON は theme_top 100 件・gta 48 件のサンプルベースであるため、本Track の評価は装置の真の応答力より過小評価の可能性がある。推定

4.4 Policy（政策 DB）— 30,118 事業

政策 DB は near の制度系問い（Q-N02 AI規制 / Q-N05 民主主義 / Q-N06 気候災害 / Q-N13 教育改革）と mid の制度系問い（Q-M02 AI制度反作用 / Q-M04 少子化 / Q-M12 教育-人材ラグ）に対して強く（score 3-5）応答する。これは政策事業が「公金が投入される制度反映」として最も具体的な観測装置であるためである。

政策事業の予算規模（finalized_amount）を考慮すると、score 5 の問い（{POL_TOP_Q}）に対する予算規模は累計 {POL_TOP_AMOUNT} 億円規模に達し、制度的関心の強さを定量的に示す。一方、概念系問い（Q-N09 主体 / Q-N11 過剰的中バイアス / Q-V07 pluriverse）に対しては score 0-1 で、政策事業として制度化されていない構造的事実を示す。

4.5 IR（IR Collector）— 1.86M セクション

IR Collector は、企業の有価証券報告書のリスク・経営方針・R&D 記述を観測する装置である。本Track の検索プロトコルは性能上の理由で先頭 1-2 キーワードに限定したため、IR の真の応答力は本Track の評価より高い可能性がある。推定

確認できた応答パターンは、AI 系問い（Q-N01 / Q-N02 / Q-N07 / Q-N08）と気候系問い（Q-N06 / Q-M08 / Q-F01）が score 4-5 で強く応答すること、規範系・神話系問い（Q-N09 / Q-V07）は score 0-1 で応答が薄いことである。IR は「企業の経営判断としてのリスク認識・戦略意思」を反映する装置であるため、規範的問いには本来不向きである。

4.6 Funding（投資シグナル）— 16,642 PR

投資シグナル DB は near の技術系問い（Q-N01 / Q-N07 / Q-N08）と mid の技術系問い（Q-M02）に対して中-高程度（score 3-4）の応答を示す。VC 投資は「未来への賭け」として技術成熟度の早期段階に投資するため、AI・バイオ・気候技術の問いには強い応答を示す。一方、規範系・制度系問いに対しては score 0-2 に留まる。

投資シグナル DB は organizations 4,180 / funding_rounds 1,927 / signals 160 を保持し、スタートアップエコシステムの構造化観測装置として機能する。本Track ではキーワードベースの press_releases 検索が中心であったため、organizations / funding_rounds の構造化情報の活用は限定的である。Track B-5 で追加活用が望ましい。

4.7 Sangaku-matcher（産学連携マッチング）— 492K レコード

産学連携マッチング DB は、3,872 社・33 ambition_taxonomy_themes・40 tech_taxonomy_themes の構造化分類を持つ装置である。本Track の評価では、ambition theme と tech theme の name + keywords へのキーワードマッチで応答件数を算出した。ambition × 100 + tech × 80 の擬似スケーリング後、AI / 環境 / 教育系問いに対して score 3-4、規範系問いに対して score 0-2 となる。

Sangaku-matcher の真の強みは「企業 × 大学 × theme の三項マッチング」にあり、ある問いに対して「動いている企業」「対応可能な大学」「該当 ambition theme」を一括で提示できる。本Track ではこの機能を Initiatives 抽出に活用したが、マッチング機能の本来の力は Track B-5 / B-6 で活用する余地がある。

PART 05

装置間の補完関係 — 5 類型

本章では、24 問それぞれに対する 7 装置の応答パターンを類型化し、装置間の補完関係を 5 つに分類する。

5.1 補完類型の定義

本Track では、装置間の補完関係を「ある問いに対して score≥3 で応答する装置の集合」として定義し、5 類型に分類する。第 1 類型「全装置応答型」は 5 装置以上が score≥3 で応答する問い、第 2 類型「制度+市場応答型」は Policy + IR + Funding の 3 装置で応答する問い、第 3 類型「研究応答型」は SG + UPR + SGRD の 3 装置で応答する問い、第 4 類型「SG 単独応答型」は SG のみが score≥3 で応答する問い、第 5 類型「全装置不応答型」は すべての装置が score≤2 に留まる問い、である。

5.2 類型別の問い分布

図5. 補完類型別の問い分布
類型定義該当問い数該当問い ID
1. 全装置応答型5 装置以上 score≥3{T1_N}{T1_QS}

5.3 補完関係 TOP 3

本Track が確認した装置間の補完関係 TOP 3 は次のとおりである。第 1 位は「SG ↔ Policy ↔ IR の三角形」で、AI ガバナンス・気候・教育の制度系問いに対して 3 装置が独立に強応答する。これは Phase A Track 3（修正版18MT）と Track 5（Signal）と Track 6（人材軌道）の三独立確証構造の本Track での再現である。第 2 位は「SG ↔ UPR ↔ SGRD の研究三角形」で、科学AI・自律AI・創薬AI の技術系問いに対して 3 装置が独立に応答する。これは Phase A Track 7（Academic）と Track 8（TA/AA）の研究側構造の本Track での反映である。第 3 位は「Funding ↔ Sangaku の市場二項」で、技術系問いに対して VC 投資と産学連携の二装置が応答する。

PART 06

領域別 Initiatives ピックアップ

PART 08

研究の限界

本章では、本Track の方法論的・データ的・解釈的限界を率直に開示する。

8.1 軽量カバレッジ評価の限界

本Track は「軽量カバレッジ評価」方針のため、各装置DBの全件走査ではなく代表キーワード 3-6 個の LIKE 検索でスコアを判定した。この方法論には四つの構造的限界がある。第一に、形態素解析を経ない単純 LIKE 検索のため、表記揺れ・活用形を漏らす（例: 「気候難民」は拾うが「気候によって追い立てられた人々」は拾わない）。第二に、UPR / SGRD は集計 JSON のみの参照で全レコード走査ができず、装置の真の規模（41,760 / 36,734 件）を反映しない。第三に、IR の検索は性能上の理由で先頭 1-2 キーワードのみで実施し、3-6 番目のキーワードでヒットする企業が漏れる。第四に、スコア境界は装置の収録規模を反映するが、「真の質的差」を直接反映するわけではない。本Track の数値は「予測的応答力の量的指標」であり、質的詳細評価は装置別の handoff（Track 5 Signal handoff §9 / Track 8 TA/AA handoff §6 等）に委ねる。

8.2 装置間の独立性に関する留保

本Track では 7 装置を「独立な観測装置」として扱うが、実際には部分的相関がある。Signal DB のソースに UPR・SGRD・IR の一部が含まれる可能性、Sangaku-matcher のソースに SGRD・UPR の一部が含まれる可能性がある。本Trackでは「装置間の独立性」を完全独立と読まず、「半独立」と解釈する。これは Phase A Track 8 が指摘した「文脈別の独立性表現処理」の継承であり、本Track の 5 補完類型分析でも「独立 N 装置の合意」ではなく「半独立 N 装置の合意」と読む。

8.3 stage 判定の構造的近似

initiatives テーブルの stage カラムは構造的近似で判定される（initiative_type + evidence_count の二軸ヒューリスティクス）。個別の正確な stage 判定は装置別の追加メタデータが必要となる。本Track の Initiatives ピックアップで提示する stage は「概略の段階」と読み、個別の詳細評価は Track B-5 / B-6 で必要に応じて精緻化すべきである。推定

8.4 24 問の網羅性に関する留保

本Track が評価する 24 問は、Track B-1 § 6.2 で B-4 対象として指定された問い群である。この 24 問の選定は B-1 が「変化検出装置で観測可能か」の事前判断で行ったが、実際の評価で「観測不可能」と判明する問いがある。本Track ではこれを「全装置不応答型」（第 5 補完類型）として明示し、Track B-2 への逆算的補完提案として位置づけた。Track B-1 が指定外とした 17 問の中にも観測可能な問いがある可能性は今回未検証である。

8.5 装置データの収集時点

本Track の集計は 2026-05-09 時点のスナップショットである。Signal DB の signals テーブル（7,668 件）、Policy DB の projects テーブル（30,118 件）、IR Collector の sections テーブル（1,862,236 件）、投資シグナル DB の press_releases テーブル（16,642 件）はそれぞれ最新更新日が異なり、本Trackでは「装置データの取得時点」を統一しない。これは装置別の更新頻度（SG は週次、Policy は四半期、IR は半期等）の差を反映する構造的事実である。Track B-5 / B-6 への引継ぎ時に本留保を明示する。
