序 — 本解析の方法

本トラックは Track B-1 が策定した41問のうち、PHIL/LIT/MY/TK/AN の5 traditions（以下「5系統」）が「すでに考え、回答してきた知」が存在する14問について、各系統の wisdom を抽出し、新規DB already_future.db として構造化することを目的とする。Phase A 9トラックが「いま立ち現れる兆候」と「2030/50/70/2100予測」の両端から問いを立てたのに対し、Track B-2 は これら14問のいずれにも、人類が数千年規模で回答を積み重ねてきた という歴史的事実を可視化し、Phase B 後続トラック（B-3 善い社会／B-4 変化検出装置）の規範的・記述的基盤を提供する。

0.1 「すでにある未来」という構え

「すでにある未来」とは未来予測の対義語ではない。本トラックは「未来は予測される」のではなく、「未来として立ち現れている問いの多くは、人類が すでに繰り返し問い、回答を蓄積してきたもの である」という認識に立つ。たとえば Q-N09「主体・人格の解体と再構築」は、第四変容期に固有のAI由来現象として2020年代に再発見されたが、仏教の無我論（紀元前2世紀ナーガールジュナ）、Hume の bundle theory（1739）、メラネシアの dividual 論（Strathern 1988）が独立に到達した認識と構造的に同型である。解釈

「すでにある」と「未来」を一語で結ぶ意図は、近代フォーサイトが暗黙に想定する「未来は新規である」という仮定の留保にある。Track B-1 §6.1 が指摘した14問の多くは、Phase A 9トラックの量的基盤の上に立てられた問いだが、その問い そのもの は2,500年規模の蓄積を持つ。本トラックはこの蓄積を 歴史的回答パターン として記述する。

0.3 抽出方法の三段

各 wisdom record は以下の三段の手続きで抽出した。第一段は 探索照会。Track B-1 §6.1 の14問それぞれについて、5系統の Skill エージェント（/anthropology, /philosophy, /lit, /myth-narratives, /traditional-knowledge）が概念的に該当しうる領域を初期照会する。第二段は 核心抽出。各系統で5-10件の候補から、問いに対する歴史的回答として最も核心的な概念・著作・人物を5-10件に絞り込む。第三段は 構造化。各 wisdom を概念名・時代・文明圏・wisdom_text（100-300字の核心引用または要約）・ source_ref・derivation_method（direct_quote / paraphrase / inference）・confidence（1-5）の8軸で構造化し、SQLite DB に格納する。

結果として、70セル（14問×5系統）中70セルを充足し（カバレッジ100%）、85件のwisdom recordsを格納した。derivation_method は paraphrase 59件・direct_quote 25件・inference 1件で、direct_quote ＋ paraphrase の合計 84件（98.8%）が確認可能なソースに基づく。inference 1件（Q-V05/AN）は明示的な源を欠くが構造的推論として残した。推定

0.4 問いに対する三類型の回答

抽出された85件の wisdom を読み解く中で、「すでにある未来」の歴史的回答が以下の三類型に分かれることが見えてきた。これは本トラック独自の解析的発見である。解釈

  • Type-A 既出回答型: 問いに対して人類が既に明示的・体系的に回答を蓄積している類型。Q-F02（世代間正義）、Q-V05（〈ゆっくりの権利〉）、Q-F06（伝統知主権）が典型。
  • Type-B 並走認識型: 問いの認識自体が複数の系統で並行して立てられ、回答は未完だが認識様式の蓄積がある類型。Q-N09（主体解体）、Q-M07（多元的人格）、Q-F04（人間-非人間境界）が典型。
  • Type-C 新規問い型: 5系統の蓄積が薄く、Phase A 兆候から立てられた純新規問い。本Track 14問では Q-V01（サイクルA前期段階の組織形態）が唯一該当。

Type-A 9問・Type-B 4問・Type-C 1問の分布は、本Track 14問の 大半が「既に問われていた問い」である ことを示す。これは Phase B 後続トラックへの最重要送り事項である。

1.1 14問の選定根拠（B-1 §6.1 の継承）

本Track が対象とする14問は、Track B-1 §6.1 が「5 traditions のいずれかが該当領域を持つ」と推定したリストである。B-1 ホライズン別の内訳は near 3問・mid 4問・far 3問・very-far 4問で、Mサイン由来別では 真M由来1問（Q-N04）、準M由来2問（Q-F02・Q-M03）、概念整合由来8問（Q-V05 含む）、単独T由来3問（Q-N12・Q-F06・Q-V01） の分布となる（Track B-1 layered-history-report.html を最終 source-of-truth として参照、Phase B Wave 3 sentinel 検証で個別ラベル同期済）。CTL-1 別では V（価値観）11問・S 1問・Env 1問・G 1問で、CTL-V に圧倒的に偏る。これは5系統が 規範的・存在論的問いに対して厚みを持つ という事実の構造的反映である。

1.3 問い接合における三系列差処理

protocols §1.4 が要求する三系列差処理（DB照会値・ブリーフィング値・分析値の並列開示）について、本Track では以下の通り処理した。第一系列は5系統 Skill による初期照会値で、各問いに対する候補数は AN 平均7件、PHIL 平均12件、LIT 平均9件、MY 平均11件、TK 平均8件であった。第二系列は B-1 §6.1 のブリーフィング値で、各問いの想定 traditions が事前に列挙されている（例：Q-N09 は「PHIL/LIT/MY/TK/AN」と全5系統指名）。第三系列は本Track の最終抽出値で、85件の wisdom records である。

三系列の差は、第一系列（初期照会）から第三系列（最終抽出）への絞り込み率として表現できる。AN 7→17（複数問い跨ぎで重複）、PHIL 12×14=168 候補→24件（14.3%）、LIT 9×14=126→14件（11.1%）、MY 11×14=154→15件（9.7%）、TK 8×14=112→15件（13.4%）。絞り込み率10%前後で各系統の核心が抽出される という結果は、本Track の方法論的妥当性を示唆する。推定

PART 2

第2部 — 14問×5traditions の抽出結果

本部では14問を near/mid/far/very-far のホライズン別に分け、各問いに対して5系統が抽出した wisdom の核心を解説する。詳細レコードは report.html 第3部および付録 DB集計ログ参照。

2.1 near 3問（2030）

Q-N04 場所性回帰の制度化

本問いに対する5系統の回答は、近代国家以前の場所制度を世界規模で蓄積している。AN は Keith Basso のアパッチ研究（場所は道徳的記憶の蓄積装置）、Elinor Ostrom の Governing the Commons（コモンズ8原則）を提供し、Q-N04 の制度設計に直接適用可能な体系が既に20-30年前に確立済みであることを示す。PHIL は西田幾多郎『場所』（1927）と Edward Casey の場所現象学（1997）が独立に「場所は主体性の根本条件」と論じてきたことを示し、Q-N04 の哲学的根拠が東西で1世紀蓄積されてきた事実を可視化する。LIT は宮沢賢治のイーハトーブ、柳田國男『遠野物語』（1910）が文学的に場所性を保存する伝統を示し、MY は世界の創世神話のほぼ全てが固有の場所（聖山・聖樹・川源）に基底を持つことを示す。TK は siida（サーミ）・hima（アラビア）・iriaichi（日本入会地）等の共同体管理地が世界各地で記録されており、UNESCO ICH に類例が体系化済みであることを示す。解釈

この7件の wisdom records は、Q-N04 が「新規に立てる問い」ではなく「既に世界的に多重に実装されてきた制度の再評価」であることを示す。Phase B Track B-3 が経路設計する際、これら7件の歴史的雛形が直接の参照体系となる。

Q-N09 多元的人格の解体と再構築

本問いに対する回答も5系統が並走する典型例である。AN は Strathern の dividual（メラネシア）と Marriott の dividual（南アジア）が独立に「人格を関係の交点として捉える」モデルを提示してきたことを示し、PHIL は仏教の無我論（紀元前2世紀ナーガールジュナ）、Hume bundle theory（1739）、Parfit『Reasons and Persons』（1984）が西洋哲学内部で人格同一性を解体する系譜を持つことを示す。LIT は Joyce『ユリシーズ』（1922）以降の意識の流れ・多視点小説が文学的に1世紀先行して「個」を解体してきたことを示す。MY は世界各地のトリックスター神（シヴァ・コヨーテ・素戔嗚）が人格の多元性を神話レベルで保存してきたことを示し、TK はアイヌのラマッ（霊魂多元論）、神道の御霊（一霊四魂）が「人格を複数霊性の合成として捉える」伝統知を保存することを示す。

これら7件は、第四変容期における「主体・人格の解体と再構築」が 近代固有の事象ではなく、近代以外の人格観への回帰 として位置づけ可能であることを示す。これは本Track の最重要発見の一つである。解釈

Q-N12 values 空白補完

FK 0.45% values 空白に対する5系統の補完力は構造的に明らかである。PHIL の applied ethics（Rawls, Jonas, Nussbaum）と古代の virtue ethics（Aristotle, 孔子, 孟子）は規範哲学として values の制度設計を主導してきた。LIT のビルドゥングスロマン（教養小説）は2世紀にわたって values 形成を物語化する装置として機能してきた。MY の倫理神話（イソップ・ジャータカ・グリム）は最古の values 教育制度を保存する。TK の口承倫理（アフリカことわざ・hadith・家訓）は世代間の values 継承の非文字制度として世界各地で実装されてきた。AN の moral economy 概念（Thompson, Scott）は経済制度に内蔵された values の可視化を提供する。

合計6件の wisdom は、FK 0.45%空白が 本来的な空白ではなく、5系統の蓄積を参照すれば既に補完済み であることを示す。Track B-1 §6.1 が指摘した「values空白双子補完」の構造的証拠。解釈

2.2 mid 4問（2050）

Q-M01 ケア・創造・共生の経済原理

本問いの抽出結果は最も豊穣で、6件の wisdom が並走する。AN は Mauss『贈与論』（1925）、Sahlins『石器時代の経済学』（1972）、Graeber『負債論』（2011）が 100年蓄積された贈与経済の人類学を提供し、PHIL は Gilligan・Noddings・Tronto のケア倫理学と儒教の仁・孟子の惻隠の心が東西で2,500年蓄積されてきたことを示す。さらに PHIL は Ramose・Tutu の ubuntu 哲学が現代南アフリカ憲法と真実和解委員会の理念基盤になった実例を示す。LIT は Le Guin『所有せざる人々』（1974）、Robinson『2312』（2012）、Okorafor『Binti』が ケア中心未来社会を物語化してきたことを示し、MY は世界の協働創造神話が「ケア・創造・共生」三位一体の神話的原型であることを示す。TK は ayni（アンデス）、minga（アンデス）、結（日本）、gotong-royong（東南アジア）が世界規模の互酬経済制度として記録されていることを示す。

合計6件は、Q-M01 が 新たな経済原理の発明ではなく、人類史的標準型への回帰 として位置づけ可能であることを示す。Phase B Track B-3 の最重点問いの規範的根拠が本Track によって体系的に提供された。

Q-M03 非西洋認識論主流化

本問いの回答は AN が圧倒的な厚みで提供する。Viveiros de Castro の perspectivism、Descola の4存在論、Marisol de la Cadena の Earth Beings は、人類学が「西洋認識論は数ある cosmology の一つ」と論証してきた30年の蓄積を示す。PHIL の比較哲学（京都学派、Panikkar、Van Norden）は学術的に8文明圏並立を実装する基盤を提供し、古代の陰陽五行・縁起・ヨーガ認識論は2,500年蓄積された非西洋認識体系の存在を示す。LIT の postcolonial canon（Achebe・Soyinka・Marquez・Rushdie・Bâ・Dangarembga）は文学的に西洋認識論前提を解体する系譜を提供する。MY DB MS08「多重存在論」と TK 全体は、非西洋認識論そのものの集積体である。

Q-M07 多元的人格の社会

本問いは Q-N09 の延長線で、5系統の回答が並走する。AN の kinship as relational personhood（Carsten, Strathern）、PHIL の和辻哲郎「間柄」哲学・Buber『我と汝』・Whitehead 過程哲学、LIT のポリフォニー小説（Bakhtin・Dostoevsky・紫式部）、MY の祖霊継承神話、TK の ayllu 親族集団社会が、それぞれ「個＋関係＋場所＋時間の織り込み」を異なる切り口で実装している。Phase B Track B-3 の分岐点濃度高問いの規範的根拠が、本Track によって6件の wisdom で支えられた。

Q-M11 身体性復権

身体性は近代以外のほぼすべての文明圏が保存してきた認識様式である。PHIL は Merleau-Ponty 身体現象学と Mauss 身体技法・道教養生・ヨーガ・禅修養が東西で2,500-3,000年蓄積されてきたことを示し、AN の embodiment 理論（Csordas, Scheper-Hughes & Lock）はこれを人類学的に再概念化する。LIT は Kafka『変身』、谷崎『陰翳礼讃』、Morrison『Beloved』、Cixous の身体性文学を集積する。MY のシャーマニズム憑依神話は身体を霊性媒体として運用する世界的伝統を示し、TK のアーユルヴェーダ・中医学・ユナニ医学・ swrtea lodge は身体を診断・治療・知識生産の中心に据えた体系を保存する。

2.3 far 3問（2070）

Q-F02 世代間正義制度化

本問いは Type-A 既出回答型の最も明確な例である。PHIL は Jonas『責任という原理』（1979）以降40年蓄積された長期倫理（Parfit, MacAskill, Ord）を提供し、TK はイロコイ連邦憲法 Great Law of Peace の「7世代律」がそのまま既存制度として記録されていることを示す。AN の祖先-子孫連続体（Fortes アフリカ研究）、LIT の未来世代主体化文学（Le Guin, Robinson, Butler）、MY の黄金時代神話・ユガ周期・ホピ予言が補完する。Q-F02 は本Track 14問で 最も「すでにある」度合いが高い 問いの一つ。解釈

Q-F04 神話的人間-非人間境界

MY DB MS01 タグ群（変身譚・動物婚姻譚・トーテミズム神話）は、本問いの神話的回答を直接保存している。AN の perspectivism と multispecies ethnography（Tsing, Haraway, Kohn）は現代の人類学的回答を提供し、PHIL の theme_nature 148件（特に Latour・Serres の自然契約）は哲学的応答を提供する。TK は Whanganui川法人格（NZ 2017）、Ganges判決（インド）、エクアドル自然権憲法が 既に制度化された応答 であることを示す。LIT の動物文学・植物文学（Coetzee, Powers, Le Guin）は文学的雛形を提供する。

Q-F06 伝統知の知識主権

本問いも Type-A 既出回答型の典型である。TK は UNDRIP 第31条（2007）と Nagoya Protocol（2010）が既に20年前に確立した制度的雛形を直接提供し、CARE 原則（GIDA 2019）は現代的拡張を示す。AN の salvage anthropology 批判（Deloria, Smith）は方法論的応答を、PHIL の認識論的不正義（Fricker）と Epistemologies of the South（Santos）は哲学的根拠を提供する。LIT の先住民文学（Silko, Momaday, Grace）は文学実践として「翻訳しない参照」を確立済み。MY は sacred/secret物語の段階的開示が 知識主権の最古の実装形態 であることを示す。

2.4 very-far 4問（2100）

Q-V01 サイクルA前期段階の組織形態

7.1 5系統 Skill 照会の網羅性限界

7.2 inference 1件の取り扱い

Q-V05/AN「rhythms of practice / Mauss-Halbwachs」は derivation_method を inference（推論）として記録した唯一のレコードである。Halbwachs『集合的記憶』と Bourdieu のハビトゥス理論を「リズム」概念で接続するのは私（Track B-2 リード）の構造的推論であり、Halbwachs・Bourdieu のテキストに「〈ゆっくりの権利〉」概念を直接見いだせるわけではない。confidence は3に設定したが、この1件は本Track の 仮説的拡張 として読まれるべきである。未検証

7.3 他の inference 候補の意図的除外

本Track 抽出過程では、確度3未満の inference 候補が多数浮上した。たとえば Q-V01（サイクルA前期段階の組織形態）について「DAO（分散型自律組織）の Plato Republic 類比」「ブロックチェーンガバナンスのカルヴァン宗教改革類比」等は、概念的に魅力的だが歴史的根拠が薄く、Track 5 が指摘した「過剰的中バイアス」の典型として除外した。これら候補の体系的記録は本handoff には収載しなかったが、後続Track が必要に応じて再検討できる。

7.4 「翻訳しない参照」の本Track 内部矛盾

Q-F06（伝統知主権）の wisdom として MY DB「sacred/secret物語の段階的開示」を記録したが、本Track 自体が伝統知をHTMLで「翻訳して参照」する形式を取ることは、Q-F06 の倫理的応答と内部矛盾する。本Track はこの矛盾を解消できず、HTML 公開の際は 「伝統知の名前と存在を記録するが、内容の詳細開示は控える」 という形式で間接的に対応した。たとえば「Hopi katsina の非公開儀礼」は名前のみを記録し、儀礼内容は記述しない。本制約は Q-F06 抽出の自己一貫性を守るための意図的限界。解釈

7.5 言語的偏向

本Track 抽出の85件は、英語・日本語の二次文献を主に参照しており、各文明圏の 原語による wisdom へのアクセスは限定的である。たとえば仏教の無我論（Sanskrit anātman）、儒教の仁（中国語 仁）、ubuntu（Nguni 諸語）等は、原語ニュアンスの保存より概念翻訳の優先で wisdom_text を記述した。これは「翻訳しない参照」の倫理（Q-F06）と部分的に矛盾する。未検証

7.6 Type-A/B/C 三類型分類の主観性
