社会展開サイクル/螺旋とミラツク羅針盤 — Track C-1 レポート

本書は領域策定 Phase C Wave 1 の Track C-1（社会展開サイクル/螺旋の提示）における最終レポートである。Phase A 9 トラック・Phase B 6 トラックが確定した「ミラツクが向き合う問いの全体像 (997 単位)」を時間軸上に展開し、サイクル A（認知転換 280-310 年）/ B（制度興亡 150-300 年）/ C（プラトー 250 年）の三重サイクルと CTI v2「双子峰プラトー」を統合した独自螺旋モデル（仮説D）を、4 ホライズン（near 2026-2035 / mid 2036-2055 / far 2056-2080 / very-far 2081-2100）に投影する。本書は「ミラツクが描く未来社会への羅針盤」を時間軸層から確立し、Phase C C-2〜C-7 への入力データを提供する。

PART I

本書の位置づけ

領域策定プロジェクトは Phase A（9 トラック / 領域診断）+ Phase B（6 トラック / 問い構造化）+ Phase C（7 トラック / 収束）+ Phase D（展開）の 4 段構造で進行する。本書は Phase C 第一段階 Wave 1 の Track C-1 として、時間軸層を確立する。

1.1 序章 — 「ミラツクが描く未来社会への羅針盤」の時間軸層

領域策定 Phase A は 9 DB 横断分析によって「ミラツクが向き合う領域とは何か」を 15 メタテーマと 6 Mサイン領域として確定した。Phase B は Phase A の上に多層人類史 41 問・すでにある未来 85 wisdom・善い社会 5 シナリオ × 30 問・7 変化検出装置 × 168 セル・動き測定 210 セルを積み上げ、「ミラツクが向き合う問いの全体像 (独立 ID 71 + 派生 926 = 997 単位)」を確定した。

Phase C はこの全体像を「ミラツクが描く未来社会への羅針盤」として収束させる第三段階である。Phase C の最重要局面は、Phase B が散開的に展開した 71 独立問い ID を「サイクル/螺旋 × 問いの全体構造 × 偉業 DB × 担い手特性」の 4 軸でミラツク独自の社会変革ビジョンに収束させることである。本書はその 4 軸のうち最も基盤となる「時間軸層」（サイクル/螺旋）を担う。

時間軸層は他の 3 軸（問い構造化 = C-2 / 偉業 = C-3 / 担い手 = C-5）の共通座標系を提供する。即ち、C-2 が問いを再構築するとき・C-3 が偉業を構造化するとき・C-5 が担い手を類型化するとき、それらは 常にどのホライズン（near/mid/far/very-far）にどの程度の確信度で位置づけられるかという時間軸的属性を持つ必要がある。本書はこの時間軸的属性を提供する。

本書が確立する羅針盤は、政府機関・大手シンクタンクが提示する「2030/2050 二点シナリオ」「Three Horizons モデル」「メガトレンド一覧」のいずれとも構造的に異なる。本書は時間スケールの異なる複数のサイクル（5 スケール）が現在 2026 で同期点を形成しているという独自構造を中核とする。これは「現在 2026」を単なる myth shift の時点ではなく、複数の異なる時間スケールの転換が重畳する稀有な瞬間として位置づけるミラツク独自の時間観である。

1.2 仮説Dの宣言

本書は事前リサーチで提案された 4 仮説（A 三重螺旋 / B PRRRC 5次元周期 / C 既存サイクル理論接続 / D ミラツク独自統合サイクル）のうち、仮説D（双子峰プラトー螺旋モデル）を採用する。

仮説Dは、Track 4（HIC/SIF/GF/TA）が同定したサイクル A/B/C と、CTI v2（Civilizational Transformation Index v2）が9時代評価で発見した「双子峰プラトー」、Phase B B-1 が確定した真Mサイン「物語転換期」+ 概念整合「第四変容期」を、4 ホライズンの時間軸上に螺旋として展開する独自モデルである。仮説Dの 5 スケール入れ子構造は以下である。

  • cosmological 5,000年: 枢軸時代-大学-印刷-産業-AI を含む文明史的局面
  • サイクル A 280-310年: worldview 層・パラダイム層の本格的転換
  • サイクル B 150-300年: 政体・企業・宗教制度の興亡
  • サイクル C 250年: 産業革命以降の高位プラトー（CTI 0.752-0.768）
  • Kondratiev/Perez 50-60年: 経済技術波動（第5波情報→第6波バイオAI脱炭素）
  • myth shift 20-30年: CLA myth 層の転換（1929-1973-2008-2018-2026）
  • litany shock 5-10年: 気候災害・地政学衝撃・パンデミック

仮説D採用の根拠は四点である：(1) Phase B B-1 多層構造 + B-3 critical juncture + B-4 装置応答 + B-5 zone との整合性、(2) Track 4 と CTI v2 の独立解析結果の時間軸上での整合、(3) 既存フォーサイト機関に類例のない独自構造、(4) Phase B 申し送り 5 件を統合的に処理可能。詳細は analysis §1.4 を参照。

PART II

三サイクル A/B/C の俯瞰

本第 II 部は Track 4（SIF/HIC/GF/TA を横断した独立解析）が同定した三重サイクル A/B/C を俯瞰し、各サイクルの周期・観測根拠・主要転換点・現在 2026 位相を整理する。三サイクルは異なる時間スケールで独立に作動するが、現在 2026 で同期点を形成している点が本書の核心観察となる。

2.1 サイクル A 認知転換 280-310年

サイクル A は worldview 層・パラダイム層の本格的転換が起きる時間スケールで、Track 4 が同定した観測平均は 280-310 年（広義仮説 500 年）である。主要転換点は枢軸時代（BCE800-200）→ 大学・印刷期（1100-1500）→ 産業革命（1760-1840）→ 電力化学革命（1870-1920）→ 情報革命（1980-2010）→ AI革命（2017-現在）の 6 点である。

サイクル A の主要転換点間隔は次の通り：印刷→産業 = 305年、産業→電力化学 = 110年、電力化学→情報 = 110年、情報→AI = 37年。Track 4 がサイクル A を「観測平均 280-310 年」と表記した根拠は、印刷→産業 = 305 年 + 産業→AI = 257 年（中点）の中間値である。後段の 110 / 110 / 37 年の縮減は、サイクル A 超長期周期内に重畳する中期サイクル（Kondratiev/Perez 50-60 年）として解釈する 【解釈】。

現在 2026 のサイクル A 位相は 「AI革命+9年 = 転換初期」である。サイクル A 一周期を 280-310 年と仮定すると、次の構造変革は 2040-2070 の窓（特に 2060 頃）に来る可能性がある 【推定】。

2.2 サイクル B 制度興亡 150-300年

サイクル B は政体・企業・宗教制度などの制度的興亡が起きる時間スケールで、Track 4 が HIC 20 ケース・GF 9,178 人物を横断して同定した。サイクル B は時間スケールが幅広く、短命型（10-50年）/ 中寿型（100-150年）/ 長寿型（200-300年+）の三つのサブパターンに分かれる。

短命型 HIC の典型例は Alexander 11 年・Rockefeller Standard Oil 41 年（1870→1911 解体）・Jack Ma Ant Group 21 年（2002→2023 規制反作用）。中寿型は一般的な企業・王朝の制度寿命（100-150 年）。長寿型はローマ帝国後期 200 年・オスマン帝国前期 200 年・徳川幕府 265 年・三井 350 年・科挙 1318 年・教会 1700 年+ である。

サイクル B の本質は 「急拡張 → 規制反作用 → 制度再編」のパターンであり、特に短命型の出現頻度が高まるのは「新興汎用技術の初期展開期」である。電力化学革命期（1870-1914）の Standard Oil 解体（41 年）と AI革命期（2017-）の Ant Group 規制反作用（21 年）は、両時代の構造的同型性を示す独立確証である 【解釈】。CTI v2 が D6 権力集中 = 0.90（9時代最大）と D5 地政学秩序 = 0.85 を同時に AI革命期に割り当てた根拠は、まさにこの構造的同型性にある。

現在 2026 のサイクル B 位相は 「AI革命に対する規制反作用の本格化期」である。Phase B B-1 Q-N02「AI革命の制度反作用」は near 2030 で顕在化を問う準Mサイン認定問い。Phase B B-3 JCT-01（AI ガバナンス制度化、2027-2030）と JCT-02（場所性回帰の制度化、2028-2032）が near 帯の主要分岐点として機能する。

2.3 サイクル C プラトー 250年

サイクル C は産業革命以降の文明史的高位プラトーが続く時間スケールで、Track 4 + CTI v2 が同定した範囲は 1760-現在（約 266 年）である。CTI v2 が「双子峰プラトー」と命名した。

9 時代の raw CTI 値（CTI v2 §6 直接引用）: 農業革命 0.688 / 文字 0.711 / 枢軸時代 0.636 / 中世大学 0.531 / 印刷期 0.666 / 産業革命 0.764 / 電力化学革命 0.764 / 情報革命 0.752 / AI革命 0.768。産業革命以降の 4 時代（1760-現在）が 0.752-0.768 の高位プラトーを形成し、AI革命/産業革命 = 1.005 倍（CTI(1850=100) 換算で 1.05 倍）に留まる。これは SIF-SI 初版「現代は産業革命の 1.4-1.7 倍」を学術的に却下した修正値である。

サイクル C の本質は 「単一の長期局面（1760-現在）の中で、産業革命・電力化学革命・情報革命・AI革命の 4 ピークが時間軸上に並ぶ」構造である。両峰の間（1840-1870 の 30 年と 1920-1980 の 60 年と 2010-2017 の 7 年）は CTI 0.700 を下回ることがなく、プラトー全体の中の局所的低下に留まる 【解釈】。

現在 2026 のサイクル C 位相は 「プラトー後期」。Track 4 仮説では サイクル C 終端が 2060 頃（産業革命 1760+300 年 = 2060）。Phase B B-1 Q-F05「サイクル C 終端の構造変革は far で本当に到来するか」（W=5/C=2/M=4、合計 11 点）は、far 2070 帯でこの仮説の検証を問う。

Tech Acceleration 100 万倍縮減を 2100 に直接外挿することには三重の限界がある。第一に 近代偏重バイアス。Track 4/Track 8 の主軸 DB は近代偏重で、SIF 1700-1900 で 57.2%・GF 1800-1900 で 35%・TA digital+industrial+modern で 66.6%・HIC 1500-1900 で 70%。古代・中世のサイクル比較は事象密度が薄い土台で行わざるを得ない（V-19 限界）。100 万倍縮減のうち、paleolithic→neolithic の縮減は記録の有無による偽の縮減である可能性が高い 【未検証】。

第二に 事象密度と構造変革強度の混同。Tech Acceleration の事象密度（件/100年）は技術出現数の単純カウントであり、CTI v2 の総合 CTI 値（構造変革強度の加重和）とは異なる次元である。Track 8 の「100 万倍縮減」を Track 4 の「サイクル A 認知転換 280-310 年」に直接接続させると、事象密度の縮減 = 構造変革の加速 という安易な等価を招く危険がある 【解釈】。CTI v2 の双子峰プラトー（産業 1760-現在の 250 年で 0.752-0.768 の安定）は、事象密度が増えても構造変革強度は安定するという反証の可能性を示唆する 【解釈】。

第三に 外挿の物理的限界。事象密度を 2100 まで指数関数的に外挿すると、digital 1,212 件/100 年から AI革命+83 年で 10,000 件/100 年（推定）を超える。これは 1 日 1 件以上の主要技術出現に相当し、人類社会の制度応答能力を構造的に超える 【未検証】。Tainter「複雑性の限界収益逓減」（1988）が示唆する文明崩壊のメカニズムが作動する可能性がある 【解釈】。

以上の三限界より、本書は 100 万倍縮減を 2100 に直接外挿することを採用しない。代わりに、サイクル A/B/C の入れ子モデル（仮説D）の中で「事象密度の縮減はサイクル C プラトー内の中期サイクル（Kondratiev/Perez 50-60 年）の重畳として現れる」という解釈を採用する。これは Robert Gordon「The Rise and Fall of American Growth」（2016）の「1870-1970 が真の革新期」論と整合し、現代の情報革命/AI革命を Carlota Perez 第5波/第6波として位置づける見方と整合する 【解釈】。

2100 への外挿の代替手段として、本書は サイクル A 前期段階 27% 地点という位置認定を採用する。これは 100 万倍縮減の指数外挿ではなく、印刷革命 1450 → 産業革命 1760（310 年）の構造類比を 2026 → 2300（仮説 270 年）に適用したものである。2100 はその 27% 地点（2026+74 年=2100、74/270=27.4%）として、印刷革命 1450 + 27.4% = 1535 年（宗教改革 1517 + 18 年、活版印刷の文化的影響が初期実装される時期）と類比的に位置づけられる 【推定】。
