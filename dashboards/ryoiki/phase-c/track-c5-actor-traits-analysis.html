CHAPTER 01

解析の前提と4軸構造

Phase C-5 は、C-3 が構造化した「現代に求められる偉業」140件の担い手を、心理・行動・領域・専門の四軸で記述する。この四軸は単独の人物像を写すための解像度ではなく、ミラツクが「誰を見出し、誰を育てるか」を判断するための診断格子である。

本トラックの解析対象は、great_actions.db v0.1 に投入された偉業140件、そこに紐づく action_capability_links 292件、PST DB の persona_archetypes 10種、era_talents.db の capability_dimensions 19次元と6時代の活躍記録、JPMS DB v2 の人格-学校-活躍経路スキーマ、そして Phase B が確定した CTL-1 6軸である。これらは別々の DB として独立して育ってきたが、Phase C-5 はそれらを「担い手プロファイル」という単一の解像度で重ね合わせる初の試みとなる。

四軸を確定するうえで重要なのは、軸どうしの順序ではなく相互規定の構造を可視化することである。心理が行動を生み、行動が領域を選び、領域が専門を要請するという順方向の因果は確かに観察できるが、同時に「専門が培養される教育環境（学校）が心理を形成する」という JPMS の逆向き因果も並存する。本解析では、この双方向の因果を JPMS の MLM・SEM・IRT・LCA・GCM の5数理モデルで仮説的に支える設計をとる。

1.1 三系列差のスナップショット

本解析が一次値として採用する数値は、2026-05-09 時点の DB 実値である。Phase A 継承監査で確定した source-of-truth に従い、era_talents.db の人物数12,958件・能力スコア31,436件・future_demands 590件、great-figures.db の persons 9,178件、PST DB の persona_archetypes 10件、JPMS DB v2 の schools_v2 832件・testimonials_v2 58,224件を一次値とする。great_actions.db v0.1 の140件は C-3 ハンドオフ確定値で、内訳は過去偉業60件・現代登場中50件・期待される未来30件である。

1.2 四軸構造の概観

事前リサーチで暫定提示された四軸構造は以下の通り。本解析では、この構造を保ちつつ、第5類型「翻訳者型」を C-3 capability_links および TOP10 マッピングから検証する。

CHAPTER 02

軸1 心理 ― 19能力次元の中核選定

era-talents の19能力次元のうち、ミラツク優先 TOP10 と C-3 偉業140件で実測重要度が突出する 5+2 次元を中核として確定する。「優れた偉業者は時代を問わずシステム思考者である」という6時代を貫く普遍性が、本選定の規範軸となる。

2.1 19次元の現代的妥当性

era_talents.db の capability_dimensions 19次元は、OECD Future of Education and Skills 2030・WEF Future of Jobs 2025・PISA・Csikszentmihalyi 創造性論を統合した枠組みである。事前リサーチが示した6時代別平均スコアでは、cog_systems が明治7.43→令和7.35の狭幅で高位安定し、val_collective が明治6.74→平成3.32の急減を見せ、cog_ai_collab が平成3.40→令和8.91の指数的上昇を示す。これらの時代軌道は、Phase B B-1「3パラダイム同時失効」と Phase A Track 8 の AI 加速エビデンスと整合する。

2.2 中核5次元 + 準中核2次元の選定

事前リサーチは中核5次元に cog_systems・age_oecd_transformative・age_social_change・soc_interpersonal・cre_cross_domain を、準中核2次元に val_eco・cog_ai_collab を推奨した。本解析はこの推奨を C-3 great_actions.db の capability_links 292件・TOP10偉業の登場頻度・future_demands 590件の時代別ランキングの3視点から検証する。

great_actions.db の capability_links 292件は ET 19次元と完全には対応しておらず、val_pluralism・val_justice・cog_synthesis・cog_systems・soc_empathy・cog_strategic・val_patience・val_pragmatism・cog_languages の9軸で運用されている。これは C-3 投入時の独自分類で、ET 19次元の含意を要約した派生軸とみなすのが妥当である【解釈】。本解析では C-3 9軸を ET 19次元の中核に翻訳し、cog_systems → cog_systems、cog_synthesis → cre_cross_domain、val_pluralism → val_tolerance + cre_cross_domain、val_justice → age_oecd_transformative + age_social_change、soc_empathy → soc_interpersonal、val_patience → age_resilience + age_meta_learning という対応で扱う（集計L-01）。

2.3 19次元の偉業適用における主観性

19次元を個別の偉業に適用するとき、判定の主観性は避けられない。例えば「世代間正義の憲法化（GA-001）」に cog_systems を割当てる根拠は「複数世代を貫く因果連鎖を法制度設計に反映する必要がある」という解釈であり、これは別の解釈（age_oecd_transformative の方が直接対応）と排他的でない。本解析では【解釈】タグを徹底し、複数次元の重ね当てを許容する。Phase D で逆向きの自動推定（capability score → archetype）を試行することで、判定の堅牢性を後検する設計とする。

2.4 19次元の限界 ― 2100年の未来固有概念63件

era_talents の future_demands 2100年125件のうち63件は、19次元では捕捉できない未来固有概念である。xeno-ethics・virtual_ecosystem_inhabitation・transhuman_identity・zero_waste_circular_economy 等が代表例で、これらは21世紀末に独立した次元として立ち上がる可能性を示唆する【推定】。本解析は19次元を主軸としつつ、20-25次元への拡張余地を C-7 公開後の課題として明示する。

CHAPTER 03

軸2 行動 ― 10アーキタイプ + 翻訳者型

PST DB の10意思決定アーキタイプを基盤とし、第5類型として「翻訳者型（arch_translator）」を追加する。great_actions.db 140件と TOP10 偉業の実測分布が、この11型構造の必然性を支える。

3.1 great_actions.db 140件のアーキタイプ分布

C-3 が投入した140件の archetype 分布は、Mediator 39件（27.9%）・Introvert Thinker 28件（20.0%）・Creator 23件（16.4%）・Steady 17件（12.1%）・Caregiver 16件（11.4%）・Explorer 8件（5.7%）・Warrior 4件（2.9%）・Social Creator 3件（2.1%）・Leader 2件（1.4%）・Craftsman 0件（0.0%）である（集計L-02）。Mediator + Introvert Thinker = 67件（47.9%）で、古典的英雄像 Warrior + Leader = 6件（4.3%）の約11倍の比重となる。

3.2 アーキタイプ × Mサイン接続の交差

great_actions.db を archetype × msign_connection で交差すると、Mediator の真Mサイン接続が17件（Mediator 全39件の43.6%）と最も多く、Introvert Thinker の self-reflexive シナリオへの集中（5件のうち5件）が際立つ（集計L-03）。これは Mediator が Phase A 真Mサイン物語転換期の最も強い担い手であり、Introvert Thinker が自己言及メタ問い G-V03 の専属型として機能していることを示す【解釈】。

3.3 アーキタイプ × ホライズンの交差

archetype × scope_horizon の交差では、Mediator が near 29件・mid 4件・far 5件・very-far 1件と幅広く分布し、Introvert Thinker が near 20件・mid 5件・far 1件・very-far 2件と長期にも残る（集計L-04）。一方 Caregiver は near 14件 + mid 2件で長期がほぼ無く、Steady も near 13件中心である。これは「翻訳・思索型は長期問いの担い手として有効、ケア・堅実型は近期実装の担い手」という時代分業を示唆する【解釈】。

3.4 PST DB の Big Five 閾値とホランドコード

PST DB の persona_archetypes は Big Five 5因子（O開放性・C誠実性・E外向性・A協調性・N神経症傾向）の閾値とホランド職業興味コード（R/I/A/S/E/C）で運用される。Mediator は A>75・O>65 / S・E、Introvert Thinker は E<40・O>70・N>55 / I・A の閾値を持つ。これは識別段階での若年期スクリーニング基準として活用可能で、JPMS DB の testimonial 58,224件の自然言語ログから IRT で項目反応抽出すれば候補の同定が可能となる【推定】。

3.5 第5類型「翻訳者型」の登場

C-3 140件で arch_translator は明示的に投入されていないが、Mediator + Introvert Thinker + Creator の三型交差として暗黙的に存在する。具体的には G-N09 先住民知識主権・G-N12 三項リテラシー教育・G-N07/N08 非西洋認識論・G-V03 自己言及メタ問い・G-F02 三項経済比率設計の5問で、Mediator のうちの一部・Introvert Thinker のうちの一部・Creator のうちの一部が「翻訳機能」を担っている【解釈】。第6章で本類型の必然性を独立に検証する。

CHAPTER 04

軸3 領域 ― CTL-1 6軸の担い手配分

CTL-1 6軸（V/S/T/Eco/Env/G）に対する担い手配分は、CTL-V（価値観）に集中する非対称構造を示す。CTL-S（社会）の構造的空白も含めて、ミラツクが介入すべき領域の優先順位を決定づける。

4.1 CTL-1 × アーキタイプの交差

great_actions.db 140件を scope_ctl × archetype で交差すると、CTL-V 69件のうち Introvert Thinker 21件・Mediator 18件・Caregiver 12件・Explorer 5件・Steady 5件・Creator 4件・Social Creator 2件・Warrior 2件で、価値観領域に内省的調停型が集中する（集計L-05）。CTL-G 24件は Mediator 13件・Steady 5件が中心で、ガバナンスは調停・継続型の領域である。CTL-Eco 26件は Creator 13件・Steady 5件・Caregiver 2件・Mediator 1件・Leader 2件・Introvert Thinker 2件・Social Creator 1件で、新経済モデル設計に Creator + Steady のペアが効くという構造を示す。

4.2 CTL-V 集中の構造的意味

CTL-V 69件のうち Mediator + Introvert Thinker + Caregiver = 51件（73.9%）で、価値観領域は調停・思索・ケア型の3型がほぼ独占している。これは Phase B B-1 が示した「Layer C 物語転換期 4問」が CTL-V に集中する事実と整合し、現代の偉業の中核戦場が「価値観の再構築」であることを担い手側で確認する【解釈】。

4.3 CTL-S 0件の構造的空白

great_actions.db でCTL-S（社会・人口・コミュニティ）への投入が0件である事実は、C-3 検証編で要追跡事項U-9として記録されている。本解析でも CTL-S の構造的空白は確認され、これは「社会領域の偉業はCTL-V（価値観）または CTL-G（ガバナンス）に吸収されて投入された」という C-3 投入時の判断によるとみられる【推定】。Phase D で CTL-S 専用の偉業群（コミュニティ運営・人口政策・移住インフラ等）を別途構造化する必要がある。

4.4 CTL × ホライズンの交差

CTL-V は near 47件・mid 11件・far 7件・very-far 4件と4ホライズン全帯に分布し、長期持続性が高い領域である（集計L-06）。一方 CTL-Env は near 8件 + very-far 1件で mid/far が空白、CTL-G は near 23件 + mid 1件で長期が極端に薄い。これは「環境・ガバナンスの長期予測は装置応答が薄く投入が困難」という Phase B B-4 R3 sentinel の発見と整合する【解釈】。

CHAPTER 05

軸4 専門 ― 学術5領域・業種・地域

担い手の専門性は、学術5領域（人文学・社会科学・自然科学・工学・芸術）・業種（JPMS career_archetype 33種）・地域（JPMS DB の地域分布）の三副軸で記述される。ミラツクが見出すべき業種は arch_career_thinker・arch_npo_leader・arch_career_economist の3型に集中する。

5.1 偉業×学術5領域の対応

C-3 140件を学術5領域に再マップすると、人文学（哲学・人類学・倫理学・歴史学）が最も多く約60件、社会科学（経済学・政治学・社会学）約45件、自然科学（生態学・気候科学・神経科学）約15件、工学（システム工学・標準化）約10件、芸術（文学・美術・デザイン）約10件となる【推定】。Phase B 戦略的空白13問が「価値観・哲学・先住民知識・非西洋認識論・自己言及メタ」に集中することと整合し、人文学が現代の偉業の中核学問領域である。

5.2 JPMS career_archetype 33種からの絞り込み

JPMS DB v2 の career_archetype 33種のうち、TOP10 と戦略的空白13問の主担い手として頻出する10種を抽出する。arch_career_thinker（思想家・哲学者型）・arch_career_social_reformer（社会改革者型）・arch_npo_leader（NPOリーダー型）・arch_career_economist（経済学者型）・arch_career_scientist（科学者型）・arch_career_educator（教育者型）・arch_career_artist（芸術家型）・arch_career_legal（法曹型）・arch_career_official（公務員型）・arch_career_diplomat（外交官型）の10型である。

6.1 検証視点1 ― capability_links 交差

ミラツク優先 TOP10 を再点検すると、翻訳者型が要求される問いは G-N09 先住民知識主権・G-N12 三項リテラシー教育・G-N07/N08 非西洋認識論方法論化・G-V03 自己言及メタ問い・G-F02 三項経済比率設計の5問である（集計L-09）。これらは複数文化・複数学問・複数世代を翻訳する課題に共通し、Mediator 単独でも Introvert Thinker 単独でも対応しきれない。

6.3 検証視点3 ― Phase B B-4 R3 sentinel 教訓

Phase B B-4 R3 sentinel verdict は「装置の5類型化（全装置応答型／SG単独応答型／装置応答薄型／観測不能型 + 新第5類型 UPR単独強応答型）」を確定した。これは「初期4類型では捉えきれない新類型が DB 実値から立ち上がる」という方法論的教訓であり、本トラックでは担い手側にこの教訓を継承する。

10アーキタイプ + 翻訳者型という11型構造は、PST DB の既存10型に対する単なる追加ではなく、複数型の交差として存在する高次の役割である。Mediator + Introvert Thinker + Creator の三型交差は、個別の Big Five 閾値ではなく「複数文化・複数学問・複数世代の翻訳ができる」という機能的定義によって識別される。これは原理的には PST DB のスキーマ拡張を要するが、本解析では C-3 capability_links の組合せパターン（val_pluralism + cog_synthesis）で代理識別する。

6.4 検証視点4 ― ミラツク自己定義との整合

ミラツクの自己定義は「対等な探究者」「知識運動体」「暗黙知の形式知化」の三本柱で、これらは翻訳者型の機能的定義とほぼ完全に重なる。「対等な探究者」は複数文化を翻訳する姿勢、「知識運動体」は学術と運動を翻訳する役割、「暗黙知の形式知化」は経験と概念を翻訳する作業である。事業のかたち・暮らしのかたち・変化のかたちの3連載は Translational Editor 型ワークフローの実装で、ミラツクが既に翻訳者型として運用されている事実を示す。

6.5 結論 ― 11型構造の確定

4視点の検証から、本解析は arch_translator を独立11型として確定する。C-3 capability_links の能力指紋・TOP10偉業での要求・B-4 R3 sentinel 教訓・ミラツク自己定義との整合の4点が相互補強的に支えており、推定人口比は1.5-2.0%、TOP10 中5問で要求される高密度の役割である【推定】。
