Track C-3 解析編 — 現代の偉業の構造化

過去 60 件 + 現代登場中 50 件 + 期待される未来 30 件 = 140 件のデータセット投入結果と、10 アーキタイプ × 5 シナリオ × 4 ホライズン マトリクス・戦略的空白 13 問対応・系譜接続の解析

作成: 2026-05-09 主軸 DB: great_actions.db 計 140 件
CHAPTER 01

導入と目的

Phase C-3 は、Phase B が確定した 71 問単一台帳・戦略的空白 13 問・5 シナリオ・8 critical junctures に対し「現代に求められる偉業」を構造化する。great-figures.db (過去 9,178 人物) と initiatives.db (現代 463 件推進中) の中間にあたる「行為レイヤー」を新規 DB great_actions.db として確立する。

本トラックは Phase C Wave 2 として Wave 1 (C-1 サイクル/螺旋・C-2 問い統合) 完了を起動条件として開始した。C-1 が確立したサイクル/4 ホライズン投影と C-2 が確立した 71 問単一台帳が前提として与えられ、C-3 はそこに「行為」次元を加えることで、Phase D (deep-knowledge 統合) への入力データを整備する役割を担う。

定義として、本書では「偉業 (great action)」を 個人または集団が、社会システムの構造的次元に作用し、当人の行動が後年において Phase A／B の Mサイン階層的変化（真Mサイン物語転換期・準Mサイン領域 等）の形成に寄与した、または寄与する蓋然性が高い行為連鎖 と定義する。great-figures.db の event_structures テーブル (situation・options・chosen_action・reasoning・counterfactual・constraints の六要素) が記述単位の原型である。

Phase C 計画書 (_PHASE_C_PLAN.md) は C-3 の最低件数を 100-150 件と指定し、内訳として過去偉業 50-70 件 + 現代登場中 30-50 件 + 期待される未来偉業 30 件を求めた。本トラックは過去 60 件 + 現代 50 件 + 未来 30 件 = 計 140 件で着地し、計画範囲内で完了した。

CHAPTER 07

主要発見 3 点と研究の限界

DISCOVERY 1
Mediator + Introvert Thinker 67 件 (47.9%) の構造的優位の確認

140 件サンプルでも、事前リサーチ §8 で予測された Mediator (39 件) + Introvert Thinker (28 件) の合計 67 件 (47.9%) が、古典的英雄像 Warrior (4 件) + Leader (2 件) の合計 6 件 (4.3%) を約 11 倍上回ることが確認された。これは Phase C-3 の核心的構造発見であり、現代に求められる偉業の人材プール論的含意を示す。Phase C-5 担い手特性研究の入力として重要。

DISCOVERY 2
Pluriverse シナリオ 42 件 (30.0%) の分布が示す『学術界 + 国家 + 国際機関』の三主体構造

Pluriverse シナリオに分類された 42 件のうち、locus_subject = academia (11) + nation (14) + international (11) の合計が 36 件 (85.7%) を占める（SQL 実値）。これは Pluriverse シナリオが「個人運動」ではなく「制度的多元化」として進行することを示し、Phase B B-5 戦略的空白の Pluriverse 5 問 (G-N07/N08/N09/M10/F01) が「装置応答薄」と判定された理由でもある。多元化の制度装置は西洋大学制度・西洋国際機関制度・西洋国家制度に依存して 8 割を超える集中を見せており、より顕著に自己矛盾的構造を持つ。Phase D の重要論点。

DISCOVERY 3
真Mサイン 61 件 (43.6%) と概念整合 66 件 (47.1%) の合計が 90.7% に達する高純度

140 件のうち msign_connection = true_msign 61 件 + concept_aligned 66 件 = 127 件 (90.7%) が Phase A Mサイン階層の主要カテゴリに紐付く。これは great_actions.db が Phase A の構造的検証装置として機能することを示し、特に true_msign 61 件は Phase A 真Mサイン物語転換期との直接連結が確立された。Phase D で deep-knowledge 書籍の 21 章マッピングを通じて、書籍内偉業事例と great_actions.db の交叉検証が可能。

7.1 研究の限界 3 点

限界 1: アーキタイプ判定の主観性 — PST DB 10 アーキタイプは Big Five + Holland コードに基づく人格類型だが、過去偉業 60 件への割当ては書籍『歴史の韻と変革』20 ケース＋追加 40 件に対し、本トラック内で本判定（事前リサーチ §1 が暫定値として提示したもの）を踏襲した。Era Talents DB の能力スコアからの自動推定検証は本トラックでは未実施【未検証】。Phase D 以降での再検証推奨。

限界 2: 期待される未来偉業の根拠強度 — 30 件のうち confidence_level = speculative 5 件・low 12 件・medium 11 件・high 2 件。speculative は GA-127 / GA-131 / GA-136 / GA-137 / GA-139 / GA-140 と Phase B B-2 wisdom 由来でなく、Phase A サイクル仮説と B 戦略的空白からの抽出による【推定】。これらは Phase C-7 公開前の sentinel ゲートでの再判定が望ましい。

限界 3: locus_subject = miratuku 偉業の自己言及性 — GA-100 (ミラツク知識運動体)・GA-127 (75年自己診断装置)・GA-136 (2100年再評価) は本トラック自身が記述する Phase C プロジェクト自体の偉業候補であり、自己言及性を持つ。これは G-V03 メタ問い対応として意図的だが、外部評価が困難。Phase C-7 公開後の外部レビューが必要【未検証】。
