1研究設計と方法

本トラックは Phase C Wave 3 の中核作業として、C-3 で構築された great_actions.db v0.1（140 件投入）に対し Phase B B-4 463 initiatives と B-5 zone 弁別を接合し、推進状況・成熟度・方向整合性の三層を上書きする「観測実績層」を生成した。本解析編は、その接合プロセス全体の SQL 集計ログと判定根拠の透明な開示を担う。

解析の中核はブリーフィング §6 で要請された四つの構造的問い、すなわち（一）463 initiatives は great_actions.db のどの archetype/scenario に紐付くか、（二）「動きはあるが方向違い」warning 偉業はどう特定されるか、（三）「動きはないが期待される」opportunity 偉業（戦略的空白起源）はどう特定されるか、（四）ミラツク優先課題 TOP10 × 偉業マッピングはどう描けるか、の系統的回答である。これらを同一の SQL ベースで透明に処理することを設計原則とした。

採用した方法は四段階である。第一段階で B-3 30 問（G-prefixed）と B-4 24 問（Q-prefixed）の独立 ID 系列をブリッジするために、_TRACK_LINKAGE_MATRIX §1.1〜1.4 の推定マッピングを継承して 41 個の Q→G 対応辞書を構築した。第二段階で 463 initiatives を Q-prefixed 単位で読み込み、Q→G 変換を経て great_actions の primary_question_id（G-prefixed）にマッチする全 actions に行為連結を生成した。第三段階で initiative の stage 分布から各 action の maturity_score を算定し、第四段階で warning（4 定義 × 8 候補問い）と opportunity（戦略的空白 13 問起源 × 3 条件）のフラグを付与した。

1.1 マイグレーション概要

great_actions.db v0.1（C-3 確定）→ v0.2（C-4 接合層）の差分は次の通り。

L-01 ALTER TABLE great_actions（11 カラム追加）: + c4_status_override (TEXT) + c4_b5_zone (TEXT) + c4_initiatives_count (INTEGER) + c4_initiatives_stage_dist (TEXT JSON) + c4_top10_rank (INTEGER) + c4_warning_definitions (TEXT JSON) + c4_warning_severity (TEXT) + c4_opportunity_conditions (TEXT JSON) + c4_maturity_score (INTEGER 0-5) + c4_direction_alignment (TEXT) + c4_updated_at (TEXT) + c4_review_note (TEXT) L-02 CREATE TABLE action_initiatives_links（多対多）: - action_id → great_actions(action_id) - initiative_id → initiatives.db - bridged_question_id_b3 - link_strength {strong / medium / weak / speculative} - link_type {direct / inverse / partial / analog} L-03 CREATE TABLE action_zone_mapping（集計）: zone × scenario × archetype の三軸集計テーブル warning_count / opportunity_count / happening_count 等を保持

v0.1 既存データは破壊せず、c4_status_override により上書き候補をフラグ管理する設計とした。これにより C-3 リードの判定（机上判定値）と C-4 リードの判定（観測実績判定値）の双方を保持し、Phase D 以降での再評価可能性を担保している。

2B-1→B-3 マッピング層

463 initiatives と 140 great_actions の接合における最初の構造的問題は、両者が異なる ID 系列を採用していることであった。initiatives.db は B-1 41 問体系の Q-prefixed（Q-N01〜Q-V07）で問いを保持し、一方 great_actions.db は B-3 30 問体系の G-prefixed（G-N01〜G-V05）で primary_question_id を保持していた。両者は独立に設計された問い空間であり、_TRACK_LINKAGE_MATRIX §0 凡例によれば「B-3 はB-1から規範層展開する独立系列のため、対応は1:N または N:1 を含む推定マップ」とされる。

この間にブリッジを置かないと、463 件全件が「対応なし」となり接合が成立しない。本トラックでは _TRACK_LINKAGE_MATRIX §1.1〜1.4 の B-3 推定対応列を継承し、41 個の Q→G 変換辞書を構築した。未検証 このマッピングは B-3 リードの最終確定を経ていないため、Phase D 段階での再評価を要する。

3.3 紐付けなし actions 64 件の構造

6maturity_score 算定結果

c4_maturity_score（0-5 値）の算定アルゴリズムは次の通り。

L-05 maturity_score 算定アルゴリズム: initiatives = 0 件: - speculative → 0 - expected → 1 - emerging → 2 - happening → 1（格下げ候補） initiatives ≥ 1 件: - scale 比率 ≥ 30% → 5（happening_scale） - pilot 比率 ≥ 50% or (P+S)/T ≥ 40% → 4（happening_pilot） - 5 件以上 → 3（happening_experiment） - 1 件以上 → 2（emerging）
maturity_score件数意味
04speculative — 仮説段階
158expected — 期待だが装置応答ゼロ
22emerging — 一部装置応答（弱）
350happening_experiment — 5+ 件・実験段階偏重
426happening_pilot — 試行段階比率高
50happening_scale — 拡大段階比率高

140 件中 maturity_score 5（happening_scale）はゼロ件、maturity 4（happening_pilot）が 26 件、maturity 3（experiment）が 50 件で、合計 76 件（54.3%）が actually-happening 状態と算定された。一方 maturity 0-1 が 62 件（44.3%）で、これは「動きが装置観測上は見えない期待型または speculative 偉業」の集合となる。推定

注目すべきは maturity_score 5 がゼロ件である事実である。これは現代の偉業の中で「scale 段階に明確に到達しているもの」が、本トラックの判定基準（initiatives の scale 比率 30% 以上）では存在しないことを意味する。「現代の偉業は依然として実験・試行段階に留まっている」という構造的事実が定量的に確認された。解釈

10主要発見 3 点

10.1 主要発見 1: 戦略的空白 13 問 = initiatives 真空地帯の二重定義確証

B-3 30 問のうち 11 問が initiatives 直接対応ゼロ件で、戦略的空白の概念が「装置応答薄（B-5 zone 弁別）」と「initiatives 件数ゼロ（B-4 派生）」の両方で構造的に支持された。great_actions レベルでも、戦略的空白起源偉業（G-M04 / G-N09 / G-V03 等）は平均 maturity 1.0 以下の opportunity 集中領域であり、Phase B の zone 弁別と Phase C の偉業構造が一貫した姿で再現される。

10.2 主要発見 2: maturity_score 5（happening_scale）ゼロ件 ― 「現代の偉業は依然として実験・試行段階」

140 actions のうち maturity_score 5 はゼロ件、maturity 4 が 26 件（18.6%）、maturity 3 が 50 件（35.7%）で、合計 76 件（54.3%）が actually-happening だが scale 段階到達はゼロ件である。これは現代の偉業 happening 群の半数以上が「実験・試行段階に留まる」構造的事実を示し、ミラツクの介入余地が「scale 段階への移行支援」に向けて広く開かれていることを意味する。推定

10.3 主要発見 3: warning vs opportunity = 17:50（1:2.94）― 楽観的構造観の数量的支持

「動きはあるが方向違い」warning 17 件 vs「動きはないが期待される」opportunity 50 件の比率 1:2.94 は、事前リサーチ仮目標 1:3 と概ね整合した。これは「ミラツクは方向違い偉業よりも未開拓領域に注目する楽観的構造観」を実データで支持する。同時に critical warning 4 件すべてが G-N12（ケア経済の組織化）= Hot zone に集中することは、「最も実装が進んでいる領域こそ critical な方向違いリスクを抱える」非対称性を可視化する。解釈
