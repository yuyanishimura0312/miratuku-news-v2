#### WARN-A: time_horizon NULL「1,534件 / 20.0%」の主張は再現不能（要修正）

analysis.html 第2.1節 行230、第6章 行490・行532、verification.html V-3.3、研究の限界 V-05 で繰り返し主張されている「time_horizon NULL もしくは特殊値が 1,534 件（20.0%）」は、実DB照会で再現できない。

DB実値:
- `time_horizon IS NULL`: **0 件**
- `time_horizon = ''`: **0 件**
- `time_horizon IN ('immediate','ongoing','immediate-5y')` 等の未明示扱い相当: **16 件**（ongoing 11 / immediate 4 / immediate-5y 1）
- そのほかは 50y+ 3 / long-term structural 1 / irregular 1 / 6-18m 1 / 2-6m 1 / 10y+ 1 など、すべて何らかのスパン値

すなわち、time_horizon の未明示は **16 件 / 0.21%** にすぎず、HTML 主張の「1,534 件 / 20.0%」とはおよそ100倍の乖離がある。これは別の DB（PESTLE もしくは古いSGスナップショット）と取り違えた可能性、もしくは早期スナップショットの値が誤って引用された可能性が高い。

主流化年推定の母集団に関する記述「現代シグナル 407 件のうち time_horizon 明示は 406 件」も、実値は **407 件すべて time_horizon 値あり**で、こちらも軽微な誤り。

→ **要修正**。analysis.html / verification.html の該当箇所を「未明示相当 16 件 / 0.21%」に訂正することを推奨。ただし結論への影響は限定的（NULL がもともと多いとされた懸念が、実は薄かったというだけで、強みホライズン宣言「near 95.6%」は 407/407 に基づくため変動しない）。

#### WARN-B: alerts detected_date 期間の主張に齟齬（要修正）

verification.html V-1.3 で「detected_date を確認すると、すべて 2026-04-29 から 2026-05-15 までに集中している」とある。しかし実DB照会では:

- `MIN(detected_date)`: **2026-04-19**
- `MAX(detected_date)`: **2026-05-02**

すなわち実際の検出期間は 2026-04-19 から 2026-05-02 の14日間。HTMLの「2026-04-29 から 2026-05-15」は両端ともに数日ズレている。月別集計（2026-04: 261件 / 2026-05: 58件）は実DBと完全一致するため、おそらく境界日付の記憶誤差。

→ **要修正**。verification.html V-1.3 の日付範囲を「2026-04-19 から 2026-05-02」に訂正することを推奨。「直近2週間で 87 件追加」という実質的な解釈は変わらない。

## 4. Phase 4: Mサイン候補の論理性 — 判定: **OK（重要な留保つき）**

Track 5 の中核独自知見「**物語転換期の三重定量証拠**」（disruption 7.49 / paradigm 20.4% / myth 11.1% U字回復）が、Track 2 CLA「物語の交代期」と Mサイン候補（複数Track合意領域）として確定可能かを評価する。

### 4.1 三重証拠の論理整合性 — OK

三つの定量証拠は、いずれも実DBから完全に再現できる（Phase 1 検証済）。さらに、三つの指標は方法論的に異なる軸を捉えている:

- **disruption_score 7.49**: 各シグナルに付与された「破壊性」の AI 評価値の時代別平均推移。9時代区分で評価。
- **paradigm_shift 比率 20.4%**: signal_type という別の AI 分類軸の時代別比率推移。
- **myth 比率 11.1%**: cla_depth という第三の AI 分類軸の時代別比率推移。

三指標が同じ AI（Claude）の評価系列に依存している点では完全独立とは言えないが、**評価軸そのものは独立**であり、同じ評価系が三つの異なる軸で同方向の変化を示したことは、診断の頑健性を高める根拠になる。Mサイン候補としての論理整合性はある。

### 4.2 Track 2 との独立性 — WARN（要留保）

しかし、Track 5 と Track 2 の関係について、独立検証側として重要な留保を加える必要がある。

Track 2（CLA）の「物語の交代期」観察と、Track 5 の「物語転換期の三重定量証拠」は、いずれも**同じ pestle-signal-db / CLA DB プロジェクトの派生**として生成されている。具体的には:

- CLA DB（91,550レコード）と SG（7,668シグナル）は同じ pestle-signal-db プロジェクト内の別DB。
- SG の cla_depth 列は、CLA四層タクソノミー（litany/systemic/worldview/myth）を直接継承している。
- SG の signals は PESTLE 196,714記事を母集団とした AI 解析の派生物であり、CLA も同じ母集団からの抽出。

すなわち、Track 2 と Track 5 は **同じ母集団・同じ AI パイプラインから生成された二つの DB を解析しており、評価軸も部分的に共有している**（cla_depth）。Track 3 検証レポート §2.4 が指摘した「同じ AI（Claude）の評価系列依存」と同じ構造的問題が、Track 2 と Track 5 の間にも存在する。

これは「物語転換期」の診断が**虚偽**であることを意味するわけではない。しかし、以下の留保が必要となる:

1. Track 2 と Track 5 を「独立到達した結論」と表現するのは過剰評価。「同一プロジェクト内の二つの派生DBが、異なる集計軸で同方向の現象を観察した」と表現するのが妥当。
2. 真の意味で Mサイン（複数Track合意）として確定するには、**完全に異なる母集団・異なる AI 評価系から生成された他DB**（例: Track 1 FK の predictions、Track 3 megatrend の Futurology Cards、外部の政府機関フォーサイト）でも同じ「物語転換」が観察される必要がある。
3. report.html §7 提言1「3 Track が独立に同一現象を捉えた典型的な Mサイン候補」の表現は、Track 2 の独立性が部分的であることを踏まえて、deploy 段階で「2 Track は同一プロジェクト派生・1 Track（Track 3）は独立母集団」と注記するのが妥当。

→ **判定: OK（ただし「Mサイン候補」という強い表現には留保が必要）**。Track 10 統合エージェントが両Track の関係性を認識した上で、Track 1（独立母集団）/ Track 8（PESTLE/Cultural Intelligence、より広い独立母集団）から第三の確証を得ることで、真のMサインに昇格させる作業が望ましい。

### 4.3 「同一現象の二重発見か独立証拠か」の本質的論点

Phase 4 の問いに対する独立検証側の結論:

> **Track 2 と Track 5 の「物語転換期」観察は、独立証拠ではなく「同一プロジェクト内の二系統並走診断」である**。これは弱点ではなく、むしろ「方法論の頑健性確認」として価値を持つ。Track 10 統合では、Track 1（独立母集団）または Track 3（書籍ベース、別パイプライン）からの第三確証が加われば、初めて「Mサイン」と呼ぶに十分な独立性を持つ。

Track 5 執筆者が「独立に到達した結論」と表現していることは、解釈として強すぎる可能性があり、deploy 段階で「同一プロジェクト内の二つの集計軸から相互確証」へ表現を緩めることを推奨する。
