音楽の数式と宇宙までを横断する学術知

音楽理論・音響物理学・神経科学・数学・宇宙論・非西洋音律体系まで、音楽という現象を 15サブフィールド全方位で集積した Production-grade 学術知識データベース。 ピタゴラスの天球音楽 (BC550) から MusicLM (2023) まで、2,500年の系譜を単一のグラフで結ぶ。

01概観

MUS-DB は音楽を「音楽理論教科書のデータ化」に留めず、音楽が宇宙・物質・身体・社会・計算と 接続する全方位を一覧化することを企図した学術知統合DBです。15 SF 685概念4,933関係 22 DB横断のスケールで、西欧偏重を構造的に補正し、 インド rāga / アラブ maqām / ガムラン slendro / 雅楽 / サブサハラ多声 / 日本独自概念 (間・一音成仏・序破急) を論理展開の駆動軸として組み込みました。

構築方式: /adb v1.1 経路A (学術概念DB) Phase 0-15 一気通貫。GMN-DB方式の専門テーブル (formulas / algorithms / tunings / instruments / genealogy_chains / cosmos_links) を踏襲。 ユーザー指示「音楽理論だけでなく音楽が持つパターン・物理学的意味・音楽と宇宙の関係まで」を スキーマ設計レベルから反映しました。
