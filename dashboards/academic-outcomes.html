Chapter 01

概要 ── AO-DB とは何か

AO-DB は、学術知の産出物（学術アウトカム）を、原典の論文から、それを生み出した著者・所属・受賞・スピンオフ・特許・規格・政策翻訳までを一貫した識別子で接続する、ミラツク学術DBエコシステムの中核基盤である。

前身の FTT-DB（未来技術動向DB）は、10工学領域 × 4時代 × 規制成熟度の281レコードに整理された俯瞰DBであったが、AO-DBはこれを継承しつつ、論文単位の実データを抱える形に再設計された。FTT v2 が定義する30 domain（AI/Robotics/Bio/Energy/Materials/Quantum/Manufacturing/Mobility/Space/Information の10基幹軸＋拡張軸）に対し、AO-DB の論文 8,657 件が領域コードを保持し、その付与率は 95.46% に達する。

AO-DB の独自性は、論文を起点としつつも「アウトカム＝学術知の社会への投射」を多形態で抱えることにある。Wikidata 由来の Nobel/Turing/Fields/Kyoto/Japan/Abel の主要6賞 1,174 件、US-DB 由来の大学発スタートアップ 3,594 社が論文・著者と接続される。今後、特許（J-PlatPat）、規格（IEEE/ISO）、政策翻訳（内閣府／NIH／EU）の3層も同一スキーマで束ねる計画である。

3層アーキテクチャ

L1 学術コア：publications / authors / affiliations / citation_links / funding_grants — 論文と人と組織の関係。

L2 アウトカム層：awards / startups / patents / standards / policy_translations — 学術知が社会に転写された証跡。

L3 メタ層：outcome_domain_map / outcome_time_map / outcome_pathway_map / publication_concepts — FTT v2 領域コード・時期・経路・AK概念の付与。

Chapter 08

スピンオフ ── US-DB 由来 3,594 社

大学発スタートアップDB (US-DB) から 3,594 社を attach。創業年は 1959-2025 年に分布し、現代の大学発エコシステムを学術論文と同一スキーマで束ねる。

startups テーブルは us_db_id を論理FKとして US-DB に接続し、founder_author_id / origin_affiliation_id を AO-DB 内部の著者・所属へ接続できる構造を持つ。現時点では US-DB 由来の3,594社を attach した段階で、founder と origin_affiliation の接続は Phase 5 の課題として残されている。論文 → 著者 → スピンオフの3点接続が完成すれば、「論文がどの程度の頻度で事業化に至るか」という LSI（Lab-to-Startup Index）の算出が可能になる。

US-DB との接続

US-DB は日本97大学・5,000+大学発スタートアップ・12セクターを抱える独立DBで、university_profiles / people / investors / funding を持つ。AO-DB の startups テーブルは US-DB の company レコードに 1:1 で対応し、学術側からの逆引きインターフェースとして機能する。

Chapter 09

L1 学術コア ── 論文・著者・引用

publications（8,920）+ authors（21,355）+ affiliations（2,876）+ publication_authors（23,694）+ citation_links（5,014）が L1 を構成する。

publications は DOI / OpenAlex ID / arXiv ID / J-STAGE ID / CiNii ID の5つの外部識別子を抱え、いずれかが必ず付与される。citation_count・altmetric_score・fwci（Field-Weighted Citation Impact）の3指標を抱え、Phase 4-E で OpenAlex 由来の参照リスト 52,669 件を取得し、AO-DB 内部で双方向に接続された internal citation links が 5,014 件成立した（internal rate 3.16%）。

publication_authors は著者順序と corresponding author フラグを抱え、23,694 レコードで論文と著者の M:N 関係を構成する。著者の ORCID 接続率は 47.0% で、これは EX-DB（experts-db）や UPR-DB（university-press-releases）との横断接続の前提となる。

Chapter 11

L3 メタ層 ── 領域・時期・経路・概念の付与

L3 は outcome_domain_map（12,505）+ outcome_time_map（0）+ outcome_pathway_map（0）+ publication_concepts（9,507）の4基。論文・受賞・スピンオフ等のアウトカム単位に対し、FTT v2 領域コード／時期コード／経路コード／AK概念ID を多対多で付与する。

outcome_domain_map は 12,505 件付与済みで、論文の 95.46% を領域に紐づける。outcome_time_map（Foundation / Acceleration / Convergence / Transformation の4時期）と outcome_pathway_map（Open / Strategic / Closed の3経路）は Phase 5-1 で投入予定。publication_concepts は AK-DB（academic-knowledge-db）の概念IDを論文に紐づけており、現状 9,507 件で、6サブフィールド（humanities / social_theory / natural_discovery / engineering_method / business_models / arts_question）にまたがる。

Chapter 15

API・エージェント

AO-DB は Claude Code 上のスラッシュコマンド /academic-outcomes エージェントから対話的にアクセスできる。ローカル SQLite ファイル（data/ao.db、12 MB）を直接クエリすることで、横断検索・統計集計・系譜分析が可能。

$ /academic-outcomes 論文 Nobel 物理学賞 2023 受賞関連
$ sqlite3 data/ao.db "SELECT title, pub_year FROM publications WHERE language='ja' AND pub_year>=2020 LIMIT 10"
$ python3 scripts/generate_dashboard.py # 本ダッシュボードを再生成

関連リポジトリ：github.com/yuyanishimura0312（private）。本ダッシュボードはミラツク知識運動体のデザインシステム（赤白CI / textbook layout）に準拠する。前身 FTT-DB のダッシュボードは future-tech-trends.html で並列に公開されており、AO-DB と相互参照可能である。
