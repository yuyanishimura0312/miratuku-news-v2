PART I — 未来実現技術の特定

序章 — このDBの原点と再定義

本DBの原点は「学術成果を軸に、各工学分野における未来実現すると想定される技術群を特定し、その情報をデータベース化する」ことにあった。Phase 1〜7+Step 3 を経て publications 8,920 / authors 21,355 / 関係性 13K件 まで量的拡張は進んだが、未来同定の核心となる trl_milestones / outcome_time_map / outcome_pathway_map / patents / standards の 5 テーブルが空のままだった。2026年5月15日、7並列チーム振り返り (Team-1〜7) で乖離を定量化し、Phase A-H で核心テーブルを稼働状態へ持ち上げた。

原点回帰の核は、FTT v2 (technologies 166件、paper_tech_mentions 13K件、scenarios 27件) を「物語層」、AK (engineering_method 2,968概念) を「概念層」、AO-DB publications 8,920件を「成果層」として三角形に組み、未来実現技術 (future_technologies) を 4つの軸 — TRL × 時間軸 × 工学領域 × 学術根拠 — で同定可能にすることにある。

以下 Part I の 7章では、本日投入した未来同定基盤 (future_technologies 682件 / trl_milestones 84件 / realization_pathway 830件 / signals 265件) を読み解いていく。Part II (第8章以降) は既存の学術成果ネットワーク (publications/awards/startups/AK 概念マッチング等) を維持する。

Chapter 01

概要 ── AO-DB とは何か

AO-DB は、学術知の産出物（学術アウトカム）を、原典の論文から、それを生み出した著者・所属・受賞・スピンオフ・特許・規格・政策翻訳までを一貫した識別子で接続する、ミラツク学術DBエコシステムの中核基盤である。

前身の FTT-DB（未来技術動向DB）は、10工学領域 × 4時代 × 規制成熟度の281レコードに整理された俯瞰DBであったが、AO-DBはこれを継承しつつ、論文単位の実データを抱える形に再設計された。FTT v2 が定義する30 domain（AI/Robotics/Bio/Energy/Materials/Quantum/Manufacturing/Mobility/Space/Information の10基幹軸＋拡張軸）に対し、AO-DB の論文 71,209 件が領域コードを保持し、その付与率は 95.46% に達する。

AO-DB の独自性は、論文を起点としつつも「アウトカム＝学術知の社会への投射」を多形態で抱えることにある。Wikidata 由来の Nobel/Turing/Fields/Kyoto/Japan/Abel の主要6賞 1,174 件、US-DB 由来の大学発スタートアップ 3,594 社が論文・著者と接続される。今後、特許（J-PlatPat）、規格（IEEE/ISO）、政策翻訳（内閣府／NIH／EU）の3層も同一スキーマで束ねる計画である。

3層アーキテクチャ

L1 学術コア：publications / authors / affiliations / citation_links / funding_grants — 論文と人と組織の関係。

L2 アウトカム層：awards / startups / patents / standards / policy_translations — 学術知が社会に転写された証跡。

L3 メタ層：outcome_domain_map / outcome_time_map / outcome_pathway_map / publication_concepts — FTT v2 領域コード・時期・経路・AK概念の付与。

Chapter 09

L1 学術コア ── 論文・著者・引用

publications（71,472）+ authors（21,355）+ affiliations（2,876）+ publication_authors（23,694）+ citation_links（5,014）が L1 を構成する。

publications は DOI / OpenAlex ID / arXiv ID / J-STAGE ID / CiNii ID の5つの外部識別子を抱え、いずれかが必ず付与される。citation_count・altmetric_score・fwci（Field-Weighted Citation Impact）の3指標を抱え、Phase 4-E で OpenAlex 由来の参照リスト 52,669 件を取得し、AO-DB 内部で双方向に接続された internal citation links が 5,014 件成立した（internal rate 3.16%）。

publication_authors は著者順序と corresponding author フラグを抱え、23,694 レコードで論文と著者の M:N 関係を構成する。著者の ORCID 接続率は 47.0% で、これは EX-DB（experts-db）や UPR-DB（university-press-releases）との横断接続の前提となる。
