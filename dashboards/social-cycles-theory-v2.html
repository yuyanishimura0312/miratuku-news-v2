Research Report / Theoretical Synthesis from 4 Databases

世紀的連鎖モデル
4DB統合による社会変動サイクル理論

本レポートは、ソーシャルイノベーション歴史構造DB（7,389事象）、偉人DB（9,178人物）、技術進化DB（1,191技術）、歴史統合ケースDB（20ケース）の4つのデータベースを統合し、人類社会の社会変動に内在する周期構造を経験的に検出した上で、独自の理論「世紀的連鎖モデル v2（Centennial Cascade Model v2）」を構築する。さらに、Kondratieff、Strauss-Howe、Modelski、Turchin、Polanyi、Acemoglu-Robinson、Carlota Perez など10の既存サイクル理論との対話を通じて、本モデルの位置づけを明確化する。

著者: 西村勇也 / 計算的検証: Claude Opus 4.7 + 4DB統合分析パイプライン
初版: 2026年5月7日

01要旨

本研究は、独立に構築された4つの構造化データベース（社会変革事象7,389件、偉人9,178人、技術1,191件、文明事例20件）を時系列的に統合し、紀元前1000年から紀元2000年の3000年にわたる社会変動の集積パターンを定量的に分析した。対数変換とトレンド除去を施した複合指標から、3つの発見が得られた。

第一に、社会変動の集積には約100年（中央値=100年、平均=126年）の周期が存在し、この周期は古代・古代末期・中世・近世のいずれにおいても安定していた。第二に、社会変革の3層（人物層・技術層・制度層）は連鎖的に運動し、特に人物層の集積が制度層の結晶化を50-75年先行する（相関係数 r=0.90, lag=-50年）。第三に、周期長は文明圏ごとに変動し、密に統合された文明（東アジア・アメリカス）は短い周期（100-125年）、覇権的文明（近現代西洋）は長い周期（275年）を示す。

これらの発見から、初期仮説「世紀的連鎖モデル v0」を構築し、Modelski Long Cycles、Turchin Cliodynamics、Strauss-Howe Generational Theory、Carlota Perez Technological Surges、Polanyi Double Movement など10の既存サイクル理論と照合した。修正後の Centennial Cascade Model v2 は、(1) 100年を人類社会の構造的時定数として確立、(2) Turchin の3圧力モデル（人口・エリート・財政）でメカニズムを基礎付け、(3) Strauss-Howe の4位相構造を周期内部に組み込み、(4) Carlota Perez の Installation/Deployment 二相性を技術層に統合した、多層的な周期理論として提示される。

02序論—問いの設定

社会には周期があるか。これは18世紀後半、Vico の歴史循環論以来、社会科学の最も大きな問いのひとつであった。Spengler は1000年スパンの文明寿命を、Toynbee は挑戦と応答による文明発展段階を、Kondratieff は50-60年の経済波動を、Strauss-Howe は80年の世代周期を、Modelski は100年のヘゲモニック周期を、Turchin は100-200年の世俗周期を提唱してきた。しかし、これらの理論はそれぞれ特定の地域・時代・領域を主たる検証対象としており、人類社会の長時間スパンで領域横断的に検証されることは少なかった。

近年、Peter Turchin らによるクリオダイナミクス（Cliodynamics）の進展は、歴史データの定量化と統計的検証の方法論を確立した。しかし、Turchin の研究も主として人口圧・エリート過剰・財政逼迫の3変数による国家崩壊サイクルに焦点が当てられており、社会変革の建設的側面（Social Innovation）と文明史的人物の出現パターン、そして技術進化の同時性を統合的に扱う研究は限られている。

本研究は、独立に構築された4つの大規模構造化データベース——(1) 5,000年の社会変革事象7,389件を集積した SI Framework DB、(2) 古代から現代までの人類史的人物9,178人を網羅した Great Figures DB、(3) 700万年の技術史1,191件を統計化した Tech Acceleration DB、(4) アレクサンドロス遠征から現代までの文明的事例20件を構造分析した Historical Cases DB——を時系列的に統合し、社会変動の集積パターンを領域横断的に検出することを試みる。

核心的な問いは次の3つである。第一に、社会変動の集積に普遍的な周期は存在するか。存在するならば、その周期長はどの程度か。第二に、社会変革の異なる層（人物・技術・制度）はどのような時間構造で連鎖するか。第三に、周期構造は文明圏ごとに普遍的か、それとも変動するか。これらの問いへの実証的回答から、独自の社会変動理論を構築することが本研究の目標である。

3.2 時系列バケット化

各DBから年代情報を抽出し、25年単位のバケットに集計した。バケット幅25年は、世代スパン（約25-30年）に対応し、また100-200年周期を解像できる最小単位として選択した。期間は紀元前1000年から紀元2000年とし、これは(1) 各DBで十分な事象密度が確保される範囲、(2) Turchin、Modelski らの先行研究が主に検証してきた範囲と整合する、二つの理由による。

3.3 トレンド除去

近代以降（特に1700年以降）、3つの層すべてで指数的な事象集積が観察される。これは社会の総合的進歩（Morris の Social Development Index と整合）の反映であり、純粋な周期成分を抽出するためにはトレンド除去が必要である。本研究では、各層の値に対して log(x+1) 変換を施した上で線形回帰トレンドを除去した残差成分を分析対象とした。

残差_t = log(値_t + 1) − (α × t + β)
複合指標_t = (残差_SI + 残差_GF + 残差_Tech) / 3

3.4 周期検出

残差時系列に対して、(1) 局所最大値検出（前後3バケット=75年で最大）、(2) prominence による絞り込み（背景からの突出度0.15以上）、(3) ピーク間隔の統計的記述、を実施した。並行して、層間のリード・ラグ関係を-150年から+150年まで25年刻みで相互相関分析した。

04発見1—100年周期の検出

複合指標の残差時系列に対する局所最大値検出により、紀元前1000年から紀元1700年までの期間に23のピークと14の谷が検出された。ピーク間の間隔分布は、中央値=100年、平均=126年であった。この周期長は、Modelski Long Cycles の主張する100年と完全に一致し、Turchin Cliodynamics の100-200年範囲の下限と整合する。

4.1 時代別の周期安定性

cycle compression hypothesis（時代を経るほど周期が短縮するという仮説）を検証するため、3000年を4つの時代に分割して周期長を比較した。

古代末期-中世 (AD1-1000)8114年100年
後期中世-近世 (AD1000-1700)5125年100年

3000年にわたって周期の中央値は100年で安定している。これは特筆すべき発見であり、人類社会には100年という構造的時定数が存在することを強く示唆する。近現代（1700年以降）では指数的成長が周期信号を圧倒し、明確なピーク検出が困難となるが、これは周期の消失ではなく、観測上の信号対雑音比の悪化として解釈される。

05発見2—三層連鎖（人物層→制度層 50-75年遅延）

偉人層・技術層・制度層の3層間で相互相関分析を実施した結果、特徴的なリード・ラグ構造が観察された。

5.1 偉人層 → 制度層の50-75年遅延

偉人の出生（25年バケット）と社会変革事象（25年バケット）の相関は、偉人層が制度層を50年先行する場合に最大（r = 0.900）となった。同時相関は r = 0.719 と低く、偉人層が25年・50年・75年・100年先行するすべての場合で同時相関を上回った。

この50年という遅延は、人間の発達心理学的観点から自然に説明される。偉人として歴史的痕跡を残す個人の多くは、25-50歳の活動期に主要業績を残す。彼らが乳幼児期・少年期に経験した文化的・物質的環境（時代精神）は、25-50年後の彼らの活動期に制度的革新として結晶化する。すなわち、ある時代の社会構造的条件が次の世代の人格形成を準備し、その世代が成人活動期に入る50-75年後に制度的変革として現出するという、緩やかな世代継承メカニズムが観察されているのである。

5.2 技術層と制度層の同時性

技術層と制度層の相関は、同時（lag=0）で最大（r = 0.945）であった。偉人層との50年遅延構造とは対照的に、技術と制度はほぼ同時期に集積する。これは、技術革新の社会的実装には制度的受容が同時に必要であり、技術と制度が相互前提的に発展することを示唆する。Carlota Perez が技術革命の Installation Phase（金融主導期）と Deployment Phase（生産主導期）として理論化した二相性は、本研究の発見と整合的である。

各文明圏ごとに同じ分析を実施した結果、周期長は文明圏ごとに有意な変動を示した。

密集して統合された文明圏（アメリカス先住諸文明・東アジア）は短い周期（100-125年）を、覇権的に拡張する文明圏（近現代以降の西洋）は長い周期（275年）を示す傾向が見られる。この変動は、以下の構造的説明と整合する。

  1. 密度仮説：人口密度と社会的相互作用密度が高い文明では、変動の伝播速度が速く、結果として短い周期が観察される。
  2. 規模効果：覇権的文明圏は地理的・人口的規模が大きいため、変動の波及・統合に時間がかかり、結果として長い周期が観察される。
  3. 断片化と統合の対比：南アジアや太平洋など地理的・政治的に断片化された地域では、各地域での独自周期が干渉し、合算した時系列では周期が長く見える可能性がある。

すなわち、100年は人類社会の下限もしくは密集統合系の固有値として現れ、覇権・断片化・規模拡大が周期長を伸ばす方向に作用する、という仮説が立てられる。

07発見4—危機谷の歴史的整合

残差時系列で検出された主要な「谷」（負のピーク）は、歴史学者が独立に同定してきた文明的危機期と高い整合性を示す。

これらの谷は単なる統計的アーティファクトではなく、独立した歴史学的研究で同定されてきた制度的・経済的・人口的危機期と密接に対応する。AD1675 の検出は、Eric Hobsbawm および Geoffrey Parker が「17世紀の一般危機（General Crisis of the Seventeenth Century）」として理論化した期間と完全に一致する。AD1375 はヨーロッパの黒死病後の社会的混乱、AD450 は西ローマ崩壊、AD225 は3世紀の危機の開始という、いずれも社会史の教科書に記述される主要な構造的危機である。

これは、本研究の検出方法が単なる数値的揺らぎではなく、実質的な社会的変動を捕捉していることの強い経験的支持となる。

08初期仮説—世紀的連鎖モデル v0

4つの発見から、以下の初期仮説 v0 を構築した。

v0 の3つの中核命題

命題1：100年の主周期

社会変動の集積は約100年（中央値=100年、平均=126年）の周期で生じる。この周期は古代から近世まで3000年にわたり安定している。

命題2：三層連鎖メカニズム

社会変革は3つの層——個人層（偉人）・物質層（技術）・制度層（社会的制度）——の連鎖的運動として展開される。特に、個人層の集積が制度層の結晶化を50-75年先行する。技術層は制度層と同時的に運動する。

命題3：危機-蘇生サイクル

深い谷（制度的混乱・危機）の後に必ずピーク（再生・革新）が続く。100-200年周期で「危機 → 集積 → 制度化 → 安定化 → 危機」の循環が観察される。

09既存研究との対話

v0仮説を10の既存サイクル理論と照合し、整合性・矛盾・修正方向を検証した。

9.1 強い支持を得た理論との関係

Modelski Long Cycles（1987）

Modelski の100年ヘゲモニック周期は、本研究の中央値100年と完全一致する。ただし、Modelski は1495年以降の世界政治覇権交代に焦点を当てる。本研究はこの周期長が紀元前1000年から確認されることを示し、Modelski 理論の射程を3000年に拡張する経験的基盤を提供する。

Turchin Cliodynamics（2003-2018）

Turchin の100-200年世俗周期は、本研究の中央値100年と整合（短い側）する。Turchin の3変数（人口圧・エリート過剰・財政逼迫）は、本研究の三層連鎖メカニズムと相同的に解釈可能である。

Turchin (2018) "Ages of Discord" は米国の政治不安定指数が約100年周期で振動することを示した。1830-1870、1910-1945、2010-2030 の3つの不安定期は、本研究の谷検出と整合する。

Carlota Perez Technological Surges（2002）

Perez の50-60年技術革命周期は、本研究の100年周期の半分に相当する。これは v0 1周期 = Perez 1.5-2周期と仮定すれば整合する。Perez の Installation Phase / Deployment Phase の二相性は、本研究の周期内部構造として組み込み可能である。

9.2 修正を要する理論との関係

Strauss-Howe 世代理論（1991）

Strauss-Howe の80年saeculumは、本研究の100年とは20年異なる。ただし、Strauss-Howe は米国史を主たる検証対象としている。本研究で西洋圏の周期が275年と長いことを考慮すれば、米国史の80年は本研究の主分析（古代から近世まで）とは異なるモードの可能性がある。Strauss-Howe の4位相（High/Awakening/Unraveling/Crisis）は、周期内部の構造として組み込む価値がある。

Kondratieff 50-60年波動（1925）

Kondratieff の50-60年資本主義経済周期は、本研究の100年の半分である。これを「v0 1周期 = Kondratieff 2周期」と仮定すれば、両者は階層的に整合する。Kondratieff は資本主義経済に限定されるため、本研究の3000年射程の中で Kondratieff が直接適用可能なのは1700年以降である。

9.3 階層的に位置づけ可能な理論

Spengler / Toynbee 文明寿命（1918, 1934）

Spengler の1000-1500年文明寿命は、本研究の100年周期より一桁長い。これは矛盾ではなく、階層的に位置づけられる。Spengler は文明全体の生命周期、本研究は文明内部の構造変動リズム——両者は異なる時間スケールでの社会変動を扱っている。

Acemoglu-Robinson 制度経済学（2012）

Acemoglu-Robinson の Critical Junctures（重要分岐点）概念は、本研究の谷期と対応する。彼らは周期論を否定するが、Critical Juncture の発生間隔を見ると100年単位で生じている事例が多い（黒死病、産業革命、グローバル化など）。

10修正後v2理論—Centennial Cascade Model v2

既存研究との対話を踏まえ、v0 を以下のように修正・拡張した v2 を提示する。

10.1 v2 の核心命題

命題A：100年は人類社会の構造的時定数

社会変動の集積周期の中央値は100年であり、これは古代から近世まで3000年にわたって安定している。100年は人類社会の構造的時定数として位置づけられる。文明圏ごとの周期長変動（100-275年）は、密度・規模・統合度に依存する派生現象である。

命題B：三層連鎖の時間構造

社会変革は個人層・技術層・制度層の3層連鎖として展開する。個人層が制度層を50-75年先行し（最大相関r=0.900 at lag=-50年）、技術層は制度層と同時的に集積する（r=0.945 at lag=0）。この遅延構造は、人間発達心理学の世代継承メカニズムで自然に説明される。

命題C：周期内部の4位相構造

100年周期は内部に4位相を持つ（Strauss-Howe inspired、25年×4=100年）。

Phase 1
0-25y
Crisis（危機・制度崩壊）
既存制度の機能不全が顕在化。Turchin の3圧力（人口圧・エリート過剰・財政逼迫）が同時集積。Polanyi 的二重運動の社会防衛側が活性化。
Phase 2
25-50y
Reconstruction（再建・人物層集積）
危機後の再建期。新世代が登場し、批判的人物が台頭。技術的試行錯誤が始まる。Schumpeter の創造的破壊の建設的局面。
Phase 3

11メカニズム—なぜ100年なのか

v2 が示す100年周期は、なぜ100年なのか。本研究は以下の3つのメカニズム的説明を統合的に提案する。

11.1 世代記憶メカニズム

第一の説明は、世代記憶のスパンに基づく。人間社会で「直接経験者の生存期間」は、おおよそ25-30年×3世代≒75-90年である。すなわち、ある世代が経験した社会的トラウマや成功体験は、その孫世代までは生きた記憶として伝承されるが、曾孫世代（4世代目）にとっては歴史教科書の記述に過ぎない。100年は、生きた記憶が消失し、構造的反復が可能になる時間スケールである。Strauss-Howe の世代理論はこのメカニズムを精緻化したが、本研究の100年は彼らの80年saeculumよりやや長い。これは検証対象の地域・時代の違いに由来する可能性がある。

11.2 制度的減衰メカニズム

第二の説明は、制度の物理的・社会的減衰スパンに基づく。憲法、宗教制度、官僚機構、インフラなどの主要制度は、設立後概ね80-120年で「構造的疲労」を示す。Acemoglu-Robinson の Critical Junctures 概念は、こうした制度的限界点を理論化したものとして再解釈可能である。Turchin の3圧力（人口圧・エリート過剰・財政逼迫）は、制度がこれらの圧力を吸収できなくなった瞬間に発生する。

11.3 技術習熟メカニズム

第三の説明は、技術革命の社会的実装に要する時間に基づく。Carlota Perez が示したように、ひとつの技術革命がInstallation（実験期）からDeployment（成熟期）まで完結するのには50-60年を要する。本研究の100年周期は、Perez の1.5-2周期に相当する。技術1サイクル（破壊期）+ 技術2サイクル（建設期）の複合構造として解釈可能である。

11.4 三つの統合

これら3つのメカニズムは、相互に独立ではなく相互強化的である。世代記憶の消失（25-30年）×3 ≒ 80-90年、制度疲労の限界（80-120年）、技術1.5サイクル（75-90年）—— いずれも100年前後で集中する。100年は、これらの異なる時間スケールが共鳴する「人類社会の固有振動数」として現れているのではないか。

13限界と今後の課題

13.1 限界

本研究の限界として、第一に、4DBの事象密度は時代によって不均等であり、特に古代の事象数は近代に比べて少ない。これにより古代の周期検出はノイズに敏感である。第二に、25年バケットは100-200年周期の検出には適切だが、より短い周期（Kondratieff 50年、Kitchin 5年）には対応できない。第三に、トレンド除去は線形を仮定したが、実際には Morris の Social Development Index は加速的（特に1500年以降）であり、より洗練されたトレンドモデルが必要である。第四に、本研究はあくまで集積の周期を扱っており、各事象の質的差異（破壊的か建設的か、地域的か全球的か）の周期構造は未検証である。

13.2 今後の課題

v2 理論を発展させるためには、以下の追加研究が必要である。

  1. 検証の拡張：他の構造化データセット（経済成長率、人口統計、紛争データ、特許出願）でv2の100年周期が独立に検出されるかを確認する。
  2. 位相の精緻化：4位相モデルを各文明圏の事象に適用し、Phase 1-4 の質的特徴がデータから区別可能かを検証する。
  3. 未来予測の検証：予測1-4を2030年代まで観測し、定量的に検証する。
  4. メカニズムの実証：世代記憶・制度疲労・技術習熟の3メカニズムを、各々独立に測定する代理指標を構築し、3つの効果の相対的寄与を分解する。
  5. 地域横断的精緻化：Modelski、Turchin、Strauss-Howe 等の理論を本研究のフレームワークに統合する形で、文明圏ごとの位相・周期差を体系的にモデル化する。

13.3 結語

本研究は、4つの独立データベースの統合分析から、人類社会の社会変動に約100年の構造的周期が存在することを経験的に確認した。この発見は、Modelski、Turchin、Strauss-Howe など個別領域で議論されてきた周期論を統合する経験的基盤を提供する。Centennial Cascade Model v2 は、(1) 100年を構造的時定数として確立し、(2) 三層連鎖の時間構造を明示し、(3) 4位相の内部構造を導入し、(4) 三つの相互強化的メカニズムを提示する点で、既存理論への独自貢献を果たす。
