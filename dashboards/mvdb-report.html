本レポートは、社会科学者が発してきた理論的命題・予測的言及103,569件に対して二段階判定（Stage 1: 経験的検証・Stage 2: 歴史検証）を行った結果を報告する。収集はAnthropicのClaude Haiku-4.5を使用したAIパイプラインにより行われた。

中心的な発見は、学術的言及の約49%が「まだ評価中（still_evolving）」であり、確証済み（vindicated）は3.0%、部分的確証（partially_vindicated）は2.8%にとどまるという非対称性である。これは社会科学知識の「進行性」を定量的に示す。

01 — Project Overview

プロジェクト概要と目的

言及検証データベース（Mention Verification Database: MVDB）は、社会科学の歴史において研究者が発してきた理論的・予測的命題を体系的に収集し、その後の歴史的事実によって検証することを目的として2026年5月に構築された。

社会科学の言及には「経験的に正しいか」という問いと、「歴史的にどう評価されたか」という問いの二層が存在する。本DBは前者をStage 1（経験的検証）、後者をStage 2（歴史検証）として分離して記録する。

対象スコープ

学術的バックグラウンドを持つ研究者による理論的・実証的命題のみを対象とした（academic_mention）。企業経営者や政治家による言及は別プロジェクトで管理する。対象分野は経済学・社会学・政治学・心理学・哲学・人類学・歴史社会学など社会科学全域に及ぶ。

二段階判定システム

  • S1 経験的検証（Stage 1）: その後の社会的実際・実証研究への適合を判定。confirmed / partially_confirmed / disconfirmed / contested / pending / too_early のいずれかに分類。
  • S2 歴史検証（Stage 2）: 長期的な学問的評価・パラダイム的位置・後代の再評価を判定。vindicated / partially_vindicated / refuted / contested / superseded / reinterpreted / still_evolving のいずれかに分類。

03 — Verification Results

検証結果の概要

Stage 2歴史検証の結果、最も多いverdictは「still_evolving（進行中）」であり、全体の49.3%を占めた。確証された言及（vindicated）はわずか3.0%、部分的確証（partially_vindicated）は2.8%にとどまる。争点化（contested）は9.0%、反駁（refuted）は0.05%だった。

Stage 2 Verdict分布

Verdict 意味 件数 割合

注目すべきは「refuted（反駁済み）」がわずか0.04%（55件）にとどまることである。これは社会科学における「反証」の困難さを示すと同時に、本検証で使用したヒューリスティックR1-R11が「まだ評価困難」なものをstill_evolvingに分類する保守的設計をとっていることを反映している。

時間軸（検証地平線）による差異

言及が行われた時点から現在（2026年）までの経過年数によって、verdictの分布が大きく異なる。特に「長期（80-150年経過）」の言及では vindicated と partially_vindicated の合計比率が相対的に高く、時間の経過が検証を容易にすることを示す。

注目すべきは心理学の vindicated 率の相対的高さである。同じ実証的手法を持つ経済学と比較しても、心理学では controlled experiment による直接的検証が可能であることが影響していると考えられる。一方で、経済学では still_evolving が17,221件（全言及の80%以上）と圧倒的多数を占めており、マクロ経済的命題の検証困難性を反映している。

06 — Key Findings

主要発見

発見1：社会科学知識の「未決定性」

学術的言及の49.3%が「still_evolving（進行中）」に分類され、確証済み（vindicated）は3.0%にとどまる。これは社会科学的命題の大半が長期的な検証過程にあり、単純な「正しい/誤り」の二項では評価できないことを定量的に示す。

発見2：時間と検証の非線形関係

短期（10-30年）では contested が圧倒的に多いが、長期（80-150年）では vindicated と contested がほぼ拮抗する。しかし150年以上経過した命題では再び評価が割れる（very_long層での reinterpreted の割合が高い）。これは「歴史的評価の安定化」が単調増加ではなく、長期的な再解釈の波に晒されることを示す。

発見3：refutedの希少性

「完全に反証された」言及（refuted）はわずか55件（0.04%）である。社会科学では物理学のような直接的な falsification がまれであり、誤った理論でも「部分的に正しい」と修正されながら存続するか、あるいは「それは別の問いだ」として再解釈される傾向がある。

発見4：分野ごとの検証可能性格差

心理学では vindicated が相対的に高く、経済学では still_evolving が圧倒的多数を占める。これは実験的手法の有無と、複雑な社会・制度条件の交絡という分野固有の方法論的制約を反映している。哲学的命題では概念的な「再解釈（reinterpreted）」が多く、これは命題の意味論的変化が時代とともに生じやすいことを示す。

発見5：14,020の知的系譜

データベースには14,020の研究者・学派・機関が登録されており、各々が平均7.4件の言及を持つ。最多言及の研究者はElinor Ostrom（76件、コモンズ論）、Henry Mintzberg（68件、組織論）、Axel Honneth（68件、承認論）であり、現代社会科学の「多声性」を体現している。

07 — Methodology

方法論的考察

自動検証ルール（R1-R11）の設計

Stage 2の歴史検証には、METHODOLOGY.mdに明記された11のヒューリスティックルール（R1-R11）を適用した。これらは発表年・経験的検証状態・研究者のノートなどから検証の判定を導く明示的・再現可能なアルゴリズムである。

  • R1 era_start ≥ 2010の場合 → still_evolving（時期尚早）
  • R2-4 1900-2010年の言及：confirmed → vindicated / partly_confirmed → partially_vindicated / disconfirmed → refuted
  • R5-6 1900年以前の言及：confirmed → vindicated (long_80_150) / partly_confirmed → partially_vindicated
  • R7-9 ノート情報：deprecated → superseded / contested → contested / "controversy"含む → contested
  • R10-11 デフォルト：era_start なし → SKIP / era_start あり → still_evolving

AI生成データの品質課題

Wave A-Fで収集した言及（約57,000件）はClaude Haiku-4.5によって生成されたものである。AIが生成した命題は実際の研究者の発言・論文からの直接引用ではなく、研究者の著作から推定された「代表的命題」である点に注意が必要である。将来的には実際の論文テキストからの直接抽出との比較検証が課題として残る。

なお、domain分類の一部に研究者名（Robert、John等）が誤って入力されているケースが確認された（waveF生成時のJSON解析の軽微なバグ）。これらは47,535件を`social_science`に一括修正済みであり、claimants.primary_domainも同様に整理完了した（2026-05-06）。

さらに、Wave A-Fで生成された言及のうち経験的検証ステータス（confirmed/partially_confirmed等）がnotes列にのみ記録されていた57,835件を、`empirical_verifications`テーブルに正式移行した。これにより Stage 1 検証済み件数は 121,717件から 179,552件（+47.5%）に拡大した。

08 — Future Work

今後の課題

本データベースは量的目標（100K）を達成したが、質的深化のためにいくつかの方向性が考えられる。

優先課題

  • 01 Stage 1経験的検証の精緻化: notes移行により 179,552件に拡大完了。現在pending（51,538件）に対して、Semantic Scholar APIや論文データベースを用いた根拠付きの経験的検証を追加する。
  • 02 domain・subdomain分類のクリーニング: Wave F生成時の軽微なバグによりdomain列に研究者名が混入した件（約5,000件）の修正。 → 47,535件を`social_science`に一括修正済み（2026-05-06完了）。
  • 03 実論文からの言及抽出: AI推定ではなく実際の論文テキスト（Semantic Scholar）から命題を抽出する pipeline の開発。
  • 04 言及間関係（mention_relations）の構築: 命題間の「引用・反証・拡張」関係ネットワークを整備し、知的系譜の可視化を行う。
  • 05 一般言及（general_mention）の整理: 36,191件の一般言及（企業・政府等）についても検証フレームを整備し、実践知と学術知の比較分析を可能にする。
