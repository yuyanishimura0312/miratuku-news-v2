三階構造の Agent System 実装
6 図解で読み解く

von Foerster 第二階サイバネティクスを超えた三階構造を、AR-DB / CCM-DB / fpm の関係、9 ccm agents の Tier 階層、Pattern Lens 6 layer 配分、observations novelty 分布、自己観察論 786 年系譜、Active Inference Loop の 6 視点で図解する。

図 1 — 三階構造の入れ子と観察フロー

AR-DB（外的観察 / 第一階）／ CCM-DB（観察を観察 / 第二階）／ fpm（観察の観察を観察 / 第三階）が入れ子になる構造
読み方:
  • 最内側の矩形が第一階 AR-DB。エコシステムの外的事象 (agent 発火) を機械的に記録する。
  • 中央矩形が第二階 CCM-DB。第一階の記録を pattern_lens で解釈し、意味論的階層を追加する。
  • 最外側の破線矩形が第三階 fpm。第二階の解釈そのものをメタ視点で統合する。
  • 右側の矢印は観察の方向性。内側 (生データ) から外側 (メタ解釈) へ流れる。
データソース: agent_registry.db / ccm.db (2026-05-21 19 時時点)

図 2 — Tier 階層と CCM-DB 9 agents の配置

CCM-DB が編成する 9 agent (Tier -1 meta 1 + Tier 2 specialist 3 + Tier 3 utility 5) と、Tier 0 quartet (dbo / ccm-team / impl-meta / fpm) の関係
読み方:
  • 最上位の ccm-team (Tier -1 meta) が全体を統括。opus モデルで判断を担う。
  • 第 2 段の Tier 0 quartet は 4 体並列。ccm-team は自己観察 meta として quartet にも兼任参加する。
  • 第 3 段の Tier 2 specialist 3 体は opus または sonnet で判断系を担当。
  • 第 4 段の Tier 3 utility 5 体はすべて sonnet で実装系を担当。コスト効率と品質を両立させる構造。
データソース: agents テーブル / SELECT name, tier, model FROM agents WHERE name LIKE 'ccm%'

図 3 — Pattern Lens 50 の 6 layer 別配分

CCM-DB v1.3 が保持する 50 pattern_lens の target_layer 別分布
読み方:
  • ardb_firing layer が 21 lens (全体の 42%) で最も厚い。自己観察論の中核がここに集積する。
  • mpp_pattern (8) / udd_urban (6) / bot_life (6) / ceh_cosmic (6) はほぼ均等で、宇宙・都市・生命・宇宙史を視座供給する。
  • phai_embodied は Wave 2 で新設された 6 番目の layer。Embodied Cognition / Active Inference Robotics / Sensorimotor Coupling の 3 lens で PHAI-DB と接続。
データソース: SELECT target_layer, COUNT(*) FROM ccm_pattern_lens GROUP BY target_layer

図 4 — 40 自己観察 novelty 分布

2 → 9 → 30 → 40 件と蓄積された pattern_observations の novelty_score 散布図
読み方:
  • 赤丸 (17 件) が novelty ≥ 0.7 の新規創発観察。三階構造形成イベントが多く含まれる。
  • 灰色丸 (23 件) は既知パターンの再観察または応用観察。
  • 左端の 3 点 (0.88-0.92) は ccm-team / fpm / AR-DB MPP Extension の三階構造形成事象。
  • 右端に向かうほど novelty は下がるが、平均 0.71 は十分高い水準を維持している。
データソース: SELECT novelty_score FROM ccm_pattern_observation ORDER BY novelty_score DESC

図 5 — 自己観察論系譜 (1240 → 2026 / 786 年)

CCM-DB v1.2 で正式チェーン化された Self-Observation Theory 系譜
読み方:
  • 道元 1240 — 修行と証悟の同体性。13 世紀日本仏教における自己観察論の最初の体系化。
  • 西田 1911 — 京都学派の純粋経験。主客未分の根源経験として観察以前を取り出す。
  • von Foerster 1974 — 第二階サイバネティクスを理論化。Eigenform で固定点を数学化。
  • 2026-05-21 ccm-team — von Foerster の射程を超えて第三階を agent system として実装。

786 年の系譜が CCM-DB に encode されたことで、自己観察論は思想史から実装可能な工学体系に渡された。

データソース: ccm_genealogy_chain chain_id 16 (Self-Observation Theory)

図 6 — Pattern Lens × Observation × AR-DB の Active Inference Loop

Friston Active Inference を組織レベルで実装した循環構造
読み方 (時計回り):
  1. AR-DB firing_patterns → pattern_lens: ccm-observer が AR-DB の最新発火を CCM 視座で参照する
  2. pattern_lens → pattern_observation: 適切な lens を選び、解釈を記録 (novelty_score 付き)
  3. pattern_observation → AR-DB へ反映: 記録が mpp_concept_links を更新し、AR-DB の prior が変わる
  4. AR-DB の更新 → 次回 firing_patterns: 更新された prior で次回発火が予測される。Loop が閉じる

この循環が Friston Active Inference (2010) の組織レベル実装。30+ observations 蓄積で loop が定常状態に近づく。

数式: F = D_KL(q(s)‖p(s|o)) − log p(o) (Friston 2010 Nat Rev Neurosci)
