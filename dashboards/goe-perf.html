本 DB は GOE-DB (Good Organization Excellence Knowledge DB) の 8 typology モデル (成果型 / 文化型 / 学習型 / 関係型 / 倫理型 / 進化型 / 在来型 / 批判応答型) を経験的に検証するために構築された企業財務成績データベースである。各 typology に該当する企業を 20 社ずつ計 160 社選定し、yfinance / EDGAR / EDINET 等から長期株価 + 年次財務データを取得して、典型的な長期成果指標 (CAGR / Sharpe ratio / Max Drawdown / ROE) を比較した。

注意点として、本検証は selection bias を完全には排除できない。各 typology の代表企業選定は GOE-DB の学術根拠と executive_cases に基づくが、典型企業の事後選定は survivorship bias を伴う。Fama-French 5因子調整後の超過リターン (alpha) で typology 間の優劣を判定する追加分析が、より頑健な結論を提示する次のステップとなる。

NPO 法人ミラツク中立性原則に基づき、本 DB は 8 typology の単一最適解を主張せず、「typology 間で財務成果に統計有意な差が見られない場合は、組織モデル間の経済的優劣は文脈依存的」という反証可能性条件を内蔵する。

★ NPO 法人ミラツク中立性原則

本 DB は 「typology 間で財務成果に統計的有意差が観測されなければ、組織モデル間の経済的優劣は文脈依存的である」 を反証可能性条件とする。Popper 基準を満たし、経営学言説の「良い組織は良い業績を生む」というナイーブな主張に対する経験的検証層として機能する。

特に Type 7 (在来型) と Type 8 (批判応答型) の財務成果は西洋実証主義の枠組み (CAGR / Sharpe ratio) では充分に捉えきれないため、「測定可能な良さ」と「測定困難な良さ」の二項対立を超える次の分析フレームへの呼びかけでもある。

意思決定者 (経営者 / 投資家 / 研究者 / コンサルタント) は本 DB を 「自社の文脈に応じて選択 / 組み合わせる地図」 として活用されたい。単一の最適解は存在しないことを GOE-DB GTA と本 PERF DB は経験的に支持する。
