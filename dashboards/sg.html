Strategy Concepts DB SC

戦略という横串概念を 12 サブフィールド（軍事・経営・競争・ゲーム理論・地政学・マーケ・イノベ・組織・プラットフォーム・行動・進化・政策）で統合した学術DB。/adb v1.1 Phase 0-15 方法論に基づき、世界最高品質基準（量100% / 多言語30%+ / IRR≥0.80 / 18 DB cross_ref / 年次自動更新）の到達を目指す。

本DBの位置づけ

「戦略」は単一学問分野ではなく、軍事・経営・ゲーム理論・地政学・進化生物学・認知科学・公共政策にまたがる横串概念である。本DBは既存 MG-DB（経営学6,314件）/ IN-DB（イノベーション9,839件）/ Startup-DB（9,031件）/ SS-DB（社会科学3,678件）と strategy_cross_db_refs で連携しつつ、独自に軍事戦略・地政学・ゲーム理論・進化戦略・認知戦略・公共政策戦略を主軸として補強する横串DBとして設計されている。

10 / 使い方

SQLite 直接照会

sqlite3 ~/projects/research/strategy-concepts-db/data/strategy.db
> SELECT * FROM strategy_concepts WHERE subfield='SF01' ORDER BY era_start LIMIT 10;
> SELECT * FROM strategy_concept_relations WHERE source_concept_id='SC_SF02_001';
> SELECT target_db, COUNT(*) FROM strategy_cross_db_refs GROUP BY target_db;

専属エージェント

/sg エージェント（Phase 5 完了で起動可能）。「孫子の戦略思想を引いて」「Porter 5 Forces の関連概念」「ゲーム理論的戦略の系譜」等の問いに答える。

深化
