ANSWER Prompt Kit DB (APK-DB)

esse-sense ANSWER+ システムが事業仮説型の問いに対し一貫品質の回答を生成するための、システムプロンプト・制御プロンプト・指示プロンプトのデータキット。CASE 01-04（人と機械の共生／バイオものづくり／地域経済の活性／家電メーカー新規事業）で実証された「候補プール → 構造化 → 戦略選別 → Top10推薦 → 用語解説」のワークフローを、7カテゴリの再利用可能な部品に分解し、組合せで多様な事業仮説に応答できる基盤を提供する。

1. 本DBについて

APK-DB は esse-sense ANSWER+ システムの「プロンプト工学」を構造化したデータベースである。23.5万人規模の研究者DB（kaken_researchers + researcher_vectors）への検索結果に対し、構造化されたレポートを一貫品質で生成するための、67本のプロンプトテンプレートと28語の用語解説辞書を内包する。

SystemPrompt（基盤人格）・ControlPrompt（品質制御）・TaskPrompt（タスク指示）・InputAdapter（入力前処理）・OutputFormatter（出力整形）・FailSafe（失敗時定型）・Glossary（用語解説）の7カテゴリで構成され、prompt_relations で「合成」「優越」「依存」「衝突」の関係を表現する。

4. 制御プロンプト6ルール

ANSWER+ システムの出力品質を担保する6つの制御ルール。CASE 02（バイオものづくり）で初回実装、CASE 04（家電メーカー新規事業）で再適用された。

  1. 研究者の氏名は省略せずに必ずフルネームで記載してください
  2. 報告レポートの体裁を取ります。必ず必要な項目は「タイトル」「概要」「本文」です。その他は指示文に応じて適切な項目と体裁で記載してください。
  3. 文章は入力された言語に合わせて記載してください（ex、日本語→日本語、英語→英語）
  4. 作成不能な指示が入力された場合（画像で生成、音声で生成、ファイルを作成、他）、「指示いただいた内容は作成を行うことができません ※esse-senseのANSWERは、テキストで作成できる回答のみ作成することができます。テキストで作成できる内容を指示ください。」と回答してください。
  5. タイムアウトや文字数超過などの場合はその旨を記載して回答に添えてください。
  6. 一般のビジネスマンがあまり使わないような専門用語が解答に含まれる場合は、レポート下部に用語解説を加えてください

6. 用語解説辞書
