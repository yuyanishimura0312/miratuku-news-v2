01 — Overview

Circulation Knowledge Database

生命・宇宙・物質・経済・社会の 15 サブフィールドを横断する循環の学術DB — CIRC-DB v1.0

循環は、自然科学・社会科学・人文学を貫く最も普遍的な構造原理の一つである。炭素が大気・海洋・土壌を巡り、熱が仕事に変換され散逸し、資本が投資・生産・消費を経て再び蓄積される。Circulation Knowledge Database（CIRC-DB）は、このような循環現象を扱う学術概念を 15 サブフィールド横断で 689 件収録し、数式 118 件・アルゴリズム 74 件・25 の既存学術 DB との接続リンク 5,015 件を持つ Production 品質の統合知識基盤である。

非西洋起源の概念が 25.3% を占める点が本 DB の際立った特徴である。五行循環論・アーユルヴェーダのヴァータ-ピッタ-カパ循環・Ibn Khaldūn の文明興亡サイクル・Maya の水貯蔵技術・オーストラリア先住民のソングライン——これらは欧米近代科学とは独立に循環の構造を発見・定式化した。本 DB はその系譜を科学的・文化的に等価に記述する。

04 — Algorithms

アルゴリズム・疑似コード

循環系の数値シミュレーションに用いられる代表的アルゴリズム 74 件から 5 件を掲載

循環系のシミュレーションには、常微分方程式の数値積分（Euler 法・Runge-Kutta 4 次法）から、エージェントベースモデル・モンテカルロ法・ネットワーク動態解析まで多様な手法が用いられる。Lorenz 系の RK4 積分は混沌的挙動の可視化に、Kuramoto モデルのシミュレーションは同期現象の閾値分析に不可欠である。

サイバネティクス・システム numerical_integration
System Dynamics Euler積分
Euler Integration for System Dynamics
INPUT: F(x,t): 微分方程式, x0: 初期値, dt: タイムステップ, T: 終了時刻
t ← 0; x ← x0
WHILE t < T:
    x ← x + F(x,t) * dt
    t ← t + dt
RETURN x(t) trajectory
時間計算量: O(n)
大気循環 numerical_integration
Lorenz系RK4積分
Lorenz System RK4
INPUT: sigma=10, rho=28, beta=8/3, dt=0.01, T=50
x,y,z ← (0.1, 0, 0)
FOR t in range(0, T, dt):
    # RK4 ステップ
    k1 = f(x, y, z)
    k2 = f(x+k1[0]*dt/2, y+k1[1]*dt/2, z+k1[2]*dt/2)
    k3 = f(x+k2[0]*dt/2, y+k2[1]*dt/2, z+k2[2]*dt/2)
    k4 = f(x+k3[0]*dt, y+k3[1]*dt, z+k3[2]*dt)
    x,y,z ← x,y,z + (k1+2k2+2k3+k4)*dt/6
OUTPUT: 3D trajectory (Lorenz attractor)
時間計算量: O(n)
生態フロー numerical_integration
Lotka-Volterra数値シミュレーション
Lotka-Volterra Simulation
INPUT: alpha, beta, delta, gamma (パラメータ), x0, y0 (初期個体数), dt, T
x, y ← x0, y0
FOR t in range(0, T, dt):
    dx = (alpha*x - beta*x*y) * dt
    dy = (delta*x*y - gamma*y) * dt
    x, y ← x+dx, y+dy
OUTPUT: x(t), y(t) 時系列 + 位相平面軌跡
時間計算量: O(n)
力学系・フィードバック numerical_integration
Kuramoto同期シミュレーション
Kuramoto Synchronization
INPUT: N (振動子数), omega_i (固有角速度, 正規分布), K (結合強度), dt, T
theta_i ← random uniform [0, 2*pi] for i=1..N
FOR t in range(0, T, dt):
    FOR i in 1..N:
        d_theta_i = omega_i + (K/N)*sum_j(sin(theta_j - theta_i))
        theta_i ← theta_i + d_theta_i * dt
    r = |mean(exp(i*theta_k))| # 秩序変数
OUTPUT: r(t) 時系列 (K < Kc: r→0, K > Kc: r→1)
時間計算量: O(N²)
力学系・フィードバック
前進オイラー法
Forward Euler Method
given f,t,y,h,N
for n=0..N-1:
  y = y + h*f(t,y)
  t = t + h
return y
05 — Genealogy Timeline

概念年代タイムライン

1600 年から 2026 年までの近代的循環概念の発展。赤点 = 非西洋起源

Carnot サイクル（1824）による熱力学的循環の定式化、Darwin の自然選択（1859）が食物連鎖進化に与えた影響、Lotka-Volterra 方程式（1925）による捕食者-被食者の数理化——これらは近代科学における循環論の確立を示す節点である。20 世紀後半には Lorenz（1963）の混沌理論、Wiener のサイバネティクス（1948）、Maturana-Varela のオートポイエーシス（1972）が加わり、循環の概念は線形的因果論を超えた複雑系の言語へと昇格した。

反証可能性と Critical View

五行論・アーユルヴェーダ等の伝統的循環論は、科学的方法論で操作化・反証可能化された概念と、形而上学的・規範的な性格が強い概念が混在する。本 DB では circ_type 列で "principle"（原理）/ "model"（モデル）/ "theory"（理論）/ "framework"（枠組み）/ "phenomenon"（現象）を区別し、科学的地位の差異を明示している。伝統医学概念には applicable_range 列で「現代科学的検証の状況」を付記している。偽科学リスクの管理は boundary_conditions テーブルで各概念の適用限界を明示することで対処する。
