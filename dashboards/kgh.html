08 / NEXT

Wave 2/3 展望

Wave 1 は方法論検証としての MVP。Wave 2 では系譜リンク密度を倍化（現状 0.5 → 1.0+）し、空白文明圏（中央アジア・東南アジア・北米先住民）を優先補完する。media_propagation_links テーブルを新設し、知の伝播における媒体の役割（口承 → 写本 → 印刷 → デジタル）を可視化する。

Wave 3 では citation_chains テーブルで多段引用チェーン（例: アリストテレス → イブン・スィーナー → アクィナス → デカルト → カント）を追跡し、10,000+ events 規模へ拡張する。Great Figures DB との双方向 cross_ref も自動マッピングする。
