KGH-DBという試み

世界中の知は、いつ、どこで、誰によって、どのような媒体を通じて生まれたのか。この問いに体系的に答えることは、これまで非常に難しかった。哲学史は哲学者の系譜を追い、科学史は科学者の系譜を追い、技術史は発明の系譜を追ってきたが、これらを横断する「知の生成史」の統合的なデータベースは存在しなかった。

KGH-DB（Knowledge Genesis History Database / 知の生成史DB）は、その欠落を埋めるために設計された。古代から現代までの人類の知識生産を、地域・時代・分野・主体・媒体という五つの軸で構造化し、知の発生点（誰が・どこで・いつ・何を）と系譜（誰から・どう影響を受けて・どう次に伝わったか）を最大解像度で追跡可能にする。

本書は、Wave 1 MVP として構築された404件の知の発生イベント、182件の主体（学派・共同体・機関・伝統・思想潮流）、151件の系譜リンクを、ナラティブとして読み解く教科書である。ダッシュボード（kgh.html）が定量的概観を提供する一方、本書は質的な系譜を辿る。

第一章

知を五つの軸で読む

KGH-DB の中核設計は、知の発生イベントを単独に並べるのではなく、五つの軸で結びつけることにある。

第一の軸は地域である。12文明圏（西欧、東アジア、南アジア、イスラム圏、メソアメリカ、サブサハラ、北アフリカ、中央アジア、東南アジア、オセアニア、アンデス、北米）を等価に扱う。西洋中心主義の学術DBが多い中、KGH-DB Wave 1 では非西洋の知が59.2%を占める。これは偶然ではなく、設計上の決断である。

第二の軸は時代である。先史・古代・古典古代・中世・初期近代・近代・現代・21世紀の8区分。線形進歩史観を採用しない。例えば「中世」は西欧の暗黒時代という旧来の偏見ではなく、イスラム黄金時代、宋元中国、グプタ後期インド、マヤ古典期後期、サブサハラのマリ・グレートジンバブエが並列的に光る時代として記述される。

第三の軸は分野である。哲学・思想、数学・自然科学、技術・工学、芸術・文芸、宗教・霊性、伝統知・実践知の6分野。重要なのは「伝統知」を独立した分野として等価に扱う点である。ヨルバの伊法占い、ポリネシアの天測航法、マオリのワカパパ系譜、オーストラリア先住民のソングラインは、ギリシア哲学やニュートン力学と同じ重みで記録される。

第四の軸は主体である。個人主体は Great Figures DB（9,178人物）への外部参照（gf_person_id）で分業し、KGH-DB は学派・共同体・機関・伝統・思想潮流という集合的主体に集中する。プラトン個人ではなく「アカデメイア」、孔子個人ではなく「諸子百家」、アル=フワーリズミー個人ではなく「バイトゥル・ヒクマ」を主体として記録する。なぜなら知の生成は本質的に集合的だからである。

第五の軸は媒体である。口承・身体伝承、碑文・刻文、写本、印刷、学術雑誌、デジタル、図像・芸術作品、物質的人工物。媒体は知の伝播経路を決定する。グーテンベルクの活版印刷以降、知の伝播速度は質的に変わった。同時に、口承伝統が文字伝統よりも劣るという旧来の偏見も明確に退ける。

第二章

非西洋の知を中心に置く

KGH-DB の最も重要な設計思想は、非西洋の知識生産を「補足」ではなく「中心」に置くことである。Wave 1 では59.2%が非西洋イベントだ。この比率は、世界人口における非西洋人口比率に近い。

これは政治的姿勢ではなく、認識論的姿勢である。例えばインカのキープ（結縄文字）は、ヨーロッパの文字体系と全く異なる原理で行政・歴史・物語を記録する高度な知識体系である。マーシャル諸島のスティック・チャート（海流図）は、太平洋の波の干渉パターンを物質的に符号化した航海技術であり、現代海洋学に再評価されている。

以下は Wave 1 に含まれる非西洋の知の発生イベントの一部である。

アシャンティ王国とゴールデン・ストール（サブサハラ・近代・哲学・思想・1701年）。ガーナのアシャンティ王国（1701-1957）がアコム神官オコムフォ・アノチェにより建国され、ゴールデン・ストール（黄金の椅子）を主権の象徴とした政治神学を確立。同時に高度なココア・金交易を発達させ、植民地化と独立運動を経て現代ガーナの基層文化に。

宋学（新儒学）の確立（東アジア・中世・哲学・思想・1175年）。北宋から南宋にかけて周敦頤・程顥・程頤・朱熹（1130-1200）らが仏教・道教の形而上学を取り込みながら儒学を再構築した。朱熹の『四書集注』は理（形而上的原理）と気（物質的力）の二元論を確立し、科挙制度を通じて東アジア全域の教育・行政・倫理観の基盤となった。知識と実践の統一（知行合一）を説き、日本江戸時代の朱子学にも直結する。

ティンブクトゥのイスラム学術センターの形成（サブサハラ・中世・宗教・霊性・1300年）。西アフリカのマリ王国・ソンガイ帝国下（14-16世紀）でティンブクトゥは三大モスク（サンコレ・ジンガレベル・シディ・ヤヒア）と付属マドラサが集積した学術都市として繁栄した。最盛期に25,000人の学生が神学・法学・文学・数学・天文を学び、70万冊を超える写本が現在も保管されている。サハラ交易路を通じた金・塩・知識の流通拠点として機能した。

孫武『孫子兵法』（東アジア・古典古代・技術・工学・-500年）。春秋末期の呉の軍事思想家孫武（前544-前496頃）が著した『孫子』13篇は戦わずして勝つ・知彼知己・地形・用間など戦略思想の古典。2,500年にわたり東アジアの軍事・政治・現代経営戦略に影響。

アボリジニ・ドリームタイム宇宙論（オセアニア・先史・宗教・霊性・-50000年）。オーストラリア先住民が約65,000年継承する世界観Tjukurpa/Dreamingは、創造期の祖霊が大地・動物・人間を生み出した時間と現在を同時に貫く宇宙論。ソングライン（既存）と共に法・宗教・芸術・親族関係・土地知識を統合する世界最古の連続宗教文化。

これらは「西洋哲学を理解するための背景」ではない。それぞれが独立した知の生態系である。KGH-DB は系譜リンクで西洋知識との接続を記録するが、それは従属関係ではなく、平等な相互作用関係として記録される。

第三章

系譜という織物

知は単独に発生しない。前の知を継承し、批判的に乗り越え、別文化圏から翻訳され、思いがけない結合によって新たな知が生まれる。KGH-DB は151件の系譜リンクで、この織物を可視化する。

系譜は8種類に分類される。direct_citation（直接引用）、translation（翻訳）、commentary（注解）、mentor_disciple（師弟関係）、critical_reception（批判的受容）、synthesis（総合）、parallel_development（並行発展）、transmission（地域間伝播）。それぞれに evidence_type（直接言及・文書参照・師弟関係・同時代推定）と confidence_level の2軸が付与され、ハルシネーション抑制のための明示的な証拠管理が行われる。

これらの系譜から見えてくるのは、「西洋哲学が独自に進化した」という旧来の物語が史実と異なることだ。アリストテレスはバイトゥル・ヒクマでアラビア語に翻訳され、アヴェロエスらの注解を経てアクィナスのスコラ哲学に届いた。アル=フワーリズミーの代数学はインドのブラーマグプタを継承し、12世紀トレド翻訳学派でラテン語化され、中世ヨーロッパ大学で標準教科書となった。知は文明圏を超えて流れる水のように移動する。

第四章

媒体が知の形を決める

同じ内容の知でも、口承で伝わるか、写本で伝わるか、印刷で伝わるかによって、その形は決定的に変わる。媒体は単なる入れ物ではなく、知の生成と伝播の様式そのものを規定する。

口承の時代、知は身体に宿る。ポリネシア航海の天測知識はナビゲーターの身体技法として伝承され、書き記すことができないほど精密な体感的判断を含む。グリオ（ジャリ）の歴史伝承、ヨルバの伊法占い、オーストラリア先住民のソングラインも同様に、口承と身体実践を不可分の知識体系として保持する。これらは「文字以前の素朴な知識」ではなく、文字に翻訳した瞬間に失われる知の様式である。

写本の時代、知は希少財となる。ナーランダー大学やバイトゥル・ヒクマやアレクサンドリアのムーセイオンは、写本を集積する知的拠点として機能した。一つの写本が消失すれば、その知識自体が失われる脆さがある。一方で、写本は注解と批評を蓄積する基盤を提供した。スコラ哲学の方法論は、写本余白への注解という物理的実践と不可分である。

1040年代の毕昇による活字印刷と、1455年のグーテンベルクによる活版印刷は、知の存在様式を質的に変えた。ルター宗教改革も啓蒙主義の百科全書も、印刷なくしては成立しない。同時に、印刷は中央集権的な検閲対象ともなった。知の大衆化と権力の検閲は同じコインの裏表である。

学術雑誌の登場（17世紀フィロソフィカル・トランザクションズ以降）は、査読制度と知識生産の専門分業を生んだ。20世紀のデジタル革命と21世紀のAI生成は、再び知の様式を変えつつある。KGH-DB の media 軸は、こうした媒体変容を構造的に記録する。

第五章

既存64+DBとの統合層として

KGH-DB は単独のDBではない。ミラツクが構築してきた既存64+ DB（Great Figures、Era Talents、Phil、LIT、MG、Innovation、Anthropology、Traditional Knowledge、Myth Narratives、Historical Cases、CTI v2、CLA、SI Framework、GC-DB 等）の上に立つ統合層（synthesis layer）である。

例えば「ナーガールジュナの空の哲学」というイベントを記録するとき、KGH-DB は人物データを持たない。代わりに gf_person_id で Great Figures DB を参照する。哲学概念の詳細は Phil-DB を参照する。学派構造は KGH 自身の agents テーブルで記録する。これにより各DBが専門化し、重複を回避しつつ、cross_db_refs テーブルを介して全体が一つの知の生態系として機能する。

Wave 1 では4023件の cross_db_refs を13個のDBに対して構築した。今後の Wave で、この接続密度はさらに高まる。最終的に、ある研究者が「アクィナスの自然法思想がアリストテレスからイブン・スィーナー経由でどう変容したか」と問うとき、複数DBが連動して系譜・人物・概念・原文・社会変容を統合的に返せる状態を目指す。

第六章

Wave 1 の限界と Wave 2/3 への展望

Wave 1 MVP は方法論検証としての段階である。明示しておくべき限界がある。

第一に、404件のイベントでは網羅性は不足する。6文明圏×5時代×6分野の180セルのうち、Wave 1 で充填されたのは40%超に留まる。中央アジア、東南アジア、北米先住民、オセアニアのアンディアン以外の地域は空白セルが多い。Wave 2 では空白セル優先補完戦略で500-1,000イベント規模へ拡張する。

第二に、系譜リンクの密度（イベント数の50.9%）はまだ薄い。Wave 2 では系譜リンク密度を倍化し、media_propagation_links テーブルを新設して「どの媒体で知が伝わったか」を構造化する。

第三に、引用チェーンの多段追跡は未実装である。Wave 3 では citation_chains テーブルで「アリストテレス → アヴェロエス → アクィナス → デカルト → カント → ハイデガー」のような多段伝播を構造化し、10,000+ events 規模へ拡張する。

本書はその出発点である。世界中の知の生成史を精緻に追うという目標は遠いが、Wave 1 で構造的基盤は確立した。Wave 2、Wave 3 を通じて、人類の知の生態系全体を可視化するDBへと育てていく。
