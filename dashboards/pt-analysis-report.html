このレポートは、Poetics DB v2.3（2,825概念／7,344系譜関係／2,768原著引用／8,084詩文／8,660三項リンク）の全面解析に基づき、詩学という分野が二千五百年にわたり形成してきた構造と系譜を俯瞰する試みである。データはプラトン『国家』前380年頃のミメーシス批判から、二〇二〇年代の認知詩学・デジタル詩学に至るまでを包括し、十二のサブフィールド（古典詩学・修辞学・弁論術・構造主義詩学・ロシア・フォルマリズム・近代美学・現象学的詩学・中世ルネサンス詩学・ポスト構造主義詩学・受容理論・認知詩学・比較詩学・デジタル詩学）に分類されている。

第1章：概念分布の文明史的非対称

十二のサブフィールドを概念数で並べると、最大は古典詩学の四百六十一件、最小はロシア・フォルマリズムの百五十八件と、約三倍の幅がある。だがこの数字を時代分布で割り戻すと、まったく違う風景が見えてくる。古典詩学の概念のうち約七十パーセントが古代から中世（紀元前後から千五百年）に分布し、二十世紀以降の項目はわずか七件しかない。これに対しロシア・フォルマリズムは百五十六件のうち百五十六件、すなわち事実上全件が二十世紀（一九一〇年代以降）に集中している。

ここから読み取れるのは、詩学の十二領域が二つのクラスタに分裂しているという事実である。第一クラスタは「長期堆積型」——古典詩学・修辞学・比較詩学・中世ルネサンス詩学の四つで、これらは紀元前から二十世紀まで連続的に概念を蓄積してきた領域である。プラトンのミメーシス批判（前三八〇年頃）からアリストテレス『詩学』（前三三五年頃）、ホラティウス『詩論』（前一九年）、ロンギノス『崇高論』（一世紀）、聖アウグスティヌスの寓意論（四世紀）、トマス・アクィナスの霊的意味論（十三世紀）、カステルヴェトロ『詩学注解』（一五七〇年）、ボワロー『詩法』（一六七四年）、コールリッジ・想像力論（一八一七年）まで、約二千年にわたる累積的議論として展開してきた。

第二クラスタは「二十世紀爆発型」——ロシア・フォルマリズム・構造主義・現象学的詩学・受容理論・認知詩学・ポスト構造主義・デジタル詩学の七領域で、これらは一九一〇年から二〇二〇年代の僅か百年強で全概念を生み出している。ソシュール（一九一六年没）、シクロフスキー「異化」（一九一七年）、インガルデン『文学的芸術作品』（一九三一年）、ヤコブソン「言語学と詩学」（一九六〇年）、ヤウス『挑発としての文学史』（一九六七年）、デリダ『グラマトロジー』（一九六七年）、レイコフ＝ジョンソン『生活のなかのメタファー』（一九八〇年）、アアサート『サイバーテクスト』（一九九七年）。これら七領域の総和は千四百件、データベース全体の約半分である。

第1の発見　詩学は二千五百年の歴史をもつが、その概念的爆発は二十世紀に集中している。古典詩学の二千年（前三八〇年〜二十世紀初頭）に四百六十一件、ポスト構造主義以降の七領域の百年（一九一〇年〜現在）に千四百件以上。概念生成速度は約三十倍に加速している。これは言語学（ソシュール）の脱出、現象学（フッサール）の方法、認知科学（レイコフ）のパラダイム変革といった「方法論的転換」が、詩学領域内で連鎖的に新概念群を生み出した結果と解釈できる。

比較詩学（四百三十五件）は両クラスタの間に位置する特異な領域である。古代から中世（二一三件）にサンスクリット・中国・日本の主要概念群が集中し、近世（一三二件）に俳諧・能楽論・国学派歌論が登場し、近代（六十四件）に翻訳論・世界文学論が加わる。これは比較詩学が「西欧の枠を出てから時間をかけて成熟する」分野であり、二十世紀的爆発のパターンとは別の、ゆるやかな複線型蓄積を示している。

第2章：系譜関係のトポロジー

七千三百四十四件の系譜関係を関係タイプで分解すると、その内訳は驚くほど偏っている。最大はderived_from（派生）で三千百十六件、これは全体の四十二パーセントを占める。次にenables（発展可能化）六百五十二件、extends（拡張）四百九十三件、complements（補完）二百十一件、related_to（関連）百七十五件、synthesizes（統合）百五十件、reinterprets（再解釈）百四十件、applies_to（適用）百三十七件と続く。これに対しopposes（対立）はわずか六十七件、critiques（批判）も六十五件と、両者を合わせても全体の二パーセントに満たない。

この比率は重要な構造的特徴を示唆する。詩学概念のネットワークは対立よりも継承の論理で成り立っているということだ。新概念は前概念を否定するのではなく、ほとんどの場合「派生する」「拡張する」「補完する」「再解釈する」関係で接続している。デリダの脱構築すらアリストテレス・ヘーゲル・ハイデガー・ソシュールの概念から派生したものとして登録されており、両者の関係はopposesではなくderived_from＋reinterpretsのセットで表現されている。これは詩学が、自然科学のように仮説を反証して進むのではなく、先行概念のなかに新しい意味の襞を発見していくという、解釈学的な進化様式を採っていることを物語る。

出次数上位の概念群は、カテゴリ生成的（taxonomically generative）な概念であることに気づく。ヤコブソンの六機能は六つの下位機能を、エートス・パトス・ロゴスは三つの説得様式を、五つのコードは五つの読解線を、霊的意味は四義（字義・寓意・道徳・天上）を、ナラトロジー三層は三段階を生成する。つまりこれらは「分類スキーマ」を提供する概念であり、その下位カテゴリそれぞれが独立した子概念として登録される構造を持つ。これに対しドゥヴァニ・崇高・脱構築のような入次数上位概念は、むしろ「磁場」として周囲の概念を引き寄せる中心点である。

第2の発見　詩学のネットワーク構造は、「派生中心型ハブ」と「分類生成型ハブ」の二種類のノードによって支えられている。前者は概念の収束点（崇高・ドゥヴァニ・脱構築）、後者は概念の発散点（ヤコブソン六機能・五つのコード・三一致）。両者は対立するのではなく、ネットワーク内で相補的に機能している。これは詩学知が、求心的な概念磁場と遠心的な分類装置を併せ持つ二重構造として組織化されていることを示唆する。

第3の発見　詩学の知的言語マップは、英語・フランス語・ドイツ語の三言語で全体の約半分（千四百三十五件、五十二パーセント）、サンスクリット・古典ギリシア語・ラテン語・日本語・アラビア語・中国語の六言語で残りの約半分（七百九十六件）を占める。この均衡は意図的に追求された結果である。「西欧主流＋非西欧少数」のパターンではなく、「西欧近代＋古典群＋非西欧伝統＋現代論文」が並列するモザイクとして現れている。

第4章：詩文層が映す文化圏のバランス

詩学が「分析対象」として扱ってきた一次テクストを文化圏で集計すると、古代ギリシャ・ローマが千五百五十二件で首位、続く中国古典千三百七件、近代ヨーロッパ千二百四十六件、日本古典九百二十七件、アラビア・ペルシア六百七十一件、東アジア（韓国・ベトナム）五百八十九件、中世ヨーロッパ五百四件、サンスクリット四百七十九件、仏典詩偈二百七十八件、二十〜二十一世紀グローバル二百四十九件、アフリカ百五十九件、先住民・口承百二十三件である。

この分布は一見、古代ギリシャ・ローマと中国古典が並走する「双峰構造」のように見える。だが時代別に分解すると、西欧伝統は「古代ギリシャ・ローマ→中世→近代→二十世紀」と途切れなく連続するのに対し、中国古典は唐宋に集中、日本古典は平安〜江戸に集中、サンスクリットは古典期に集中、というように、各文明圏が独自の「黄金期」を持っている。詩学の「万年」をひとまとめに語るのではなく、それぞれの文明圏のリズムを尊重する必要がある。

詩文層と概念層を重ねると、興味深いミスマッチが現れる。概念上位三領域は古典詩学（四百六十一）・比較詩学（四百三十五）・ポスト構造主義（二百八十五）だが、詩文上位三文化圏は古代ギリシャ・ローマ・中国古典・近代ヨーロッパである。つまり「概念は西欧近代と非西欧古典に多く、詩文は古代ギリシャ・ローマと中国古典に多い」という構造的非対称が存在する。これは、現代の詩学者が古代の詩文を分析対象に選ぶ傾向、すなわち「古典をめぐる現代理論」というメタ・パターンを反映している。デリダは古代ギリシャを論じ、ジュネットはプルーストを論じ、王國維は唐詩を論じる、といったように。

第5章：三項リンクが示す詩学の三角形

本DBの最も独創的な構造は、概念↔原典↔詩文の三項リンク（八千六百六十件）である。これは「ある概念A は、原典B の founding passage で確立され、詩文C はその例証である」という三角形を、可機械処理可能な形で記録する。

たとえば「カタルシス」は、原典『アリストテレス詩学』六章一四四九b二十四–二十八節で「悲劇は……同じ感情の浄化を達成する（μίμησις πράξεως ... δι' ἐλέου καὶ φόβου περαίνουσα τὴν τῶν τοιούτων παθημάτων κάθαρσιν）」として確立され、詩文ソフォクレス『オイディプス王』一一八六–一一九六行（テーバイ合唱）が代表的な例証として接続される。これらが三項一組として記録されている。

三項リンクは現在、四十二概念・三千三百八十一テクスト・四十二原典源を被覆している。被覆率としては概念全体の僅か一パーセントだが、被覆された概念群は基底的なものに集中しており——ミメーシス・カタルシス・崇高・幽玄・もののあはれ・ラサ・ドゥヴァニ・異化・脱構築・間テクスト性など——、これら基底概念に対する三項関係を完備したことが、本DBの質的飛躍を構成している。

三項リンクの分布で特筆すべきは、同一概念が異なる文化圏のテクストを横断して例証するパターンが既に現れていることだ。たとえば「崇高」概念は、ロンギノス『崇高論』を原典とし、サッフォー断片三十一・ピンダロス『オリュンピア祝勝歌』第一歌・聖書詩篇・ミルトン『失楽園』・ワーズワース『ティンターン僧院』にまたがって例証される。ここで詩学は単一文化の規範ではなく、異文化テクスト群を通底する読解装置として機能している。三項リンクは、その通底性を構造的に可視化する。

第4の発見　三項リンク（concept↔text↔source triple）は、詩学知識を「概念定義の集合」でも「原典引用の集合」でも「詩文集成」でもなく、「概念がいかにテクストに即して定義され、そのテクストが他のテクストの読解にどう転移するか」を捉える構造である。これは古典的な概念辞典・引用集・アンソロジーのいずれにもない第四の知識形式であり、AI時代における「詩学的読解の構造化」を可能にする基盤を提供する。

第6章：見えてきた構造と系譜

四層（理論・原典・詩文・三項）の交差から見えてきたものを、五つの系譜として整理する。

系譜1：模倣論の二千五百年（プラトン → デリダ）

ミメーシス（模倣）概念は、プラトン『国家』第三巻・第十巻における詩人追放論（前三八〇年頃）から始まり、アリストテレス『詩学』（前三三五年頃）でカタルシスとプロット概念へ展開し、ロンギノス『崇高論』（一世紀）でヒュプソスの源泉に位置づけられ、アウエルバッハ『ミメーシス』（一九四六年）で西欧文学全体の表象様式論へ拡張され、デリダ『散種』（一九七二年）で「双重の模倣」として脱構築される。本DBは入次数十四の「ドゥヴァニ理論」と並んで、入次数八の「異化（オストラネーニエ）」が、ミメーシスの逆転的継承——「自動化された模倣からの再覚醒」——として位置づけられることを示す。模倣／異化／脱構築は対立ではなく、二千五百年にわたる同一問題の三段変奏である。

系譜2：感情論の東西並走（ラサ／カタルシス／あはれ／崇高）

詩文が読者にもたらす感情の分類と機能化は、ほぼ同時期に複数の文明圏で独立に体系化された。インドのバラタ『ナーティヤシャーストラ』（前二〇〇年〜後二〇〇年）は九ラサ（恋情・滑稽・悲哀・憤怒・英雄・恐怖・嫌悪・驚異・寂静）を、ギリシアのアリストテレス『詩学』（前三三五年）はカタルシス（哀れみと恐れの浄化）を、日本の鴨長明『無名抄』（一二一一年）と藤原俊成・定家による「あはれ」「幽玄」を、それぞれ独立に提唱した。本DBの比較詩学領域は、この四つの伝統を等価に並置することで、「詩学的感情論」が文化圏を超えた人類学的な普遍課題であった可能性を示唆する。

系譜3：意味の階層論（聖書解釈学 → 構造主義 → 認知詩学）

詩文の意味を複数の層で読むという方法論は、出次数六の「霊的意味」（オリゲネス・カッシアン・トマス・アクィナスにいたる中世聖書解釈学の四義）を起点とし、出次数六の「五つのコード」（バルト『S/Z』一九七〇年、解釈・記号・象徴・行為・文化）を経て、出次数七の「概念ブレンディング」（フォコニエ＝ターナー二〇〇二年、二つの入力空間と汎用空間からブレンド空間が生成される認知過程）へと変容する。中世の聖書四義（字義・寓意・道徳・天上）は、二十世紀の構造主義的コード論を経由して、二十一世紀の認知詩学的メンタルスペース理論へと、形式を変えながら継承されている。意味階層論は本質的に解釈の認知装置であり、その装置自体が時代ごとに再発明されている。

系譜4：話者と聴者の問題（弁論術 → 受容理論）

アリストテレス『弁論術』（前三五〇年頃）における出次数六の「エートス・パトス・ロゴス」（話者の人格・聴衆の感情・論理）は、二千年を経てヤウス『挑発としての文学史』（一九六七年）の「期待の地平」、イーザー『読書行為』（一九七六年）の「内包された読者」「空白」へと連続している。本DBの入次数上位「読者反応批評」（十一）「内包された読者」（十一）は、いずれも古代弁論術における「聴衆」概念の現代的変奏として位置づけられる。「話者→聴者」の弁論術的構造が、「テクスト→読者」のコミュニケーション構造に変換されたのが受容理論であり、この継承関係は本DBのderived_from関係でも確認できる。

系譜5：媒体と詩学（写本 → 印刷 → デジタル）

デジタル詩学（百七十八概念）は、二十世紀末以降に爆発的に登場した最新領域である。アアサート『サイバーテクスト』（一九九七年）の「エルゴディック文学」、ヘイルズ『電子文学』（二〇〇八年）、マノヴィッチ『ニューメディアの言語』（二〇〇一年）は、いずれも従来の口承詩学・写本詩学・印刷詩学が前提としていた媒体条件を、デジタル媒体に再適応させた成果である。本DBは、デジタル詩学の概念群がderived_fromとして参照する先行概念群——「ハイパーテクスト性」「インタラクティブ性」「アルゴリズム的著者性」——をマッピングすることで、デジタル詩学が独立に発生したのではなく、記号論・構造主義・口承理論からの正統な継承であることを示している。

第7章：結語——AI時代の詩学知識基盤として

本DB v2.3 の構築過程（Phase 1〜10、二〇二六年五月）は、「概念だけ」「原典だけ」「詩文だけ」を集めるのではなく、四層を交差させて構造化するというアプローチの実証実験でもあった。Codex並列ワーカーとClaude実行チームの協働により、約一万八千件のレコードが構造化され、四十二概念について三項リンクが完備された。この「概念磁場と原典証跡と詩文例証の三角形」は、従来の詩学辞典・引用集・アンソロジー・テキストブックのいずれにもない第四の知識形式である。

大規模言語モデルが詩学的概念を扱うとき、しばしば「ハルシネーション」（虚構の引用や典拠の捏造）が問題になる。本DBは原語＋日訳＋英訳＋意義分析の四要素を一引用ごとに記録し、原典の所在情報（書名・章節・年代・著者・言語・PDアーカイブURL）を保持することで、その回避を構造的に支援する。生成AIに詩学的議論を要求する際、本DBを retrieval source として用いることで、原典証跡を伴った応答が可能になる。

本DBはまた、「詩学＝西欧の伝統」という暗黙の前提をデータレベルで覆す試みでもある。サンスクリット詩学（ドゥヴァニ・ラサ・アランカーラ）、中国詩論（文心雕龍・滄浪詩話・人間詞話）、日本歌論（風姿花伝・無名抄・三冊子）、アラビア・バラーガ、ペルシア・スーフィー詩学を等価に収録し、引用著者ランキングではヴァーマナ・劉勰・世阿弥・ルーパ・ゴースヴァーミン・司空圖・嚴羽が、ジュネット・デリダ・インガルデン・イーザーと同じ平面上で並走する。この「並走する複数系譜」を構造として可視化したことが、本DBの最大の貢献である。

最終的所見　詩学は「西欧古典の単線継承」でも「ポストモダンの解体」でも「文化相対主義の並列」でもなく、「複数の foundational concept（崇高・ドゥヴァニ・あはれ・異化・脱構築）が独立に磁場を形成し、それらが二十世紀以降に方法論的に交配する」という、複層磁場ネットワークとして組織化されている。その全貌を二千八百二十五概念・七千三百四十四関係・二千七百六十八引用・八千八十四詩文・八千六百六十三項リンクという数値の幾何学として一覧できる装置が、本DBである。

今後の拡張課題は三つある。第一に、三項リンク被覆率（現在概念の一パーセント）を二十パーセント以上に引き上げ、各 founding concept について複数の例証テクストを接続すること。第二に、詩文層八千件のなかで概念リンクを持たない六千件超に対しても、機械学習を用いた候補リンク提案を実装し、人手レビューを介して検証すること。第三に、本DBをretrieval-augmented generationの基盤として、「概念質問→原典提示＋例証詩文＋系譜可視化」を統合的に応答する詩学アシスタントを構築することである。

詩学は二千五百年の累積知である。本DBは、その累積を分散探索可能な構造として再編成する第一歩である。
