方法論注記

本DBは /academic-db-build v1.1 経路A (Phase 0-15) で構築。 Phase 0 (Scoping) → Phase 1 (Schema + 150 必須理論チェックリスト) → Phase 2 (収集 Wave 1-2b) → Phase 3 (品質検証: source_url 100% / 重複 0 / 必須理論 93% カバー) → Phase 4 (関係構築 4.11x ratio) → Phase 14 (Cross-DB refs: 27 DBs / 199 refs) → Phase 5 (本ダッシュボード + 教科書)。 Production 完備の絶対基準として継続反復中。Wave 3 で 5,500+ concepts まで拡張予定。

関連エージェント: /dsd。検証: /ddb design-studies-db。 連動: editorial-design-db (edd) 紙面実例カタログ・dsdb Webデザインサイト DB と相補。
