01プロジェクト要旨

02Block A — 117件未充実ナラティブの再生成

v6で残された117件のうち、Codex 6チームに分割（IS_ANC_A/B 各20件、PA_EM 30件、AF_20C 21件、WE_IND 21件、MISC 5件）して再生成を実施した。v3〜v6 で蓄積した禁止フレーズリスト（テンプレート的冒頭句、Iliffe/Cooper/Mamdani/Hopkins の機械的引用、5フィールド間の重複等）を冒頭に明示し、「description フィールドの史実情報を必ず織り込む」「各事象に異なる冒頭文を作成」を厳守ルールとした。

結果として、5チームが正常完了し（REJECT 0件）、計82件が品質基準を満たして適用された。出力品質は v3〜v6 と質的に異なり、各事象が固有の年代・人物・場所・政策を含み、参照学者の選択も事象内容に応じて変化する、学術的に publication-ready な水準に到達した。たとえばウィスコンシン州直接予備選挙はラフォレット知事と1903年州法、メキシコ・エヒード制度はサパタとアヤラ綱領、エレノア・ルーズベルトは1948年世界人権宣言という固有の歴史的文脈で記述された。残るPA_EM 30件のみ、事前バッチサイズ問題で stall し、v8 へ送られた。

03Block B — Drayton 4段階分類の100%完備

v6で残された16件の Drayton 未分類事象（ウスマン・ダン・フォディオのジハード、扶南王国建国、フェニキア・アルファベット、ムスリム同胞団エジプト創設等）について、Python による手動キュレーションで分類を完備した。各事象の type / mechanism / scale から、Bill Drayton モデル（direct_service / scaled_direct_service / pattern_change / framework_change）への割当を学術的判断で決定した。たとえばジハード国家建設はアフリカ西部での新国家形成として framework_change、フェニキア・アルファベットは書字システムの大陸横断的伝播として pattern_change、ロッヘフェーンの単発接触は direct_service と分類した。

これにより、SI Framework DB の 7,389 全事象に Drayton 段階が付与され、100% 完備が達成された。最終分布は framework_change 3,865 / pattern_change 3,095 / scaled_direct_service 337 / direct_service 92 となり、制度変革と規範変容が概ね均衡し、規模拡大型と直接サービス型が少数派という、長期社会変革史として妥当なバランスに収束した。

04Block C — 表記揺れ標準化辞書の整備と適用

v6で報告のみに留めた表記揺れ問題（ムハンマド/Muhammad の499件、ガンディー/Mahatma Gandhi の混在、チンギス/Chinggis 等）に対し、20主要人名の標準化辞書を整備し一括統一を実施した。標準化方針は「日本語文中の英語表記は日本語標準形へ統一」「重複する音写は最も一般的な日本語形を採用」とした。

適用結果として5フィールド合計133イベント、134箇所の表記が統一された。最頻置換はムハンマド（70件）、ガンディー（18件）、アウラングゼーブ（15件）、アクバル（11件）、毛沢東（9件）、孫文（6件）、サラディン（4件）、ネルー（1件）。これにより、SI Framework DB のナラティブ全体は人名表記の一貫性を獲得し、検索性と引用可能性が大幅に向上した。

05Block D — Tier-A 21件への引用学者補強
