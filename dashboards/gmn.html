03系譜：Whitney → Takens → Sugihara → Pao

本 DB の中核系譜は、Whitney 埋め込み定理 (1936) を数学的基盤とし、Takens (1981) の遅延座標埋め込み定理を経て、Sugihara & May (1990 Nature) で Simplex Projection、Sugihara et al. (2012 Science) で Convergent Cross Mapping (CCM) へと発展した。Pao + Park (2026 bioRxiv) の Generative Manifold Networks (GMN) は、この系譜の最新到達点として、CCM をネットワーク化されたマニフォールド間の相互作用関数に拡張した。

05アルゴリズム — 擬似コード集

計算量と参照実装を伴う 109件のアルゴリズムを収録。以下は代表的な 15件。

Box-counting Dimension (1919) O(N·(1/epsilon)^d) for naive grid; O(N log N) with efficient algorithms

for epsilon in [epsilon_min, ..., epsilon_max]:
  N[epsilon] = count boxes of side epsilon that contain at least 1 attractor point
fit log(N) vs log(1/epsilon) by linear regression
d_B = slope of fit

Forecast Horizon Estimation via Lyapunov Exponent (1963) O(max_tp * L * E)

# Empirical EDM approach to estimate lambda_max:
For tp in 1..max_tp:
  rho[tp] = Simplex(ts, E_opt, tp=tp)['rho']
# log(rho) vs tp slope ≈ -lambda_max
lambda_est = -slope(log(rho) vs tp)
forecast_horizon = 1 / lambda_est

Granger Causality (1969) O(n * p^2)

GrangerCausality(X, Y, p):
  fit Y ~ lag(Y,1..p)               # restricted VAR
  fit Y ~ lag(Y,1..p) + lag(X,1..p) # unrestricted VAR
  F = ((RSS_R - RSS_U)/p) / (RSS_U/(n-2p-1))
  p_value = F_distribution_pvalue(F, p, n-2p-1)
  reject H0 if p_value < alpha

Long-Term Potentiation (LTP) (1973)

1. Apply high-frequency stimulation (HFS: 100 Hz, 1 s) to Schaffer collaterals
2. NMDA receptors unblock (Mg2+ expulsion) if postsynaptic depolarization coincides
3. Ca2+ influx -> CaMKII activation -> AMPA receptor phosphorylation & insertion
4. Synaptic weight increases; measure EPSPs pre vs. post (>30 min)

Delay Coordinate Embedding (1980) O(N·E)

input: time series x[1..N], E (embed dim), tau (lag)
for t = 1 to N - (E-1)*tau:
  v[t] = x[t], x[t+tau], ..., x[t+(E-1)*tau]
return delay matrix V (rows = delay vectors)

Takens Embedding Theorem (1981) O(N·E)

input: scalar time series {x_t}, embedding dim E, lag tau
for t = 1 to N-(E-1)*tau:
  v_t = [x_t, x_{t+tau}, x_{t+2*tau}, ..., x_{t+(E-1)*tau}]
return matrix V of delay vectors

Embedding Dimension (1981) O(N·E^2) for FNN

Estimated by FNN: increase E until FNN fraction < threshold (typically 0.01-0.05)
Or by Cao's method: find E where E1(E) stabilizes near 1.0

Correlation Dimension (1983) O(N^2) naive; O(N log N) with optimized algorithms

for r in r_range:
  count pairs (i,j) where dist(x_i, x_j) <= r
  C[r] = 2*count / (N*(N-1))
fit log(C) vs log(r) in scaling region
d_C = slope of linear fit

Wolf Algorithm (1985)

for each step t:
  find nearest neighbor to x(t)
  track separation d(t) = |x(t) - x_neighbor(t)|
  compute log(d(t+L)/d(t))
  renormalize; accumulate MLE estimate

Fading Memory Property (1985) Not algorithmic; theoretical property

Verify fading memory:
1. Run reservoir with inputs u and u' differing only far in the past
2. Measure state divergence at present time
3. If divergence -> 0 as past-difference-time -> -inf, fading memory holds

Time Lag / Tau Selection (1986) O(N·tau_max·bins^2)

for tau = 1 to tau_max:
  compute AMI(tau) = mutual_information(x[t], x[t+tau])
return tau at first local minimum of AMI

Mutual Information for Lag Selection (1986) O(N·tau_max)

for tau = 1 to tau_max:
  compute joint histogram p_ij of (x[t], x[t+tau])
  compute marginals p_i, p_j
  AMI[tau] = sum_{i,j} p_ij * log2(p_ij / (p_i * p_j))
return tau at first local minimum of AMI

Singular Spectrum Analysis (1986) O(N·L^2) for SVD of L×K matrix

input: time series x[1..N], window length L, target rank d
K = N - L + 1
build trajectory (Hankel) matrix X (L x K)
X = U * Sigma * V^T  (SVD)
reconstruct with d principal components: X_d = U_d * Sigma_d * V_d^T
extract reconstructed series by averaging anti-diagonals of X_d

Recurrence Plot (1987) O(N^2·E)

input: delay-embedded trajectory X (N x E), threshold epsilon
for i in 1..N:
  for j in 1..N:
    R[i,j] = 1 if ||X[i] - X[j]|| <= epsilon else 0
plot R as black-and-white 2D image

Local Linear Approximation on Manifold (1987) O(N^2·E) for neighbor search + O(k·E^2) for regression

for each target point x_t:
  find k nearest neighbors {x_k} in reconstructed space
  weight neighbors: w_k = exp(-theta * dist(x_t, x_k) / mean_dist)
  fit weighted linear regression: x(t+1) = A * x_t + b
  predict: x_hat(t+1) = A * x_t + b
