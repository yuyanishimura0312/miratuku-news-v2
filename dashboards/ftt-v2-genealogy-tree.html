5. 解釈

合流ハブの構造: グラフェン (MATERIAL) / neuromorphic computing (NEUROMORPHIC) / synthetic biology (SYNBIO) / bioelectronic medicine (BIOELEC) / cellular agriculture (AGRI) が in/out 両側で最も多く接続される系譜ハブ。これらの技術は領域横断的に引用されており、現代の未来技術における「結節点」を学術論文 evidence で同定できる。

領域横断パターン: cross-domain edges 114 (52%) は within-domain 106 (48%) と拮抗し、技術が領域内で閉じない実態を裏付ける。特に QUANTUM ↔ PHOTONICS、NEUROMORPHIC ↔ PHOTONICS、MEDICAL → SYNBIO、BRAIN_CI → BIOELEC など、生命基盤 × 情報基盤 × 物質基盤の三重合流が顕著。

政府/シンクタンク seed 復活ゼロ: 全 220 edges は paper_citations 125,748 から derived。各 edge の evidence_paper_ids JSON は最大 10 件の論文 ID を保持し、citation chain の根拠を学術論文のみで追跡可能。
