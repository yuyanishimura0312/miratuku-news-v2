v2 → v3 の変更

v2 で投入した政府機関ロードマップ seed (NASA / IEA / IPCC / EU FET / NEDO / FAO / WHO / DOE / FDA / NIH 等 115 件) を 全て削除。本 v3 は 学術論文 evidence のみ で構築。各 milestone には evidence_paper_id (OpenAlex 由来の高被引用論文) が必ず紐付く。

主要強化点:

  • mention 再分類: 未分類 7,532 件のうち 1,096 件 (14.5%) を excerpt キーワード解析で propose/apply/review/critique/forecast に振り分け (apply +747、critique +154 が主)
  • 学術論文 milestone: 高被引用論文 (citation ≥ 50) の abstract から "first demonstrated"/"commercial"/"prototype" 等のキーワードで 147 件を抽出 → technology_milestones に投入
  • 学術論文 TRL: abstract に "TRL N" / "Technology Readiness Level N" 言及がある 32 論文を解析、3 件の学術 TRL evidence を追加 (LUNAR 領域中心)
  • forecast 年代抽出 75 件: 学術 excerpt から年代キーワード抽出 (regex/decade keyword)
制約: 学術論文は基本的に過去-現在の達成記録なので、未来 milestone は forecast 言及からのみ抽出可能。2050+ の長距離予測は 11 件、2100+ は 3 件のみ。これは規範的ソース除外による必然的な薄さで、より長距離の精度向上には paper_citations 構築 + forecast 専門論文の追加収集が必要。
