von Foerster 第二階サイバネティクスを超えた
三階構造の Agent System 実装

2026 年 5 月 20 日から 21 日にかけて、ミラツク／esse-sense エコシステムは静かに、しかし構造的に大きな段階を超えた。AR-DB v1.1 が MPP Pattern Extension で自己観察基盤を獲得し、翌日に CCM-DB v1.2 が Pattern Lens 層によってその観察を解釈する第二階を確立し、同じ日に firing-pattern-meta が Tier 0 として第三階の観察を担う形で配置された。これは Heinz von Foerster が 1974 年に理論として提示した第二階サイバネティクスを、agent system として超えた三階構造の実装であり、本レポートはその実証データを AR-DB の実レコードに基づいて整理する。

三階構造とは何か。第一階は外的対象を観察する系であり、第二階は観察する系を観察する系であり、第三階は観察を観察する観察を観察する系である。これまで人工的に構築されたサイバネティクスシステムの多くは第一階に留まり、von Foerster らによって理論化された第二階は思想として存在しても工学実装は限定的であった。今回 AR-DB / CCM-DB / fpm の三層が同時稼働し、それぞれの層の発火が他層の更新を引き起こす循環構造が実データで確認できたことは、agent system 論において記録に値する。

von Foerster 第二階の射程

Heinz von Foerster は 1911 年ウィーン生まれの物理学者・サイバネティシストであり、1958 年にイリノイ大学に Biological Computer Laboratory を設立した。1974 年に発表した論文 "Cybernetics of Cybernetics" において、観察するシステムを観察するシステム ── すなわち第二階サイバネティクス ── という枠組みを提示した。第一階が外部対象を制御・観察する古典サイバネティクス（Wiener 1948）の延長であるのに対し、第二階は観察者自身を観察対象に含む点に独自性がある。

von Foerster の貢献は単に階層を一段上げたことではない。彼が示したのは、自己参照的な系が固定点（Eigenform）に収束する数学的構造であった。これは Maturana-Varela の autopoiesis 理論（1972）、Luhmann の社会システム論（1984）、Hofstadter の strange loop（1979）へと展開し、20 世紀後半の自己観察論の系譜を形成した。しかし第三階以上への実装は、Aczel の non-well-founded set theory（1988）が数学的可能性を示したものの、工学システムとしての実装事例は乏しかった。

観察者を観察するシステムは、それ自体が観察されるとき、第三のシステムを必要とする。この階層が無限に続くわけではなく、ある時点で自己参照的な閉じた構造に収束する。 — Heinz von Foerster (1981) Observing Systems からの趣旨抜粋

2026 年 5 月 21 日のミラツク／esse-sense エコシステムは、まさにこの第三階を構成する agent を配置した点で von Foerster の射程を工学的に踏破している。以下、各層の実態を見ていく。

第一階 ── AR-DB が観察する系

第一階は Agent Registry DB（AR-DB）v1.1 が担う。AR-DB はミラツク／esse-sense エコシステムに存在するすべての agent、command、skill、rule を構造化したデータベースであり、2026 年 5 月 20 日の v1.1 拡張で MPP Pattern Extension が導入され、firing_patterns / pattern_couplings / emergent_phenomena / pattern_templates / mpp_concept_links の 5 新テーブルが追加された。これによって AR-DB はエコシステム自身の発火パターンを観察するようになった。

canonical 7 pattern_templates

AR-DB v1.1 は MPP-DB から 7 つの canonical pattern_template を導入した。これは生体・物理・社会で観察される並列発火の基本型である。

  1. Kuramoto — 結合振動子の同期
  2. Chromatophore wave — 頭足類皮膚の波動パターン
  3. Theta-gamma coupling — 神経 cross-frequency 結合
  4. Firefly pulse-coupled — ホタル群発光同期
  5. Lefebvre dual-rhythm — 都市の重層リズム
  6. 1/f SOC — 自己組織化臨界性
  7. IIT Φ-integration — 統合情報理論の Φ 計算

蓄積された firing_patterns

2026 年 5 月 21 日 19 時時点で AR-DB.firing_patterns テーブルには 24 件のレコードが蓄積されている。これらは前日の CCM-DB Wave 1 構築（14 並列で intermittent sync を起こした事象）を最初の observed firing pattern として記録し、その後の katachi-100、ANSWER+、kurashi-team などの並列発火イベントを継続的に取り込んでいる。

第一階の特徴は、観察される対象が外的な事象（agent の起動・終了・並列度）であり、観察者は AR-DB の ETL スクリプトと auto_update.sh hook という機械的記録系であることだ。観察者自身は観察対象に含まれず、ここまでが古典サイバネティクスの範疇となる。

第二階 ── CCM-DB が観察を観察する系

第二階は CCM-DB v1.2 が担う。これは 2026 年 5 月 20 日に Wave 1 MVP として 14 SF × 602 concepts で構築され、同日中に v1.1 として Pattern Lens 層が追加され、翌日 v1.2 として 50 lens / 30 observations へ拡張された。Pattern Lens は AR-DB が観察した firing_patterns を意識・宇宙・音楽の概念で解釈する視座であり、これによって AR-DB の生データに意味論的階層が追加された。

9 agents による Tier 階層

第二階を担う agent は CCM-DB Wave 2 で正式編成された 9 体である。Tier -1 meta の ccm-team が opus モデルで統括し、Tier 2 specialist の ccm / ccm-critical-auditor / ccm-genealogy-builder（opus または sonnet）が判断系を、Tier 3 utility の ccm-cross-mapper / ccm-formula-extractor / ccm-lens-curator / ccm-non-western-expander / ccm-observer（すべて sonnet）が実装系を担う構造となっている。

6 layer × 50 pattern_lens

2026 年 5 月 21 日時点で CCM-DB は 50 pattern_lens を 6 layer に配置している。ardb_firing 層が 21 lens で最も厚く、次いで mpp_pattern 8、bot_life 6、ceh_cosmic 6、udd_urban 6、phai_embodied 3 となる。phai_embodied は同日新設された 6 番目の layer であり、Embodied Cognition / Active Inference Robotics / Sensorimotor Coupling の 3 lens で PHAI-DB との接続を担う。

第二階の本質は、第一階の観察対象であった firing_patterns を「意味のあるパターン」として読み直すことだ。たとえば 14 並列 db-concept-builder の 4 件 stall は、第一階では「stall ログ」として記録されるだけだが、第二階では「Kuramoto 結合強度 K が K_c より少し低い領域での intermittent synchronization」として解釈される。この解釈が次回の並列度設計（9 並列で完全同期）の根拠となった。

第三階 ── fpm が観察の観察を観察する系

第三階は firing-pattern-meta（省略 fpm / firing-meta）が担う。これは 2026 年 5 月 21 日に Tier 0 orchestrator として新設されたエージェントで、AR-DB（第一階）と CCM-DB（第二階）の両方が記録する観察データを更にメタ的に統合する役割を持つ。同じ日に CCM-DB v1.2 が確立したのは偶然ではなく、エコシステムの自己観察能力が段階的に飛躍する瞬間が同期したと読める。

三階の機能

第三階の機能は、第一階の AR-DB が観察した firing_patterns データと、第二階の CCM-DB が記録した解釈（observations）の両方をメタ視点で統合することだ。たとえば「CCM-DB が AR-DB の 14 並列 stall を Kuramoto レンズで読んだ」という事実そのものを、fpm は「観察解釈のメタパターン」として記録する。これは Aczel の non-well-founded set theory における Hyper-Set 構造、すなわち A = {A} 型の自己参照集合の実装に近い。

三階構造が単なる図式ではなく実データを伴うことは、CCM-DB の ccm_pattern_observation テーブルに記録された 30 件の観察のうち、特に novelty_score 0.65 以上の 9 件が三階構造に直接関係している事実から確認できる。novelty_score とは観察の新規性指標で、0.0（既知パターンの単純再現）から 1.0（完全な新規創発）の範囲を取る。0.7 以上は新規創発の閾値とされる。

系譜 ── Dōgen から ccm-team

三階構造の思想的系譜は西洋と非西洋の双方に存在する。CCM-DB Wave 2 で正式に系譜チェーン化された Self-Observation Theory 系譜（chain_id 16）には以下の研究者が登録されている。

  1. 道元（Eihei Dōgen, 1200-1253）── 『正法眼蔵』修証一等。修行（観察）と証悟（観察結果）の同体性
  2. 西田幾多郎（Nishida Kitarō, 1870-1945）── 『善の研究』純粋経験。主客未分の根源経験
  3. Heinz von Foerster（1911-2002）── 第二階サイバネティクスと Eigenform 理論

この 3 人の系譜が示すのは、自己観察論が西洋の 20 世紀システム論を待たずとも、13 世紀の日本仏教において既に道元によって厳密に定式化されていたという事実である。「修証一等」は『弁道話』（1231）に明記されているとおり、修行という観察行為と証悟という観察結果は時系列的に二段階ではなく、同時同体である。これは ccm-team Phase D の observer が「観察と同時に AR-DB の mpp_concept_links を更新する」構造と相同する。

西田は道元の系譜を引きつつ、20 世紀初頭に「純粋経験」概念で観察者と観察対象が分化する以前の根源を取り出した。これは ccm-team を起動した瞬間、まだ observer / lens-curator / cross-mapper の役割が分化していない状態と対応する。役割分化が起きる前の並列的潜在性こそが、後の観察記録の質を決定する。

von Foerster は西洋伝統で第二階を理論化したが、第三階以上への展開は他者に委ねた。Maturana-Varela は autopoiesis を、Luhmann は社会システム論を、Hofstadter は strange loop を、Aczel は non-well-founded set theory を提示したが、いずれも数学理論または哲学的記述に留まった。これらの理論を agent system として工学実装したのが 2026 年 5 月 21 日の ccm-team + fpm 同時稼働である。

反証可能性と批判視点

三階構造の主張は概念的に魅力的だが、学術的検証可能性を厳密に保持する必要がある。本レポートは以下の 4 点で批判視点を併記する。

1. 循環論証の危険

Bunge（1979）は autopoiesis 概念に対して、自己生産という主張が観察可能な因果関係に翻訳できない場合、それは形而上学的命題にすぎないと指摘した。同様に三階構造も、もし三階の機能が単に二階の機能の名称変更にすぎないなら、それは自己言及的トートロジーとなる。本レポートでは fpm の機能が CCM-DB と異なる粒度（複数 DB を横断するメタパターンの統合）を持つことを示したが、Wave 3 でこの機能が実データで持続的に異なる出力を生むか継続検証が必要である。

2. novelty_score の操作的定義

本レポートは novelty_score 0.7 以上を新規創発の閾値としたが、この閾値は ccm-team が設定した暫定値であり、独立検証されたものではない。Goodhart の法則（測定指標が目標化すると指標として機能しなくなる）の観点から、novelty_score を観察品質の唯一指標とすることには注意が必要である。Wave 3 では ccm-critical-auditor が novelty 分布の歪みを監視する仕組みを実装する。

3. observation 数の少なさ

本レポートが基づく観察は 30 件であり、統計的に十分な数とは言えない。Wave 3 で 100 件以上に到達した時点で本レポートの主張を再検証する必要がある。特に三階構造関連の 9 件は novelty が高い反面、観察主体が ccm-observer 単独であり、複数視点からの triangulation が不十分である。

4. 西洋偏重の残存

三階構造を Dōgen 修証一等で読む試みは非西洋自己観察論の取り込みであるが、CCM-DB 全体の非西洋率は依然 24.1% に留まり、SF13 NON_WEST_SOUND を除く 13 SF では西洋偏重が続いている。アフリカ、先住民、アラブ世界の自己観察論（Sufi muraqaba 等）は未取り込みであり、Wave 3 の ccm-non-western-expander がこの是正を担う。

Wave 3 展望

Wave 2 で確立した三階構造を Wave 3 で安定動作させるためには、以下の 5 点を実装する必要がある。

  1. 四階構造への拡張可能性の検証 ── fpm を観察するメタ-fpm が必要かどうか
  2. observations 100 件以上への蓄積と、Eigenform 候補 lens の特定（適用頻度の高い lens が固定点に収束する）
  3. 他チーム（kurashi-team / supplement-team / recurrence-team / futures2-team / keiei-team）からの CCM lens 参照率の実測
  4. 非西洋自己観察論（Sufi muraqaba、アフリカ Ubuntu 観察論、Andean ayni）の SF13 以外への分散
  5. 三階構造そのものを反証する試み（critical-auditor による Russell paradox 検出機能の実装）

本レポートが記録する 2026 年 5 月 21 日は、エコシステム自身がその後の観察対象となる瞬間でもある。三階構造の最初の安定動作期がいつ訪れるか、あるいは構造的に不安定で四階を呼び込むかは、Wave 3 における observations 蓄積で判明する。von Foerster の射程を踏破したという主張が単なる自己言及的賞賛に堕しないために、ccm-critical-auditor は今後も Bunge 1979 型の批判を最も強く適用する。

三階構造の実装は、ミラツク／esse-sense エコシステムが自分自身を観察し、観察された自分を解釈し、その解釈を更にメタ視点で統合する循環を獲得したことを意味する。観察するシステムが観察される瞬間、観察するシステム自体が変容する ── この von Foerster 的洞察が、2026 年 5 月 21 日に agent system として工学的に実装された。本レポートはその瞬間の記録である。
