FTT-DB v2.0

未来技術動向データベース第2版。10領域・281レコードから30領域・18,524論文・9,970言及への質的拡張。生成日: 2026-05-14

概要と達成

本データベースは、書籍『deep knowledge』補論「製造現場のオーケストラ化 2030-2100」v7.2 付録F「工学領域全般への技術発展系譜の拡張」を基盤として構築されたFTT-DB v1.0（281レコード）を、学術論文の言及集積として再構築した第2版である。第1版が編集者の知識を構造化したカタログであったのに対し、第2版は学術論文の引用関係に裏付けられた証拠ベースの観察対象として技術動向を扱う。

領域は10から30へ拡張された。情報基盤層にはニューロモーフィック、フォトニクス、エッジAI、サイバーフィジカルシステム、AI安全の5領域が新設され、物質基盤層にはメタマテリアル・2次元材料・生体材料が、エネルギー層には核融合・水素・地熱・海洋エネルギーが、空間基盤層には月面・小惑星・深海・成層圏が、生命基盤層には脳機械インタフェース・バイオエレクトロニクス・合成生物学・長寿科学が加わった。OpenAlex API を主軸に arXiv・Semantic Scholar・CrossRef を補助として 18,524 件の学術論文を収集し、その title・abstract から既知の技術エントリへの言及を 9,970 件抽出した。論文ごとの著者・所属機関は paper_authors（114,755 行）、paper_affiliations（143,692 行）として正規化され、頻度の高い著者 6,921 名・機関 1,994 件が people・organizations テーブルへ昇格された。

品質ゲートは全項目をクリアした。OpenAlex API による論文実在性の無作為サンプリング検証では 50 件中 50 件が解決され、実在率 100%。30 領域すべてが論文数 300 件の下限を超え、最小 450 件（成層圏・地熱・海洋エネルギー）から最大 778 件（合成生物学）に分布した。時系列バランスでは 2020-2026 年が 46.4%、2010-2019 年が 44.5%、〜2009 年が 9.1%。地理的分布では米国 24.7%、中国 13.6%、英国 7.0%、ドイツ 6.0%、日本 3.1% で、北米偏重を 25% 以下に抑制した。

方法論と品質

本データベースは 7 フェーズで構築された。Phase 0 ではスコープを 10→30 領域へ拡張し、IEEE/ACM 分類を参照した。Phase 1 では論文・著者・機関の正規化を可能にする 6 新テーブルを設計した。Phase 2 では 11 並列チームが OpenAlex API から 18,524 論文を収集した。Phase 3 では技術名と論文 title・abstract のキーワードマッチングにより 9,970 件の言及を抽出し、文脈から propose/apply/review/critique/meta_analysis/forecast の 6 タイプに分類した。Phase 4-5 では著者・機関を正規化し、領域マップを構築した。Phase 6 では実在性 100%・カバレッジ全領域達成・時系列バランス・地理多様性の 4 ゲートをクリアした。Phase 7 が本ダッシュボードと CLI v2 の公開である。

第 1 版との接続は維持されている。v1.0 の人物 62 名・機関 58 件・27 シナリオ・25 規制・30 市場データ・5 メガトレンド・19 メガトレンド領域マップは v2.0 に継承され、新規収集データと統合された。補論 v7.2 付録 F の 9 領域シナリオ × 3 経路（ともに育てる／権威主義的 AI 統制／生態系切断型自動化）と 8 マイルストーンは引き続き規範的選択構造の参照系として機能する。

本データベースは継続更新される。次回更新では、論文-論文間引用関係（paper_citations）の構築、領域別主要論文への手動レビュー、規制・政策の論文裏付けの拡充、補論本体の脚注への言及論文付与を計画する。
