双子峰の解剖学 — 単一周期内の三層連鎖として

CTI v2 の双子峰プラトーは、産業革命と電力化学革命を二つの独立した峰として配置する。一八五〇年と一九〇〇年に、それぞれ CTI 一〇〇という同じ高さの峰が立ち、両峰のあいだに一八七〇年代から一八九〇年代の連続的な高地が広がる。この発見は、Robert Gordon が一八七〇年から一九一四年を「人類史上もっとも生産性が伸びた時期」と呼んだ事実と、Vaclav Smil の人当たりエネルギー消費データと、Carlota Perez のテクノ経済パラダイム論によって、複数の独立な学問的視点から支持されている。双子峰プラトーは堅固な観測である。

だが、ここで問わねばならない問いがある。双子峰の二つの峰は、なぜそこに立つのか。なぜ一八五〇年と一九〇〇年なのか。なぜ両峰のあいだは谷ではなく高地なのか。この問いに、CTI v2 の枠組みだけでは答えきれない。CTI v2 は文明の高さを測る定規であって、その高さがなぜそこに立つかという生成過程の問いには、別の道具を必要とする。

その道具となるのが、次章で詳述する世紀的連鎖モデル（Centennial Cascade Model、CCM v2）である。CCM v2 は、社会変革を個人層・物質層・制度層の三層連鎖として捉える。社会変革の集積を二十五年単位のバケットで測ると、これら三層は別々の時間構造で集積する。個人層（偉人）の集積は、制度層（社会変革事象）の集積を平均五十年先行する。技術層は制度層と同時的に集積する。三千年のデータから機械的に抽出されたこの相関構造（偉人→制度の遅延五十年で相関〇・九〇〇）は、十九世紀においてもまた、双子峰プラトーの内的構造として直接的に現れる。

双子峰の時代を、十年単位の高解像度で見直そう。十九世紀後半の SI Framework DB（七千三百八十九事象）、Great Figures DB（九千百七十八人物）、Tech Acceleration DB（千百九十一技術）の事象と人物と技術を、十年バケットに集計したとき、何が見えるか。

このデータが浮かび上がらせるのは、双子峰の正体である。第一峰（一八五〇年代）は、Person Layer の集積として見えている。Karl Marx（一八一八年生まれ）、Charles Darwin（一八〇九年）、Abraham Lincoln（一八〇九年）、Otto von Bismarck（一八一五年）、福沢諭吉（一八三五年）、Louis Pasteur（一八二二年）、James Clerk Maxwell（一八三一年）、Gregor Mendel（一八二二年）。彼らはこの十年間に成熟期へ入った世代であり、生まれは一八〇九年から一八三五年に集中する。この世代の集積こそが、CTI v2 が一八五〇年に観測する第一峰の実体である。

第二峰（一八八〇年代）は、Tech Layer と Institution Layer の集積として見えている。Thomas Edison（一八四七年生まれ）、Nikola Tesla（一八五六年）、Alexander Graham Bell（一八四七年）、Wilhelm Conrad Röntgen（一八四五年）、伊藤博文（一八四一年）、Theodore Roosevelt（一八五八年）、Émile Durkheim（一八五八年）。彼らは第一峰の世代より約三十年遅く生まれ、一八八〇年代から一九〇〇年代にかけて成熟期に入った。彼らが生み出した技術（電力、内燃機関、電話、X線、ハーバー=ボッシュ法）と制度（独占禁止法、所得税、年金制度、独立国民国家）は、十九世紀末から二十世紀初頭の社会基盤を組み替えた。

すなわち、双子峰の二つの峰は、独立した二つの文明的事件ではない。それは単一の百年周期（一八二五年から一九二五年）の内部における、三層連鎖の異なる時相が、CTI v2 の二十五年解像度で観測されたときに二つの極大値として現れた姿である。第一峰の偉人世代が、三十年後に第二峰の技術と制度を作る。両峰のあいだの「凹み」が真の谷ではなく高地のままに留まるのは、両峰が同じ百年周期の Phase 3（Innovation）と Phase 4（Institutionalization）として連続しているからである。

この発見は、CTI v2 の双子峰プラトーを否定するものではない。むしろ、双子峰プラトーがなぜ堅固な高地として現れるかの、構造的説明を与える。一八二五年代の Crisis（ナポレオン戦争後の構造的危機、ウィーン体制の限界、産業労働者階級の出現）から始まる百年周期は、Phase 2（Reconstruction、一八三〇年代から五〇年代）で偉人世代を集積させ、Phase 3（Innovation、一八五〇年代から七〇年代）で第一峰を作り、Phase 4（Institutionalization、一八七五年代から一九二五年）で第二峰と制度結晶化を作る。次の Crisis は一九二五年から一九四五年の世界大恐慌と二度の世界大戦であった。

双子峰プラトーは、この単一の百年周期が CTI v2 という指標で観測されたときの姿である。CTI v2 が見る「双子峰」と、CCM v2 が見る「単一周期」は、対立する観測ではない。同じ深層構造を、異なる解像度の異なる定規で測った結果である。本書はこの両者をともに採用する。CTI v2 で双子峰の高さを、CCM v2 で双子峰の生成構造を、それぞれ独立に記述することができる。

そしてこの認識は、AI 革命を解釈する際にも一つの指針を与える。もし AI 革命が新たな百年周期の Phase 3 として現れるなら、その第一峰は二〇五〇年代に Person Layer の集積として、第二峰は二〇八〇年代に Tech と Institution の同時集積として観測されるだろう。その「双子峰」のあいだに、CTI v2 で測れば堅固な高地が広がる。これは予測ではなく、過去の双子峰が示す構造的パターンを、現在の私たちが立つ位置に当てはめた仮説である。次章でこの仮説の根拠を、CCM v2 の三千年データから詳述する。
