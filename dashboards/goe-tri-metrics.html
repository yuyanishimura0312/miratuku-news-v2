GOE-Tri 採点シート

「良い会社かどうか」を倫理(E)・受託(I)・学習(L)の3面から測る審査指標。各6項目・計18指標に、何を見るかの解説と、確保したいデータの説明を添えた。各項目を0〜4点で採点し、面ごとに100点へ換算する。合計1本の順位はつけず、E・I・L の3つの点数の「形」で読む。

18指標 / 3面 各0-4点 → 面別100点 既存制度に接地 2026-07-07

使い方。 各指標の「見るのは何か」の解説と、確保したいデータを読み、右の「点数の目安」に照らして0〜4点で採点する。0=該当なし/宣言のみ、4=数値が高水準かつ外部から検証できる状態。面ごとに6項目の合計(24点満点)を100点へ換算し、E・I・L の3つの点数で示す。最後に「打ち消し条件」に触れる兆候があれば、宣言が立派でも該当の面から差し引く。数値の区切りは目安であり、業界・規模に応じて較正して使う。

0 なし1 宣言のみ2 制度あり3 運用実績4 仕組み+外部検証
E

倫理面 ── 誰に責任を負っているか

株主だけでなく従業員・取引先・地域・環境への責任が仕組みになっているか
E1目的の定款記載後戻りできない使命

見るのは、会社の社会的な目的が「経営者が代わっても消せない形」で定められているか。定款への明記や、目的信託・公益法人格・B Corp認証があれば、株主の短期圧力から使命を守れる。宣言文だけで法的な拘束をもたないものは低く評価する。

確保したいデータ

会社の目的が公式にどう定められているかを、登記や定款といった公的な書類で確認する。社会的目的が明記されているか、さらに目的信託やB Corpのように後から変えにくい形になっているかを見れば足りる。頻繁な更新は不要で、一度確認すればよい。

確保したいデータ例:登記簿・定款の事業目的条項／認定NPO・公益法人・B Corp認証／目的信託の設定有無
4点目的信託・公益法人・B Corp など、代替わりでも消えない形2点定款に社会的目的を明記(法的拘束は弱い)0点記載なし
採点01234
E2独立社外取締役の比率外からの目

見るのは、経営を外からチェックする独立社外取締役が実質的に機能しているか。3分の1以上いて、指名・報酬委員会で実権を持つかを確認する。人数がいても発言や議決に実質が伴わない「名ばかり」の状態は評価しない。

確保したいデータ

取締役会の顔ぶれと権限を、公開資料で確認する。独立社外取締役が何人・何割いるか、指名や報酬を決める委員会に実際に関わっているかを見る。

確保したいデータ例:有価証券報告書・コーポレートガバナンス報告書の役員構成／独立社外取締役の人数と比率／各委員会の構成
4点3分の1以上、かつ従業員・地域の声を反映する仕組みあり2点3分の1未満〜2名以上0点実質ゼロ
採点01234
E3ESG外部格付第三者評価

見るのは、環境・社会・統治を利害のない第三者がどう格付けしているか。MSCIやSustainalyticsの外部評価を使い、自己申告の見せかけを避ける。絶対値だけでなく、数年での改善傾向と、機関ごとに評価が割れていないかも確認する。

確保したいデータ

外部の評価機関が公表している格付を参照する。1社だけでなく複数の格付を見て、水準・経年の変化・機関ごとの評価の割れ具合を確認する。

確保したいデータ例:MSCI ESG格付(AAA-CCC)／Sustainalytics ESGリスクスコア／FTSE Russell 等の公開データ(年次)
4点MSCI AA以上 / Sustainalytics 20未満(低リスク)2点MSCI BBB〜BB / リスク20〜300点CCC / 未取得
採点01234
E4温室効果ガス削減環境の実績

見るのは、排出を実際に減らしているか。科学的な削減目標(SBT)の認定と、前年比の実削減量の両方を確認する。目標を掲げるだけで実績が伴わない企業と、着実に減らす企業とを区別する。売上原単位で補正すると実質が見える。

確保したいデータ

排出量の実データと削減目標を、開示資料で確認する。何トン出しているかの推移と、科学的な削減目標を掲げて実際に減らしているかを見る。

確保したいデータ例:Scope1+2(可能ならScope3)排出量の推移／SBT認定の有無と水準／統合報告書・CDP開示(年次)
4点SBT認定(1.5℃) かつ 前年比で実削減2点削減目標を公表(実績は途上)0点目標も開示もなし
採点01234
E5情報開示と外部保証検証できるか

見るのは、不利な情報まで開示し、その内容を第三者が保証しているか。ISSBやTCFDに沿った開示に外部保証が付いているかを確認する。判断の基準は「開示の量」ではなく「外から検証できるか」。都合の悪い情報を隠していないかを重視する。

確保したいデータ

サステナビリティ関連の開示資料と、その保証状況を確認する。国際基準に沿って開示しているか、そこに第三者の保証が付いているかを見る。

確保したいデータ例:統合報告書・有報のサステナビリティ開示／ISSB(S1/S2)・TCFD準拠状況／第三者保証報告書の有無
4点ISSB(S1/S2)準拠 かつ 外部保証を取得2点任意開示あり(保証なし)0点ほぼ非開示
採点01234
E6役員報酬の非財務連動本気度の証し

見るのは、経営者の報酬に非財務目標(ESG・従業員指標)が実際に連動しているか。連動の有無だけでなく、その比率が開示され、名目的に小さすぎないかを確認する。「連動している」という言葉と、実際の比率とを分けて見る。

確保したいデータ

役員報酬の決め方を示す資料で、報酬と非財務目標のつながりを確認する。報酬に何が連動し、その比率がどれくらい開示されているかを見る。

確保したいデータ例:報酬方針・株主総会招集通知の役員報酬構成／非財務指標の連動比率／評価指標の中身
4点ESG・従業員指標が報酬に連動し、比率を開示2点連動をうたうが比率不明0点財務指標のみ
採点01234
I

受託面 ── 長く誠実に受け託されているか

既存の国際指標が最も測れない面。数値の代理指標で可視化する
I1取引先への支払サイト買い手よし

見るのは、取引先への支払いが遅延や手形で相手に負担を押しつけていないか。支払日数と現金比率を確認し、短く現金払いなら高く評価する。下請法の指導歴は明確な減点。不況時にどう振る舞うかにこそ、受託の姿勢が表れる。

確保したいデータ

取引先への支払い条件と、公的な指導歴を確認する。支払いまでの日数や現金・手形の別、下請法上の問題がなかったかを見る。

確保したいデータ例:下請代金の支払日数／現金・手形の比率／公取委・中小企業庁の指導歴／パートナーシップ構築宣言の登録
4点30日以内(現金) かつ 下請法の指導歴なし2点60日以内0点60日超 / 手形依存 / 違反歴あり
採点01234
I2離職率(定着)健全さの鏡

見るのは、人が辞めずに働き続けているか。離職率を全産業平均(約15%)や同業と比べ、大きく下回れば高く評価する。業界差が大きいので必ず同業比較で読む。新卒3年内の離職や、特定層への偏りも併せて確認する。

確保したいデータ

人の出入りを示す人事データを確認する。離職率がどのくらいか、同業平均と比べて高いか低いか、辞める層に偏りがないかを見る。

確保したいデータ例:有報・人的資本開示の離職率／自己都合離職率／業界平均との比較(年次)。非上場は入退社台帳
4点5%未満2点12%未満0点18%以上
採点01234
I3平均勤続年数・存続年数続く力

見るのは、組織が長く続く力があるか。平均勤続年数と創業からの年数を確認する。ただし高齢化による見かけ上の長さと区別し、若手がきちんと定着しているかまで見て、はじめて持続する力と判断する。

確保したいデータ

働く期間と会社の歴史を示すデータを確認する。平均してどれくらい長く働いているか、創業から何年たっているか、若手が定着しているかを見る。

確保したいデータ例:有報の平均勤続年数／会社概要の創業年／年齢構成／100年企業などの登録
4点平均勤続15年以上 / 創業100年以上2点平均勤続10年前後 / 創業30年以上0点短期離職が常態
採点01234
I4財務の健全性(長期受託)腰を据える

見るのは、短期利益に偏らず腰を据えて経営しているか。自己資本比率と負債の水準、配当の継続を確認する。危機のときに雇用や取引を守れる余力があるかで読む。過度な内部留保は別の問題として、水準で判断する。

確保したいデータ

財務諸表から、経営の安定度を確認する。自己資本の厚みや借入の重さ、配当を続けられているかを見る。

確保したいデータ例:有報・決算短信の自己資本比率／有利子負債の推移／配当継続年数。非上場は決算書
4点自己資本比率50%以上・安定配当を継続2点30%前後0点20%未満・短期偏重
採点01234
I5従業員の健康(健康経営)世間よしの起点

見るのは、働く人の健康を守っているか。健康経営優良法人・ホワイト500の認定を確認し、加えて健診受診率や労災の実態を見る。認定の取得そのものが目的化していないか、中身の指標で裏を取る。

確保したいデータ

従業員の健康に関する認定と実態データを確認する。健康経営の外部認定に加え、健診の受診や労災の状況を見る。

確保したいデータ例:健康経営優良法人・ホワイト500・なでしこ銘柄の認定／健診受診率／労災件数／長時間労働者の割合
4点ホワイト500 / なでしこ銘柄に選定2点健康経営優良法人に認定0点認定なし
採点01234
I6現場の主体性(改善提案)生きた組織

見るのは、現場の一人ひとりが工夫し声を出せているか。改善提案の件数と実装率、小集団活動の有無を確認する。提案の数だけでなく、現場の声が実際に経営へ届く経路があるかまで見る。

確保したいデータ

現場の改善活動を示す社内データを確認する。改善提案がどれくらい出て、実際に採用されているか、小集団の活動があるかを見る。

確保したいデータ例:1人あたり改善提案件数/年／提案の実装率／小集団活動(QCサークル等)の有無と参加率
4点1人あたり年10件以上、または全社的な採算・改善の仕組みが稼働2点提案制度はあるが低調0点仕組みなし
採点01234
L

学習面 ── 学び、変わり続けているか

失敗から学び、前提を問い直し、知が現場から生まれているか
L1心理的安全性スコア学びの土台

見るのは、疑問や失敗を恐れずに口にできるか。心理的安全性尺度(7項目)のチーム平均と経年変化を確認する。これが低いと失敗が隠れ、改善が止まる。部署間で格差が大きくないかも見て、組織全体の実態をつかむ。

確保したいデータ

従業員への匿名アンケートの結果を確認する。安心して発言・失敗できると感じているかを尺度で測り、その推移を見る。

確保したいデータ例:心理的安全性尺度(7項目・7点)のチーム平均／経年推移(匿名サーベイ・半期〜年次)
4点平均5.5以上、かつ前年より改善2点平均4.5〜5.00点4.0未満 / 未測定
採点01234
L2従業員エンゲージメント貢献意欲

見るのは、働きがいや貢献意欲があるか。Gallup Q12やeNPSを継続測定し、傾向を見る。単発の数値でなく、経年の伸びと自由記述の質で読む。高スコアが異論封殺の裏返しでないかにも注意する。

確保したいデータ

エンゲージメント調査の結果を確認する。働きがいや推奨度のスコアと、その経年の伸びを見る。

確保したいデータ例:Gallup Q12(5点)平均／eNPS／パルスサーベイの推移(四半期〜年次)
4点Q12平均4.0以上 / eNPS が正の値2点Q12 3.5前後 / eNPS 0付近0点低水準 / 未測定
採点01234
L3教育・研修への投資学びへの資源

見るのは、人が学ぶことにどれだけ資源を割いているか。1人あたりの教育投資額や研修時間を確認する。金額だけでなく、現場で活かされているか(L4・L6)と併せて読む。投資が一部の層に偏っていないかも確認する。

確保したいデータ

教育にかけた費用や時間のデータを確認する。1人あたりどれくらい投資しているか、その配分が偏っていないかを見る。

確保したいデータ例:1人あたり教育投資額(円/年)／研修時間(h/年)／OJT以外の学習機会
4点1人あたり年5万円以上 / 40時間以上2点年2〜3万円 / 20時間前後0点ほぼ投資なし
採点01234
L4失敗から学ぶ仕組み隠さない文化

見るのは、失敗を隠さず共有し次に活かしているか。ふりかえりや失敗共有会が定例で回り、改善に反映された記録があるかを確認する。制度の有無より運用実績を重視し、報告した人が不利にならない仕組みまで見る。

確保したいデータ

失敗を扱う社内の記録を確認する。ふりかえりや共有会が定例で行われ、改善につながった記録があるかを見る。

確保したいデータ例:ポストモーテム・失敗共有会の頻度と件数／改善に反映された事例の記録／ヒヤリハット報告数
4点定例で失敗を共有し、改善に反映した記録がある2点制度はあるが形骸気味0点失敗が語られない
採点01234
L5内部からの登用育ち継がれる

見るのは、学んだ人が育ち登用されているか。管理職の内部登用比率と育成計画の明確さを確認する。外部登用が悪いのではなく、育成の空洞化が起きていないかを見る。多様な人材に機会が開かれているかも併せて確認する。

確保したいデータ

登用と育成に関する人事データを確認する。管理職がどれくらい内部から登用されているか、育成計画があるかを見る。

確保したいデータ例:管理職の内部昇進比率／育成計画・後継者計画の有無／階層別研修の設計
4点管理職の内部登用が7割以上、育成計画が明確2点半々0点外部依存・育成計画なし
採点01234
L6前提を見直した実績問い直す力

見るのは、「今までのやり方」そのものを問い直せているか。過去数年で戦略や前提を公式に見直し、実際に意思決定を変えた事例があるかを確認する。議論だけで終わっていないか、危機の後追いでなく平時から起きているかを見る。

確保したいデータ

戦略や意思決定の見直し履歴を確認する。過去数年で前提を見直し、実際に決定を変えた事例があるかを見る。

確保したいデータ例:過去3年の戦略・事業前提の見直し回数と内容／意思決定を変えた具体事例／取締役会議事録・中計の改訂履歴
4点前提を見直し、意思決定を実際に変えた事例がある2点見直しの議論はあった0点前例踏襲のまま

打ち消し条件

次の兆候があれば、宣言が立派でも該当の面から差し引く。

見せかけの環境配慮。環境目標を掲げる一方で、排出の実態・訴訟・罰金と食い違う。E −最大10
理念の裏の過重労働。「家族的」「三方よし」を掲げながら、過労死・是正勧告・極端な高離職がある。I −最大10
掛け声だけの学習。学びを掲げつつ、異論が封じられ研修が形だけ。L −最大8
自己申告のみ。外部検証も、後から消せない仕組みもなく、宣言だけ。全面 上限50

点数の出し方

各面6項目(24点満点)を100点に換算し、打ち消し条件を引く。合計1本の順位はつけず、3つの点数「形」で示す。

面の点数 = 6項目の合計 ÷ 24 × 100 − 打ち消し（0〜100にそろえる）
出力 = { E, I, L }

用途に応じて重みを変えた参考値を出してもよい。ただし重みは必ず開示する。

投資の見極め E:0.45 I:0.25 L:0.30
事業承継・地域企業 E:0.25 I:0.45 L:0.30
変化への強さ E:0.25 I:0.25 L:0.50
迷ったら(中立) E:0.33 I:0.33 L:0.33

数値の区切りは出発点の目安であり、業界平均・企業規模・上場非上場で調整して使う。非上場・中小企業は開示情報が少ないため、社内データや聞き取りで補う。この採点シートは合否を一発で決める道具ではなく、「どの面が強く・どの面が弱いか」を見える化し、次の対話の起点をつくる診断ツールである。

この採点シートは、詳細版の学術的な裏づけ(3つの類型・既存指標・学術理論との関係)を、現場で使える形へ落とし込んだもの。指標は既存の制度(ESG格付・下請法・健康経営・心理的安全性尺度・Gallup Q12 など)に接地している。
