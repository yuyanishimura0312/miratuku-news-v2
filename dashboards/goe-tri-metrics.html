GOE-Tri 採点シート(使える版)

「良い会社かどうか」を倫理(E)・受託(I)・学習(L)の3面から測る、実際に使える採点シート。各6項目・計18指標に、約150字の解説と「どんなデータで測るか(想定データ)」を添えた。各項目を0〜4点で選ぶと、画面下に E・I・L の点数が自動で出る。合計1本の順位はつけず、3つの点数の「形」で読む。

18指標 / 3面 各0-4点 → 面別100点 その場で自動採点 既存制度に接地 2026-07-07

使い方。 各指標の解説と想定データを読み、右の「点数の目安」に照らして 0〜4点を選ぶ。0=該当なし/宣言のみ、4=数値が高水準かつ外部から検証できる状態。18項目を選ぶと、画面下に E・I・L の3つの点数が自動計算される。最後に「打ち消し条件」に触れる兆候があれば、宣言が立派でも該当の面から差し引かれる。数値の区切りは目安であり、業界・規模に応じて較正して使う。

0 なし1 宣言のみ2 制度あり3 運用実績4 仕組み+外部検証
E

倫理面 ── 誰に責任を負っているか

株主だけでなく従業員・取引先・地域・環境への責任が仕組みになっているか
E1目的の定款記載後戻りできない使命

会社が「何のために存在するか」を、経営者の交代でも揺るがない形で定めているかを見る。定款や目的信託への記載は、株主の短期圧力から社会的使命を守る最後の砦になる。単なる宣言文と違い、法的な拘束力をもつ点が要で、買収や世代交代を経ても使命が生き残るかどうかが、この一点で分かれる。

想定データ

登記簿・定款の事業目的条項／法人格(認定NPO・公益法人・B Corp認証の有無)／目的信託の設定有無。定性(有無)＋文書実物。更新頻度は低く、一度確認すれば足りる。

4点目的信託・公益法人・B Corp など、代替わりでも消えない形2点定款に社会的目的を明記(法的拘束は弱い)0点記載なし
点数を選択
E2独立社外取締役の比率外からの目

経営を身内だけで回さず、外部の目が実質的に効いているかを測る。独立社外取締役が3分の1以上いれば、暴走や不正へのブレーキになりやすい。人数だけでなく、指名・報酬委員会での実権を伴っているかも併せて見る。名ばかりの社外役員では機能しないため、発言や議決に実質が伴っているかまで踏み込む。

想定データ

有価証券報告書・コーポレートガバナンス報告書の役員構成／独立社外取締役の人数と比率(%)／指名・報酬委員会の構成。年次・公開。非上場は役員名簿と選任経緯。

4点3分の1以上、かつ従業員・地域の声を反映する仕組みあり2点3分の1未満〜2名以上0点実質ゼロ
点数を選択
E3ESG外部格付第三者評価

環境・社会・統治を、利害のない第三者がどう評価しているかを取り込む。自己申告でなく外部機関の格付を使うことで、見せかけを排しやすい。複数機関の格付が割れる場合は、その分散の大きさ自体も判断材料になる。格付の絶対値だけでなく、数年単位での改善傾向まで合わせて読むと精度が上がる。

想定データ

MSCI ESG格付(AAA-CCC)／Sustainalytics ESGリスクスコア(数値)／FTSE Russell 等。各機関の公開データベース。年次更新。未カバー企業は業界水準で補正。

4点MSCI AA以上 / Sustainalytics 20未満(低リスク)2点MSCI BBB〜BB / リスク20〜300点CCC / 未取得
点数を選択
E4温室効果ガス削減環境の実績

環境への責任を、掛け声でなく実際の排出削減で見る。科学的根拠にもとづく削減目標(SBT)の認定と、前年比の実削減量の両方を確認する。目標を掲げるだけで実績が伴わない企業と、着実に減らす企業とを分けて評価する。事業成長に伴う排出増は売上原単位で補正して見ると、実質の努力が捉えやすい。

Scope1+2(可能ならScope3)排出量の時系列(t-CO2e)／SBT認定の有無と水準(1.5℃ / WB2℃)。統合報告書・CDP開示。年次。売上原単位でも補足する。

E5情報開示と外部保証検証可能性

都合の良い情報だけでなく、不利な情報も含めて開示し、第三者の保証を受けているかを見る。ISSBやTCFDに沿った開示に外部保証が付けば、情報の信頼度が上がる。開示の量よりも、外から検証できるかどうかを重視する。とりわけ不利な情報を隠さず出す姿勢こそ、誠実さの試金石になる。

想定データ

統合報告書・有価証券報告書のサステナビリティ開示／ISSB(IFRS S1/S2)・TCFD準拠状況／第三者保証報告書の有無と範囲。年次・公開。

E6役員報酬の非財務連動本気度の証し

経営者が本気で非財務目標を追うかは、報酬の設計に表れる。利益だけでなくESGや従業員指標が報酬に連動し、その比率が開示されていれば、責任が仕組みとして担保される。連動の「うたい文句」と実際の比率とを分けて見る。連動比率が名目的に小さすぎないかまで確かめると、実効性が判断できる。

想定データ

報酬方針・株主総会招集通知(委任状)の役員報酬構成／非財務指標の連動比率(%)／評価指標の中身。年次・公開。

4点ESG・従業員指標が報酬に連動し、比率を開示2点連動をうたうが比率不明0点財務指標のみ
点数を選択
I

受託面 ── 長く誠実に受け託されているか

既存の国際指標が最も測れない面。数値の代理指標で可視化する
I1取引先への支払サイト買い手よし

立場の弱い下請けや取引先に、支払い遅延や手形で負担を押しつけていないかを見る。支払サイトが短く現金払いなら、取引先の資金繰りを守る誠実さの証しになる。下請法にもとづく指導歴があれば、それは明確な減点材料である。好況時だけでなく、不況時にどう振る舞うかにこそ受託の本質が表れる。

想定データ

下請代金の支払日数／現金・手形の比率／公正取引委員会・中小企業庁の指導・勧告歴／パートナーシップ構築宣言の登録。半期〜年次。取引先アンケートでも補える。

4点30日以内(現金) かつ 下請法の指導歴なし2点60日以内0点60日超 / 手形依存 / 違反歴あり
点数を選択
I2離職率(定着)健全さの鏡

人が辞めずに働き続けられるかは、組織の健全さを最も端的に映す。全産業平均(約15%)を大きく下回る低離職は、働く人が大切にされている代理指標になる。ただし業界差が大きいため、必ず同業と比べて読むことが前提となる。新卒3年内の離職や特定層への偏りも併せると、隠れた問題が見えてくる。

想定データ

有価証券報告書・人的資本開示の離職率(%)／自己都合離職率／業界平均との比較。年次。非上場は社内人事データ(入退社台帳)から算出。

4点5%未満2点12%未満0点18%以上
点数を選択
I3平均勤続年数・存続年数続く力

組織として長く続く力を見る。平均勤続年数が長く、創業から長い年月を重ねているほど、短期の波に流されず受託を続けてきた証しになる。ただし高齢化による見かけ上の長さと区別し、年齢構成と併せて読むことが必要である。若手がきちんと定着しているかまで見て、はじめて持続する力と言える。

想定データ

有価証券報告書の平均勤続年数／会社概要の創業年／年齢構成。年次・公開。100年企業認定・老舗の登録なども参考にする。

4点平均勤続15年以上 / 創業100年以上2点平均勤続10年前後 / 創業30年以上0点短期離職が常態
点数を選択
I4財務の健全性(長期受託)腰を据える

短期利益に偏らず、腰を据えて経営しているかを財務で見る。自己資本比率が高く、無理な負債に頼らず安定配当を続けているなら、長期の受託に耐える体力がある。過度な内部留保には別途批判もあるため、水準で判断する。危機のときに雇用や取引を守れる余力があるか、という観点で読むとよい。

想定データ

有価証券報告書・決算短信の自己資本比率(%)／有利子負債の推移／配当継続年数。年次・公開。非上場は決算書(貸借対照表)から算出。

4点自己資本比率50%以上・安定配当を継続2点30%前後0点20%未満・短期偏重
点数を選択
I5従業員の健康(健康経営)世間よしの起点

「世間よし」の起点は、まず働く人の健康を守ること。経済産業省の健康経営優良法人やホワイト500の認定は、労働環境への投資を外部が確認した証しになる。認定の有無に加え、健診受診率や労災の実態も併せて見る。認定の取得そのものが目的化していないか、中身の指標で裏を取ることが肝心である。

想定データ

健康経営優良法人/ホワイト500・なでしこ銘柄の認定／健診受診率／労災件数／長時間労働者の割合。年次・公開および社内衛生データ。

4点ホワイト500 / なでしこ銘柄に選定2点健康経営優良法人に認定0点認定なし
点数を選択
I6現場の主体性(改善提案)生きた組織

現場の一人ひとりが工夫し、声を出せているかを見る。アメーバ経営や小集団活動のように、現場が採算や改善の主体になっていれば、上意下達でない生きた組織の証しになる。提案の「数」だけでなく、実装された割合も重要である。現場の声が実際に経営へ届く経路があるかまで確かめると、実態がつかめる。

想定データ

従業員1人あたり改善提案件数/年／提案の実装率／小集団活動(QCサークル等)の有無と参加率。社内データ。年次。

4点1人あたり年10件以上、または全社的な採算・改善の仕組みが稼働2点提案制度はあるが低調0点仕組みなし
点数を選択
L

学習面 ── 学び、変わり続けているか

失敗から学び、前提を問い直し、知が現場から生まれているか
L1心理的安全性スコア学びの土台

「こんなことを聞いたら」と恐れずに、疑問や失敗を口にできる度合いを測る。学習の土台であり、これが低いと失敗が隠され改善が止まる。Edmondsonの7項目尺度でチーム単位に測り、経年の変化まで見るのが要である。部署間の格差が大きくないかも確認すると、組織全体の実態がつかめる。

想定データ

心理的安全性尺度(7項目・7点)のチーム平均／経年推移。匿名の従業員サーベイ。半期〜年次。設問例「失敗しても責められない」等。

4点平均5.5以上、かつ前年より改善2点平均4.5〜5.00点4.0未満 / 未測定
点数を選択
L2従業員エンゲージメント貢献意欲

働きがいや貢献意欲があるかを測る。エンゲージメントが高い組織は学びと改善が回りやすい。Gallup Q12やeNPS(推奨度)を使い、単発でなく継続測定で傾向を見る。高スコアが異論封殺の裏返しでないかにも注意する。数値の高さより、経年の伸びと自由記述の質を合わせて読むと確かである。

想定データ

Gallup Q12(5点)平均／eNPS(-100〜+100)／パルスサーベイの推移。従業員サーベイ。四半期〜年次。市販の測定サービスでも取得可。

4点Q12平均4.0以上 / eNPS が正の値2点Q12 3.5前後 / eNPS 0付近0点低水準 / 未測定
点数を選択
L3教育・研修への投資学びへの資源

人が学ぶことに、どれだけ資源を割いているかを見る。1人あたりの教育投資額や研修時間は、学習を本気で支える意思の表れ。ただし金額だけでなく、それが現場で活かされているか(L4・L6)と併せて読むと実態がつかめる。投資が一部の層だけに偏っていないか、配分の公平さも確かめる観点になる。

想定データ

従業員1人あたり教育投資額(円/年)／研修時間(h/年)／OJT以外の学習機会。人的資本開示・社内の教育費データ。年次。

4点1人あたり年5万円以上 / 40時間以上2点年2〜3万円 / 20時間前後0点ほぼ投資なし
点数を選択
L4失敗から学ぶ仕組み隠さない文化

失敗を隠さず共有し、次に活かす仕組みがあるかを見る。ふりかえり(ポストモーテム)や失敗共有会が定例で回り、改善に反映された記録があれば、学習が実際に起きている証し。制度の有無より、運用の実績を重視する。失敗を報告した人が不利にならない仕組みがあるかまで踏み込むと、本物かどうか分かる。

想定データ

ポストモーテム/失敗共有会の頻度・件数／改善に反映された事例の記録。社内文書・議事録。随時〜年次。ヒヤリハット報告数も参考。

4点定例で失敗を共有し、改善に反映した記録がある2点制度はあるが形骸気味0点失敗が語られない
点数を選択
L5内部からの登用育ち継がれる

学んだ人が育ち、登用されているかを見る。管理職の内部登用比率が高く、育成計画が明確なら、組織のなかで学びが蓄積・継承されている証し。外部登用が悪いわけではないが、育成の空洞化が起きていないかを確かめる。多様な人材に登用の機会が開かれているかも、併せて見るべき観点になる。

想定データ

管理職の内部昇進比率(%)／育成計画・後継者計画の有無／階層別研修の設計。人事データ。年次。役員の内部出身比率も補足になる。

4点管理職の内部登用が7割以上、育成計画が明確2点半々0点外部依存・育成計画なし
点数を選択
L6前提を見直した実績問い直す力

「今までのやり方」そのものを問い直せているか(ダブルループ学習)を見る。過去数年で戦略や事業前提を公式に見直し、実際に意思決定を変えた事例があれば、変化に対応する力の証し。議論だけで終わっていないかを問う。見直しが危機対応の後追いでなく、平時から起きているかも重要な観点である。

想定データ

過去3年の戦略・事業前提の見直し回数と内容／意思決定を変えた具体事例。取締役会議事録・中期経営計画の改訂履歴。

打ち消し条件

次の兆候があれば、宣言が立派でも該当の面から差し引く。チェックすると下の点数に自動で反映される。

点数の出し方(この採点シートの計算)

各面6項目(24点満点)を100点に換算し、打ち消し条件を引く。合計1本の順位はつけず、3つの点数「形」で示す。

面の点数 = 6項目の合計 ÷ 24 × 100 − 打ち消し（0〜100にそろえる）
出力 = { E, I, L }

画面下のバーに、選んだ点数から計算した E・I・L がその場で表示される。用途に応じて重みを変えた参考値も選べるが、重みは必ず開示する。

投資の見極め E:0.45 I:0.25 L:0.30
事業承継・地域企業 E:0.25 I:0.45 L:0.30
変化への強さ E:0.25 I:0.25 L:0.50
迷ったら(中立) E:0.33 I:0.33 L:0.33

数値の区切りは出発点の目安であり、業界平均・企業規模・上場非上場で調整して使う。非上場・中小企業は開示情報が少ないため、社内データや聞き取りで補う。この採点シートは合否を一発で決める道具ではなく、「どの面が強く・どの面が弱いか」を見える化し、次の対話の起点をつくる診断ツールである。

この採点シートは、詳細版の学術的な裏づけ(3つの類型・既存指標・学術理論との関係)を、現場で使える数値へ落とし込んだもの。指標は既存の制度(ESG格付・下請法・健康経営・心理的安全性尺度・Gallup Q12 など)に接地している。採点結果はこの端末内でのみ計算され、どこにも送信されない。
