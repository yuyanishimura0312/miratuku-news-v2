教科書 deep-knowledge-foresight 全8章を AR-DB と10のミラツク DB で構造化した DKF-DB（116概念・76事象・79問い）から、「深い知の時代に問うべき問い」を意味的にクラスタリングし、最終的に7つへ集約した。各問いには、なぜそれが今問うべき問いなのかの根拠と、個人・共同体で向き合う実践の入口を併記する。

QUESTION 01 / 07

AIが究極化した「浅い知」を引き受けたあと、人類の手元に残る「深い知」を私たちはどう識別し、どう守るのか

CLUSTER: 浅い知/深い知の境界 ／ 候補プール 22 件
関連章: Ch2 · Ch6 · Ch7

なぜこの問いか

Chapter 6「浅い知の時代の完了」と Chapter 7「深い知の時代の再来」の対構造そのものを担う問い。Polanyi 二層論を出発点に、形式知化できる知をAIに引き渡すという文明史的決断と、引き渡せないものへの注意の集中を同時に問う。CQ-DB 7,276問いの ai_invariant + ai_reformulated 51.6%（3,753件）の中心命題と一致する。哲学DB の Polanyi が PHIL-DB に未収録で innovation_theory に編入されている構造的事実が示すように、「深い知」を識別する語彙そのものを現代社会は失いつつある。この識別を取り戻す作業が7問の起点となる。

実践への入口

自分の仕事・暮らしの中で、AI に手渡せる作業（外部化できる手順・記号・記述）と、自分で身体的に行うことに意味のある営み（味わう・関わる・記憶になる）の境界線を、毎週一つずつ言語化する習慣から始められる。境界は固定的でなく可変であり、技術と価値観の両方が動く中で更新され続ける。境界を引くこと自体が深い知への入口である。

クラスタの全体像

AI が浅い知を究極化したあと、人類の手元に残る「深い知」をどう識別し、どう守るかという、Ch6 → Ch7 の中核命題に対応するクラスタ。形式知/暗黙知の境界、身体化認知、AI の理解と人の理解の差異を問う。Ch2「理論駆動 vs データ駆動」/ Ch6「確率的オウム議論」/ Ch6「形式知に変換できない知識はAIにあるか」/ Ch7「AI⇄人の分担」を含む14問が該当。

QUESTION 02 / 07

歌う・踊る・祈る・看取る・抱きしめる ── 身体に属する営みのうち、誰にも譲り渡せないものをどう生き続けるか

CLUSTER: 身体に属する営みの不可譲性 ／ 候補プール 10 件
関連章: Ch5 · Ch7 · Ch8

なぜこの問いか

Chapter 7「祈ることはできない、歌うことはできない、踊ることはできない。祈りとは、祈っている身体そのものの状態であり、外部化できない営みである」を直接受ける問い。Merleau-Ponty 身体知（PHIL-DB 23概念）/ Mauss 身体技法 → Bourdieu ハビトゥス（AN-DB 系譜実装）/ 詩学 2,785概念中「うた65・おどり103・こえ62・いのり15」の2,500年蓄積を裏付けとする。CQ-DB の ai_embodiment_care 428問い・ai_mortality_existence 680問いがこの問いの母集団。技術的可能性と価値観に基づく選択を区別する Chapter 7 の倫理姿勢を、日常の身体の高さに落とし込む。

実践への入口

週に一度、自分の身体だけで完結する営みに30分の時間を空ける。料理を最初から作り食べる、声を出して歌う、誰かを抱きしめる、土に触れる、祈る。「効率化できる」「外部化できる」「代行できる」と気づいた瞬間に、それでも自分でやることを選ぶ。この選択の積み重ねが、身体に属する不可譲な領域を時代の中に保つ最小単位となる。

クラスタの全体像

歌う・踊る・祈る・看取る・抱きしめる ── 身体に属する営みのうち譲り渡せないものを問うクラスタ。Ch7 食事の例（AI=選ぶ/運ぶ/組み立てる ⇄ 人=味わう/分かち合う/記憶になる）の構造を核に、Ch5 Heidegger「死への先駆」、Ch7「触覚記憶」「分娩立会い」「巡礼の身体性」、Ch8 Ubuntu / 西田「場所」を含む11問が該当。

QUESTION 03 / 07

西洋近代科学が人類の知の局所現象でしかないとすれば、神話・伝統知・非西洋哲学を「過去の遺物」ではなく「未来の方位」として呼び戻すには何が要るか

CLUSTER: 西洋近代知の限界と伝統知・非西洋哲学の再来 ／ 候補プール 15 件
関連章: Ch1 · Ch2 · Ch5 · Ch7 · Ch8

なぜこの問いか

Chapter 7「人類の知の生成のかなりの部分は非西洋圏が担ってきた。西洋近代科学の歴史は、人類の知の生成史のごく一部の局所現象に過ぎない」を直接担う問い。伝統知DB 88.7% 非西洋・神話DB 56.1% 非西洋詩文層・TC-DB 循環時間 63.8% 非西洋・KGH-DB 古代100% / 中世81% 非西洋 という4DB横断の量的根拠で支えられる。CQ-DB の ai_traditional_nonwestern 665問い・ai_religion_sacred 459問いがこの問いの母集団。脱植民地的AI論・Ubuntu哲学・道元・西田・先住民データ主権を「思想史的回想」ではなく「未来への方位」として読み直すことを要請する。

実践への入口

「自分の地域・先祖・身体に蓄積された深い知は何か」を、家族・地域・祖先に問いを向ける形で取り戻す。書物経由でなく、土地と人の関係から学び直す。同時に、海外の非西洋哲学（Ubuntu / 仏教認識論 / インド哲学 / 先住民知）を、エキゾチックな参照ではなく、自分の問いの相方として遇する。Eurocentric な枠組みを「中立」と感じる感覚そのものを、定期的に疑うこと。

クラスタの全体像

西洋近代科学が人類の知の局所現象でしかないとすれば、神話・伝統知・非西洋哲学を「過去の遺物」ではなく「未来の方位」として呼び戻すには何が要るか、を問うクラスタ。Ch1 序章「うしろ側に見る未来」の方位反転、Ch2 認識論的帝国主義、Ch5 仏教/ヒンドゥー/儒教、Ch8 Ubuntu/先住民データ主権 を含む15問が該当。

QUESTION 04 / 07

文字以後5,200年「前方に置かれてきた未来」を、循環する時間・世代継承する時間・足元に折り畳まれる時間へとどう取り戻すか

CLUSTER: 時間観の取り戻し — 足元の未来 ／ 候補プール 1 件
関連章: Ch1 · Ch3 · Ch5 · Ch7

なぜこの問いか

Chapter 7 の決め台詞「未来は常に足元にある」を担う問い。TC-DB（477概念）の循環時間 63.8% 非西洋 vs 線形時間 66.5% 西洋という劇的な非対称性が、西洋線形進歩史観が人類の例外であることを実数で示す。Ch1 序章「うしろ側に見る未来」の方位反転は、この時間観の取り戻しから始まる。CQ-DB urgency_horizon = 2050+ ホライズン 1,612問いの70.8%（1,142問い）が深い知5SFに集中する事実は、問いの重心が既にこの方向へ移動していることを示す。哲学的アンカーは道元「有時」(1240) と西田「永遠の今」、実践的アンカーは Haudenosaunee 七世代思考 / Wales Future Generations Act 2015 / Long Now Clock。

実践への入口

判断するときに「7世代後にどう見えるか」を一拍置いて考える習慣を持つ。年単位の計画だけでなく、季節・月相・人生サイクル・世代といった複数の時間スケールを並走させる。日記でなく季記を書く、祖父母世代から孫世代までの言葉を聞く、土地に長く根を張った生業に学ぶ。未来は前方ではなく、いま・ここの厚みの中に折り畳まれていると気づくこと。

クラスタの全体像

文字以後5,200年「前方に置かれてきた未来」を、循環する時間・世代継承する時間・足元に折り畳まれる時間へとどう取り戻すか、を問うクラスタ。Ch1 アンデス パチャ / マヤ循環 / 七世代、Ch3 ロングタームイズム / 近視眼問題、Ch5 死という教師、Ch7 未来は常に足元にある、を含む12問が該当。

QUESTION 05 / 07

AI/AGI が「環境」となる時代に、意識・知能・主体・死といった古典的問いを、私たちは2,500年ぶりにどう問い直すか

CLUSTER: 大哲学時代の問いの再起動 ／ 候補プール 16 件
関連章: Ch5 · Ch6

なぜこの問いか

Chapter 5「2026 — 大哲学時代の到来」の核命題。Karl Jaspers の枢軸時代（BC800-200）に中国諸子百家・インド仏陀・ペルシア・ギリシャで同時発生した根本問いが、AI/AGI 登場によって 2,500 年ぶりに再起動している、という現状診断。哲学DB 10,292概念・PHIL-DB の27サブフィールド・KGH-DB 677events・PQS-DB（philosophical-questions-era-analysis）が裏付ける。Latour アクター・ネットワーク論を経由してAIを「道具」ではなく「環境」として受け止める前提が前提。CQ-DB の ai_intelligence_consciousness 460問い・ai_mortality_existence 680問い・ai_religion_sacred 459問いが母集団。

実践への入口

「AI には意識があるか」「LLM は理解しているか」といった問いを、技術評価の問いとしてだけでなく、自分自身に対して「では私の意識・理解とは何か」と折り返す問いとして受け止める。古典哲学（プラトン / 仏教 / 儒教 / 諸子百家）を、書斎の本ではなく日々の対話に持ち込む。AI 時代に新しく問われる問いは、多くの場合 2,500 年前にすでに問われた問いの現代語訳である。

クラスタの全体像

AI/AGI が「環境」となる時代に、意識・知能・主体・死といった古典的問いを2,500年ぶりにどう問い直すか、を問うクラスタ。Ch5 LLM意識 / Floridi第四革命 / IIT / Heidegger死への先駆 / 仏教認識論、Ch6 確率的オウム / 集合的知能、を含む14問が該当。

QUESTION 06 / 07

AI/AGI が技術主権・地政学・労働・民主主義を同時に組み替える「3緊張期の重なり」の中で、深い知の時代へ向かう分岐を集合的にどう選び取るか

CLUSTER: 3緊張期の重なりの中の集合的選択 ／ 候補プール 13 件
関連章: Ch3 · Ch4 · Ch6 · Ch8

なぜこの問いか

Chapter 4「歴史変動から見えた所見 — 3つの緊張期の重なり」（技術-制度乖離 / 政治中心制度疲労 / 権力軸移動）と Chapter 8「2070-2100年 3階梯」を架橋する問い。CLA 91,550レコード（1900-2026 / 127年）/ PESTLE 196K記事 / Geopolitical Risk 132カ国・422K records / SI events 7,389件が裏付ける。Chapter 7 が政策論を意図的に書かない設計判断（背景レポート §9）を引き受ける形で、Chapter 8 へ橋渡しする位置にある。CQ-DB の ai_governance_law 502問い・ai_labor_economy 453問い・ai_ethics_alignment 516問いが母集団。

実践への入口

「自分の組織・地域は、深い知の時代へ向かう分岐をどう選ぼうとしているか」を、政策・調達・技術選定・採用基準といった具体決定に問う。決定の前に「7世代後どう見えるか」を挟む（問い4 と接続）。技術選定では「効率化のため」だけでなく「人類が残したい身体・場所・関係を守るため」を判断軸に加える。集合的選択は個々の決定の総和として成立する。

クラスタの全体像

AI/AGI が技術主権・地政学・労働・民主主義を同時に組み替える「3緊張期の重なり」の中で、深い知の時代へ向かう分岐を集合的にどう選び取るか、を問うクラスタ。Ch3 ロングタームイズム / 近視眼問題、Ch4 米中AI規制分断 / AI主権 / 権力集中 / AIガバナンス多極化、Ch6 環境影響規制、Ch8 公共調達 を含む13問が該当。

QUESTION 07 / 07

深い知を個々人の知ではなく「時代として」取り戻すために、私たちは『we（ともにある知）』の倫理をどう編み直すか

CLUSTER: we の倫理 — 時代として取り戻す ／ 候補プール 3 件
関連章: Ch7 · Ch8

なぜこの問いか

Chapter 7「われわれはようやく『深い知』を個々人の考えではなく、時代として取り戻すことができる」と Chapter 8「ともに未来を生きる」を直接架橋する最終問い。源泉サイクル GC-DB の N7 we / N8 源泉還流ノードと、Bourdieu の文化資本 / Sen ケイパビリティ / Ostrom コモンズ / Folbre ケア経済の系譜が裏付ける。哲学DB の Buber Ich-Du (1923) / Levinas / 和辻 間柄 / Macintyre 共同体、人類学DB の commensality / conviviality（ただし AN-DB では未収録の弱点）、Ubuntu哲学。CQ-DB の subject_actor=civic+collective+affected が 38.5% を占める分布が、個から共同体への問いの重心移動を実証する。問い1〜6 はすべてこの最終問いに向かって編まれる。

実践への入口

「私が深い知を持つ」から「私たちが深い知の時代を生きる」への主語の転換を、日常の語りで実践する。家族・地域・職場・組織で、深い知に属する営み（祭礼・看取り・育児・食卓・道具の手入れ）を一人で抱え込まず、複数世代・複数立場で共有する仕組みを編む。源泉サイクル N8「源泉還流」を個人サイクルではなく we サイクルとして回す。Chapter 8 が招く「ともに未来を生きる」の最小単位は2人以上の合意である。

クラスタの全体像

深い知を個々人の知ではなく「時代として」取り戻すために、私たちは『we (ともにある知)』の倫理をどう編み直すか、を問うクラスタ。Ch7「深い知は個々人の知としてではなく、時代として取り戻せるのか」、Ch8 和辻間柄論 / Dewey 公衆 / 仏教無常 / 西田場所論 / Ubuntu / ポスト人新世「他者と地球と共にある知」を含む11問が該当。最終クラスタとして全7問を束ねる位置にある。
