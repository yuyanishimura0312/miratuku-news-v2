本分析は GOE-DB (Organization Excellence Knowledge DB) に集積された 1,784 学術概念 × 8 typology × 154 研究者 × 88 文献 × 50 経営事例を、Strauss-Corbin Grounded Theory Methodology (1990/1998) の 3 段階コーディング法 (Open / Axial / Selective) で分析し、「良い組織とは何か」の中核カテゴリを抽出した。

結論を先に述べる。良い組織は単一最適解として存在せず、8 typology の軸 (成果 / 文化 / 学習 / 関係 / 倫理 / 進化 / 在来 / 批判応答) × 4 構成要素 (中核哲学の堅持 / 多 stakeholder 統合 / 多時間軸応答 / 反証可能な動的均衡) の多次元空間において、組織が置かれた文脈 (業界 / 規模 / 文化圏 / 時代) に応じて立ち上がる動的均衡として現れる。

本 GTA はミラツク NPO 中立性原則に基づき、両論を併記し、単一の規範的処方を避けた。意思決定者 (経営者 / 投資家 / 研究者 / コンサルタント) は本分析を「自社の文脈に応じて選択 / 組み合わせる地図」として活用されたい。

Phase 3: Selective Coding (選択的コーディング)

★ 中核カテゴリ

Falsifiable Dynamic Equilibrium of Multi-Stakeholder Multi-Temporal Anchoring
良い組織とは、自己の中核哲学を堅持しながら、複数 stakeholders の異なる時間軸の利害を統合的に応える反証可能な動的均衡を維持する組織である。

4 構成要素

1. 中核哲学の堅持 (Core Philosophy Anchoring)

創業者またはグループが明文化した中核哲学を、利益圧力 / 制度的同型化圧力に対しても堅持する能力。

学術根拠: Type 5 (倫理型) + Type 7 (在来型) の 505 concepts

3. 異なる時間軸の利害応答 (Multi-Temporal Responsiveness)

短期 (四半期業績) と長期 (世代を超える価値創造) の異なる時間軸の利害に同時に応える能力。

パラドックス的発見

  • **同一企業内で「良い」判定が逆転する**: Toyota TPS = Lean Excellence と評価されながら、Karoshi/Foxconn Suicides の温床にもなる。「良い組織」は文脈依存。
  • **8 typology は補完的でなく時に対立的**: Type 1 (HPWS 業績主義) は Type 8 (Karoshi 批判) と直接対立。Type 6 (Teal) は Type 7 (在来文化) と協働困難。
  • **在来型 (T7) と批判応答型 (T8) が批判耐性最高 (0.80 / 0.90)** が、両者は西洋実証主義の枠組みでは測定困難 (Tsui 2007 Indigenous Management の方法論問題)。
  • **西洋系 6 typology (T1-T6) は実証性高いが文化中立性に課題** (Henrich et al 2010 WEIRD bias 問題)。GOE-DB 154 researchers のうち 70% が西洋圏で、構造的偏向は是正中。
  • **「良い組織」の単一最適解は存在しない**。8 typology は意思決定者が文脈と価値観に応じて選択 / 組み合わせる地図として機能する。NPO 法人ミラツク中立性原則と整合。

NPO 法人ミラツク中立性原則

本 GTA は「良い組織とは何か」の単一最適解を提示せず、8 typology × 4 構成要素 × 5 パラドックスの多層構造を中立的に整理した。「良い組織」の判定は組織が置かれた文脈 / 業界 / 規模 / 文化圏 / 経営者世代 / 時代によって変動するため、本分析は 意思決定者が自社の文脈に応じて選択 / 組み合わせる地図 として活用されるべきである。

特に Type 7 (在来型) と Type 8 (批判応答型) の批判耐性が高い (0.80 / 0.90) ことは、両者が西洋実証主義の枠組みを超えた長期的妥当性を持つことを示唆するが、それゆえに測定容易性が低い (0.40 / 0.35) というトレードオフを内包する。これは「測定可能な良さ」と「測定困難な良さ」の二項対立を超える新しい評価フレーム構築への呼びかけでもある。
