01プロジェクト要旨

v3〜v5の3ラウンドで5,056件の学術ナラティブを付与してきた本DBは、データの量的拡張と質的厳密性の両立を進めてきたが、依然として4種の残課題があった。第一に、v4・v5で新規追加された1,608件の事象に Drayton 4段階分類が未付与であった。第二に、v5で取りこぼされた186件の事象にナラティブが未充実であった。第三に、v3〜v5の全ナラティブ群に固有名音写の表記揺れ（中黒分離、ムハンマド／Muhammad の混在等）が散見されていた。第四に、Tier-A 事象77件の引用学者の整合性監査が未実施であった。

v6はこれを4ブロック並行で完備化する。Block A（Drayton分類）と Block B（残ナラティブ）はCodexチームによる並列処理、Block C（音写検証）と Block D（学者照合）は Python による機械的検証で実施した。Block A は概ね100%完了、Block B はテンプレート再発を QC で検出し品質基準を満たさない出力を Reject、Block C は450件の中黒分離を自動修正、Block D は Tier-A 21件のスパース引用事例を v7 手動精緻化対象として特定した。

02Block A — Drayton 4段階分類の補完

v4・v5で新規追加された1,608件の事象は、文明圏×時代×規模の文脈情報こそ備えていたものの、Bill Drayton の4段階モデル（direct_service / scaled_direct_service / pattern_change / framework_change）の分類が未付与であった。v6ではこれを19の Codex チームに分割し、各チームに最大140件の小バッチで分類タスクを委ねた。各事象の type / scale / actors / mechanism / description から、論理的に該当段階を判定する規則ベースの判断を要求した。

結果として19/19のチームが完了し、1,592件が分類された。残16件は event_id のバッチ漏れによる未処理であり、v7 で対応する。文明圏別では、cross_civilizational・south_asian・islamic・central_asian で全件完備、african と pacific でほぼ全件完備となった。

03Block B — 残ナラティブの完備化試行

v5で取りこぼされた186件の事象に対し、3つの Codex チーム（NB_RESIDUAL_A/B/C）でナラティブ生成を試行した。NB_RESIDUAL_A（70件）は QC を通過したものの、Iliffe・Cooper F.・Mamdani・Hopkins A.G. を全アフリカ事象で機械的に引用するテンプレート傾向が観察された。NB_RESIDUAL_B（70件）は v3 と同様の冒頭句テンプレート（「[Year]の[Country]では、[event]が生じた背景に...」）を多用したため QC で REJECT、データベース適用から自動的に除外した。NB_RESIDUAL_C（46件）は Codex 内部で stall が発生し、SQL 出力に到達せず未完了に終わった。

結果として、本ラウンドは69件の追加ナラティブを得たが、依然として117件が未充実のまま残った。v7 では、(1) NB_RESIDUAL_B の REJECT 群を含めた117件に対し、より厳格な禁止フレーズリストと事象固有性の要求を追加、(2) Codex 単一プロセスの token budget をより小さなバッチで分散、(3) 必須参照学者リストの「文明圏ごとの厳密対応」ではなく「事象ごとに3名以上を文献検証付きで提示」する設計、によって対応する。

v6で生成された69件のナラティブには narrative_source='codex_team_v6' のタグが付与されており、将来的な手動レビュー対象として識別可能である。

04Block C — 固有名音写の機械検証

v3〜v5で生成された全ナラティブフィールドを対象に、固有名の音写問題を機械的に検証した。最も深刻な問題は、英単語が中黒（・）で分離される異常表記である。たとえば「khagan・conversion・state」は本来「khagan-conversion-state」または「カガン・改宗・国家」と表記されるべきものである。これは Codex の生成過程で日本語の中黒区切りロジックが英単語にも誤適用されたために生じた構造的問題であった。

本ラウンドでは、3単語以上の中黒連結パターン（[A-Za-z]+(・[A-Za-z]+){2,}）を正規表現で検出し、ハイフン区切りに自動置換した。si_process フィールドで263件、causal_narrative で153件、description で21件など、合計450件の異常表記を修正した。一方、表記揺れ（ムハンマド/Muhammad の499事例、Genghis/Chinggis の132事例、Salah al-Din の14事例など）は、文脈依存の判断が必要なため自動修正は行わず、レポートに記録するのみとした。これらは v7 以降の手動標準化対象である。

05Block D — Tier-A 事象の引用学者照合

Tier-A 評価の77件の事象について、refs フィールドの引用学者数と命名整合性を監査した。43/77 が4名以上の学者を引用しており、量的には十分であった。一方、21/77 で引用学者が3名未満（うち4件が1名のみ）であり、これらは本来であれば Tier-A の質的水準を満たすために追加の主要研究者が必要である事例である。

たとえば「アショーカ王の石柱勅令と仏教国家」（SI_PM_0001）は Thapar R. のみ、「ガダ制度（オロモ族の世代制民主主義）」（SI_PM_0006）は Asmarom Legesse のみ、「アガ・カーン開発ネットワーク」（SI_IS_0007）は Ruthven のみ、と単一引用に留まっている。これらは v3 段階で curated されたエントリで、量よりも特定の primary source への忠実性を優先した結果である。本ラウンドの監査は、これらを「v7 で追加学者の補強対象」として識別する位置付けである。

Tier-A 全体では、Hourani（Arabic Thought in the Liberal Age）、Eisenstein（The Printing Press as an Agent of Change）、Lane（Venice）、Murra（Inka State）、Watson（Roman Law）など、各専門領域の古典的研究者が引用されており、引用品質は概ね合格水準にある。

06限界と今後（v7に向けて）

v6ラウンドの限界としては、第一に、Block B のナラティブ生成において、Codex のテンプレート使用問題が再発した。v3・v4・v5で蓄積された禁止フレーズリストは事前に開示しても、Codex は別の表現で同等のテンプレート構造を生成する傾向があり、構造的根絶には未到達である。第二に、Block C の表記揺れ問題は、文脈判断が必要な範疇（ムハンマド/Muhammad など）には自動修正を適用できず、機械的検証の限界が明確になった。第三に、Block D の学者監査は、本来であれば各引用著作の年代と事象年代の整合性まで検証すべきであるが、本ラウンドでは引用学者数の量的監査に留めた。

v7では、(1) NB_RESIDUAL の117件残を、各事象の civilization × era × type に対応した小バッチ（10件以下）で再生成、(2) 表記揺れの主要パターン（人名・地名・概念名）について標準化辞書を整備し、機械置換可能な範囲を拡大、(3) Tier-A 21件のスパース引用事象に対し、各事象の主題に最も近い研究者2-3名を追加引用する手動精緻化、(4) Drayton 残16件の手動分類、によって対応する。最終的には、外部学者によるサンプリング・レビューを経て、SI歴史的構造変革DBは公開可能な学術データセットとして完結することを目指す。
