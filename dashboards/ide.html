CHAPTER 01概観

投資家・ベンチャーキャピタル・プライベートエクイティ・合併買収実務者のデューデリジェンスから投資実行・モニタリング・出口までの全プロセスを支える、考え方・概念・数式・理論・証明・数値例の学術的に検証された統合知識基盤として構築されている。各概念には LaTeX 形式の数学的定式化を必須化することで、投資判断の論理的根拠を全てトレース可能にする設計とした。

本データベースの存在意義は、投資仮説の検証を直感や慣行ではなく、数学的・統計的に厳密に追跡可能な学術知の連鎖として裏打ちすることにある。マーコウィッツの現代ポートフォリオ理論から伊藤解析、ブラック・ショールズ公式、スペンスのシグナリング理論、グロスマン＝ハートの不完備契約理論、サールマンのベンチャーキャピタル評価法、カーネマン＝トヴェルスキーの見通し理論、アルツナーの整合的リスク測度まで、投資判断を支える理論群を相互参照可能な単一の知識グラフとして統合する。

CHAPTER 05Investment Scoring Engine

Phase 14.5 で構築する Investment Scoring Engine は、9 次元のデューデリジェンスを数学的に裏打ちされた構造化スコアとして出力する。team・market・product・traction・moat・financial・legal_regulatory・valuation_fit・esg_impact の各次元がそれぞれ ide_concept の数式に紐付き、出力は Expected MOIC・Expected IRR の信頼区間・ファンド内 Sharpe 比類比・5 年生存確率・Power Law 上位寄与確率・VaR(95%) と CVaR(99%) を返す。

各スコアの根拠は ide_concept の数式と AR-DB の関連 DB から取得した evidence サンプル 15-30 件を URL 付きで引用する設計とし、ハルシネーション混入を構造的に排除する。これにより投資判断の責任を曖昧にせず、参照可能な学術知の連鎖として記録する。

CHAPTER 07方法論・品質基準

本 DB は /academic-db-build v1.1 の Phase 0 から Phase 15 を順守し、Phase 14.5 で Investment Scoring Engine を追加した拡張版方法論に基づく。評価者間一致度は Gwet AC1 を主指標、Cohen's κ を参考値とし、観測一致率・有病率・サンプルサイズを併記する 5 件セットで品質を担保する。

文化バランスは非西洋率 30% 以上を絶対基準とし、伊藤清の確率解析を起点とした東京数理解析学派、奥野正寛・伊藤秀史の契約理論、宮島英昭の日本企業合併買収研究、林毅夫の新構造経済学、ハビーブ・アハメドとマフムード・エル・ガマールのイスラム金融、サンギート・チョーダリーのプラットフォーム数理を構造的に組み込む。単なる西洋理論の地域適用ではなく、非西洋発の固有理論を論理展開の駆動軸として配置する。
