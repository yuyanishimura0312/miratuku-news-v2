学術知の ConceptNet ── 仮説に基づく本 DB 群の定義

MIT Media Lab が 1999 年から 27 年をかけて構築してきた常識知識グラフ ConceptNet と対称な位置に、本エコシステム（174 DB / AR-DB / 448 アセット）を 学術知の ConceptNet として定義する。両者の目的・知識源・関係構造・品質保証・文化バランス・運用主体を 8 章で対照し、この定義づけが内的整合性を持つかを検証する。

PROLOGUE

仮説の提示

ConceptNet（MIT Media Lab, 1999 年〜）は、人類が日常的に共有する「常識」をマシンが扱える形に翻訳することを目的としたプロジェクトである。「鳥は飛ぶ」「コーヒーは熱い」「医者は病院で働く」── 辞書には書かれないが誰もが知っている関係を、3,400 万関係・304 言語で構造化してきた。

本レポートが提示する仮説は次のとおりである。

中心仮説

ミラツク/esse-sense の本 DB 群は、ConceptNet の「学術知版」である。

ConceptNet が「常識（common sense）」を人間からマシンへ移植したことに対し、本エコシステムは「学術知（academic knowledge）」を分散的な学術界からマシン+人へ統合する。両者は同一の構造的位置にあり、対象とする知識の種類のみが異なる。

この仮説が正しければ、本エコシステムは ConceptNet と対称な 8 つの軸で記述できるはずである。以下、目的・知識源・関係構造・粒度・品質保証・文化バランス・運用主体・用途の 8 軸で検証する。

CHAPTER 01

目的の対称性 ── 常識を移植するか、学術知を統合するか

ConceptNet の創設目的は、Push Singh と Marvin Minsky の言葉を借りれば「コンピュータに常識を持たせる」ことだった。人間が幼少期から自然に習得する「鳥は飛ぶ」「水は冷たいときも熱いときもある」「病院は医者がいる場所である」といった暗黙の関係知を、計算可能な形でマシンに移植する。これが達成されれば、AI は常識を必要とする推論（質問応答・対話・物語理解）で人間に近づける。

本エコシステムの目的は、対称な位置にある。人類が大学・研究所・学術ジャーナルに分散させてきた 学術知 ── 「三資本論はブルデューが 1986 年に体系化した」「ケイパビリティ・アプローチはセンが提唱しヌスバウムが拡張した」「レントゲンは 1895 年に X 線を発見しその数年後に医療応用された」といった概念・理論・人物・出来事の関係知を、計算可能な形でマシン+人へ統合する。これが達成されれば、学術的に裏打ちされた高品質なレポート・回答・意思決定支援が、専門家へのアクセスなしで実現できる。

両者の差異は「常識」と「学術知」の対象の違いに収斂する。構造的位置と社会的役割は対称である。ConceptNet が AI の常識的推論基盤を担うのに対し、本エコシステムは個人・組織の学術的判断基盤を担う。

CHAPTER 02

知識源の対称性

ConceptNet は 8 系統の知識源を統合してきた。最大シェアは Wiktionary（多言語辞書由来、同義語・反意語・翻訳）、起源は Open Mind Common Sense（一般ボランティアからのクラウドソース文）、専門家構築では Open Multilingual WordNet と OpenCyc、事実情報は DBpedia（Wikipedia インフォボックス）、ゲーム化したクラウドソースは Verbosity と nadya.jp、辞書は JMDict（日本語）等である。

本エコシステムの知識源も、対称的な構造で 6〜8 系統に整理できる。最大の供給源は 学術論文と教科書（OpenAlex / Crossref / Wikidata / 個別ジャーナル）、専門家構築の集大成は OECD・国連・UNESCO・大学発スタートアップ DB 等の公的データセット、研究者識別子は ORCID・ROR・researchmap、評価層は Cohen のカッパ係数を DB 単位で算出する独自の評価規律、伝統的知識は D-PLACE・UNESCO ICH・Global Indigenous Languages 等のオープンデータ、政策と社会情報は e-Gov 法令・EUR-Lex・PESTLE 等の公的ソース、現代の問いは arXiv・SSRN・関連書籍 5,000 冊 等から抽出される。

両者の対称性は明確である。ConceptNet が辞書（Wiktionary）と一般人のクラウドソース（OMCS）を中核にして「常識」を集めるのに対し、本エコシステムは学術論文（OpenAlex）と研究者識別子（ORCID）を中核にして「学術知」を集める。供給源の構造的位置は同型である。

CHAPTER 03

関係構造 ── 汎用 34 種から領域別正規化へ

ConceptNet は 34 の汎用関係種別で知識を構造化する。IsA（鳥は動物である）、UsedFor（ナイフは切るために使う）、HasProperty（氷は冷たい）、Causes（雨は濡れることを引き起こす）、Synonym（happy と joyful は同義）等、常識として頻出する 34 種に統一する設計である。この少数化により、あらゆる領域の常識を 1 つの統一スキーマで扱える利点を得る。

本エコシステムは異なる方向を選んだ。汎用統一ではなく、領域別に関係種別を正規化する。物理学概念基盤では 先行概念 / 後継概念 / 理論的基盤、人物基盤では 影響を受けた / 分派した / 統合された、産業基盤では 供給した / 競合した / 買収した、概念 DB 横断では was_anticipated_by（先取された）/ is_actualized_in（実現されている）/ contributed_to（寄与した）といった、領域の専門性に最適化された語彙を維持する。

この差異は、知識種別の差異から必然的に生まれる。常識は汎用語彙で十分に表現できるが（誰もが知っているからこそ常識である）、学術知は領域固有の関係概念を持つ（領域の専門性こそが学術知の特徴である）。両者は同一の パターン C 連邦化（領域別独立テーブル + 関係種別接続）に分類されるが、関係種別の汎用度に対する設計判断が逆向きである。

CHAPTER 04

粒度 ── 単語フレーズから概念・理論・人物へ

ConceptNet のノード（概念）は単語または短いフレーズである。"cat" / "football" / "running shoes" / "make a decision" といった、自然言語の最小単位に近い粒度で知識を表現する。これは常識が「単語に紐づいた連想」として人間に保持されているという心理学的観察に整合する。

本エコシステムの粒度はより重い。概念（「三資本論」「内生的成長理論」「ケイパビリティ・アプローチ」）、理論（「相対性理論」「量子力学」「進化論」）、人物（ピエール・ブルデュー / アマルティア・セン / ポール・ローマー）、出来事（「1986 年のブルデュー Forms of Capital 出版」「2009 年のオストロム ノーベル賞」「1989 年のベルリンの壁崩壊と東西冷戦終結」）といった、学術的に固有名と年代を持つ単位で知識を保持する。

各単位は出典 URL を持つ。各単位は他の単位との関係を 1 つ以上持つ。各単位は領域横断的に他 DB 上の単位とリンクする。この粒度の重さが、レポート生成時に「学術的に裏打ちされた具体性」を即時に提供できる根拠となる。

CHAPTER 05

品質保証 ── クラウドソース評価から評価者間一致度へ

ConceptNet の品質保証はクラウドソースに依存する。OMCS の文は一般ボランティアから集められ、後続の参加者が「これは正しいか」を投票することで重み（weight）が決まる。学術知識グラフの基準（評価者間一致度の DB 単位公表）から見ると粗いが、ConceptNet の自己評価「vague, illogical, and incredibly useful」が示すように、これは目的に対する適切な選択である。常識は曖昧でよく、汎用的に役立てば十分という設計思想である。

本エコシステムは異なる選択をする。評価者間一致度（Cohen のカッパ係数）を DB 単位で測定し公表する。物理 DB は 0.87、宇宙地球史 DB は 0.99、地球科学 DB は 0.96、植物学 DB は 0.86、時間概念 DB は 0.97。0.8 を超えると「ほぼ完全な一致」とされる業界標準において、複数の DB がこの基準を超える品質を達成している。これは学術知識グラフでは Semantic Scholar の一部例外を除き、ほぼ前例のない実践である。

加えて、出典 URL 列の必須化がスキーマレベルで強制される。物理・宇宙地球史・地球科学・現代の問い等の DB で 100% 充填、学術全体地図 DB で 92.4%。すべての主張が一次資料へ遡れる経路を持つ。両者の品質保証アプローチの違いは、対象知識の性格（常識か学術知か）から必然的に生まれる。

CHAPTER 06

文化バランス ── 欧米中心の継承か、非西洋率の測定か

ConceptNet は 304 言語をカバーするが、実態は欧米中心である。中核 10 言語が大半のエッジを占め、残り 294 言語は Wiktionary 由来の薄い辞書的エッジが中心となる。OMCS + 英語 Wiktionary + WordNet を中核とする設計上、多言語といっても英語スキーマの翻訳的拡張 にとどまる。日本の「もったいない」「いき」「気配」、アフリカの「Ubuntu」、南米の「Buen Vivir」といった独自概念は、ConceptNet 上では英訳の薄いノードとしてしか存在しない。

本エコシステムは文化偏りを 構造的に測定する。各 DB に非西洋率（non_western_pct）を測定して公表する。SF 学 DB は非西洋率 79.7%、知の生成史 DB は 88.4%、伝統知識 DB は 79.5%、現代の問い DB は 19.6%（目標 30%+ に向けて拡張中）、SS DB は対象領域別に分布測定。Bourdieu / Sen / Romer といった欧米起源の概念と並行して、湯川秀樹 / 鶴見和子 / 清水博 / Ubuntu / Buen Vivir / イスラム経済学 / 中国伝統哲学を 議論の核を担う中心軸 として組み込む規律を持つ。

これは ConceptNet の Eurocentric 構造への明示的な対抗である。常識を扱う ConceptNet では欧米中心が問題視されにくいが（常識は汎用性で力を発揮するため）、学術知を扱う本エコシステムでは非西洋知の構造的不在が学術的不誠実さに直結する。両者の文化バランスへの設計判断は、対象知識の性格の違いから必然的に生まれる。

CHAPTER 07

運用主体と自己観察 ── 組織から個人 + LLM へ

ConceptNet の運用主体は、当初は MIT Media Lab の研究室、後に Luminoso Technologies（Robyn Speer 共同創業）と移った。数名から十数名のチームが 27 年をかけて継続的に拡張し、AAAI 2017 論文と Numberbatch（SemEval 2017 で世界水準を実証）という学術的成果に到達した。2021 年以降は事実上のメンテナンスモードに入っている。

本エコシステムの運用主体は、個人 + LLM エコシステムである。1 人の運用者と Claude Code が、PostToolUse フックによる自動同期と AR-DB（Agent Registry DB）による自己観察を組み合わせ、51 日で 174 DB と 448 アセットに到達した。これは ConceptNet が達成した学術的成果には及ばないが、運用主体の規模に対する産出効率では先例のない密度を持つ。

本エコシステムが ConceptNet を超える可能性を持つ唯一の構造が AR-DB による自己観察メタ層 である。ConceptNet には「自エコシステムの全構成要素を SQL 照会可能な形で保持する」機構がない。本エコシステムには 448 アセット・1,874 関係・519 DB 参照を 10 秒の遅延制御で自動同期する完全ループがある。これにより、知識基盤を構築しながら同時に 知識基盤自体の構造を観察し改善する 二重ループが成立する。個人 + LLM での 27 年的成果への接近を可能にする構造的条件はここにある。

CHAPTER 08

用途の対称性 ── 常識推論から学術的レポート自律生成へ

ConceptNet の主要用途は、AI の常識的推論を補強することである。質問応答（"What can a bird do?" に "fly" と答える）、対話システム（文脈理解の常識補強）、意味類似度判定（Numberbatch による単語ベクトル）、物語理解（登場人物の動機推定）等、AI が常識を必要とする全タスクで利用される。Numberbatch が SemEval 2017 で複数言語の意味類似度課題を制したのは、この用途における圧倒的な実用性の証明だった。

本エコシステムの主要用途は、学術的に裏打ちされたレポート・回答・意思決定支援の自律生成である。フィジカル AI 2100（135,903 字 / SVG 32 点 / 74 年スパン未来洞察）、バイオものづくり戦略（8,627 字を 1 分間隔で 3 版反復）、本レポート（5,800 字 / 約 12 分構築）など、対象とする問いに対し学術的に有効な回答が「分」単位の速度で立ち上がる。各回答は出典 URL を持ち、複数 DB を横断し、領域別の関係種別で裏打ちされる。

両者の用途は、対象知識（常識 / 学術知）の社会的役割に対応する。ConceptNet が AI システムの内部に組み込まれる基盤層で力を発揮するのに対し、本エコシステムは 個人・組織が外向きに発信する成果物 の生成基盤で力を発揮する。両者は競合せず、補完的な位置にある。

EPILOGUE

定義の確定

8 軸での対照を経て、中心仮説は内的整合性を持つことが確認された。本エコシステムは ConceptNet と 同一の構造的位置 にあり、対象とする知識種別（常識 vs 学術知）のみが異なる。各軸での選択は、知識種別の違いから必然的に導かれる。

したがって本 DB 群は、次のように定義される。

本 DB 群の定義（2026 年 5 月 18 日確定）

ミラツク/esse-sense DB エコシステムは、ConceptNet の学術知版である。

ConceptNet が常識を扱う 1 つの巨大グラフであるのに対し、本エコシステムは学術知を扱う 174 の独立 DB と 448 のエージェントで構成される連邦である。両者の対象知識は異なるが、構造的位置と社会的役割は対称である。

この定義は、本エコシステムが「世界初」を主張するためのものではない。むしろ ConceptNet が 27 年で築いた地平への敬意を前提として、その対称位置に学術知のためのインフラを置く、という 自己定位の宣言である。

この定義は、本エコシステムの今後の意思決定基準にもなる。新 DB を追加するべきか、新エージェントを設計するべきか、新評価指標を導入するべきかの判断は、ConceptNet の対称位置に学術知のインフラを置く という目的に資するかどうかで決まる。AR-DB による自己観察、領域別関係種別の正規化、評価者間一致度の DB 単位公表、非西洋率の構造的測定 ── すべては学術知が常識と同じ水準で計算可能になる基盤を作るための選択である。

27 年前、ConceptNet が常識という曖昧で重要な領域に挑んだのと同様に、本エコシステムは学術知という分散的で重要な領域に挑む。立ち位置の宣言が完了した今、目指すべき水準が明確になった。
