01概要

SEO 学術 DB v1.0-final は、検索エンジン最適化 (SEO) を Information Retrieval (IR) / Web Search Science の応用領域として体系化する横串学術データベースである。SIGIR (情報検索国際会議) / WSDM / CIKM / WWW / TOIS / JASIST 等の一次論文を起点とし、Moz・Yoast・Ahrefs 等の業界実務知は二次資料として位置づける。

2026-05-23 時点で 13+1 サブフィールド × 1,905 concepts × 8,015 cross_db_refs (25+ target DBs) を達成。207 concepts に LaTeX 数式・自然言語証明・数値例を同梱し、4 層 architecture (Layer 1 学術 / Layer 2 実データ / Layer 3 意思決定支援 / Layer 4 実行 API) で実装直結まで支援する。

本 DB は /ddb 二段階開発 フレームワーク (Stage 1 量 + Stage 2 質 の交互サイクル) を 5 サイクル完遂して構築した。非西洋率 6.5% → 34.0% (+27.5pt) の文化的多様性を構造的に組み込み、Eurocentric 偏重を是正している。

079-dim SERP Scoring Engine

IDE-DB の Phase 14.5 Investment Scoring Engine (9 次元 DD) を SEO に適用した SERP composite score。Cobb-Douglas 幾何平均で 9 次元を統合し、Delta Method で 95% 信頼区間を算出。

composite = ∏_i x_i ^ (w_i / Σ w_i)
CI_95 = exp(log(composite) ± 1.96 · √(Σ (w_i/Σw)² σ_i²))

085 つの Expected Value Model

SEO 投資判断のための 5 つの期待値モデル。seo_algos.ev_models で実装。

  1. E[CTR](position, intent) — Backlinko + Advanced Web Ranking 2024 empirical CTR 曲線。Position 1=27.6%, Position 10=1.6%。intent multiplier (informational 1.0 / navigational 1.4 / commercial 0.85 / transactional 0.75)。
  2. E[ΔTraffic](current, target, MSV, intent) — ランク移動による traffic 増加。(CTR(target) - CTR(current)) × MSV。
  3. E[Backlink](DA, days, quality, MSV) — log-linear regression: log(E[BL]) = -2.0 + 0.04·DA + 0.6·Q + 0.3·log(MSV) - 0.001·days。Ahrefs 2024 calibration。
  4. RAT (Ranking Acquisition Time) — Top 10 到達に要する月数。RAT = (rank_gap / (10·DA/100)) × (1 + 4·comp) × max(2-Q, 0.5)。Aleyda Solis 2023 industry survey + Ahrefs 2024 calibration、最大 36 ヶ月。
  5. 5y-Retention (5 年 retention probability) — sigmoid: P = σ(0.05·DA + 2.0·Q + 0.3·log(1+updates) - 0.001·age - 1.5)。Long-term content survival。
