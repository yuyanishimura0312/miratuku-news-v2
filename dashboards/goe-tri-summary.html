Executive Summary ・ GOE-DB Typology

三類型による組織卓越性の審査指標

「良い組織」に単一の正解を与えず、性格の異なる3つの卓越性――倫理型・在来型・学習型――を並置する軸として企業を審査する。GOE-DB の実測値に接地し、既存指標の空白を代理指標で補い、学術理論との関係を可視化したうえで、証憑を要求する実行可能なルーブリックまで到達させた。その骨子を約5000字にまとめる。

GOE-DB concepts 1,784 typology 8類型 measurement 75 cross_db_refs 185 / 23DB 2026-07-07
はじめて読む方へ ── 3つの言葉だけ先に

3つの面で会社を測ります。倫理面=誰に責任を負っているか(環境・社会・従業員・取引先)。受託面=長く誠実に受け託されているか(存続・現場の主体性・三方よし)。学習面=学び変わり続けているか(失敗から学ぶ・心理的安全性)。

本文では、この3つを学術的な呼び名で「倫理型・在来型・学習型」とも呼びます。また「測定可能性」は数値で測りやすいか、「批判耐性」は批判に対して崩れにくいか、「プロファイル」は3つの点数の組み合わせ(順位ではなく形)のことです。具体的な採点方法は 採点シート にまとめています。

01なぜ3つの面を「並べて」測るのか

GOE-DB は「良い組織・良い企業卓越性」を15サブフィールド1,784概念で集積し、それを測定可能性・批判耐性・文明圏・学派の多次元でクラスタリングして8類型を導いた。本レポートはそのうち、倫理型(Type 5)・在来型(Type 7)・学習型(Type 3)の3つを取り出す。3つを選んだ理由は、性格が互いに大きく異なり、企業の別々の顔を照らすからである。倫理型は「誰に責任を負うか」、在来型は「どれだけ長く受託しつづけるか」、学習型は「どれだけ学び変わりつづけるか」を問う。

重要なのは、これらを優劣で並べないことだ。NPO法人ミラツクの中立性原則は「良い組織」の単一定義を禁じる。したがって3類型は対立軸ではなく相補軸であり、最終出力は総合順位ではなく、各軸をどれだけ備えるかのプロファイルとなる。3つを選んだもう一つの理由は、測定可能性と批判耐性の座標上でこれらが互いに離れた三角形を描き、独立した情報を運ぶからである。測定しやすい類型ばかりを選べば、審査は「測りやすいものだけを測る」偏りに陥る。

この翻訳を可能にするのは、GOE-DB が測定層(SF15)を独立して持ち、GPTW・健康経営銘柄・B Corp・Q12・心理的安全性尺度など75件の実在指標を、信頼性係数やライセンスまで含めて台帳化している点にある。概念(何が卓越か)・批判(どんな落とし穴か)・数式(どれだけ効くか)・測定(どう測るか)という四つの軸を同時に備えるがゆえに、本レポートは類型を「測れる審査項目」へ落とし込み、宣言だけを称揚せず、批判で偽陽性を除ける指標を構成できる。

02三類型とその構成要素

TYPE 5

倫理型

目的と多様な利害関係者への責任を制度化する。ステークホルダー理論・B Corp・CSV・ESG・ミッションエコノミー。

測定 0.72 / 批判耐性 0.65 ・ 西洋寄り
TYPE 7

在来型

非西洋に根ざした受託と現場の主体性。三方よし・道徳経済合一・アメーバ・人単合一・Ubuntu・Tata。

測定 0.40 / 批判耐性 0.80 ・ 非西洋0.9
TYPE 3

学習型

心理的安全性を土台に学び・前提を問い直し・知を創る。Senge・Argyris・SECI・DLOQ・Edmondson。

測定 0.65 / 批判耐性 0.70 ・ 中間

倫理型は Freeman のステークホルダー理論を起点に、Mackey のコンシャス・キャピタリズム、Porter-Kramer の共有価値創造、B Lab の認証、そして2019年ビジネス・ラウンドテーブルの目的再定義やパタゴニアの目的信託へと制度化が進んだ系譜を持つ。測定可能性が高いのは ESG 格付や B Corp スコアが整うためだが、宣言と実態の乖離を突くグリーンウォッシング批判に晒される。

在来型は近江商人の三方よし、渋沢栄一の道徳経済合一、稲盛のアメーバ経営、トヨタ生産方式、海爾の人単合一、Tata の受託者統治、アフリカの Ubuntu までを束ねる。数世紀の実践に淘汰された思想ゆえ批判に強い一方、「世間」や関係性は標準尺度に乗りにくく、測定可能性は8類型で最も低い。ここに既存の国際指標が届かない空白がある。

学習型は Senge の5つの規律、Argyris のダブルループ学習、野中の SECI と「場」を骨格とし、心理的安全性(Edmondson)を前提に据える。DLOQ や Garvin の学習組織サーベイで測れるが、学習を掲げて思考を止める「機能的愚かさ」に陥る危険を内包する。したがって審査では、研修時間や制度の有無ではなく、失敗が実際に語られ・前提が更新され・知が現場から創発しているかという、学習が起きている証拠を問う必要がある。

三類型を一枚の座標に置くと、測定しやすい倫理型、測定しにくいが批判に強い在来型、その中間の学習型が三角形を描く。この非対称は次章の設計の中心的な手がかりになる。測定可能性が高い軸は既存指標が充実している可能性が高く、低い軸は既存指標の空白地帯である可能性が高い。指標設計とは、この非対称を認識したうえで、空白を代理指標で埋め、充実領域では既存指標を賢く借用する作業にほかならない。

033軸の企業審査指標

3類型を、E軸(倫理・ステークホルダー)、I軸(在来・受託)、L軸(学習・知識創造)の審査軸へ翻訳する。各軸を GOE-DB が保持する75件の実在指標に接地させると、既存指標のカバレッジが軸ごとに大きく偏ることが見える。E軸は B Corp・MSCI ESG・DJSI・GRI・SASB・TCFD・ISSB と充実し、L軸も DLOQ・Garvin・Q12・Edmondson PSI と整う。ところがI軸は構造的な空白で、接地できるのは健康経営銘柄・なでしこ銘柄・ISO 26000 程度にとどまる。

本指標の付加価値

ESG や B Corp が高得点でも、それは西洋的枠組みで測った像にすぎない。日本や東アジアの企業が持つ「長期存続を旨とする受託」「現場の一人ひとりが採算を担う主体性」は既存指標では不可視化される。I軸はその不可視の卓越性を、存続年数・離職率・支払条件・提案制度といった代理指標で可視化するために置かれる。

合成にあたっては、単一総合スコアで序列化せず、E・I・Lの3値プロファイルを基本とする。用途に応じて重みを可変にし、投資デューデリジェンスでは E軸を、事業承継や地域企業評価では I軸を、変化適応力の審査では L軸を厚くする。重みは常に開示し、単一最適解を強制しない。プロファイルの利点は、二つの企業を比べたときに「どちらが上か」ではなく「どこが違うか」を語れる点にある。E軸が高くI軸が低い企業は開示と統治は整うが長期受託に課題を抱え、逆にI軸が高くE軸が低い企業は堅実に続くが対外的な説明責任の制度化が遅れている、というように。この違いは序列では失われ、プロファイルでのみ見える。

04学術理論との接地(AR-DB)

各軸がどの学術理論に依拠するかを、GOE-DB の他DB参照(cross_db_refs 185件・23DB)を通じて可視化した。参照の型は等価125・関連36・拡張18・翻訳元6に分かれる。集計すると、E軸(SF08)は源泉サイクルDBの三資本論・経済学DBへ、I軸(SF10)は哲学DB・判断力DB・人物DBへ、L軸(SF06)は知識活性化DB・知識組織化DBへと、重心がはっきり分かれた。

軸主接地DB(参照型)含意
E軸gc 三資本・ec 経済学・mg(等価)多資本の定量測定に接地
I軸philosophy・tlj(翻訳元/等価)経営学でなく哲学に接地=翻訳で目減り
L軸kas 知識活性化・kos・philosophy知識科学+権力知批判を内包

参照の型のうち翻訳元(translates_from)は、在来型の非西洋概念――儒教・道家・Ubuntu・Tawhid――が西洋の哲学へ翻訳的に接続していることを示す。等価接続が理論の足場の固さを語るのに対し、翻訳元接続は意味の移し替えに損失が伴うことを示唆する。この糸をたどれる基盤が AR-DB であり、GOE-DB の185本の参照はエコシステム全体に張られた関係の網の一部として、各軸の理論的血統を可視化する。ある審査項目の妥当性を疑うとき、それがどのDBのどの概念にどの型で接続しているかをたどれば、根拠の強さと弱さがそのまま見える。

この接地の非対称が精緻化の核心を与える。E軸は「測れる資本」、I軸は「翻訳で目減りする受託」、L軸は「反省を内包する知」に接地する。ゆえに実行指標は、E軸を定量開示で、I軸を代理指標と定性証憑で、L軸をサーベイと反省の証拠で――と、軸ごとに求める証拠の種類を変えねばならない。とりわけI軸に翻訳元(translates_from)参照が集中する事実は、第3節で述べた代理指標が理論の側からも要請されることを裏づける。

05実行力ある指標 ── GOE-Tri

以上を、審査担当者がそのまま使える採点ルーブリックへ落とし込む。設計原理は3つ。第一に各項目に証憑を必須とし、宣言だけでは加点しない。第二に軸ごとに証拠の型を変える。第三に批判応答型(Type 8=批判的経営研究)を減点ゲートとして組み込む。各軸5項目、計15項目を0〜4点(0=なし、1=宣言のみ、4=後戻り不能な仕組み+外部検証)で採点し、軸別に100点換算する。

減点ゲートは4つ。グリーンウォッシング(ESG宣言と実排出・訴訟の乖離)、労働強化(在来理念の裏で過重労働・過労死・高離職)、機能的愚かさ(学習を掲げつつ異論封殺)、理想の礼賛(自己申告のみで外部検証なし)。それぞれ Bebchuk-Tallarita、今野晴貴のブラック企業論、Alvesson-Spicer、Parker といった批判研究に根拠を持ち、宣言の巧みさによる偽陽性を打ち消す。

出力形式

最終アウトプットは総合順位ではなく { E, I, L, gates } のプロファイル。用途別の推奨重みは、投資DD=E:0.45/I:0.25/L:0.30、事業承継・地域=E:0.25/I:0.45/L:0.30、変革適応=E:0.25/I:0.25/L:0.50。重みは開示する。

採点は各軸5項目、計15項目を0〜4点で行う。0=該当なし、1=宣言のみ、4=後戻り不能な仕組み+外部検証。宣言(1点)と制度(2点)を区別し、運用実績の証憑(3点)と経営者交代でも消えない仕組み+外部検証(4点)をさらに分ける。この段階設計により、看板の掲げ方がうまいだけの企業と実質を伴う企業とが分離される。とりわけI軸では、存続年数・離職率・支払条件・提案制度といった代理指標を用いる。これは妥協ではなく、翻訳で目減りする在来型の価値を客観データで捕捉する積極的な設計であり、第3部の学術接地分析が「I軸は哲学に翻訳接続し目減りが起きる」と示したことの実務的な帰結である。

この指標は「唯一の合否判定器」ではない。反証条件も明示している。GOE-Tri の3軸プロファイルが、独立に測った長期存続・従業員福祉・不祥事発生と無相関であれば、指標は誤りとして棄却される。とりわけI軸は測定可能性0.40の領域を代理指標で補うため不確実性が大きく、非上場・中小企業では証憑の入手性も下がる。したがって GOE-Tri は、3つの卓越性のプロファイルを可視化し、対話と精査の出発点を与える診断ツールとして位置づけられる。単一の理想企業像を強制しないという姿勢こそ、この指標が守る核である。
